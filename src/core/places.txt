# Win顺自带的系统入口和关键词，补充 Windows 设置检索清单（SystemCatalog）。
#
# 大部分入口来自 Windows 自带的清单（ImmersiveControlPanel\Settings\AllSystemSettings_*.xml），
# 名称和关键词都是系统语言的。这里做两件事：
#
# 1. 给清单里已有的入口补关键词（清单里没有的说法，如“网卡”）。方括号里写它的打开命令，
#    必须和清单里的一字不差（不分大小写），同一个命令的每一条都会加上：
#
#      [%windir%\system32\control.exe /name Microsoft.DeviceManager]
#      keywords = 驱动; 显卡; devmgmt
#
#    新版“设置”的页面写 ms-settings: 地址；控制面板项写
#    %windir%\system32\control.exe /name <规范名称>[ /page <页面>]。
#    wsbench --places 会列出这台电脑上所有入口的打开命令。
#
# 2. 新入口。方括号里是一个固定的英文 id（记进“最近使用”，不要改），另写 open：
#
#      [disk-management]
#      name = 磁盘管理 | Disk Management     （中文 | 英文，按 Windows 显示语言选）
#      open = %windir%\system32\mmc.exe %windir%\system32\diskmgmt.msc
#      keywords = 分区; 格式化
#      kind = tool                           （tool 默认 | settings | control | security）
#      icon = %SystemRoot%\System32\shell32.dll,-16  （可省略：用打开命令所指文件的图标）
#
#    打开命令和清单里某一条相同时，搜索结果里只出现得分高的那一条。
#    程序或管理单元（.msc）不存在的入口不显示（家庭版没有 gpedit.msc）。
#
# 关键词用分号隔开，拼音自动可用（“wk”能找到“网卡”），不用另写。
# 单个字不按关键词匹配，所以不必写“卡”“网”这样的单字。
