# 网页搜索 / Web search

Win顺 的官方可选网页搜索插件。设置 → 插件 → 插件库安装并启用后，展开插件卡片即可管理网站、关键词、搜索建议及图标，也可导入、导出网站列表。不需要额外进程。

例如输入 `baidu 天气` 搜百度；只输入关键词并回车打开网站。也可以按网站名称或拼音查找。搜索建议仅在网站关键词后输入文字时请求，可在插件设置中关闭。

升级时，原“网页搜索”的网站、顺序、关键词、图标、建议设置会迁入本插件；已启用的旧“网页快捷搜索”示例中的关键词也会合并，冲突时保留原网页搜索的配置。停用或卸载插件保留这些配置，重新启用后继续使用。截图识字后的“网页搜索”也由本插件提供。

The official optional web search plugin for WinShun. Install and enable it from Settings → Plugins → Plugin library, then expand its card to manage sites, keywords, suggestions and custom icons, or import/export the list. No extra process is started.

Type `baidu weather` to search, or a keyword alone to open its site. Sites also match by name or pinyin. Suggestions are requested only after a site's keyword and can be disabled.

An upgrade preserves the former built-in configuration and merges keywords from the enabled legacy web sample. Existing built-in keywords keep precedence. Disabling or uninstalling keeps the configuration for later use. Web searches from screenshot OCR use the same provider.
