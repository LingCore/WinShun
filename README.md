## 中文

全新配置首次启动会显示两页引导：第一页选择搜索与索引、打开方式，第二页选择剪贴板历史、截图。可返回调整，最后确认才统一生效；截图确认后下载组件并核对权限。也可“稍后设置”，先用文件名搜索和双击 Ctrl。已有配置升级不会重复弹出。

**Win顺** 是 Windows 上免费开源的快速搜索启动器：连按两下 Ctrl 弹出搜索框，边打字边出结果。按文件名或拼音秒找文件，搜 Word、Excel、PDF 里的文字，打开应用和系统设置，还有剪贴板历史、截图和贴图、对话框搜索、任务栏搜索框、插件和给 AI 用的 MCP 搜索。

它直接读 NTFS 主文件表（MFT）建索引，三百多万个文件几秒建好，增删改名实时跟上，**不用装 Everything**。不需要账号，不上传数据。界面有简体中文和英文。

📖 每个功能怎么用，见 **[使用说明](docs/使用说明.md)**。

### 功能

**0.21.0 更新**　插件的结果也能在内容详情和预览里看：会打开文件的结果按那个文件显示，不是文件的结果（如邮件）由插件提供文字或文件（插件协议新增 `details`，Python / PowerShell SDK 已支持）。截图插件 1.1.3：“识别屏幕文字”有了自己的快捷键（默认不设，框选即识别并复制，不出工具条、不进截图历史）；贴图滚轮缩放更平滑并显示百分比，标注的粗细、字号、马赛克格子用滚轮或 `[` `]` 细调。在文件夹里打字可以用 `Ctrl+Shift+D` 只搜这一层；新增“打开时切换为英文输入”开关（默认关）；Directory Opus 里的搜索框放在正在打字的那一栏里。详见[发布说明](docs/release-notes/v0.21.0.md)。

**0.20.0 更新**　以修复和体验为主。截图在设置里选了保存目录后，保存按钮和 `Ctrl+S` 直接存进去，不再弹窗，点一下“已保存”的通知就在文件夹里选中这张图（截图插件 1.1.1）。文件夹快捷菜单的设置重新整理：触发方式（双击鼠标左键、鼠标中键）和触发位置（资源管理器、桌面）分开选，菜单末尾的“在此搜索”“命令提示符”等也可以分别关掉。修复：“文件”“文件夹”范围里多出的插件提示行、搜索栏 Logo 下半部分点不到、剪贴板数字键直接粘贴漏给前台程序，以及“按住连按，松开粘贴”要整个组合一直按着的问题。详见[发布说明](docs/release-notes/v0.20.0.md)。

**0.19.0 更新**　截图插件新增演示和白板，可以直接在桌面上画、用激光笔指；截图的按键可以自己改，`WASD` 能挪指针，设置页和工具条重新整理。新增资源管理器标签页插件，插件可以跟随 Win顺 的管理员权限（点一次确认），也可以用 Scoop 安装。图片文字搜索在“全部”里不用打 `ocr` 就出结果，认得出画出来的 PDF 文字、颠倒的页面和长图，也读 JFIF、GIF、HEIC、AVIF，跨空格、繁简和短词也能搜到。设置窗口打开更快。详见[发布说明](docs/release-notes/v0.19.0.md)。

#### 🔍 文件搜索

- **WSL 文件搜索**：在设置 › 搜索范围 › 网络与 WSL 中添加 Linux 项目或用户目录；自动列出已安装的发行版，支持用户目录快捷添加、选择文件夹或粘贴路径。文件名、拼音和首字母一起搜，发行版停止时保留已收录结果，恢复运行后自动更新。
- **网络与 WSL 扫描控制**：每个文件夹的“扫描设置”可单独限制每日时段（支持跨午夜）和最大层数；0 表示不限，1 层只读取当前文件夹。时段外暂停后台文件名和内容读取，已有结果照常可搜；“立即核对”可临时扫描一次文件名，仍遵守层数限制。默认不限制。

- **双击 Ctrl** 打开（也可以改成双击 Alt 或 Shift），再按一次或 `Esc` 关闭；三百多万个文件里搜一次只要几毫秒。
- **拼音和首字母**：`ndbg` → 年度报告，`baog` → 报告；多音字按常用读音。打错了同音字（年度报高）找不到时，自动按读音再找一遍。设置里可以让搜索框每次打开时先切到英文输入，直接打字母。
- **搜整台电脑**：所有本地磁盘，U 盘可选（没收录的 U 盘插着时，列表末尾会提示你顺手搜一下它）；**NAS、内网共享文件夹（SMB）和 WebDAV 文件夹**（NAS 的 WebDAV、坚果云这类网盘）也能加进来一起搜，服务器关机时收录过的照样能搜到，服务器重启后自己连回来；想搜它们里面文件的内容，在那个位置的卡片上打开“搜索文件内容”。没有管理员权限的电脑也能用：只索引你选的文件夹（见下面“管理员权限”）。
- **排序懂你**：自己的文件在前，系统目录、`node_modules` 在后，名字完全一样的最前。每行显示修改日期，也可在设置中开启文件大小，无需展开窗口；两项可分别开关。`Ctrl+S` 在最匹配、最新、最早之间切换；底栏的“更多”里还能按名称、所在文件夹、类型、大小排。不输入时列出最近打开或最近修改的文件，也可以不列；还可以设成每次打开时清空搜索。结果怕点错的话，设置里可以改成双击才打开。
- **程序优先**：搜 `curl`，`curl.exe` 排在文件夹 `curl` 和 `curl.h` 前面；优先哪些类型可以自己改（默认 exe、bat、cmd、ps1、msi，像 Listary 的“优先显示的文件类型”）。
- **数字键直达**：`Ctrl+1`～`Ctrl+9` 打开当前可见的第几项（也可改成 `Alt`）；快捷编号默认常显在图标左侧独立列，也可以设成按住时出现或不显示。已有显示设置继续保留。滚动后按可见条目重新编号；别的软件也用这些键当快捷键时，Win顺 的窗口在前面时归 Win顺。设置 › 结果列表 › 显示与预览 里的“键盘提示”可以隐藏搜索框右下角的快捷键帮助按钮和底栏上的按键提示；截图的“全部按键”入口也能在工具条按钮设置里隐藏。
- **按类型找**：选中 **文件** 后，下面一排是文件夹、文档、图片、视频、压缩包等类型，可以同时选择多类；再点一次取消，点“不限”重置。`Ctrl+Tab` 依次切换；点 `+` 或在设置里自己加类型。
- **不想看到的文件**：设置 › 搜索范围 里可以跳过一些类型和文件名，`*`、`?` 通配；默认跳过 Office、WPS 打开文档时生成的 `~$` 临时文件。搜索框里打的就是这样的名字时，照样找得到。
- **大图浏览**：搜索面板右下角可切换“列表 / 大图”，图片、视频和 PDF 使用异步缩略图；拖动滑块或按住 `Alt` 滚动滚轮调整大小，保留浏览位置，记住视图和尺寸。多选、右键菜单和拖出文件继续可用。
- **搜索面板**：结果太多时，点搜索框右上角的小按钮或按 `Ctrl+E`，同一个窗口展开成面板（像 Listary）：左边按范围、类型、修改时间、大小、位置筛选，右边按列显示结果，点列头排序；右键列头可选名称、路径、类型、大小、修改时间、创建时间、文件夹和来源，拖动调整顺序和宽度，自动保存布局；什么都不输入也能按条件浏览整个索引（三百万个文件也是毫秒级）。`size:>10mb`、`dm:7d` 这类写法直接打在搜索框里也行。再按一次就缩回搜索框。
- **长文件名**：名字放不下时在中间缩短，扩展名和结尾留着（“…第二版.xlsx”）；鼠标停在这一行上，显示完整的名字、位置、大小、修改和创建时间。拖动搜索框的左边或右边可以调宽（记住宽度，双击边缘恢复默认）。
- **Logo 操作**：搜索栏左侧的 Win顺 Logo 集中三个操作：左键打开设置，中键钉住 / 取消钉住（也可按 `Ctrl+T`），右键把窗口移回当前显示器可用区域的正中央；拖动 Logo 仍能移动窗口。钉住时显示图钉标记，点别处、打开文件后搜索框都不收起，`Esc` 关闭。
- **预览**：在结果上按 `Alt+P`（或右键“预览”）看一眼文件，启动器不关：图片、文本（自动认 UTF-8 / GBK）、Word / Excel / PowerPoint / PDF（用资源管理器预览窗格的同一套预览程序）、文件夹里有什么；上下键换一行就换一个文件，再按 `Alt+P`（或点预览窗口的叉）关掉；`Esc` 关的是启动器，预览开着时下次打开还在。后台开着 QuickLook 或 Seer 时交给它们。 搜索结果的预览键可在设置中改为空格、功能键或未占用的组合键；空格模式下用 `Shift+空格` 继续输入空格。
- **缩略图**：图片、视频、PDF 等在结果里直接显示缩略图，代替类型图标，“打开”“另存为”对话框旁的搜索框里也一样；设置 › 结果列表里可以关。
- **右键菜单**：右键一行有打开位置、复制路径、加入收藏等；按住 `Shift` 右键（或菜单里的“更多选项”），出现 Windows 自己的完整右键菜单，和资源管理器里一样，选中几行也行；复制、剪切、删除之后搜索框不关。
- **拖出去就能用**：结果直接拖进微信、邮件、资源管理器。
- **实时更新**：读 USN 变更日志，改名、新建、删除马上搜得到；拔 U 盘不会提示“设备正在使用”。

#### 📄 文件内容全文搜索

- 切到 **内容** 范围，搜文件里的文字，结果显示命中的那一行。
- **内容详情窗格**：`Ctrl+E` 面板中提供摘要、匹配、文本、原生预览和报告；查看全部已读取匹配、过滤与上下文、Excel 工作表和真实行号，并导出文本／CSV／HTML／XLSX、复制或打印。完整统计按需执行，部分结果会注明。[使用说明](docs/使用说明.md#在面板中阅读全部匹配)
- **普通搜索更安静**：**全部** 自动补充已有内容索引中的命中，不会因为停留在搜索框就批量解析文档。还有未搜索的内容时，点“搜索内容”继续；也可以直接切到 **内容**，读取尚未索引的文件。
- **能搜的文件**：
  - 纯文本：txt、md、log、csv、json、代码等；
  - 文档：**Word、Excel、PowerPoint、PDF、WPS**，结果里显示第几页、第几张幻灯片或哪个表的第几行。
- **怎么找**：可以写多个词、用引号找整个短语，结果按相关度排。
- **只搜某个文件夹**：词后面加文件夹名和斜杠，`年度报告 abc/` 只在叫 abc 的文件夹里找（`/abc` 放在最后也行，`工作/abc/` 只要“工作”里的那个）；同名的文件夹都搜，搜索框下面列出它们，`Ctrl+Tab` 挑其中一个。也可以点下面的收藏文件夹，或在结果的文件夹上右键“在此文件夹中搜内容”。
- **编码和速度**：自动识别 UTF-8、UTF-16、GBK 编码；内容索引可选，默认关着，在 **内容** 范围搜索框下面那一行右端点一下就打开；打开后几十万个文件也很快。第一次建内容索引时，索引服务直接从磁盘读文本文件，杀毒软件不用一个个检查，快得多。超过大小上限的、系统目录里的、类型没列出的文件默认不搜，搜完会告诉你各有几个，点一下就临时把它们也搜了。
- **没有索引服务也能搜**：只是慢一些，直接去读文件。
- **安全**：文档由一个权限受限的独立进程读取。

#### 🚀 应用和系统设置

- **应用**：开始菜单里的所有应用都能搜，含 Microsoft Store 应用。名称、拼音、首字母（`vsc`）、程序名（`winword`）都行；`Ctrl+Shift+Enter` 以管理员身份运行。

#### 📂 “打开”“另存为”对话框

- **对话框旁的搜索框**：输入文件夹或文件名（拼音也行），回车，对话框直接转过去；网页上传文件、WPS 的对话框、VBA 宏弹出的“浏览文件夹”也认；安装程序（Inno Setup）里的“浏览文件夹”窗口也有，选好只是把路径填进去，“确定”还是你自己点（选开始菜单文件夹的那个不接管）。
- **`Ctrl+G`**：转到资源管理器、Total Commander、Directory Opus、XYplorer、Pulse 或 OneCommander 正在显示的文件夹，和 Listary 的同名快捷键一样。OneCommander 使用当前活动面板的路径，无需额外配置；对话框建议也可列出其他打开的标签，状态未同步时先使用活动目录。
- **不输入时**：列出打开着的文件夹、刚复制的路径、收藏和最近用过的文件夹。
- **自动转过去**：可以设成对话框一出现就转到文件管理器的文件夹，或者先停在上次的位置，从文件管理器切回来时再转。
- **Blender**：安装并启用 [文件对话框扩展](integrations/blender/winshun_file_dialog/README.md)，独立的打开、另存为和导入窗口即可使用搜索栏；保存、导出仍在 Blender 确认。Windows x64，已实测 Blender 5.2。[自定义对话框兼容与验证范围](docs/dialog-compatibility.md)。
- **Blender (English)**: enable the [file-dialog extension](integrations/blender/winshun_file_dialog/README.md) to use WinShun in separate Open, Save As and Import windows. Save/Export confirmation stays in Blender. Tested on Windows x64 with Blender 5.2.

#### 🗂️ 资源管理器里：双击空白处、右键搜索此处

- **双击空白处**：在资源管理器或桌面的空白处双击，按“收藏夹 / 最近的文件夹 / 已打开的文件夹”进入二级页面。收藏夹包含文件夹、文件、应用、系统位置和自定义命令，显示名称与图标，悬停查看完整路径或命令；选文件夹就在原窗口里转过去（桌面上开新窗口）。自定义命令点击即可执行，`{query}` 接收当前目录，命令里设置的工作目录优先。三类入口可在设置里分别开关；触发方式（双击鼠标左键、鼠标中键）和位置（资源管理器、桌面）也分开选，菜单末尾的“在此搜索”“复制路径”“命令提示符”“PowerShell”“收藏这个文件夹”“Win顺 设置”可以分别关掉。
- 菜单不抢焦点，支持方向键、回车、首字母和滚动；右方向键进入，左方向键、退格或 `Esc` 返回，首页 `Esc` 关闭。点别处或再双击就关。Listary 在运行时让给它。
- **Directory Opus 里也能双击**：Win顺 可以替你在 Opus 的设置里加好这条命令（Opus 会重启一下），关掉或卸载时换回原来的。
- **Directory Opus 里直接打字搜索**：在设置 → 打开 Win顺 → 对话框中单独开启，默认关闭。在文件列表里从字母或数字开始输入，就用 Win顺 搜，当前标签的文件夹里的排在最前（和资源管理器一样），双栏也跟随正在操作的一栏；`Esc` 回到 Opus，打开文件夹或 `Ctrl+Enter` 定位结果也回到原来的一栏。改名、地址栏、菜单和以符号开头的 Opus 查找模式仍按原来的方式操作。
- **用快捷键弹出**：双击被别的程序占了，或者想在 Total Commander、XYplorer、Pulse 里用，就在设置里给文件夹菜单设一个快捷键，在任何窗口里按：资源管理器、桌面、Directory Opus、Total Commander、XYplorer、“打开”“另存为”对话框里选中的文件夹在那个窗口里打开（Pulse 里交给 Pulse，按它的“从其他程序打开的文件夹”设置开新标签或新窗口），别的窗口里用文件管理器打开；再按一次关闭。
- **右键“用 Win顺 搜索此处”**：文件夹、文件夹的空白处和磁盘的右键菜单里都有（Windows 11 在“显示更多选项”里），搜索框带着这个文件夹打开，接着打字就在里面找。设置里可以关。
- **直接打字搜索**：在资源管理器的文件列表里随意打字，Win顺 就带着打的字搜，和 Listary 一样：这个窗口的文件夹（含子文件夹）里的排在最前，一条细线“其他位置”下面是别处的；点“只搜 …”或按 `Ctrl+Shift+D` 就只搜这个文件夹，再按一次只搜这一层（不含子文件夹），设置里也能设成每次都只搜它或只搜这一层。中文输入法照常组拼音，`Esc` 回到资源管理器。选中的文件夹在同一个标签页里打开，接着打字就再往里一层；选中一个文件或文件夹按 `Ctrl+Enter`，也在这个标签页里转到它所在的文件夹并选中它（设置里选的文件管理器是资源管理器时）；资源管理器的 `Shift` 右键菜单也不会被抢走按键。设置里打开（它代替了资源管理器自己的按首字母跳到文件，所以默认关）。

- **窗口避让与同步选中**：从资源管理器打字打开时，原窗口旁边放得下整个搜索框就放在旁边，不挡原窗口；放不下（窗口很大、居中或最大化）时，像 Listary 一样出现在文件列表的右下角，不会跑到屏幕角落。都不改变记住的常用位置。少数电脑上 Windows 不让搜索框到最前面时，资源管理器保留焦点，打的字照样进搜索框（不经输入法，拼音直接当字母搜）。浏览原目录的直接子项时，原标签页同步选中并显示对应项目，键盘焦点仍在搜索框；子目录和其他位置的结果不会自动带走原目录。

#### 📋 剪贴板历史（代替 Win+V）

- **记什么**：复制过的文字、图片、文件都记下来。
- **怎么打开**：`Win+V` 或自设的快捷键；开在输入光标旁，不抢焦点。
- **调整大小**：拖动剪贴板窗口的四边或四角调整宽高，预览展开时也可调整；尺寸自动保存，双击边缘恢复默认。屏幕空间不足时临时缩小，保留记住的尺寸；文字默认随设置 › 外观 › 界面大小，也可在设置 › 剪贴板 › 剪贴板大小单独选（含每条一行的“密集”）。复制的图片文件也显示缩略图。
- **怎么粘贴**：双击或 `Enter` 粘贴（也可以设成像 Windows 自带的那样单击就粘贴），`Shift+Enter` 粘贴为纯文本，`Alt+1`～`9` 直接粘贴第几条（图标上的序号默认一直显示，可在设置里调整）。
- **不开面板直接粘贴**：设置 › 剪贴板 › 快捷键 里打开“不打开面板直接粘贴”（`Ctrl+1–9` 或 `Alt+1–9`），在别的程序里就能直接粘贴前九条，格式照旧。默认关，打开后这些键在别的程序里原来的用处（比如浏览器切换标签页）就让给它。
- **按住连按，松开粘贴**（和 Ditto 一样）：设置 › 剪贴板 › 快捷键 里打开“按住连按快捷键，松开粘贴”。按住快捷键里的 Ctrl、Alt、Shift 或 Win，每再按一下就往下选一条，松开就粘贴；按住约一秒再松开粘贴第一条，按着时按 `Esc` 不粘贴。默认关。
- **粘进上传框**：在 Windows 的“打开”文件选择框里从剪贴板历史粘贴文件，完整路径直接填进“文件名”，多个文件也行，再点“打开”。
- **公式和嵌入的对象**：Word 里单独复制的公式、文档里嵌入的对象，记成一条带图的历史（公式的文字也搜得到），粘回 Word 里还是能编辑的公式或对象，只认图片的程序拿到的是图片；`Shift+Enter` 把公式粘贴成一行文字。（用 Word 测过。）
- **能搜**：拼音搜索，`@wx` 只看微信里复制的；**图片里的字也能搜**（默认使用 Windows 支持的识别语言；安装增强文字识别后使用 PaddleOCR，提升中英文、数字和小字的效果，识别过程都在本机完成）。
- **预览**：全文、大图、颜色值的 HEX / RGB / HSL；GIF 动图支持播放和暂停。点一条旁边的眼睛按钮（或 `Alt+P`）开关预览，预览开着时鼠标停在哪一行就预览哪一行；预览窗口更宽，中间的竖线可以拖着调，下次还记得；图片缩略图可以调大，不打开预览也看得清。
- **图片保留原格式**：复制来源提供 PNG、JPEG 或 GIF 时，保存原始数据；只有位图时转存 PNG。按住图片拖到文件夹，或在资源管理器里从剪贴板历史粘贴图片，都会沿用保存的格式；用 Ctrl 或 Shift 选多张还能一起保存。
- **整理**：固定、分组、多选按顺序合并粘贴，钉住后可以一条接一条地往表格里填；固定的可以排在最前，顺序可以拖动或用 `Ctrl+↑`/`↓` 自己排。`Ctrl+A` 选中列出来的全部，行菜单里的“删除全部”一次清掉，按 `Ctrl+Z` 能恢复。
- **复制过的文件被删了**：那一条会标“已不存在”；可以设成自动隐藏或自动清理（固定的和分组里的不动，拔掉的 U 盘不算）。
- **从别处导入**：设置 › 剪贴板 › 保留 里的“导入剪贴板历史”，可以导入 Ditto 的数据库（装了 Ditto 的话一键导入）、`.txt` 文本和 `.csv` 表格（中文 Excel 存的 GBK 也认）；导入的放进一个新分组，不会被自动删除，已经有的内容会跳过。
- **隐私**：密码管理器复制的密码不记录，历史只存在本机。
- **截图**（插件库里的“截图与录屏”插件，在 设置 › 插件 › 插件库 装上；快捷键自己录，想用 `PrtScn` 也在它卡片上的“设置”里打开。以前开着截图的，升级后自动装上，设置照旧）：
  - **区域／全屏录屏和 GIF**：框选后点“录屏”或按 `Ctrl+R`，在浮条上切换“选区／全屏”；全屏录制选区所在的整块显示器（含任务栏），切回选区会恢复原范围。支持 MP4 或 GIF；可以暂停、继续、选择画质、鼠标指针和点击高亮，还能在视频角落显示按下的快捷键和鼠标按键（默认关闭；选“全部按键”时打的字也会录进去）。MP4 可选系统声音和麦克风，默认都关闭；GIF 不含音频，后台生成时显示进度。控制条不录进画面，录完能继续录下一段。
  - **框选**：鼠标移到窗口、按钮上就把它框出来，框外变暗，点一下选中，也可以拖出一块；滚轮扩大或缩小框。设置、计算器这类程序里的侧栏和按钮也能框出来（Chrome、Edge、VS Code、微信这类 Chromium 程序里面不识别，只框整个窗口，需要时手动拖选）。`WASD` 每次把鼠标光标挪 1 个物理像素（按住左键拖框时也行，框跟着光标走），`Shift+WASD` 每次 10 个物理像素；方向键移动选区，`Shift`+方向键改大小；`R` 循环恢复本次运行中最近 10 个不同选区，`Shift+R` 反向切换，使用当前画面；`,` `.` 翻看之前的截图（整屏、选区和标注都恢复，可重新框选、接着改），默认留最近 10 次。
  - **放大镜和取色**：跟着鼠标放大像素，`C` 复制鼠标下的颜色并结束截图，单按 `Shift` 在 `#RRGGBB`、`rgb()`、`hsl()` 三种写法之间换。选好区域后放大镜只在选区里出现。
  - **HDR 屏幕**：开着 HDR 时截图颜色照常，不发灰；在截图的设置里打开“HDR 屏幕上同时保存 HDR 图片”（默认关），`Ctrl+S` 保存时在 PNG 旁边多存一份同名的 `.jxr`，亮的地方保持原来的亮度，用 Windows 的“照片”就能看。
  - **识别文字并复制**：`Shift+C` 把选区里的文字识别出来，直接复制。
  - **识别屏幕文字（取字）**：在截图设置 › 快捷键里另录一个“识别屏幕文字”的快捷键（默认不设），按下后直接拖选一块或单击窗口，松开鼠标就识别并复制，没有工具条，也不留截图；旁边弹出一张小卡片显示“已复制”和前几行字，点“编辑”可以改了再复制。托盘菜单和 `cap` 搜索里也有“识别屏幕文字”。
  - **快捷键提示**：截图时屏幕左下角列出此刻能用的按键，框选前、选好后、拿着标注工具时各不相同。它不抢着出来：开始截图后停一下才淡入，一按鼠标就立刻消失；选好区域后不会马上冒出来，停下来约 2 秒没操作才出现一次，一动就走；拖动和打字时自动隐藏；选区或工具条挡住左下角就换到右下角，鼠标靠近时变得几乎透明，不挡画面，也不会截进图里。按 `?` 临时显示或隐藏，点“不再显示”就关掉，想要回来在截图设置 › 快捷键里打开“截图时显示快捷键提示”。
  - **延时**：`Ctrl+Shift+D` 或工具条的“延时”，倒计时（秒数在设置里选）到点才定住屏幕，用来截菜单、悬停提示。设置里可以让截图带上鼠标指针（默认关）。
  - **二维码**：`Q` 读选区里的二维码，文字显示在小窗口里可以复制；是网址时多一个“打开链接”，点了才打开。
  - **标注**：矩形、椭圆、箭头、直线、曲线、路径、画笔、荧光笔、文字、序号和打码；曲线和路径的节点可再调整，荧光笔有不同绘制模式。序号可以选 `1 2 3`、`A B C`、`a b c`、罗马数字、圈里的数字，序号旁边还能直接写字。打码有马赛克、模糊、纯色和抹平（用四周的底色盖住，像擦掉了一样），可以框也可以涂抹，打码的地方还原不出来。
  - **智能打码**：选好区域停一会儿，Win顺 在本机找出图里的手机号、身份证号、银行卡号、邮箱、密钥和本机用户名，提示“发现 N 处”，点一下（或 `Shift+B`）全部盖上，一次 `Ctrl+Z` 全撤；自动找的可能有漏，发出去前再看一眼。
  - **长截图**：网页、聊天记录、文档、文件列表比屏幕还长时，选好区域按 `Ctrl+L`（或工具条的“长截图”），保留选区边框和操作按钮，默认自己向上或向下滚动、Win顺 拼接；可直接复制、保存、贴图，或按 `Enter` 进编辑窗口。需要时可开启“自动滚动”。只能左右滚的、一直在动的画面不适合。
  - **完成**：`Enter` 复制，截图进剪贴板历史，图里的字也能搜；在截图设置里选了保存目录时，`Ctrl+S` 或保存按钮直接存进该目录，旁边的小箭头里有“另存为…”；没选时 `Ctrl+S` 弹出系统“另存为”窗口，小箭头里的“保存到旧路径”直接存入“图片\屏幕截图”。取消保存窗口会保留选区和标注。保存后点一下右下角的通知，就在文件管理器里选中这张图。打开设置里的“复制截图时同时贴图”，复制的同时也贴在屏幕上。标过的图以后还能再打开接着改，从剪贴板历史、搜索框或贴图上都能进，可多选、取色、裁剪。
  - **贴图**：`F3` 把截图贴在屏幕上，一直在最上面，可以缩放、调透明度、转和翻、收成小块、识别文字，或用 `T` 在图上拖选文字直接复制；双击贴图做什么（回到 100%、关闭、收起或不做什么）可以在设置里选。托盘菜单“截图 › 贴图”或设置里的“贴图的快捷键”优先贴剪贴板里的图片；没有新图片时，把最近截图贴回原位置并保留标注。设了“鼠标穿透”的贴图，按住 `Ctrl` 就又能拖动、点右键菜单。`F3`、`Ctrl+S` 和贴图里的这些键都能在截图设置的“按键”里改成别的键，或者清除不用。
  - **识别文字、查找**：工具条的“识别文字”读出图里的字，可以复制、用它搜索或去网页搜索；搜索框里打 `jt` 加空格，按图里的字找截过的图。
  - **演示和白板**：托盘菜单“截图 › 演示 / 白板”，或输入 `cap 白板`；在截图设置 › 快捷键里录一个快捷键也行（默认不设）。直接在正在用的桌面上画：画笔、荧光笔、箭头、文字、序号，`X` 是激光笔，轨迹很快消失。`Esc` 或右键让鼠标和键盘回到下面的程序（比如翻 PPT），`W` 白板、`K` 黑板。笔迹是屏幕上的像素，录屏和屏幕共享要选整个屏幕才录得到。
  - **自己定**：框选之后双击左键、右键、中键、鼠标侧键各做什么（复制、复制并贴图、保存、贴图、识别文字并复制或搜索、取消、后退），工具条上要显示哪些按钮，都在设置里自己选。

#### 🔎 任务栏搜索框

- 在 Windows 11 任务栏上放 Win顺 自己的搜索框（Windows 10 是固定一个按钮），结果在任务栏上方淡入淡出。
- 位置固定，不跟着图标挪：图标居中时在任务栏最左边，图标靠左时在托盘图标左边；任务栏挤了就自动变窄。也可以改成在任务栏上固定一个 Win顺 图标。

#### 🤖 AI 助手（MCP）

- **能做什么**：Win顺 是一个 MCP 服务器，AI 能用它搜文件名、文件内容和最近修改的文件。
- **怎么连**：Claude Desktop、Claude Code、Cursor、VS Code 在设置里一键连接。
- **安全**：
  - 默认只读，只看得到 AI 客户端自己有权限看的文件；
  - 可以设不让 AI 看到的文件夹；
  - 每次调用都有记录。
- **帮你设置**：对 AI 说“帮我把 Win顺 调顺手”，它会问几个问题，再一次改好几项设置。改之前先弹窗问你，改完在右下角告诉你，几秒内能撤销；涉及安全的几项总会先问你。
- **命令行 `ws`**：在终端里搜，像 Everything 的 `es`：`ws 报告`（文件名）、`ws grep 发票`（内容）、`ws text 计划.docx`（读出文档里的文字）、`ws recent --days 7`。能跑命令的 AI（Claude Code、Codex）用它比用 MCP 省上下文，`ws skill --install claude` 装上用法说明。和 MCP 共用一个开关、同一套安全设置。

#### 🎨 外观和设置

- **外观**：浅色、深色跟随系统，Windows 11 云母（Mica）效果；圆角或直角（直角和 Windows 10 一样）；图标在 150% 缩放下也清晰。界面大小有紧凑、标准、宽松三档，托盘和任务栏的图标可以换成单色；程序 Logo 统一显示在搜索栏内部，作为固定操作入口。
- **搜索偏好**：打开一次即可在后续匹配搜索中靠前，中文、拼音、首字母共享同一应用或文件的使用记录；较久未使用的偏好会逐渐衰减。
- **设置**：搜索框输入“设置”“配置”或 `settings`，回车打开，也可按 `Ctrl+,`。设置窗口内可以搜索（`Ctrl+F`，`kjj` 找到“快捷键”），改了立即生效。
- **文件管理器**：打开文件夹、打开所在位置时用资源管理器、Total Commander、Directory Opus、XYplorer 或 Pulse（装了的才列出）；别的文件管理器也行，在设置 › 打开 Win顺 › 对话框里填它的命令。
- **备份**：设置 → 高级里选一个文件夹（放在同步盘里就是云备份），设置、收藏、对话框的固定项、自己加的网页图标和插件会自动备份，保留最近 10 份，随时恢复。
- **换电脑迁移设置**：设置 → 高级 → 备份，点“导出备份…”保存 ZIP；新电脑安装后点“从备份恢复…”，校验通过后自动重启。不用开启自动备份，当前配置会先备份到本机；插件密码需重新填写，收藏和自定义路径请检查是否还有效。
- **更新**：有新版本时在托盘提醒；点“下载并安装”，Win顺 下载后先核对 SHA-256 再安装（便携版只换程序文件，不动 `data`；用 Scoop 装的改为“用 Scoop 更新”，由 `scoop update` 完成），也可以照旧自己下载安装。

### 下载安装

1. 到 [Releases 页面](https://github.com/LingCore/WinShun/releases/latest) 下载 `WinShun-版本号-x64-setup.exe`，双击安装。Windows 提示“已保护你的电脑”时，点 **更多信息 → 仍要运行**（还没有代码签名证书）。安装时可以选“为所有用户安装”（要管理员同意，带索引服务，最快）或“只为我安装”（不要管理员权限，不装索引服务，只索引你选的文件夹）；当前账户不是管理员时，默认推荐“只为我安装”。
2. 装完托盘里出现 Win顺 的图标，索引几秒就建好。连按两下 Ctrl 开始搜索。
3. 有新版本时，在更新提醒里点“下载并安装”（便携版是“下载并更新”），Win顺 自己下载、核对后装好并重新打开；也可以手动运行新的安装程序。设置和索引都保留。AI 工具（Claude Code、Cursor 等）正连着 Win顺 时，安装程序会先问一声：现在装，它会断开，装好后在它里面重新连接 Win顺 或重启它；也可以等它用完再装。卸载在 Windows 的“设置 → 应用”里。

不想安装的话，下载 `WinShun-版本号-x64-portable.zip`，解压到任意文件夹，运行里面的 `WinShun.exe` 就行。设置、记录、剪贴板历史和索引都存在它旁边的 `data` 文件夹里，整个文件夹可以拷到 U 盘或别的电脑；第一次启动时，这台电脑上原来的设置和数据（`%APPDATA%\WinShun`、`%LOCALAPPDATA%\WinShun`）会复制过来，原处的不动。升级时把新版解压到同一个位置覆盖，`data` 留着。删掉 `data` 文件夹（先退出 Win顺），就和安装版一样存在原来的地方。

用 [Scoop](https://scoop.sh) 管理软件的话，两行命令装好：

```powershell
scoop bucket add winshun https://github.com/LingCore/WinShun
scoop install winshun
```

装的就是上面的便携版（设置和索引存在 Scoop 的 `persist\winshun\data` 里），开始菜单里有 “WinShun”，终端里直接能用 `ws`。更新：Win顺 弹出更新提醒时点“用 Scoop 更新”（会打开一个窗口运行 `scoop update`，完成后自动重新打开），或自己运行 `scoop update winshun`。卸载用 `scoop uninstall winshun`，会先取消开机自启、右键菜单等 Win顺 登记的项目，设置和索引保留；加 `-p` 才连同数据一起删除。Scoop 不会装索引服务，需要索引整个磁盘时到 **设置 › 搜索范围 › 磁盘 › 索引方式** 里开启。

标准安装版和便携版按需安装增强文字识别：到 **设置 › 剪贴板 › 记录 › 增强文字识别** 下载约 12 MB 的组件，也可以选择本地组件包。安装后剪贴板和截图共用，离线识别，不需要重启。旧版已有的识别文件继续使用。无网络的电脑可选 `WinShun-版本号-x64-offline-setup.exe`，自带完整识别组件；或把 Release 中的 `WinShun-ocr-*.zip` 拷过去从本地安装。截图识别尚未安装时会保留原图，安装后继续识别。 程序更新、插件库和增强识别的 GitHub 文件默认优先通过两个加速镜像下载，连接失败或文件校验不符会自动换源，最后尝试官方原站。

系统要求：Windows 10 或 11，64 位。

### 管理员权限

- **平时不用**：Win顺 以普通权限运行。安装版带一个很小的“Win顺 索引服务”，由它读 NTFS 主文件表（MFT）和 USN 变更日志，所以照样几秒建好索引、实时跟上改动。安装时要管理员同意一次，之后登录和打开都不弹 UAC。
- **能看到哪些文件**：和 Everything 一样，索引里有整块盘的文件名，包括这台电脑上其他用户的；没有权限的文件照样打不开。
- **便携版**：默认一个个文件夹走一遍来建索引，第一次慢一些，之后实时跟上改动。在设置 → 索引方式里可以装上索引服务，或以管理员身份重新启动。便携版装索引服务时，会把服务程序复制一份放进 `%ProgramFiles%\WinShun Service`，只有管理员能改，普通程序没法把它换掉；以前装过的，设置里会提醒并有“修复”按钮。
- **没有管理员权限（“只为我安装”）**：安装时选“只为我安装”，不装索引服务，也不用管理员同意。这时 Win顺 只索引你选的文件夹（设置 › 搜索范围 › 文件夹 里改，默认是桌面、文档、下载、图片这些常用位置），可以从资源管理器把文件夹直接拖进去；改动实时跟上，每天再整个核对一遍（也可以改成每小时、每 4 小时或只在启动时）。输入的文件夹不在索引范围里时，搜索框会提示，点“这次也搜它”只搜这一次，点“加入索引”就长期收录。内容搜索照样能用，只是慢一些。
- **管理员直读**：管理员账户可以在设置 → 索引方式里选“管理员直读”，像旧版一样整个程序以管理员身份运行、直接读盘。
- **以管理员身份运行的程序**：Windows 不让普通权限的程序往它们里面打字。往这样的窗口里粘贴时，Win顺 只复制，提示你按 `Ctrl+V`；它们的“打开”“另存为”对话框旁也有搜索框：装了索引服务的安装版能像别的对话框一样直接转到选中的文件夹，`Ctrl+G` 也管用；便携版和“只为我安装”的版本只能复制选中的路径，要你自己粘贴到路径框里。
- **它们在最前面时双击 Ctrl 没反应**：Windows 也不把发给它们的按键交给普通权限的程序，所以没装索引服务时，这种窗口在最前面，双击 Ctrl（Alt、Shift）没反应；带 Ctrl、Alt、Shift 或 Win 的组合键（比如 `Alt+Space`）照样能用。装了索引服务就没有这个问题（服务的助手听得到），Win顺 自己以管理员身份运行（管理员直读）时也没有。这种程序第一次在最前面停一会儿时，Win顺 会弹一次通知说明：设了组合键就提醒你改按它；便携版（含 Scoop 装的）能装索引服务时，点通知直接到 设置 › 索引方式，在下面一行装上。每个程序只说一次，最多说 3 个，一次运行只说一次。
- **打开的东西是普通权限**：从 Win顺 打开的文件和应用都以普通权限运行，只有 `Ctrl+Shift+Enter` 才以管理员身份运行。

### 常见问题

**和 Everything、Listary 有什么区别？**
Win顺 自己建索引，不用装 Everything。文件名、拼音、应用和文件内容在一个框里搜，针对中文做了优化。对话框里有和 Listary 一样的 `Ctrl+G` 和搜索框，但不嵌进资源管理器窗口。

**双击 Ctrl 和别的软件冲突？**
Listary、PowerToys 的“查找鼠标”默认也用双击 Ctrl，关掉其中一边就行，或者让 Win顺 改用双击 Alt 或 Shift、只认左边或右边的键（设置 › 打开 Win顺 › 双击哪个键、用哪一边；输入法用 Shift 切换中英文的，双击 Shift 会切换两次，最后回到原来的状态）。也可以在 Win顺 里改用别的组合键。游戏全屏、藏起鼠标时，Win顺 默认不响应双击 Ctrl。

**AutoHotkey 改的键在 Win顺 里不起作用？**
选了“管理员直读”时，Win顺 以管理员身份运行，Windows 不让普通权限的程序拦截发给它的按键。换回别的索引方式，或用 AutoHotkey 的 UI Access 模式、以管理员身份运行脚本。

**占多少内存？索引能不放 C 盘吗？**
- **内存**：每 100 万个文件约 30 MB，用着的时候整个程序一般 120～140 MB；不用它一分钟后，任务管理器里降到十几 MB。
- **索引位置**：在设置 → 高级 → 索引位置里，可以移到其他内置硬盘。

**索引很慢，或者出了问题？**
到 **设置 › 高级 › 诊断日志** 点“导出诊断日志”，把打开的文件夹里的 `WinShun-diagnostics.zip` 发到 GitHub Issues 或论坛。诊断包记的是版本、系统、磁盘、索引进度和错误，以及界面显示、字体和剪贴板按键转发的状态（字显示不对时先导出再重启），不含设置、剪贴板内容、搜索历史和文档正文。剪贴板搜索失效时，关闭面板后尽快导出即可；转发记录只含次数、放行原因和错误码，不记录具体按键或搜索词。

**收费吗？会上传数据吗？**
完全免费，MIT 开源。只在这些时候联网：检查新版本时连接 lcstp.com（可以关掉；只发送系统版本和安装方式，不带个人信息），你点“下载并安装”后经第三方镜像或 GitHub 下载安装包，并用 SHA-256 校验；第一次显示某个网页搜索或书签时取一次那个网站的图标；打开设置里的“插件库”这一页、点“刷新”或安装插件时，到插件库取列表和插件（以前开着、现在不再随 Win顺 自带的截图与录屏、局域网传输、按意思找、翻译、浏览器书签和网页搜索，升级后也从插件库取一次）；在网站关键词后打字时，把这些字发给那个网站取搜索建议（不打关键词时一个字也不发，可以在设置里关掉）；你自己打开“按意思找”插件并选了云服务时，把文档的文字发给你选的服务商；用“翻译”插件时，把要翻译的句子发给你填的翻译服务。索引和历史只存在本机（`%LOCALAPPDATA%\WinShun`）。

### 从源码编译

需要 Visual Studio 2022（“使用 C++ 的桌面开发”）、Qt 6.8 或更新版本（推荐 6.12，MSVC 2022 64 位套件）、CMake 3.25+ 和 Ninja。

```powershell
./scripts/build.ps1                                # 编译（不跑测试）
./scripts/build.ps1 -Tests 'tst_capture'           # 编译 + 只跑指定的单元测试
./scripts/build.ps1 -QtDir C:\Qt\6.12.0\msvc2022_64 # 指定 Qt（默认用 QTDIR 或 C:\Qt 下最新的版本）
./scripts/build.ps1 -Deploy                        # 生成可分发的文件夹 dist\WinShun
./scripts/release.ps1                              # 打包安装程序和 SHA256SUMS.txt（需要 Inno Setup 6.5+）；加 -Publish 发布到 GitHub
```

也可以用 Qt Creator 或 VS Code（CMake Tools）打开，预设见 `CMakePresets.json`。源码结构和设计见 [docs/architecture.md](docs/architecture.md)，踩过的坑见 [docs/pitfalls.md](docs/pitfalls.md)。

## English

A fresh profile starts with two setup pages: search and activation first, then clipboard history and screen capture. Go back to adjust your choices; all changes take effect after final confirmation. Capture downloads its component and asks for permission after confirmation. Choose “Set up later” to begin with filename search and double-tap Ctrl. **WinShun** (Win顺, "Windows made smooth") is a free, open-source search launcher for Windows. Press Ctrl twice and a search bar pops up, with results as you type:

- find files and folders by name or by pinyin;
- search the text inside Word, Excel and PDF files;
- launch apps and open Windows settings.

It also brings a clipboard history, screenshots with pins, a search bar for file dialogs, a taskbar search box, plugins and an MCP server for AI assistants.

It reads the NTFS master file table (MFT) directly, indexing three million files in a few seconds and following every change live: **no Everything install needed**. It needs no account and uploads nothing. The interface comes in English and Simplified Chinese. Screenshots: [above](#screenshots). A step-by-step guide to every feature (in Chinese): [docs/使用说明.md](docs/使用说明.md).

  - **Speed**: press Ctrl twice (or Alt or Shift twice, if you prefer); a search over three million files takes milliseconds.

  - **Keyboard navigation**: `Ctrl+J` / `Ctrl+N` moves down; `Ctrl+K` / `Ctrl+P` moves up; `Ctrl+U` / `Ctrl+D` pages up / down. `Ctrl+Shift+D` switches current-folder filtering.

Existing display choices are preserved. They follow the visible results after scrolling; while a Win顺 window is in front they are Win顺's, even if another app uses them as global hotkeys. Under Settings › Result list › Display and preview, “Keyboard hints” can hide the shortcuts help button at the right of the search box and the key hints in the footer; capture's All keys button can be hidden among the toolbar buttons.

The small button at the box's corner or `Ctrl+E` grows the same window into a panel, as Listary has it: filters down the left (scope, kind, date modified, size, folder), sortable columns on the right; right-click headers to choose name, path, type, size, modification and creation times, folder or source, and drag to reorder or resize them; the layout is saved; with nothing typed it browses the whole index by those filters (milliseconds over three million files). `size:>10mb` and `dm:7d` work in the box too. Drag the left or right edge of the search box to widen it (the width is remembered; double-click an edge for the default).

  - **Logo controls**: the WinShun logo on the left opens settings with a left click, toggles pinning with a middle click (`Ctrl+T` also works), and centers the window in the current monitor's work area with a right click. Drag it to move the window. A pin badge shows when pinned: clicks elsewhere and opened files keep the box up; `Esc` closes it.
  - **Preview**: `Alt+P` on a result (or Preview in its menu) shows the file without leaving the launcher: pictures, text (UTF-8 or GBK, detected), Word, Excel, PowerPoint and PDF (through the same preview handlers as File Explorer's preview pane), what a folder holds; the arrows move it to the next row, `Alt+P` again (or the × on the preview) closes it; `Esc` closes the launcher and leaves the preview as it is, so it is back the next time the launcher opens. QuickLook or Seer, when running in the background, shows it instead. The result preview shortcut can be changed to Space, a function key, or an unused chord in Settings; Shift+Space still types a space.

  - **By kind**: under **Files**, a row of kinds (folders, documents, pictures, videos, archives…); `Ctrl+Tab` steps through them, `+` adds your own.
  - **Files you never want to see**: Settings › Search scope skips some types and file names, with `*` and `?` wildcards; by default the `~$` temporary files Office and WPS make beside open documents. Typing such a name in the box still finds it.
  - **Drag out**: drag results into a chat, a mail or Explorer.
  - **Live updates**: the USN change journal is read, so renamed, new and deleted files are found at once; unplugging a USB drive never says it is in use.
  - **Large icons**: switch the search panel between a list and a thumbnail grid. Resize previews with the slider or `Alt`+wheel, select several file categories together, and keep the normal selection, menus and file dragging. The view and thumbnail size are remembered.
  - **Query syntax**: `"exact phrase"`, `!exclude`, `!node_modules\`, wildcards `*` `?`, `ext:pdf,docx`, `folder\name`, and paths (`D:\My Files\`, `tools/out/`). Add OR groups (`report | summary 2026`, AND takes precedence), name anchors (`^IMG`, `.pdf$`), or `regex:^IMG_\d+\.(jpg|png)$`; invalid expressions explain the error. `Ctrl+R` turns on regex mode, where every word is a regex, as in Everything. `:pictures,videos` combines type keywords.
- 📄 **Full-text search**
  - **Content details pane**: the `Ctrl+E` panel offers Summary, Hits, Text, native Preview and Report tabs. Read all available matches, refine hits and context, inspect Excel sheets with real row numbers, and copy, print or export text, CSV, HTML and XLSX. Full counts run on request; partial results are labelled.
  - **What**: the **Content** scope searches inside txt, md, logs, source code and **Word, Excel, PowerPoint, PDF and WPS** files, showing the page, slide or sheet and row.
  - **Quieter everyday searches**: **All** adds matches from the existing content index without launching document parsers. Choose **Search contents** when offered, or switch to **Content**, to read files that have not been indexed yet.
  - **In one folder**: add a folder's name and a slash, `annual report abc/`, to search only in folders named abc (`/abc` last works too; `work/abc/` takes the one in work); folders of the same name are all searched and listed under the box, `Ctrl+Tab` picks one. Or pick a favorite folder there, or right-click a folder in the results → Search contents in this folder.
  - **How**: ranked by relevance, with a content index for speed; UTF-8, UTF-16 and GBK are detected. The first content index reads text files straight from the disk through the index service, so antivirus does not check them one by one and it is done much sooner. Files over the size limit, in system folders or of unlisted text types are skipped; the list says how many of each, and one click searches them too.
  - **Without the index service**: it works too, only slower, as the files are read as you search.
  - **Safety**: documents are read by a separate process with restricted rights.

    - **Text and search**: Recognize text on the toolbar shows the words in a picture to copy, to search with, or to search on the web; `jt` and a space in the search box list past screenshots by the text in them.
    - **Presenter and whiteboard**: Screenshot › Presenter / whiteboard in the tray menu, or `cap whiteboard`; you can also record a hotkey for it in the screenshot settings under Shortcuts (none by default). It draws on the live desktop: pen, highlighter, arrow, text, numbers, and `X` for a laser pointer whose trail fades at once. `Esc` or a right click hands the mouse and keyboard back to the programs below (to flip a slide, say); `W` is a whiteboard and `K` a blackboard. The ink is pixels on the screen, so recordings and screen sharing need to capture the whole screen.
    - **Yours to set**: what a double left click, the right, middle and side buttons do after you have chosen an area (copy, copy and pin, save, pin, read text and copy, search or search the web, cancel, step back), and which buttons the toolbar shows.
- 🔎 **Taskbar search box**: WinShun's own search box on the Windows 11 taskbar, or a pinned WinShun icon instead (the only way on Windows 10). The box has a fixed place the icons never push around: the taskbar's left end with centred icons, left of the tray icons with left-aligned ones; a whole box, its icon and label, or its icon alone, as Windows' own search, narrower by itself when the taskbar fills up. It works on its own or alongside Windows search; hiding Windows search, taking over `Win+S`, and searching as you type in the Start menu are all optional.
- 🤖 **AI assistants (MCP)**
  - **What**: WinShun is an MCP server. Claude Desktop, Claude Code, Cursor and VS Code connect in one click and search file names, file contents and recent changes.
  - **Safety**: read-only by default, limited to what the AI client may see, with folders kept from AI and a call log.
  - **Setting up**: tell the AI to “set up WinShun for me”; it asks a few questions and changes several settings in one go. A window asks you first, a notice at the bottom right says what changed and offers Undo for a few seconds; security-related settings always ask.
  - **Command line `ws`**: search from a terminal, like Everything's `es`: `ws report` (names), `ws grep invoice` (contents), `ws text plan.docx` (a document's text), `ws recent --days 7`. AI agents that run commands (Claude Code, Codex) need less context with it than with MCP; `ws skill --install claude` installs its instructions. It shares MCP's switch and safety settings.
- 🎨 **Looks and settings**
  - **Looks**: light and dark themes following Windows, Windows 11 Mica, rounded or square corners, including application-drawn rounded corners on Windows 10, sharp icons at any scaling; compact, standard or roomy sizes, and a monochrome tray and taskbar icon if you like; the app logo stays inside the search bar as its persistent action control.
  - **Settings**: searchable (`Ctrl+F`); changes apply at once.
  - **File manager**: folders and file locations open in File Explorer, Total Commander, Directory Opus, XYplorer or Pulse (those installed are listed), or in any other file manager whose commands you enter under Settings › Open WinShun › Dialogs.
  - **Backup**: choose a folder under Settings → Advanced (a synced folder makes it a cloud backup); settings, favorites, dialog pins, your own web icons and plugins are backed up as they change, the last 10 kept, ready to restore.
  - **Move to another PC**: under Settings → Advanced → Backup, choose “Export backup…” to save a ZIP, then “Restore from backup…” on the new PC. Automatic backups need not be enabled. The current configuration is saved locally first; enter plugin passwords again and check custom paths on the new PC.
  - **Updates**: announced in the tray; “Download and install” fetches the package, checks its SHA-256 and installs it (the portable copy swaps only its program files, never `data`; a copy installed with Scoop offers “Update with Scoop” instead and lets `scoop update` do it). Downloading the installer yourself still works.

### Download and install

1. Download `WinShun-<version>-x64-setup.exe` from the [Releases page](https://github.com/LingCore/WinShun/releases/latest) and run it. If Windows says “Windows protected your PC”, click **More info → Run anyway**: the app is not code-signed yet. Setup offers “for all users” (an administrator approves it; comes with the index service, the fastest) or “for me only” (no administrator needed, no index service; only the folders you choose are indexed), and recommends “for me only” when your account is not an administrator.
2. When the WinShun icon appears in the notification area, it is running; the first index takes a few seconds. Press Ctrl twice and type.
3. To upgrade, click “Download and install” (“Download and update” for the portable copy) when WinShun tells you about a new version: it downloads, checks and installs it, then starts again. Running a newer installer yourself works too. Your settings and index are kept. If an AI tool (Claude Code, Cursor …) is connected to WinShun, Setup asks first: install now and reconnect WinShun in that tool (or restart it) afterwards, or install later. Uninstall from Windows Settings → Apps.

To skip the installer, download `WinShun-<version>-x64-portable.zip`, unzip it anywhere and run `WinShun.exe` in it. Settings, history, clipboard and index are kept in the `data` folder beside it, so the whole folder can go on a USB stick or another PC; on the first start, what this PC already has (`%APPDATA%\WinShun`, `%LOCALAPPDATA%\WinShun`) is copied in, the originals left in place. To upgrade, unzip the newer one over it and keep `data`. Without the `data` folder (quit WinShun first), it keeps them where the installed copy does.

With [Scoop](https://scoop.sh), two commands do it:

```powershell
scoop bucket add winshun https://github.com/LingCore/WinShun
scoop install winshun
```

This installs the portable package (settings and index live in Scoop's `persist\winshun\data`), adds “WinShun” to the Start menu and puts `ws` on the PATH. To update, click “Update with Scoop” in WinShun's update reminder (it opens a window that runs `scoop update`, then starts WinShun again) or run `scoop update winshun` yourself. `scoop uninstall winshun` first takes back what WinShun registered (autostart, Explorer menus ...) and keeps your settings and index; add `-p` to delete the data too. Scoop does not install the index service; to index whole disks turn it on in **Settings › Search scope › Disks › Index method**.

Standard and portable packages install enhanced text recognition on demand. Open **Settings › Clipboard › Recording › Enhanced text recognition** to download about 12 MB, or install a local component archive. Clipboard and screenshots share it and work offline after installation, with no restart. Existing recognition files remain usable. For a PC without internet, choose `WinShun-<version>-x64-offline-setup.exe`, or copy the Release’s `WinShun-ocr-*.zip` and install it locally. Screenshot recognition keeps the original image and continues once the component is installed. App updates, the plugin library and enhanced recognition prefer two download mirrors for public GitHub files, then the original source; failed connections and rejected files automatically try the next source.

Requires Windows 10 or 11, 64-bit.

### Administrator rights

- **Not needed day to day**: WinShun runs with your normal rights. The installed version comes with a small “WinShun Index Service” that reads the NTFS master file table (MFT) and change journal (USN) for it, so millions of files are still indexed in seconds and changes followed live. An administrator approves the install once; after that there is no UAC prompt at login or when you open it.
- **Which files you see**: as with Everything, the index holds the file names of whole drives, other users' on this PC included; files you have no rights to still won't open.
- **Portable version**: by default it walks the folders one by one, so the first index is slower; changes are followed live after that. Settings → Index access can install the index service or restart it as administrator. When a portable copy installs the service, it puts a copy of the service program in `%ProgramFiles%\WinShun Service`, where only administrators can change it, so no ordinary program can swap it; an older registration gets a warning and a Repair button in the settings.
- **Without administrator rights (“for me only”)**: pick “for me only” in Setup: no index service, and no administrator needed. WinShun then indexes only the folders you choose (Settings › Search scope › Folders; the desktop, documents, downloads, pictures and the like to begin with), and you can drag folders in from File Explorer. Changes are followed live, and everything is checked again once a day (hourly, every 4 hours or only at start are options). When the folder you type is not indexed, the search box says so: “Search it this time” looks there once, “Add to the index” keeps it. Content search still works, only slower.
- **Direct as administrator**: on an administrator account, Settings → Index access → “Direct (administrator)” runs the whole app as administrator and reads the drives itself, as earlier versions did.
- **Programs running as administrator**: Windows doesn't let normal-rights programs type into them. Pasting into such a window only copies, and WinShun tells you to press `Ctrl+V`. The search bar beside their Open / Save dialogs appears too: the installed WinShun with the index service jumps to the chosen folder just as in other dialogs, and `Ctrl+G` works there; a portable copy, or one installed for you only, can only copy the chosen path for you to paste into the path box yourself.
- **Double Ctrl does nothing while they are in front**: Windows doesn't give the keys typed into them to normal-rights programs either, so without the index service double Ctrl (Alt, Shift) does nothing while such a window is in front; a shortcut with Ctrl, Alt, Shift or Win (`Alt+Space`, say) still works. With the index service installed this doesn't happen (the service's helper hears the keys), nor when WinShun itself runs as administrator (Direct). The first time such a program stays in front for a moment, WinShun says why in one notification: it names your shortcut if you set one, and where a portable copy (Scoop's too) can install the index service, a click opens Settings › Index access, with the install button just below. Each program is mentioned once, three at most, and one per run.
- **What you open is not elevated**: files and apps you open from WinShun run with your normal rights; only `Ctrl+Shift+Enter` runs one as administrator.

### FAQ

**How is it different from Everything or Listary?**
WinShun builds its own index, so Everything is not needed. File names, pinyin, apps and file contents are searched from one box, tuned for Chinese. File dialogs get Listary's `Ctrl+G` and a search bar, but WinShun does not embed itself in Explorer windows.

**Ctrl twice clashes with another program?**
Listary and PowerToys' Find My Mouse use it too: turn it off on one side, let WinShun use Alt or Shift twice instead, or count only the left or the right key (Settings › Open WinShun › Key to press twice / Which side), or give WinShun another shortcut. (An input method that switches language with Shift switches twice on a double Shift, so it ends where it began.) Full-screen games and games that hide the mouse are ignored by default.

**AutoHotkey remaps don't work in WinShun?**
With “Direct (administrator)” chosen, WinShun runs as administrator, and Windows keeps normal-rights programs from intercepting keys sent to it. Pick another index access, or run the script with UI Access or as administrator.

**Memory? Index location?**
- **Memory**: about 30 MB of index per million files; the whole app is usually 120–140 MB while in use, and drops to about 15 MB in Task Manager a minute after you stop using it.
- **Index location**: the index can move to another built-in drive under Settings → Advanced.

**Indexing is slow, or something is wrong?**
Under **Settings › Advanced › Diagnostic logs**, click “Export diagnostic logs” and attach the `WinShun-diagnostics.zip` from the folder that opens to a GitHub issue. It holds the version, system, disks, indexing progress and errors, not your settings, clipboard, search history or document text.

**Is it free? Does it collect data?**
Free and MIT-licensed. It goes online only to check lcstp.com for new versions (you can turn that off; only the Windows version and the kind of install are sent, nothing personal) and, when you click “Download and install”, to download the package through third-party mirrors or GitHub, checked against its SHA-256, to fetch a web shortcut's or bookmark's site icon once, to fetch the plugin list and plugins when you open the Plugin library page in the settings, press Refresh or install one (and once after an update, for Screenshot and recording, LAN transfer, Search by meaning, Translate, Browser bookmarks or Web search if you had them on: they no longer come with WinShun), to ask a site for search suggestions while you type after its keyword (nothing is sent without a site keyword; you can turn this off), and, if you turn on the “Search by meaning” plugin with a cloud service, to send document text to the service you chose, and, when you use the Translate plugin, to send the sentence to the translation service you entered. The index and history stay on your PC (`%LOCALAPPDATA%\WinShun`).

### Build from source

Needs Visual Studio 2022 (Desktop development with C++), Qt 6.8 or later (6.12 recommended, MSVC 2022 64-bit kit), CMake 3.25+ and Ninja.

```powershell
./scripts/build.ps1                                # build (no tests)
./scripts/build.ps1 -Tests 'tst_capture'           # build and run only the named unit tests
./scripts/build.ps1 -QtDir C:\Qt\6.12.0\msvc2022_64 # pick a Qt kit (default: QTDIR or the newest under C:\Qt)
./scripts/build.ps1 -Deploy                        # make the distributable folder dist\WinShun
./scripts/release.ps1                              # package the installer and SHA256SUMS.txt (needs Inno Setup 6.5+); -Publish makes the GitHub release
```
