# Win顺 0.25.0 发布验证

2026-11-12，在 Windows 11 x64（150% 缩放）、Qt 6.12.0、MSVC 2022 Release 环境完成构建和相关验证。构建源码为 `54ec60c3`（版本号、发布说明与文档），构建目录 `build/release025`，交付文件在 `dist/release025`。此后的提交只更新海报、截图文档和验证证据，不涉及参与编译的文件。

## 构建与相关回归

- 全新配置，编译主程序及官方可选插件。标准、离线安装器及主程序版本资源均为 `0.25.0`。
- 按本次改动选择 13 项 CTest，全部通过：核心库（快捷筛选的条件、单字母找回应用、重命名的名字检查、反馈入口）、查询语法（筛选前缀）、语法上色、剪贴板（备注）、插件（`ph:` 图标、即时关键字、管理员重启）、书签插件、外观（全部 Phosphor 图标名，四种缩放）、设置里的类型与筛选、AI 设置、Shell 启动。[CTest 输出](validation/release025/ctest-related.txt)
- 各项功能自己的实测记录在对应目录：快捷筛选（`validation/quick-filters-20261112`）、首次引导（`validation/onboarding-redesign-20261111`）、重命名、备注与预览上色（`validation/features-prs-20261111`）、对话框只搜当前文件夹（`validation/issue286-20261111`）、管理员程序上按住连按（`validation/issue287-20261111`）、Directory Opus 与插件启动（`validation/issues-242-82-20261111`、`validation/issues-288-242-20261111`）。
- `tst_settings` 本版有改动（快捷筛选的读写），但它在本机约 5% 的运行里因配置文件被别的进程短暂占住而失败（见 0.24.0 的记录），没有放进发布构建的测试集；快捷筛选的设置读写由 `tst_settingsfilters`（真实设置窗口）和功能当时的 `tst_settings` 运行覆盖。

## 生产界面与海报

部署目录的 `WinShun.exe` 完成三项生产预览，零 QML 警告，采用 D3D11、200% 和临时配置：完整设置窗口（逐页逐标签，55 张）、类型与筛选页的编辑检查、真实主窗口的导航检查（81 项全部通过，含面板里快捷筛选的开、叠加、关和前缀）。首次引导用 `tools/verify-onboarding.ps1` 跑了 `capture` 与 `english` 两个用例，均通过。[二进制来源](validation/release025/capture.json)、[海报原图摘要](validation/release025/poster-sources.json)、[引导检查](validation/release025/onboarding-summary.json)

本版海报三张，沿用品牌方形模板，1440×1440、JPEG 质量 96、关闭色度抽样：

- 新增“常用条件，一点就用”（设置 › 结果列表 › 类型与筛选：快捷筛选一节，上面是绑定了文件夹的 `cw` 类型），加进截图文档的“搜文件”分组。
- 重拍“第一次打开，两步设好”（引导改成左右两栏）和“文件类型，由你来定义”（多了绑定文件夹的图标按钮）。

README 仍只放封面。其余海报沿用旧图。**没有海报的**：搜索面板里的快捷筛选小片（导航检查会压窄窗口并悬停在小片上，截图里提示框压住文字，只留作证据不做海报）、F2 重命名、预览上色与 `.ai` / `.psd`、剪贴板备注；这几处需要用演示数据走实机拍摄流程，留到下次整套重拍。

逐一对比官方插件编译用到的源文件（`ninja -t inputs` 列出的输入与 `v0.24.0..HEAD` 的改动求交集），三个插件有变化，均已在版本号提升到 0.25.0 之前，从干净的工作副本 `64f3d99b` 构建发布：

| 插件 | 版本 | 最低主程序 | 变化 |
| --- | --- | --- | --- |
| 浏览器书签 | 2.0.4 | 0.17.0 | 也读账户书签 `AccountBookmarks`；声明读取的路径增加，更新时需要用户确认 |
| 截图与录屏 | 1.1.11 | 0.18.0 | 跟进共用代码：按名字取图标、窗口边框与标题栏、输入框 |

截图与图片文字搜索两个新包与上一版的文件清单相同。公开 `index.json` 中三个条目的版本、SHA256 与本地包一致，签名验证通过（`ws-index-2026a`），共 33 个插件。其余官方插件（休息提醒、翻译、LocalSend、语义搜索、资源管理器标签页、网页搜索）的编译输入没有变化，不重新发布。

## 没有覆盖的

- 本次发布流程里没有对新功能再做实机键鼠测试，依据的是各功能开发时的实测记录和上面的生产预览检查。
- 快捷筛选开发时没有做实机键鼠测试（见其验证记录），只有真实窗口里的鼠标事件检查。
- 书签插件 2.0.4 没有在真实 Win顺 里走一遍“更新时确认新增路径”的流程，只核对了宿主的判断代码（读取路径增加即要求确认）和 `tst_bookmarks`。
- 安装包没有在干净系统上做覆盖升级实测；本版没有改动安装器脚本和索引服务。
- 遗留：展开面板后偶发一次约 1 秒的“结果来晚了”日志，原因未查明（见 `13e39c46` 的提交说明），不影响结果正确。
