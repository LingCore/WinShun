# 鼠标手势 2.0 设计

插件 `winshun.gestures`（插件库，C++，常驻）。1.0.0 只有“按住右键画方向 → 做一件事”。2.0 的目标：用起来比 WGestures 1.8.5 顺手，又保持轻（常驻部分不带 Qt）。

## 比 WGestures 强在哪

| | WGestures 1.8.5 | 鼠标手势 2.0 |
|---|---|---|
| 同一个手势在不同场合 | 全局一套，另可按程序分 | 按程序分之外，还看**有没有选中文字**、**在屏幕哪个角上画**；越具体的越优先 |
| 选中文字 | 一个“Web 搜索”命令（靠模拟 Ctrl+C） | 选中文字后的手势单独一组：复制、剪切、网页搜索、用 Win顺 搜、翻译（结果就地显示，点一下复制）；用 UI Automation 读选中的字，不碰剪贴板 |
| 形状 | 只有上下左右 | 上下左右，外加**顺时针、逆时针画圈** |
| 触发角、摩擦边 | 有，容易误触 | 有；角上要停一下才算，按着鼠标键拖东西时、全屏游戏里都不触发；触发时有提示；关机类动作先倒数 5 秒，可取消 |
| 画着画着反悔 | 停住等超时 | 按 Esc 或点一下左键，马上作废 |
| 右键 + 滚轮 | 有（手势修饰） | 有：默认切换标签页，可改 |
| 关机、重启、睡眠 | 靠运行命令 | 现成的动作，带确认倒数 |
| 和别的功能打通 | 无 | 打开 Win顺 搜索框、用 Win顺 搜选中的字、翻译插件、Win顺 默认网页搜索 |
| 设置 | 自己的窗口，画手势录入 | Win顺 风格的设置窗口：在窗口里用右键画出新手势，动作按类别挑，按键现场录，屏幕示意图设触发角和摩擦边，冲突当场提示；搜索框里打“手势”看全部 |
| 资源 | .NET，常驻约 10 MB | 常驻 C++ 无 Qt；设置窗口打开时才起，关了就退 |

## 一条规则

所有手势、触发角、摩擦边、滚轮都是同一种“规则”：**什么时候（触发） + 在哪（条件） → 做什么（动作）**。

### 触发

- 画出的手势：方向串 `L R U D`（左右上下，最多 6 段），或画圈 `cw`（顺时针 ↻）、`ccw`（逆时针 ↺）。
- 触发角：`corner:tl` `corner:tr` `corner:bl` `corner:br`。
- 摩擦边：`edge:top` `edge:bottom` `edge:left` `edge:right`。
- 右键 + 滚轮：`wheel:up` `wheel:down`。

### 条件

- `where`（只对画出的手势）：在屏幕哪个角上画（按起笔点）：`tl` `tr` `bl` `br`，不写就是哪都行。角上的范围是那块屏幕宽、高各 1/5。
- `selection: true`（只对画出的手势）：只在有选中文字时。
- `apps`（画出的手势和滚轮）：只在这些程序里（`["photoshop.exe"]`），不写就是所有程序。触发角和摩擦边看的是前台窗口，不分程序。

同一个触发有几条规则都对得上时，取最具体的：程序 > 选中文字 > 角落 > 通用。具体的那条动作为空，就是“在这里这个手势什么都不做”。

### 动作

- 内置（`do`）：

  | 类别 | 动作 |
  |---|---|
  | 网页 | 后退 `back`、前进 `forward`、刷新 `refresh`、回到顶部 `top`、到底部 `bottom` |
  | 标签页 | 新建 `newtab`、关闭 `closetab`、重新打开关掉的 `reopentab`、上一个 `prevtab`、下一个 `nexttab` |
  | 窗口 | 关闭 `close`、最小化 `minimize`、最大化/还原 `maximize`、置顶/取消置顶 `topmost`、显示桌面 `desktop`、任务视图 `taskview`、切到上一个窗口 `lastwindow` |
  | 文字 | 复制 `copy`、剪切 `cut`、粘贴 `paste`、撤销 `undo`、重做 `redo`、全选 `selectall`、网页搜索 `websearch`、用 Win顺 搜 `findwinshun`、翻译 `translate` |
  | Win顺 | 打开搜索框 `search` |
  | 系统 | 静音 `mute`、音量加 `volumeup`、音量减 `volumedown`、播放/暂停 `playpause`、下一首 `nexttrack`、上一首 `prevtrack`、锁屏 `lock`、关闭屏幕 `screenoff`、睡眠 `sleep`、关机 `shutdown`、重启 `restart`、注销 `signout` |

- 按键（`keys`）：`Ctrl+Shift+T`、`Win+D`、`F5`。
- 打开（`open`）：程序、快捷方式、文件、文件夹、网址。
- 输入文字（`type`）：把一段字打到光标处。
- 都不写：什么也不做。

### 存法

所有规则存在一个隐藏的文字设置 `rules` 里（JSON，进 `WinShun.ini`，跟着 Win顺 的备份走）。空着就是默认规则。

```json
{"version": 2, "rules": [
  {"on": "DR", "do": "close"},
  {"on": "cw", "where": "br", "do": "shutdown"},
  {"on": "D", "selection": true, "do": "copy"},
  {"on": "L", "apps": ["photoshop.exe"], "keys": "Ctrl+Z"},
  {"on": "corner:tl", "do": "taskview"},
  {"on": "wheel:down", "do": "nexttab"}
]}
```

卡片上照旧显示的设置：画出轨迹和提示 `trail`、全屏程序里也用 `fullScreen`、这些程序里不用 `exclude`。1.0 的 `left`…`upDown`、`more` 改成隐藏：`rules` 还空着、而这些改过时，第一次启动把它们换算成规则存进 `rules`，之后不再读。

主程序要加的（0.41.0）：设置项 `"hidden": true`（不画在卡片上、不给 AI 看，其余照常）；工具 `power`（权限 `system:power`），替插件关机、重启、睡眠、休眠——插件的令牌没有关机特权；工具 `selected_text`（权限 `selection:read`），替插件读前台窗口里选中的字——插件的作业带着剪贴板限制，跨进程的 UI 自动化在作业里一律超时（pitfalls“作业有任何 UI 限制，UI 自动化就不通”）。

## 默认

- 画：← 后退，→ 前进，↑ 回到顶部，↓ 到底部，↓→ 关闭窗口，↓← 最小化，↑↓ 打开搜索框（和 1.0 一样）。
- 选中文字时：↓ 复制，↑ 网页搜索，→ 翻译。← 照旧后退。
- 右键 + 滚轮：上一个 / 下一个标签页。
- 触发角、摩擦边、画圈：默认都不设（设置窗口里一眼能看到，点一下就设）。

## 运行时

- **选中文字**：画出的第一段对上某条 `selection` 规则时，后台线程请 Win顺 读（`selected_text`：Win顺 用 UI Automation 问前台窗口的焦点元素有没有选中的字，文字取前 4000 字；Chromium 程序和 Firefox 不问，在那里选中文字的手势不起作用，还是平常的手势）；只认画手势的窗口就是前台窗口的情况，250 毫秒没回话就当没有。提示上直接写“复制「选中的前十几个字…」”，松手前就知道会做什么。
- **画圈**：累计转过的角度到 300° 以上、终点回到起点附近、外框不太扁，就是圈；正负定顺逆时针。
- **触发角**：指针进到某块屏幕的“硬角”（两条边外都没有别的屏幕）2 像素内，停 150 毫秒触发；离开 50 像素才能再触发。
- **摩擦边**：贴着“硬边”（边外没有别的屏幕，离边 6 个逻辑像素内）来回 3 次以上、每段 24 个逻辑像素以上、1.2 秒内完成；触发后 1 秒内不再算。
- 触发角和摩擦边：有鼠标键按着、手势暂停、前台是全屏程序（没开“全屏也用”）或在排除名单里时不算；触发时在角上/边上闪一下动作名。
- **右键 + 滚轮**：右键按着滚滚轮，每格做一次；用过滚轮，松开右键就什么都不做（不弹菜单）。
- **反悔**：画的时候按 Esc（临时注册的热键）或按一下左键，作废。
- **关机、重启、注销、睡眠**：屏幕中间一张卡片倒数 5 秒，Esc 或点“取消”就不做，Enter 或点“现在就…”马上做。关机、重启不强制关程序，没保存的程序照常拦下。
- **翻译**：选中文字的旁边出一个气泡，先写“正在翻译…”，回来后显示译文；点一下复制译文并收起，Esc、点别处或指针走远就收起。没装或没设好翻译插件时，气泡里说明，点一下打开设置。

## 设置窗口

卡片上的“设置”打开（插件 `settingsWindow`）。常驻进程（无 Qt）按需起一个子进程 `WinShunGestures.exe --editor`，它像截图插件那样用 Win顺 的 Qt 和共用控件（`WinShunGesturesEditor.dll`）；两边用管道传 JSON 行：常驻进程发当前设置和外观，设置窗口发改动，常驻进程转给 Win顺（`winshun/settings/update`），存好后再发回最新的。关窗口子进程就退。

分页：

1. **手势**：所有画出的手势一行一个——手势的小图和箭头、在哪个角（有的话）、动作；点动作换，× 删。“添加手势”：在窗口里的画板上用右键画（同一套识别），选在哪画、选动作，和已有的冲突时当场写“会替换：关闭窗口”。下面一段“按住右键滚滚轮”：向上、向下各一个动作。
2. **选中文字时**：同样的列表，只列 `selection` 规则，上面一句说明。
3. **触发角与摩擦边**：一张屏幕示意图，四个角、四条边各一个按钮，写着当前动作；点哪个设哪个。
4. **程序**：每个程序一组自己的手势（同一个列表控件）；“这个程序里不用手势”就是排除名单。
5. **常规**：轨迹和提示、全屏也用、暂停、恢复默认。

动作选择器：按类别分组的一块面板（网页、标签页、窗口、文字、Win顺、系统），末尾“按下按键…”（现场录）、“打开程序或文件…”、“打开网址…”、“输入文字…”、“什么都不做”。

## 测试

- `tst_gestures`：识别（方向、画圈、太长）、规则解析和存回、匹配优先级、1.0 设置换算、触发角和摩擦边的判定（纯逻辑，屏幕布局当参数传进去）。
- `tst_plugin`：`hidden` 设置不上卡片、照常传给插件和更新；`power` 没权限时拒绝。
- Win10 虚拟机（真输入）：默认手势、画圈、角落手势、选中文字（记事本、Edge）复制/搜索/翻译、触发角、摩擦边、右键 + 滚轮、Esc 反悔、关机倒数取消、设置窗口画手势和改动作。
