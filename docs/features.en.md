# WinShun features

Everything WinShun does, area by area. Back to the [README](../README.md#english); screenshots are in [docs/截图.md](截图.md). A step-by-step guide (in Chinese) is in [docs/使用说明.md](使用说明.md).

On a fresh install the search bar beside Open / Save dialogs, the folder menu and typing to search in File Explorer start switched on, as Listary has them (0.36.0; an upgrade keeps what you had), each a card under Settings › Plugins › Installed › Built-in features where it can be turned off. Some built-in feature cards (typing in Directory Opus, typing in OneCommander, the drop pie) have a More settings link that jumps to the related settings. Some extras start switched off: Paste as file, the clipboard history taking over `Win+V`, the taskbar search box and the system switches. Plugins described as in the plugin library are installed from Settings › Plugins › Plugin library.

## File search

- **An empty search panel** (0.28.0): "List all files in the empty search panel" under Settings › Appearance › Size and layout (on by default) can be turned off, so the panel lists nothing until something is typed.

- **Query history**. The clock button opens the last 100 completed queries. `Ctrl+Up` / `Ctrl+Down` browses them and restores the previous draft at the newest position. Settings can choose Alt with the arrows or disable the keys. Delete individual entries or clear the list. Plugin keyword searches such as `= 3*7` are kept too and run again when picked; the hash and Base64 keywords, where passwords get typed, are not. History follows the usage-recording switch.
- **Open windows**. In All, sorted by relevance, matching current window titles and program names appear first. Enter activates the selected window, including a minimized one.
- **Minimal empty search**. Enable Pure search mode under Appearance › Size and layout to keep only the input bar when empty. Results and the scope tabs return as you type; the history and expand buttons stay hidden, their shortcuts still work. Beside it, Scope tabs › Merged turns All / Files / Content into one button that names the current scope: a click or `Tab` goes to the next. Both start off.
- **Typing on the desktop**. With "Type to search on the desktop" on (Settings › Integration › File managers, off by default), a key typed while the desktop's icons have the keyboard opens the box to search the whole PC. Not while an icon is renamed or a menu is open, nor with `Ctrl`, `Alt` or `Win` held.
- **Choose the row buttons**. Settings › Result list › Row buttons picks which buttons a result's row ends with, and in which order: the upper line is what shows, left to right as on the row (drag to reorder, click to take one off); the lower line is the rest (click to add at the end). Run as administrator, Open location, Terminal, Copy, Copy path and Delete come by default; Preview, Copy name and Favorite can be added. A button shows only on rows it applies to, and one left out stays in the right-click menu. Reset puts it back.
- **No delete button**. Click Delete in Row buttons to take it off: rows of files and folders then end without the bin; delete from Move to Recycle Bin or More options in the right-click menu. An older "Show the delete button" turned off carries over.
- **Move to Recycle Bin** (0.45.0, #434): WinShun's own right-click menu has a red Move to Recycle Bin (“(N items)” for several rows), also for rows in different folders; apps, settings, commands, plugin rows, web rows, windows, offline or missing files, drive roots and bare share roots are left out. It is there even with the delete button turned off. Windows' own menu (More options, `Shift`+right-click) acts on rows in different folders too (#464; it used to act on the current row alone). The footer's clear-history button is a broom now, so it no longer looks like deleting files.
- **Merged scopes and panel controls**. Optionally merge All and Files and filter file kinds in All. Hold Ctrl to see kind keywords. Assign a direct panel hotkey under Settings › Shortcuts › Open WinShun, and use the panel's filter button to collapse its sidebar while retaining active filters.

- **Speed**: press Ctrl twice (or Alt or Shift twice, if you prefer); a search over three million files takes milliseconds.
- **Pinyin**: `ndbg` finds 年度报告; a mistyped homophone (年度报高) is retried by sound. A setting can switch the input method to English each time the search box opens, so letters go straight in; right after a logon, if the system flips it back to Chinese a moment later, WinShun puts it back, while switching to Chinese yourself with a key is never undone (0.45.0).
- **Where**: all local drives, USB drives and external hard disks if you like (including disks that report themselves as fixed, such as most USB enclosures; an unindexed one that is plugged in is offered at the end of the list), and **NAS / SMB network shares and WebDAV folders** (a NAS's WebDAV, cloud drives such as Jianguoyun), still searchable while their server is off and reconnected by themselves after it restarts; turn on “Search file contents” on a location's card to search inside its files. On a PC without administrator rights it indexes only the folders you choose (see Administrator rights below). A directory link, junction or mounted folder (`mklink`) that leads to what is indexed nowhere else (a disk not chosen, a volume without a letter, a share not set up) is indexed under the link's own path and followed live, links made later too (0.32.0, needs the new index service; at most 256). Disks indexed by walking (no MFT read) find their links too, during the walk and as they are made (0.34.0). A link to a folder on a disk that is indexed already is walked under its own path too, as when you add that folder by hand, so the link's path finds what is in it; the links inside a linked folder are taken the same way (a `.skills` link whose skills are links themselves shows each skill's files under `.skills\<skill>`), and so are links in dot-folders such as `.claude` or `.config`; these are left out: Windows' own compatibility links (hidden or system, such as `C:\Documents and Settings`), links to a whole disk, loops back to the link or a folder above it (also a link inside a link that leads back to where the outer link really is), and links inside tool folders such as `node_modules` or `AppData` (pnpm and npm make thousands there). A link to a network share that is set up already is still not taken twice.
- **Order**: your own files first, the date modified on each row, `Ctrl+S` for best match / newest / oldest, and More in the footer sorts by name, folder, type or size. Click a result once to select and twice to open, if you would rather not open one by mistake (a setting). Recent files are listed when the box is empty, or nothing if you like; the search can also start empty each time it opens. A folder with nothing in it says “Empty folder” right after its name (at the row's end before 0.42.0) and a 0-byte file “Empty file”, so you need not open them to find out (0.38.0; told from the index, never the disk; hidden folders and network shares are not marked, and since 0.46.0, #460, neither is a link to a folder, a junction or a symbolic link: it has nothing under it in the index, yet leads to a folder that has files).
- **Programs first**: `curl` lists `curl.exe` before the folder `curl` and `curl.h`; which file types go first is yours to change (exe, bat, cmd, ps1 and msi to begin with, like Listary's preferred file types).
- **Learned order**: one opening improves later matching searches for the same app or file, across Chinese names, pinyin and initials. Old preferences decay. Type `settings` or `config`, or press `Ctrl+,`, to open WinShun settings; a plugin's name with `settings` (`translate settings`) opens that plugin's card in them (0.38.0). These rows are remembered like any other, and can be kept among the favorites with a keyword of your own; `Ctrl+Shift+C` on one copies its `winshun://` link.
- **Keyboard navigation**: `Ctrl+J` / `Ctrl+N` moves down; `Ctrl+K` / `Ctrl+P` moves up; `Ctrl+U` / `Ctrl+D` pages up / down. `Ctrl+Shift+D` switches current-folder filtering.
- **Shortcuts**: `Ctrl+1`…`Ctrl+9` opens a visible result (or choose `Alt`). Numbers are visible by default in a separate column before the icons; choose hold-only, always or never with Number key hints (Settings › Result list › Behavior), one setting shared by the search box, the clipboard and the bar beside Open / Save dialogs. Existing display choices are preserved. The numbers always mark the rows in view: after scrolling, `Ctrl+1` (or `Alt+1`, whichever modifier is set) opens the first row you can see, and the clipboard pastes the visible rows the same way. While the list is scrolled, the bottom of the search box (and of the dialog bar) shows where you are, such as `6–10 / 18`, and the scroll bar lights up; resting the pointer on a number says what pressing it does. While a Win顺 window is in front they are Win顺's, even if another app uses them as global hotkeys. Under Settings › Result list › Display and preview, “Keyboard hints” can hide the shortcuts help button at the right of the search box and the key hints in the footer; capture's All keys button can be hidden among the toolbar buttons.
- **Letter jump** (off by default; Settings › Result list › Behavior › Letter jump): tap a key by itself and every row in view gets a letter; the letter opens that row, the rows past the ninth too, with one hand. The key is the number keys' modifier unless you choose `Ctrl`, `Alt` or `Shift`, and the letters and their order are yours too, digits included (for example `QWERTASDFGZXCVB12345` for the left hand). The bar under Open and Save dialogs has the letters too (a letter goes there, as `Enter`). In the search box `Shift`+letter picks that row and puts letters on its buttons (open location, terminal, copy, copy path, delete twice); in the clipboard it selects or unselects that row and the letters stay, so you can pick several and paste them together with `Enter`; in the dialog bar it only selects the row. The tap again or `Esc` leaves. With the number keys off and Letter jump on (0.45.0), Number key hints decides a passive preview of the letters: Always show (the default) keeps quiet plain letters beside the rows (resting the pointer on one says “Tap Ctrl, then X”) and, once the key is tapped, they turn into solid accent keycaps and a letter jumps; Show while held shows them after the key is held about 0.2 s; Never shows them only after the tap. With the number keys on, the letters come only after the tap, as before. The key is `Ctrl` by default when the number keys are off.
- **Open an address**: with the Web search plugin on, a web address typed in the search box (`github.com/LingCore`, `baidu.com`, `localhost:3000`, with or without `https://`) gets an "Open the address" row first; a file of that very name on the PC stays first. Names that look like files (`main.py`, `notes.md`) are not addresses.
- **Fill in what was just copied** (off by default; Settings › Result list › Behavior): one line copied in another program at most 3, 5 or 10 seconds before the search box opens is searched at once, selected so typing replaces it.
- **Search panel**: too many hits? The small button at the box's corner or `Ctrl+E` grows the same window into a panel, as Listary has it: filters down the left (scope, kind, date modified, size, folder, name), sortable columns on the right; right-click headers to choose name, path, type, size, modification and creation times, folder or source, and drag to reorder or resize them; the layout is saved; with nothing typed it browses the whole index by those filters (milliseconds over three million files). A custom size takes a unit (`40 KB`, `1.5 GB`; a bare number is MB) and a custom date `2026` or `2026-3` for a whole year or month; a box it cannot read is underlined in red (0.38.0). `size:>10mb` and `dm:7d` work in the box too. **Name** (0.46.0, #457) opens three boxes, no syntax to remember: *Starts with* (`IMG_2026`), *Ends with* (`final` finds `report final.docx`: the end before the extension, though `.docx` can be written too) and *Without*, words kept out, separated by spaces (`draft copy` hides names with either). What is typed is taken as it is, not case sensitive, with no pinyin and no regular-expression symbols; the three boxes work together and with the words in the search box and the other filters, and emptying them (or Clear all) or closing the panel takes them off. **Quick filters** (as Everything's filters): save a query you use often under a name, such as `!$RECYCLE.BIN\` as "No Recycle Bin" or `ext:pdf size:>10mb`, with the `+` in the side bar; it becomes a chip that narrows whatever you type at a click, several at once all apply, and content searches skip the files they exclude. Give one a prefix (say `nobin`) and `:nobin report` applies it from the plain search box too, several at once and beside a kind's prefix. One can have a sort of its own (a "Big files" filter, largest first), in force while it is on (0.38.0). Edit them under Settings › Result list › Kinds and filters. Press it again to collapse.
- **Panel hotkey** (0.30.0): the hotkey set for "Open the full search panel" under Settings › Shortcuts › Open WinShun closes the panel when pressed again while it is up and in front (before, only `Esc` did); with the small search box up, it expands the box into the panel.
- **Long names**: a name that does not fit is shortened in the middle, keeping its extension and end ("…v3 final.xlsx"); rest the pointer on the row to see the full name, location, size, modified and created times. Drag the left or right edge of the search box to widen it (the width is remembered; double-click an edge for the default).
- **File sizes**: Settings › Result list › Display & preview can show sizes in the compact results, alongside modification dates or on their own. Off by default; sorting by size always shows sizes. Folders and unknown sizes stay blank.
- **Logo controls**: the WinShun logo on the left opens settings with a left click, toggles pinning with a middle click (`Ctrl+T` also works), and opens the position menu with a right click. Settings › Result list › Behavior › Logo right click can make that one click straight to the top, the center or the last dragged position; the logo's tooltip names it. Drag it to move the window. A switch beside that setting hides the logo for a plainer box: the words start where it was, the small bar at the top still moves the window, and a pin key appears before the scope tabs while pinned. A pin badge shows when pinned: clicks elsewhere and opened files keep the box up; `Esc` closes it. Open a result and come back within a minute with the same words, and the footer points to `Ctrl+T` (twice at most, never after the first pin).
- **A pinned box is a window of its own** (0.43.0): pinned with `Ctrl+T`, it gets a taskbar button and shows in `Alt+Tab`; its button or `Win+D` minimizes it, and the opening shortcut, the button or `Win+D` again brings it back where it stood. Closed from the taskbar while minimized, it opens as always next time. Unpinned, it is what it was; there is no setting for this. What is opened from a pinned box (a file, a folder, a program) comes up in front of it, kept on top or not: the box and its preview stay behind with the same results, and the opening shortcut, a click on it or its taskbar button brings them back over the other windows for the next result, the list as it was left: the same rows in the same order, on the row you were on, not searched again. A file or folder opened from the results is tagged Opened after its name for as long as the same words are searched for (another scope, a kind filter, the box closed and opened again), so those looked at already are told from the rest among many of the same name; other words clear the tags. Settings › Result list › Behavior › Keep the search box pinned (off by default) pins it from the start, with no `Ctrl+T` after each restart: it stays up as results are opened and closes on `Esc`; `Ctrl+T` still unpins it until WinShun starts again.
- **Preview**: `Alt+P` on a result (or Preview in its menu) shows the file without leaving the launcher: pictures, text (UTF-8 or GBK, detected), Word, Excel, PowerPoint and PDF (through the same preview handlers as File Explorer's preview pane; where this PC has none, as with only WPS or no office suite, or for a file downloaded from the internet, the document's text, by page, slide or sheet, with Excel's own row numbers), what a folder holds; the arrows move it to the next row, `Alt+P` again (or the × on the preview) closes it; the enlarge key in its header (or a double click on the header) makes it as tall as the screen and wide to its right edge, over the launcher but never over its names, so the box stays in use, and it stays enlarged until put back; `Esc` closes the launcher and leaves the preview as it is, so it is back the next time the launcher opens (turn off Restore preview on reopen under Settings › Result list › File quick preview to close it with the launcher). Code, JSON, YAML, INI / TOML, XML / HTML and Markdown are coloured, and the words searched for are marked with a highlighter's fill and bold and scrolled into sight, the line of the first one banded across (0.51.0, #482; a colour alone was lost among the colours of code). When the box is emptied and nothing is listed, the preview window steps aside and comes back with the next file (0.51.0, #492). Illustrator `.ai` and Photoshop `.psd` / `.psb` files are drawn as pictures without Adobe's software (an `.ai` trimmed to what is drawn on its artboard). QuickLook or Seer, when running in the background, shows it instead. The result preview shortcut can be changed to Space, a function key, or an unused chord in Settings; Shift+Space still types a space.
- **Thumbnails**: pictures, videos, PDFs and the like show their thumbnail instead of their type's icon, in the results and in the search bar beside Open / Save dialogs; Settings › Result list can turn them off. Types a program installed on the PC makes thumbnails of (CorelDRAW's `.cdr`, a slicer's `.stl` / `.3mf`, CAD drawings, SVG: whatever File Explorer shows a thumbnail for) show theirs too; Office documents and shortcuts keep their icons.
- **Context menu**: right-click a row for its location, Copy path, Add to favorites, Open in terminal (the Command Prompt, or under Settings › Result list › 操作习惯 Windows PowerShell, PowerShell 7, Windows Terminal with its default profile, Git Bash, WSL, whichever are installed, or a command line of your own run in that folder with `{query}` for it) and more. In the action menu (right-click, `→` or `Ctrl+O`), Open in Terminal as administrator sits right below Open in Terminal, using the same terminal; `Shift`+click on a row's terminal button does the same, and on a file it opens the file's folder; `Shift`+right-click (or More options in that menu) brings up Windows' own full context menu, as in File Explorer, for one row or several, in one folder or not (#464): with two files picked it has a diff tool's Compare, and compressing, Copy, Cut, Delete and Properties are for all of them (Create shortcut then puts the shortcuts on the desktop); after copy, cut or delete the search box stays open. With 默认使用系统右键菜单 on (Settings › Result list › Behavior, off by default, 0.43.0) it is the other way round: a right click on a file or folder brings up Windows' own menu and `Shift`+right-click WinShun's (whose More options row then says right click); apps, plugins and web rows, which have no system menu, keep WinShun's; the Menu key and `Shift+F10` swap too (they bring up Windows' menu, `Shift`+Menu and `Ctrl+Shift+F10` WinShun's), and `Ctrl+O` stays WinShun's menu.
- **Run as administrator, remembered**: with "Remember “Run as administrator”" on (Settings › Result list › Behavior, off by default), an app or program run once with `Ctrl+Shift+Enter` runs as administrator on `Enter` from then on; its row says Admin, and "Run with normal rights" in its menu makes `Enter` plain again.
- **Scope remembered**: the scope you chose (All, Files, Content or a kind) comes back at the next start, unless Clear the search on every opening is on; a typed prefix or a plugin row does not change it.
- **By kind**: under **Files**, a row of kinds (folders, documents, pictures, videos, archives…); `Ctrl+Tab` steps through them, `+` adds your own. Hold a kind and drag it sideways to put it elsewhere: the others make way, and held at either end the row scrolls on. Folders moves too; No limit stays first. Settings › Result list › Kinds and filters › File types has the same order, with a handle on each row and Move up / down; the search panel and `Ctrl+Tab` follow it, and Restore defaults restores it.
- **Just files and folders** (0.50.0): a kind whose extension is `*` (or `*.*`) is every file, with or without an extension, and no folder: what No limit finds less the folders. Delete the kinds you do not want, add one called Files with `*`, and the row is No limit, Folders, Files. `ext:` typed still narrows it; its number counts the files found.
- **Files you never want to see**: Settings › Search scope skips some types and file names, with `*` and `?` wildcards; by default the `~$` temporary files Office and WPS make beside open documents. Typing such a name in the box still finds it. A link under the excluded folders leads there (0.36.0).
- **Folders to index or to skip, typed or pasted** (0.43.0): Settings › Search scope › Folders has a box above both lists, 索引的文件夹 and 不搜索的文件夹: paste or type a path and click Add (quotes and forward slashes are fine), or use the folder picker. Environment variables such as `%USERPROFILE%\Documents` or `%TEMP%` work too; they are kept as written, so the list still fits another PC or user name, and resting the pointer on an entry shows what it stands for now (当前展开为). A bare name typed among the folders to skip points you to 名称和类型 on the next tab, where names and types are skipped.
- **Excluded folders, looked at on demand**: when a file-name search finds nothing, or some matches lie in the folders to skip (such as `%TEMP%` and Windows' cache folders) or are of a skipped type, the box adds a line such as “N items in excluded folders” or “N skipped files matched”. Show this time lists them for this search only, and Exclusions… (Settings… on the skipped-files line) opens the matching setting. Type a path inside an excluded folder and it offers Search it this time, which walks that folder on the disk once; a path outside the indexed folders offers Add to the index. When only the folders you chose are indexed it may say “Only the folders you chose are indexed; more may be elsewhere”, with Don't show again. A skipped extension typed out in full (`report.bak`) lists those files. The full search panel has the same lines.
- **Drag out**: drag results into a chat, a mail or Explorer. Drag with the **right** button into Explorer and on release it asks what to do: copy, move, make a shortcut, or an archive tool's "extract here"; a right click without moving still opens the row's menu (0.32.0).
- **Rename in place**: `F2` on a file or folder (or Rename in its menu) turns the name into a box with everything before the extension selected; `Enter` renames through the shell, so `Ctrl+Z` in File Explorer takes it back, and `Esc` leaves the name alone. A name Windows refuses, or one already taken there, is explained in the footer. One row at a time.
- **Quick filters**: save a query under a name, as Everything's filters do (`!$RECYCLE.BIN\`, `ext:pdf size:>10mb`). Each is one click in the panel's filters, and all that are on must match; they also apply to content searches. Give one a prefix under Settings › Result list › Kinds and filters and `:nobin report` applies it from the plain box.
- **A file kind bound to a folder**: a kind under Settings › Result list › File types can name the folders it searches, so `cw:` lists the CSV files of one work folder.
- **Counts on the type chips**: with something typed in Files, each chip under the search box shows how many matches that kind has, after its name; “Any” is the total and “Folders” the folders. The other kinds keep their numbers while one is chosen. Above 9999 a number is shortened (`12k`). On by default; Settings › Result list › File types › Counts on the type chips turns it off.
- **A second key for Enter**: Settings › Result list › Behavior can record another key (a function key, or an unused Ctrl / Alt chord) that opens the selected result as `Enter` does. None by default; never Space.
- **Live updates**: the USN change journal is read, so renamed, new and deleted files are found at once; unplugging a USB drive never says it is in use.
- **Installing the index service from the portable edition** (Settings › Search scope › Disks › 索引方式): WinShun copies the service into a place only administrators can write to, never to run from your downloads or desktop. Where this PC's Program Files permissions have been changed, it tries `%ProgramFiles%\WinShun Service`, `%ProgramData%\WinShun Service` and `%ProgramFiles(x86)%\WinShun Service` in turn and takes the first that ordinary users cannot write to, with no console window (0.43.0; before, one place was tried and it ended in “error 5”). When none will do, the settings name the folder and what is wrong with it (`C:\` owned by an account that is not an administrator's, say, or an account allowed to change `C:\Program Files`) and give the commands that put it right: choose 复制命令, paste them into Command Prompt (Admin), run them and install again. The commands touch that one folder only: they give it back to the Administrators group, or leave that account able to read and run; `service.log` has the details.
- **Large icons**: switch the search panel between a list and a thumbnail grid. The grid has no column headers, so the footer's chips order it (best match / newest / oldest, More for name, folder, type and size) and show the order in use (#483). Resize previews with the slider or `Alt`+wheel, select several file categories together, and keep the normal selection, menus and file dragging. The view and thumbnail size are remembered. A plugin row that opens a file (an Image text search result opens a picture) shows that file's thumbnail, here and in the list, not the plugin's icon; a row whose plugin draws its own details (mail) keeps the plugin's icon (0.45.0, #448).
- **Into folders, a level at a time** (GitHub #361): put the keyboard on a folder found (`↑` `↓`, or a click) and `Tab` goes into it: the box holds its path and lists what is in it, ready to search there; `Tab` on a folder in there goes on down. `Ctrl+Backspace` (the caret at the end) comes back a level: out of a folder entered with `Tab`, back to the words and the scope searched before, that folder selected again; on a path typed, to the folder above, the one left selected; a half-typed name goes first. A half-typed path (`D:\Wo`) completes to the folder listed first. The row the list selects by itself keeps `Tab` for the scopes (press `↑` or `↓` on it first); so do Content, regex mode and plugin keywords. The search box that opens when you type in a folder's File Explorer window does the same (0.46.0, #454): what you type is read as a path from that folder, so part of a subfolder's name (or `subfolder\next`) is completed by `Tab` and stepped into, and the box carries on showing the full path; `Ctrl+Backspace` comes back to the window's folder with the words and the way it was searched.
- **Query syntax**: `"exact phrase"`, `!exclude`, `!node_modules\`, wildcards `*` `?`, `ext:pdf,docx`, `folder\name`, and paths (`D:\My Files\`, `tools/out/`). Add OR groups (`report | summary 2026`, AND takes precedence), name anchors (`^IMG`, `.pdf$`), `regex:^IMG_\d+\.(jpg|png)$`, or independent FZF subsequence terms (`fz:rpt`, `fuzzy:nsrch`); invalid regex expressions explain the error. `Ctrl+R` turns on regex mode, where every word is a regex, as in Everything. `:pictures,videos` combines type keywords.
- **Optional FZF fuzzy matching**: configured independently under Settings › Result list › Display and preview › Additional search sources and matching modes › Fuzzy matching (FZF) (`Off`, `On no results` by default, or `Always on`). In `On no results`, normal file search stays deterministic with zero overhead and only falls back to FZF (≥3 characters, with a clear banner and discrete highlights) when nothing matches, while installed apps also support word-boundary fuzzy matching (`vcode` → Visual Studio Code). Turn it `Off` for pure deterministic matching everywhere (`fz:` still works on demand), or choose `Always on` to rank normal matches first and fuzzy matches after (with a clickable `fz` badge beside the search box). Quoted terms, plain `!exclusions`, Everything compatibility and saved quick filters always stay deterministic. An app found only by a fuzzy guess is lifted by use only when you opened it for those letters before, so one used every day no longer passes an app named as typed (`tim` lists TIM before System Informer; 0.51.0).
- **WSL file search**: add a Linux project or home folder under Settings › Search scope › Network & WSL. Installed distributions appear automatically. Search file and folder names alongside local files, including pinyin; indexed results remain available while WSL is stopped and update automatically when it runs again.
- **Remote scan controls**: each network or WSL folder has independent daily scan hours (including overnight windows) and a maximum depth. Depth 0 is unlimited; depth 1 lists only the chosen folder. Background name and content reads pause outside those hours; cached results remain searchable. Check now runs one manual name scan, still respecting depth. Both limits are off by default.

## Full-text search

- **Content details pane**: the `Ctrl+E` panel offers Summary, Hits, Text, native Preview and Report tabs. Read all available matches, refine hits and context, inspect Excel sheets with real row numbers, and copy, print or export text, CSV, HTML and XLSX. Full counts run on request; partial results are labelled. While the pane is open, a click on a file only selects it (the pane follows) and a double-click or `Enter` opens it; `F11` fills the screen with the panel, and again puts it back (0.33.0).
- **How many files** (0.51.0, #476): in **Content**, the panel's footer says how many files hold the words: “N files found so far…” while the scan goes on, “N files in all” when it is done, “N files listed, scroll down for more” when scrolling brings more.
- **What**: the **Content** scope searches inside txt, md, logs, source code and **Word, Excel, PowerPoint, PDF and WPS** files, showing the page, slide or sheet and row.
- **Quieter everyday searches**: **All** adds matches from the existing content index without launching document parsers. Choose **Search contents** when offered, or switch to **Content**, to read files that have not been indexed yet.
- **Either word, and regular expressions**: `now|soon` (or `now | soon`) finds files with either word; with other words, those and either. A word after `regex:` or `re:` is a regular expression matched within a line, any case unless it starts with `(?-i)`; in regex mode (`Ctrl+R`) every word is one. An expression with some fixed text in it (`invoice-[0-9]+`) is as fast as a word with the content index on; one with none reads every file. A broken expression says why. `ws grep` and the MCP tool `search_content` take the same.
- **In one folder**: add a folder's name and a slash, `annual report abc/`, to search only in folders named abc (`/abc` last works too; `work/abc/` takes the one in work); folders of the same name are all searched and listed under the box, `Ctrl+Tab` picks one. Or pick a favorite folder there, or right-click a folder in the results → Search contents in this folder.
- **Only some kinds of file** (0.45.0, #447): in **Content**, choosing a kind in the panel's filter (Pictures, Documents…) no longer jumps to Files: it stays in Content and reads only those kinds, plugin rows such as Image text search narrowed with them. The kinds are for this opening only, not saved, and are kept across a trip to Files; each shows first in the strip under the box with Files' icon and colour, a click removes it, the No limit chip removes them all and `Ctrl+Tab` still goes round the folders only. Files of other kinds are neither read nor counted as passed over, so the “not in content search's types” line stays quiet. The placeholder names them (“Search Pictures for text”).
- **Typed file types and names**: written as in a name search, before or after the words: `annual report *.docx` or `annual report ext:docx` reads Word documents only, `TODO ext:py;js` those two types, `contract report*.pdf` PDFs whose names start so, `error !*.min.js` leaves minified scripts out. What was understood shows first in the strip under the box (a funnel); a click takes it out of the box. A word with `*` needs a dot to count (`*.py`): `**note**` and `a*b` are still text, and `"*.py"` in quotes is searched for as it is. Regex mode (`Ctrl+R`) reads every word as an expression, so use the kinds above there. Works with folders (`annual report *.docx finance/`), narrows plugin rows such as Image text search, and `ws grep` and the MCP tool `search_content` take the same.
- **How**: ranked by relevance, with a content index for speed; UTF-8, UTF-16 and GBK are detected. The first content index reads text files straight from the disk through the index service, so antivirus does not check them one by one and it is done much sooner. Files over the size limit, in system folders or of unlisted text types are skipped; the list says how many of each, and one click searches them too.
- **Without the index service**: it works too, only slower, as the files are read as you search.
- **Safety**: documents are read by a separate process with restricted rights.

## Apps and settings

The star on a hovered tile adds it to or takes it from the favorites; a right-click opens the menu a row has. The panel and the dialog bar do not have this tab.
- **Apps › Running** (0.29.0): the first chip, Running, lists the windows open right now as tiles (icon and window title). `Enter` or a click switches to that window, restoring it if it is minimized, instead of starting the program again; typing narrows them, and the list follows windows as they open and close. - **WinShun itself**: `admin` (管理员, 提权) lists Restart WinShun as administrator, for plugins that need it (an in-app update started while it runs so asks for administrator rights once more afterwards, 0.34.0+); `winshun`, `issue` or 反馈 lists its issue tracker and discussions.
- **Settings**: about 1,200 Windows settings pages and Control Panel items (`ncpa.cpl`, “network adapter”), plus Group Policy, Disk Management, hosts, AppData and more.
- **Power and session commands** (0.45.0, #428; part of the System switches plugin, #477): type shutdown, restart, sleep, hibernate, lock or signout (关机, 重启, 睡眠, 休眠, 锁屏 and 注销 work too) for the matching row. They come with the System switches plugin: without it there are no such rows, and with it “Power commands in search” on its card turns them off while the switches stay. They are listed in All like the system settings and hidden with “Search system settings”; sleep and hibernate are left out where the PC does not support them. Everything but lock asks twice: the first `Enter` or click arms the row (“Press Enter or click again to confirm Shut down · Esc to cancel”) and a second one within 5 seconds runs it; `Esc`, another query, another row or the timeout disarms it. Lock runs at once. Nothing is forced, so programs with unsaved work still ask. Pinyin and initials work as well: `gj` or `guanji` is 关机 (shut down), `cq` restart, `sm` sleep, `xm` hibernate, `zx` sign out; a whole name typed so ranks as the Chinese word does, since the first `Enter` only arms the row, yet behind any app, file or folder whose name has those letters as typed (a folder `GJ`). A guess that fits only part of a name, a word shared by several of them (`dy`, 电源) and lock, which runs at once (`sp`), still rank behind apps and ordinary pages. History never lifts these rows, and opening several selected rows skips them; the folder menu only runs lock and, for the rest, says to search and confirm in the search box.
- Searching for files only? Turn off app and settings results in the settings, and All lists files and content alone.
- **System switches plugin**: enable it in Settings → Plugins. Off for fresh profiles; upgrades preserve the previous system-search choice. Dark mode, hidden files, file extensions, Bluetooth, WLAN, volume and mute, keep awake, each with its live state at the end of its row; `Enter` flips it in place and the box stays open, `Ctrl+Enter` opens its settings page. `bluetooth off`, `mute` and `volume 30` act in one step; `awake 1h` keeps the PC awake for an hour.

With "The words after the keyword find files" on for a command (off by default), `code my project` lists the files and folders that `my project` finds, and `Enter` on one hands its full path to the command; the command's own row comes last, or first when the words are a path that exists. - **Your commands in the right-click menu of files** (0.29.0, off by default): tick "Show in the right-click menu of files and folders" on a command (it needs `{query}`) and a right-click on a file or folder in File Explorer offers "WinShun commands ›" with these commands. Choosing one hands the full path to `{query}`; the working folder is the command's own, or else the folder the file is in. Under "Show more options" on Windows 11.
- **Press `` ` `` while dragging**: hold the left button on files or folders (no need to drag yet; File Explorer, the desktop, Total Commander or another program) and press the key below `Esc` (it types nothing during the drag): your favorite folders appear round the pointer, 8 to a page. On the way to a column the pointer can cross other folders without switching, resting in the middle closes the columns, and a column too long for the screen scrolls while the pointer rests on the arrow at its top or bottom. The progress and name-conflict windows are Windows' own, and `Ctrl+Z` in File Explorer undoes it. Let go in the middle or press `Esc` and nothing happens; press the key again or drag further away and it closes, and the drag goes on as usual. On by default; turn it off in Settings › Favorites (“Press ` while dragging files to bring up the favorites pie”). It does not work while WinShun itself runs as administrator.

## Open and Save dialogs

- **Search bar**: a search bar under every file dialog; type a name (pinyin too), press Enter, and the dialog goes there; a file opens straight away in an Open dialog, as Enter opens it in the search box, while `Ctrl+Enter` only goes to its folder and selects it (Save As and dialogs of programs run as administrator go there and fill the name in, the button stays yours); web page uploads, WPS dialogs and the "Browse For Folder" box of VBA macros too. The "Browse for folder" window of installers made with Inno Setup has it as well: a pick only fills in the path, and you press the installer's OK yourself (the Start Menu folder picker is left alone). The extraction path windows of Bandizip, 7-Zip and WinRAR have the bar too: a pick writes the folder into their path box, and OK stays yours (run against the real Bandizip 7.36; 7-Zip and WinRAR with stand-in windows).
- **Where the bar goes**: under the dialog while the bar fits there (Auto and Below), its list opening upward when there is no room under it. A dialog that reaches the bottom of the screen or is maximised gets the bar over the taskbar at the bottom (on top, at most 800 wide so the tray and clock stay in view), clear of the dialog's title and address bar, as Listary does (0.33.0). Beside it only when not even that fits. Below also makes a dialog that is too tall shorter when it first shows, for two rows of results; Auto leaves it as it is.
- **`Ctrl+G`**: jumps to the folder open in File Explorer, Total Commander, Directory Opus, XYplorer, Pulse or OneCommander, like Listary. OneCommander uses its active pane's folder, with no extra setup; dialog suggestions can also list its other open tabs, falling back to the active folder while tab state is out of sync. When XYplorer's scripting does not answer (the free edition, XYplorer run as administrator, a popup open), the folder is read from its address bar and window title instead, and WPS's Open and Save dialogs are gone to every time they are reopened, not only the first (0.45.0).
- **Numbers**: the bar has the number keys too, marking the rows in view and following the list as it scrolls. Number key hints (Settings › Result list › Behavior; hold-only, always or never) is one setting shared by the search box, the clipboard and this bar. While the list is scrolled, the bottom of the bar shows where you are (`6–10 / 18`) and the scroll bar lights up; resting the pointer on a number says what pressing it does.
- **Only the dialog's folder**: `Ctrl+Shift+D` in the bar, or "Only inside …" in its "…" menu, searches only the folder the dialog is showing and what lies in it; the folder's name appears before the text and follows the dialog. The same key, a click on that name or the menu brings the whole PC back. The choice is remembered.
- **Suggestions**: open folders, a path you just copied, favorites and recent folders, listed as soon as you click into the bar with nothing typed. With 点进来就列出常用位置 off (Settings › Integration › Dialogs, or the bar's right-click menu; on by default; 0.43.0) nothing is listed on the click: they appear once you type, or press `↓`, and stay until the bar loses focus. Under “What common places to list” in the same place (0.45.0, #438) four sources, all on by default, can be ticked off one by one: open folders, a path on the clipboard, favorites and recent folders. A source left unticked never appears, not even on `↓`, and searching is unaffected; with all four unticked nothing is suggested before you type.
- **Going there by itself**: optional, as the dialog opens, or only when you come back to it from the file manager. Coming back, it goes to the folder in front there every time, even when that window showed it all along; only a folder the dialog was just sent to is not repeated (0.31.0).
- **Programs run as administrator**: with the index service installed, `Ctrl+G` and going there by itself also work in dialogs of programs run as administrator, including Windows XP style Open / Save dialogs and AutoCAD's own file window (the folder is put into the file name box, OK is sent once, and your file name is put back). A file picked in the search bar goes there with its name filled in; Open or Save stays yours. Without the service, the path is copied for you to paste.
- **Blender**: enable the [file-dialog extension](../integrations/blender/winshun_file_dialog/README.md) to use WinShun in separate Open, Save As and Import windows. Save/Export confirmation stays in Blender. Tested on Windows x64 with Blender 5.2; see the [dialog compatibility notes](dialog-compatibility.md).
- **Programs' own file windows**: a file window a program draws itself (ArcGIS's "Add Data", say) is not a Windows dialog, so WinShun does not know it until you show it once: open that window, click "Learn a window" under Settings › Integration › Dialogs, and within five seconds switch back to the window and click into the box that takes the file name. From then on the search bar, `Ctrl+G` and going there by itself work on it: a folder is typed into that box and confirmed with Enter, a file goes in as its whole path and is confirmed too, while `Ctrl+Enter` goes to its folder and leaves its name in the box for you to confirm. It needs a window that already goes to a path typed into its name box. The rules live in `dialogs.json` in the data folder ("Rules file"; a saved change applies at once): the program, the window (`class`, `title`, `*` for any run of characters), the box (`box`: `type`, `id`, `name`, `class`, `index`) and what confirms it (`confirm`: `"enter"` or a button). Not for programs run as administrator.

- **Search**: pinyin, `@app` filters, and **words in copied pictures** (Windows recognition by default; install enhanced recognition for PaddleOCR, with better Chinese, English, numbers and small print; its optional high-accuracy model (about 22 MB, under the same setting) adds Japanese, traditional Chinese and many more rare characters for screenshots, clipboard pictures and picture search, and “Use a model I downloaded…” takes any PP-OCR recognition model in ONNX format (a larger one, or another language's) after a trial reading. Since 0.39.0 a very long, thin picture (say 33,000 × 35 px) is read in about the memory of an ordinary screenshot instead of several GB, and a picture the program crashed on twice while reading it is no longer read: it stays, without searchable words).
- **Preview**: full text, pictures, HEX / RGB / HSL color values. The eye button (or `Alt+P`) opens and closes it; while it is open, the row under the mouse is shown. It is wider now, and the line beside it can be dragged, the width remembered.
- **Original image formats**: PNG, JPEG and GIF data supplied by the source are kept as received; bitmap-only copies become PNG. Drag pictures into a folder or paste them into File Explorer to save them in their stored format. Select several with Ctrl or Shift to save them together. GIF previews can play and pause.
- **Paste**: double-click or `Enter`, or one click as in Windows' own history (an option). Number hints on the icons are always visible by default and can be adjusted in Settings.
- **Paste as plain text by default** (0.45.0, off by default): Settings › Clipboard › Recording › Paste actions and list display › “Paste as plain text by default”. On, a click, double click, `Enter`, `Alt+1`–`9` (the number keys set for the panel) and the keys of “Paste without opening the panel” paste words without their font, colour or link formatting; `Shift+Enter`, `Alt+Shift+1`–`9` and the menu's “Paste with formatting” (only on an entry that has formatting) keep it. Files and pictures paste as they are, a copy keeps every format, and several picked entries still go as their joined words. The pinned status line, the shortcut list and the preview's hint say which way `Shift` goes. The global “Paste as plain text” shortcut is separate and always pastes plain.
- **Photoshop and Illustrator** (#432): they read the clipboard only as they come to the front, so a picture chosen in the clipboard used to paste as the one read last. For these two programs (recognised by file name) WinShun gives the front to an unseen window of its own and straight back once the clipboard is written, waits 0.15 s, then presses `Ctrl+V`; an entry only copied there (`Ctrl+C`, or Copy in its menu) and pasted with Photoshop's own `Ctrl+V` is the one copied too. Every other program keeps the focus throughout.
- **Into programs run as administrator**: Windows drops the keys a normal program sends them, so the index service presses the one paste chord for you (Settings › Clipboard › Paste into programs run as administrator, on by default). Without the service the entry is copied and you press `Ctrl+V`.
- **Paste without opening it**: Settings › Clipboard › Shortcuts › “Paste without opening the panel” (`Ctrl+1–9` or `Alt+1–9`) pastes the first nine entries straight into any program, format kept. Off by default; when on, those keys no longer do their usual job in other programs (switching browser tabs, say).
- **A shortcut for one entry** (0.47.0), as in Ditto: right-click an entry, choose “Set shortcut…”, and settings open on that entry under Settings › Clipboard › Shortcuts › Shortcuts for single entries; press the keys you want (`Ctrl+Alt+1`, say). From then on those keys paste that entry into any program without opening the clipboard, wherever it stands in the list, formatted as a usual paste (plain when “Paste as plain text by default” is on). An entry with a shortcut goes into Pinned (or stays in its group) so it never expires, and shows its keys at the right of its row and in Settings › Shortcuts › Keys at a glance. One shortcut, one entry: keys already given to another entry, taken by WinShun itself or by another program or Windows are refused with a line in red saying which. “Change shortcut (…)…” and “Remove shortcut” in the entry's menu, or Clear in the settings, change it; deleting the entry drops its keys, and `Ctrl+Z` brings them back. Up to 200 entries.
- **Hold and press again**, as in Ditto: Settings › Clipboard › Shortcuts › “Hold and press again, release to paste”. Keep the shortcut's Ctrl, Alt, Shift or Win held: each further press moves one entry down, and letting go pastes it; held about a second, letting go pastes the first entry; `Esc` while holding pastes nothing. Off by default. It works over programs run as administrator too, while pasting into them is on.
- **Upload boxes**: in a Windows “Open” file box, pasting files from the clipboard history puts their full paths in the File name field, several at once if you like; then click Open.
- **Equations and embedded objects**: an equation copied from Word is kept as formatted text, shown as it looked (as one from WPS), and pastes back into Word as an equation you can still edit; `Shift+Enter` pastes it as a line of text (0.38.0; it used to be a picture entry). An embedded object (or an equation from an editor that gives no formatted text) is kept as a picture entry, with its text, which you can search, and pasted back as an object you can still edit; a program that only takes pictures gets the picture. (Tested with Word.)
- **Organize**: pins, groups, multi-paste in order, and `Alt+1`…`Alt+9`; pinned items can come first, and the order is yours to drag or move with `Ctrl+↑`/`↓`. `Ctrl+A` picks every listed entry, Delete all in the row menu clears them at once, and `Ctrl+Z` brings them back. A note of your own on an entry (Add note in its menu) leads it in bold and is found by the search, pinyin included; pick one of seven colours beside the box (or `Tab` through them) to tell kinds of entries apart at a glance, each readable in light and dark.
- **Keep duplicates** (0.47.0, off by default): copying something already in the history normally moves that entry to the top instead of adding one. Turn on Settings › Clipboard › Recording › Keep duplicates to record every copy, as Ditto does. The same content copied twice in a row is two entries too; only a repeat within half a second counts as the same copy (some programs write the clipboard twice for one copy). Pasting from the clipboard is not a copy, so it adds none. Turned off again, the duplicates already kept stay.
- **Copied files that are gone**: their entry says “no longer there”, and can be hidden or cleaned out automatically (pinned and grouped entries stay; a pulled-out USB drive does not count).
- **Import**: Settings › Clipboard › Keeping › Import clipboard history takes a Ditto database (one click if Ditto is installed), `.txt` text and `.csv` tables (GBK files saved by Chinese Excel are recognised); what is imported goes into a new group, is never cleaned out automatically, and entries you already have are skipped.
- **Back up and restore**: Settings › Clipboard › Keeping › Back up and restore. “Back up…” saves the whole history, with its groups, notes, entry shortcuts and pictures, as one ZIP file; “Restore…” on a new PC, or after reinstalling Windows, replaces the history there with the backup's and restarts WinShun once. Entries in no group are still cleaned out by the item and time limits after a restore. A file that fails its checks leaves the history untouched and says why. It is a separate file from the settings backup under Settings › General, which leaves the clipboard history out.
- **Screenshots in the history**: Keep pictures under Settings › Clipboard › Record now covers pictures copied elsewhere only; screenshots taken with the Screenshot and recording plugin have a row of their own below it, Keep screenshots. All (the default) puts copied, pinned and saved screenshots into the history; Copied only keeps just the ones you click Copy on; Off keeps none (copying still puts the picture on the system clipboard, so it can be pasted). After an upgrade with Keep pictures off, Keep screenshots starts at Off.
- **Privacy**: passwords from password managers are not kept, and the history stays on your PC.
- **Programs left out**: Settings › Clipboard › "Don’t keep copies from these programs". When one of them copies, WinShun does not even open the clipboard. If copy and paste misbehaves in a program while WinShun runs (someone reported ArcMap not pasting copied features), adding it there is the first thing to try.

## Screenshots and recording

- **Keys on a pin** (Screenshot and recording 1.1.14): after a click on it, `E` edits, `O` reads its text, `Shift+C` copies all its words (1.1.31), `Shift+F` reads a formula in it (1.1.40), `U` sends it to the top edge and back; changeable under Keys › Pin window. A tab on the top edge can be dragged left and right along that edge when it is in the way (0.46.0, #456); it stops at the ends of the screen and, let go over another pin's tab, goes beside it; a click still opens it.
- **Pin from File Explorer** (0.29.0): right-click a picture file › Pin to screen (WinShun); see In File Explorer.

The Screenshot and recording plugin comes with the setup and the portable copy: turned on in the first-run guide it is installed from there, with no download, and updated from the plugin library like the others; otherwise install it in Settings › Plugins › Plugin library. Record your own shortcut under Settings on its card (the first-run guide picks `F1`, or `Ctrl+Alt+A`, `Ctrl+Alt+S`, `Ctrl+Alt+X` when that is taken), and turn on `PrtScn` there too if you want it. Who had screenshots on gets it installed with the update, settings as they were.

- **Area and full-screen recording**: choose Record or press `Ctrl+R` after selecting an area, for MP4 or GIF. Switch between Area and Full screen on the controls; Full screen records the entire monitor containing the selection, including its taskbar, and Area restores the original selection. Pause and resume, choose one of four qualities (Ultra, the sharpest, saves a selection up to 1920 × 1080 at twice its size, so small coloured text stays as clear as on screen) and 15, 30 or 60 frames a second for MP4, cursor and click highlights, a cursor trail (a line that follows the pointer and draws back into it when it stops; off by default), and optionally show the shortcuts and mouse buttons pressed as keycaps in a corner (off by default; "All keys" records typing too). MP4 audio is optional and off by default; GIF is silent. Controls stay out of the recording. Choose a save folder (in the recording options, or as “Recording folder” in the screenshot's settings), move the control bar by its grip or by any empty place on it, or record another take without replacing the previous file. Recording also works on Windows 10 1809 (LTSC 2019) from 1.1.30: that version has no display capture in Windows.Graphics.Capture, so the screen is read the classic way, at some more CPU for large areas. While recording, a trash button (“Discard this recording without saving”) throws the take away at once, for MP4 and GIF alike: the partial file is deleted and the panel closes. The options sit in two columns (Quality | Frame rate, Mouse | Keys, Save to across the width; one column when narrow), and a GIF stores only what changed in each frame, so a still background does not shimmer and files are usually smaller.
- **Toolbar and saving**: the toolbar has two rows: the common tools, undo/redo, pin, save, cancel and confirm next to the selection, and the line, highlighter, text recognition, formula, QR, scrolling screenshot, recording, delay and the key list in a shorter second row (the rows swap when the toolbar sits above the selection). The first button, Select (an arrow, 1.1.37), puts the current tool down to select and move again. A click with the pen or the highlighter leaves a dot (#461), and while either is held the pointer is its tip, in its size and colour, in the picture editor too. Drag the toolbar by its left grip together with its style panel. Choose the screenshot save folder and a shortcut to pin the latest screenshot in the screenshot's settings. After a save, click the notification to see the file selected in your file manager.
- **Choosing**: rest the pointer on a window or a button and it is outlined, with everything outside it dimmed; click to take it, or drag an area; the wheel makes the outline larger or smaller. Side panels and buttons in apps that draw their own interface, such as Settings and Calculator, are outlined too (not inside Chromium apps such as Chrome, Edge, VS Code and WeChat, where only the whole window is outlined; drag an area there). `WASD` moves the mouse pointer by one physical pixel (also while the left button is held, so the area follows) and `Shift+WASD` by ten; the arrow keys move the area and `Shift`+arrows resize it. `R` cycles through up to 10 distinct recent areas from this run on the current picture; `Shift+R` cycles in reverse; `,` and `.` step through past captures (the whole screens, the area and the annotations, editable again), the last 10 kept by default.
- **Magnifier and color**: the pixels under the pointer, enlarged; `C` copies the color under it and ends the capture, and `Shift` alone switches between `#RRGGBB`, `rgb()` and `hsl()`. Once an area is chosen, the magnifier shows only inside it.
- **HDR screens**: captures on an HDR screen keep their normal colors. Turn on “Also save an HDR picture on HDR screens” in the screenshot's settings (off by default) and `Ctrl+S` saves a `.jxr` of the same name beside the PNG, with the bright parts as bright as they were; Windows Photos shows it.
- **Copy the words**: `Shift+C` reads the words in the area and copies them; a small card beside the area then says Copied and shows the first lines, and Edit opens the text to change and copy, as Read text on screen does (Screenshot and recording 1.1.41, #489). “Show a card with the result” in the capture settings turns the card off; the words are then copied with nothing shown, unless none were found. On a pin, `Shift+C` shows the same card when its words have not been read yet; words already read are copied at once, as before.
- **Read text on screen**: record a separate “Read text on screen” shortcut under Shortcuts in the capture settings (none by default). Press it, drag over an area or click a window, and when you let go its text is read and copied, with no toolbar and no screenshot kept; a small card beside it says Copied and shows the first lines, and Edit opens the text to change and copy (the card's heading, surface and close button match the OCR window's, Screenshot and recording 1.1.31). It is also in the tray menu and under `cap` in the search box.
- **Shortcut hints**: while capturing, the bottom-left corner lists the keys that work right now: different before choosing, after choosing and with an annotation tool. It waits its turn: it fades in only after a short pause at the start, goes the moment you press a mouse button, and after you choose an area it appears once only if you stop for about 2 seconds, leaving again as soon as you move. It is hidden while you drag or type. When the area or the toolbar covers that corner it moves to the bottom right; when the pointer comes near it turns almost transparent. It never ends up in the picture. `?` shows or hides it for one capture, "Don't show again" turns it off, and "Show shortcut hints while capturing" in the screenshot's settings (Shortcuts) turns it back on.
- **Delay**: `Ctrl+Shift+D`, or Delay on the toolbar, counts down (the seconds are a setting) and freezes the screen only at the end, for menus and tooltips. “Include the mouse cursor” in the settings puts the pointer in the picture (off by default).
- **A full-screen video** (Screenshot and recording 1.1.35 and 1.1.36): a Store app such as Windows' Media Player or Movies & TV in full screen sits above every desktop window, so an ordinary capture would be hidden under it. Press the capture shortcut as usual and the full-screen picture is captured, `Esc` leaves. With the index service installed (0.46.0, 1.1.36), a helper the service starts puts the capture over the player: mouse, keys and the input method work as usual, and the player stays in full screen, with no controls and no taskbar showing; copy, saving into the save folder, cancel, Copy the words (`Shift+C`) and Delay are like that. What opens a window of its own (Pin, Recognize text, QR codes, scrolling screenshot, recording, and Read text on screen, Translate screen region and Capture and pin) first takes the player out of full screen so that its window can be seen, and so does the Save As dialog, after which the player goes back into full screen (the others leave it out). Without the index service (the “only for me” install, or a portable copy that has not installed it), or when the helper cannot start, it works as in 1.1.35: the player leaves full screen before the capture and goes back after copying, saving or cancelling, and if it will not leave, the capture ends with a notification saying why.
- **QR codes**: `Q` reads a QR code in the area and shows its text to copy; for a web address there is an Open link button, and nothing opens until you click it. Small codes and QQ's round, dotted ones are read too.
- **Formulas** (Screenshot and recording 1.1.40, WinShun 0.50.0): `Shift+F` after choosing an area, or Formula on the toolbar's second row (on a pin: `Shift+F` or Read formula in its menu; in the picture editor: Formula on its toolbar) opens Formula recognition. On the left are the picture, the formula as read, drawn, and its LaTeX source: edit the source and the drawing follows; what cannot be drawn, such as an unpaired brace, says so. On the right, pick what to copy: LaTeX (papers, editors), Markdown (note apps, in `$$`), Word equation (pasted into Word it is an equation you can keep editing; other programs get its MathML as text) or Typst. Copy copies it, `Ctrl+Enter` copies and closes, `Esc` closes; the choice is kept. Export copies the drawn formula as a picture or saves it as PNG or SVG. A reading it is unsure of asks you to check it against the picture; a picture without a formula says so. It is for a formula or a line of maths: on a page of mixed text and formulas, choose the formula alone. It reads with Pix2Text's MFR 1.5 model (about 115 MB), which is not bundled: Download model in the window, or Download and install under Settings › Clipboard › Recording › Formula recognition model (Hugging Face's mirror in China first, then Hugging Face, each file checked; or put `encoder_model.onnx`, `decoder_model.onnx` and `tokenizer.json` you downloaded in one folder and pick one with Install from local files…), no restart needed; Remove takes it away. It reads on this PC, nothing is uploaded, usually in under a second.
- **An exact size**: click the size by the selection, or press `F`, to type a width and a height, lock the shape for drags, handles and `Shift`+arrows, or pick from a list of sizes and shapes you can add to. Before selecting, `F` and a size make a selection of that size at the pointer.
- **Marking up**: rectangle, ellipse, arrow, line, curve, path, pen, highlighter, text, numbers and redaction. Curve and path nodes remain adjustable, and the highlighter offers different drawing modes. Numbers can be `1 2 3`, `A B C`, `a b c`, Roman numerals or numbers in circles, and a few words can be typed beside one. Redaction is mosaic, blur, solid or Smooth (covered with the surrounding background, as if wiped away), as a box or a stroke; what is under it cannot be worked back out. `Esc` steps back (Screenshot and recording 1.1.31; while capturing, in the editor and when editing a pin alike): with a tool such as the pen or text in hand, it puts the tool down; with annotations selected, it deselects them; only then does it drop the annotations or close the editor, so an earlier annotation can be picked and changed without clicking the tool off first. Text boxes can be dragged while being edited and while the text tool is on.
- **Smart redaction**: after you rest on an area, WinShun reads it on your PC and finds phone numbers, ID card and bank card numbers, e-mail addresses, keys and this PC's user name, and offers “N found · click to redact”; one click (or the Smart redact button, or `Shift+B`) covers them all and one `Ctrl+Z` takes it back. It can miss some, so look once more before you send.
- **Screenshot translation**: Translate on the capture toolbar pins the selection where it is with its words translated in place: the original words are covered with the background colour and the translation is set where they were, in their colour and at about their size, bold where they were bold and centred where they sat in the middle of a button. A picture already pinned can be translated too: Translate on its menu. "Translating…" shows in the corner meanwhile; `Tab` turns the pin between the original and the translation, and its menu has Show the original and Copy the translation. It is a pin like any other: move it, zoom it, copy it, save it. Made for flat backgrounds such as windows, web pages and documents; words on a photo leave a patch, and slanted lines stay as they are. For plain text, choose Recognize text and then Translate in that window: the original above, the translation below, after editing or selecting some of it if you like (all of it when nothing is selected, up to 3,000 characters). A sentence the screen wrapped onto several lines is put together again before it is translated; short lines such as menus and lists stay one per line. The translation can be selected and copied, and a button copies all of it. It uses the Translate plugin from the plugin library with the service you set there, or any other plugin that says it can translate (0.32.0): the official one is asked first, and the next is tried when one has no service set up or fails; a translator installed but switched off is said so, with a button that turns it on; when the plugin or a service is missing, or the translation fails, the text recognition window opens instead and says so with a button that goes straight to the settings, and you go on from where you were. "Read text and translate" is also among the mouse button actions, and the toolbar button can be turned off in the settings.
- **Translate with a hotkey** (Screenshot and recording 1.1.19): record a “Translate screen region” shortcut under Shortcuts in the capture settings (none by default), or use Screenshot › Translate screen region in the tray menu or `cap`. Drag over an area or click a window, and when you let go the words are translated in place, as Translate on the toolbar does, with no toolbar and nothing in the screenshot history. `Esc`, a right click or the hotkey again cancels. It uses the service set up in the Translate plugin; when that is missing, the OCR window says why.
- **Whole windows only** (1.1.19): before selecting, `Tab` (the key Snipaste uses) outlines whole windows only, not the buttons and boxes inside them; `Tab` or `Shift+Tab` again brings them back. The choice is kept, “Detect whole windows only while selecting” in the settings is the same switch, and it works when reading or translating text on screen too. `Shift`+arrow keys move the pointer ten pixels at a time before a selection.
- **Across monitors** (1.1.30): with more than one monitor, drag a selection from one onto another, or drag a selection or its edge across; scroll the wheel up once past the whole screen to outline every monitor, then click. The picture is each monitor's own pixels side by side, whatever their scaling, with black where no monitor is. The toolbar and size stay on the monitor of the selection's bottom-right corner, and annotations can cross the seam. A selection over several monitors cannot be a long screenshot or a recording.
- **Spotlight** (0.45.0, key `G`): dims the whole picture and leaves the areas you mark. Rectangle or Circle (`Shift` for a square or a true circle); several areas share one veil, so areas that do not touch can be lit together. The veil's opacity is 40%, 60% (the default), 80% or 100%, with the wheel or `[` / `]` for steps lighter and darker; 100% covers everything but the marked areas. Its colour is #000000 (default), #212121, #FFFFFF or anything the eyedropper (`I`) picks. Each area can be moved, resized, deleted, undone and redone; changing the colour or opacity changes all of them, and a new area takes over the veil. The veil sits above redaction and below the other annotations, so arrows and text stay on top and covered pixels stay hidden. It is in the editor too and kept in `.wsedit` files; the presenter has no spotlight (`G` does nothing there).
- **Redact a line with a click**: with the redact tool, a line of text under the pointer gets a red frame; a click covers that line, another click on it shows it again. A click that slips a few pixels still counts as a click, and a covered line clicked with another redaction style chosen takes that style instead of being shown (Screenshot and recording 1.1.41, #499). Dragging still draws a box as before.
- **Scrolling screenshots**: for a web page, a chat, a document or a file list longer than the screen, choose the area and press `Ctrl+L` (or Long screenshot on the toolbar); that key and the recording's `Ctrl+R` can be changed under Keys › While capturing (0.46.0, #455), to a single letter too (`L`, say: the tool that had the letter keeps its digit; `W` `A` `S` `D` `R` `F` `C` `G` `H` `Q` `I` and `Z` are needed by the capture itself and are refused; so are digits, signs and `Shift` with a letter): scroll manually while WinShun stitches the frames, then press `Enter` to open the result in the editor. Turn on Auto-scroll when needed. Content that only scrolls sideways, or keeps moving, does not suit it. Auto-scroll is a steady stream now (0.45.0): small wheel ticks while the frames are stitched as they arrive (it slows down if stitching falls behind), a speed button beside the switch cycles Normal, Fast and Slow for the run, and it stops at the end of the page or at 30,000 px. It follows the direction you last scrolled by hand and switches itself off if you scroll the other way twice or a frame cannot be joined (“Reconnect here”). Where only the real wheel works (WinUI and UWP surfaces), the pointer is parked in the area and given back afterwards; moving it outside the area pauses the scrolling. The panel shows a status line, the size, Vertical / Horizontal and Auto-scroll, with the preview in a window of its own; big animated pictures in a chat and ±1 px jitter no longer throw the stitching off.
- **Finishing**: `Enter` copies it, into the clipboard history too, where the words in it can be searched (Keep screenshots under Settings › Clipboard › Record decides which are kept: all by default, only copied ones, or none); with a save folder chosen in the screenshot's settings, `Ctrl+S` or Save saves straight into it and the arrow beside Save offers “Save as…”; without one, `Ctrl+S` opens the native Save As dialog and the arrow offers “Save to previous folder” (Pictures\Screenshots). Cancelling Save As keeps the selection and annotations. “Pin screenshots when copying” also pins it on the screen whenever it is copied. A marked-up picture can be opened and changed again later, from the clipboard history, the search box or a pin, with multi-select, a color picker and cropping.
- **Pins**: `F3` pins it on the screen, always on top: zoom, change opacity, rotate and flip, fold it to a small tile, read its text, or select the words in it and copy them (the next two bullets). What “Double-clicking a pin” does (back to 100%, close, fold or nothing) is a setting. Capture › Pin image in the tray menu, or the configurable Pin image shortcut, pins a clipboard image first, then copied text (0.38.0, Screenshot and recording 1.1.26); otherwise it restores the last screenshot at its original position with annotations. Text is pinned as a card in the current style and theme, keeping its line breaks and indents (code in a monospaced font), the first part of a long text shown with “…”; `Ctrl+C` on it copies the whole text, and its menu also offers Copy picture. In the clipboard history, `F3` (Pin to screen) does the same for a text or link entry, except entries kept from view. A click-through pin can be reached again by holding `Ctrl` over it, to drag it or use its right-click menu. `F3`, `Ctrl+S` and the keys inside a pin can be changed, or cleared, under Keys in the screenshot settings.
- **Select the words in a pin** (Screenshot and recording 1.1.31): a pin's words are read in the background (on this PC), so the pointer turns into a text cursor over them and a drag selects; `Ctrl+C` or `T` copies, `Ctrl+A` selects all. Dragging blank space or with `Alt` held still moves the pin, and `Esc` clears the selection first. With words selected, the pin's menu starts with Copy selected text and Copy picture. Turn it off with 贴图后自动识别文字 in the capture settings' Pin page (on by default); `T` or Select text in the menu then still starts the old way, a drag over lines that copies on release.
- **Copy all the words in a pin** (Screenshot and recording 1.1.31): `Shift+C` on a pin, or Copy all text in its menu, copies every word in it, as `Shift+C` does while capturing; words already read are copied at once. A pin of copied text, or one showing its translation, copies that text without reading it again. The key can be changed under Keys in the capture settings.
- **Edit a pin where it is** (1.1.19): `E`, or Edit in its menu, grows the toolbar on the pin itself (below it when there is no room above) instead of opening a window; `Enter` or Done puts the edited picture on the pin, `Esc` steps back (the tool, then the selection, as above) and then leaves it as it was. Click a pin and pause, and its keys are listed in the bottom-left corner of the screen; `?` or `F1` shows or hides the list.
- **Close a pin from its corner** (1.1.20): when the mouse comes onto a pin, a round close button appears in the corner on the side it came in from; one click closes the pin, no menu needed. The outermost corner still resizes; the button goes when the mouse leaves.
- **Pin groups** (0.45.0, #451): group pins and show one group at a time; the others are hidden, not closed. Right-click › Group ticks the pin's group and moves it to another or to a new one (with groups of your own it also has Switch active group and Show all groups); the tray menu's Screenshot › Pin groups lists the groups with their pin counts and can switch, show all, create, rename and delete (a deleted group's pins go back to Default). The Pin groups section on the Pin to screen page of the screenshot settings creates, switches and deletes too, and records a Switch pin group shortcut (none by default) that cycles through Default and your groups. `cap group name` creates a group and switches to it, and `cap` with 分组 lists them. Default can be neither renamed nor deleted; at most 20 groups of your own, names up to 32 characters. New pins join the active group (Default while all are shown); Close others only touches the visible pins and Close all pins closes every group's; hiding all pins is separate from groups, and switching group or choosing Show all brings every pin back.
- **Capture and pin** (0.45.0, #450): record a Capture and pin shortcut under Shortcuts in the capture settings (none by default), or use Screenshot › Capture & pin in the tray menu or `cap`. Drag an area or click a window and on release it is pinned right where it is, with no toolbar; `Enter` pins what is under the pointer, `Esc`, a right click or the shortcut again cancels. Pressed during an ordinary capture it pins the selection at once, or, with none yet, switches to this kind of picking (and from Read text or Translate it switches to pinning). The picture goes into the screenshot history too.
- **Pin history** (0.45.0, #446): with the clipboard unchanged, each further press of the Pin image shortcut (or Screenshot › Pin in the tray menu, or `cap`) pins the next earlier picture: finished captures and closed pins are remembered with their annotations (still editable), position and source file, and pins already on the screen are skipped. How many are kept (Off, 10, 20 by default, 50) and in which order (recently closed first, or by capture time) is under Pin actions on the Pin to screen page of the screenshot settings. The history lives in memory; after a restart the presses fall back to the screenshot history on disk (whole screens, annotations and place kept).
- **Save back to the original file** (0.45.0, #427): a picture pinned or edited from a picture file (copied in File Explorer or WeChat, a search result, Explorer's right-click) saves straight back with `Ctrl+S` or “Save to original (file name)” in the menu, for png, jpg (quality 92), bmp and tif (jpg and bmp flatten transparency onto white); other formats Windows reads (gif, webp, heic, avif) are not written back and keep to Save to Screenshots. The file is replaced atomically through a temporary file in the same folder, and a read-only file, one in use or a full disk is explained. Not offered for a picture shrunk because it exceeds 60 million pixels, or a file in the plugin's own data folder. Save As… (named after the original) and Save to Screenshots stay in the menu and the editor's drop-down; the editor first updates the pin it came from, then writes.
- **Pin hints outside the picture** (0.45.0): the zoom and opacity percentage and status notes (Translating…, Tab shows the original, Saved to…) float in a small pill above the pin, and the text-selection hints (Reading text…, Drag to select text · Esc to leave, Copied selected text) in one below it, flipping to the other side, then right, then left, at a screen edge; only a full-screen or oversized pin gets them inside, clear of the close button. The pills take no focus and clicks pass through them.
- **Text and search**: Recognize text on the toolbar shows the words in a picture to copy, to search with, or to search on the web; when the picture is a table, Copy as a table (Screenshot and recording 1.1.25; merged cells since 1.1.39) puts it on the clipboard for Excel, WPS and Word to paste into cells: merged cells arrive merged, a cell of several lines stays one cell, a title above and a note below get rows of their own, and codes with a leading zero or long numbers stay as they are. A ruled table is read from its drawn lines; one without (rows ruled across only, striped, or no lines at all) by a table model that comes with the plugin and runs on this PC (PaddleOCR's SLANet_plus, 7 MB); where neither is sure, from where the words stand. Plain text with a tab between cells is on the clipboard too, for everything else; `jt` and a space in the search box list past screenshots by the text in them. In the text window, Merge lines (0.45.0) joins the broken lines of a paragraph (no space between Chinese characters, one between Latin words; lines ending in `. ! ? : ;` and lines before a list item keep their break) and a second click restores them; Copy all, Copy as table and Copy translation show a Copied tick, and `Ctrl+Enter` copies the selection (or all of it) and closes the window.
- **Presenter and whiteboard**: Screenshot › Presenter / whiteboard in the tray menu, or `cap whiteboard`; you can also record a hotkey for it in the screenshot settings under Shortcuts (none by default). It draws on the live desktop: pen, highlighter, arrow, text, numbers, and `X` for a laser pointer whose trail fades at once. `Esc` or a right click hands the mouse and keyboard back to the programs below (to flip a slide, say); `W` is a whiteboard and `K` a blackboard. The ink is pixels on the screen, so recordings and screen sharing need to capture the whole screen.
- **Yours to set**: what a double left click, the right, middle and side buttons do after you have chosen an area (copy, copy and pin, save, pin, read text and copy, search or search the web, cancel, step back), and which buttons the toolbar shows.

## Taskbar search box

WinShun's own search box on the Windows 11 taskbar, or a pinned WinShun icon instead (the only way on Windows 10). The box has a fixed place the icons never push around: the taskbar's left end with centred icons, left of the tray icons with left-aligned ones; a whole box, its icon and label, or its icon alone, as Windows' own search; when the taskbar fills up the box first narrows to a smaller one you still type into (0.43.0), and only then falls back to icon and label or the icon alone. The Search box style row in the settings says when it has narrowed and to what, and the box widens again once there is room. Under Search box position you can keep it beside the tray with centred icons too. It works on its own or alongside Windows search; hiding Windows search, taking over `Win+S`, and searching as you type in the Start menu are all optional.

- **Tray icon clicks**: under Settings › Integration › Taskbar › Tray icon, Left-click tray icon (Open search box by default) and Middle-click tray icon (Open Settings by default) each take one of: Open search box, Open full search panel, Open clipboard, Open Settings, Open screenshot history (needs the Screenshot and recording plugin; opens the search box with its screenshot-history keyword), Pause / resume clipboard recording (a notification says which), Do nothing, and the actions enabled plugins offer. A right click always opens the tray menu.

## AI assistants (MCP)

- **What**: WinShun is an MCP server. Claude Desktop, Claude Code, Cursor and VS Code connect in one click and search file names, file contents and recent changes.
- **Safety**: read-only by default, limited to what the AI client may see, with folders kept from AI and a call log.
- **Setting up**: tell the AI to “set up WinShun for me”; it asks a few questions and changes several settings in one go. A window asks you first, a notice at the bottom right says what changed and offers Undo for a few seconds; security-related settings always ask.
- **Command line `ws`**: search from a terminal, like Everything's `es`: `ws report` (names), `ws grep invoice` (contents), `ws text plan.docx` (a document's text), `ws recent --days 7`. AI agents that run commands (Claude Code, Codex) need less context with it than with MCP; `ws skill --install claude` installs its instructions, and `npx skills add LingCore/WinShun` installs them for other assistants, together with skills for writing a plugin and for working on WinShun itself. `ws plugin` manages plugins: `list`, `search translate`, `install <id, package or folder>`, `enable`, `disable`, `remove`; what needs your yes (a plugin's permissions the first time it is turned on, an unreviewed package, a removal) WinShun asks you in its own window. It shares MCP's switch and safety settings.

## Looks and settings

- **Interface font**. Choose a font in Appearance. It applies across all interface styles, light and dark, while menus follow the interface size. A font may be chosen under its English or its Chinese name (LXGW WenKai and 霞鹜文楷 are the same font) and stays chosen after a restart (0.29.0); the list shows each font once, under the name Windows lists it by. The list has a search row of its own: type part of a name, move through the matches with the arrow keys or `Page Up` / `Page Down`, and take one with `Enter` (0.31.0).
- **Double-tap actions**. Choose search, clipboard history or a compatible enabled plugin action for a Ctrl, Alt or Shift double tap under Settings › Shortcuts › Open WinShun.
- **A shortcut for Settings**. Open settings, in the same place (Settings › Shortcuts › Open WinShun), takes one key combination (such as `Alt+X`; none by default) that opens the WinShun settings window; pressed again while the settings are in front, it closes them.
- **Preview handoff**. The content pane's native Preview tab can take over the current floating preview with its document layout. Preview-follow behavior is configurable and placement is steadier near screen edges.
- **On-demand UI**. The search panel and some row actions are created when needed, reducing the number of objects in ordinary search. Health focuses on current activity and memory use.
- **Where the memory is** (0.46.0, #459): Settings › Health (last in the list) shows what WinShun uses now, the figure Task Manager gives for it, and splits it into File index, Windows and data, **Kept for a quick opening**, thumbnails, the program itself, plugins and document readers, with the service on a last row; Give back now returns the idle part at once. “Kept for a quick opening” is what the search box and the clipboard need to come up fast, left in memory on purpose when idle memory is given back, so any wait before the shortcut costs no more time; it is capped at 64 MB in all and has its own line instead of counting under Windows and data. The settings window keeps each page you look at while it is open; half a minute after you close it the pages are put away again, all but the first, and opened sooner everything is as you left it. While 80 % or more of the PC's memory is in use, idle memory is not given back (0.50.0, #471): given back then, other programs take it at once, and the next opening and search read it back from the disk a page at a time, seconds on a busy PC; it goes back once there is room. The diagnostics package carries the same breakdown and what holds idle memory back.

- **Interface styles**: Settings › Appearance › Interface style offers four looks for every window: Refined native (精修原生, the default: Windows 11's own, following the accent colour), Brand colours (品牌色彩), Soft tactile (轻拟物质感: raised keys, light depth) and Liquid Glass (液态玻璃: Windows' own Acrylic behind restrained glass surfaces, with two sliders for transparency and clarity), each in light and dark.
- **Looks**: light and dark themes following Windows, see-through Mica on Windows 11 (in the Refined native and Brand colours styles), Windows' own rounded corners or square ones, sharp icons at any scaling; dense (one line per result in the launcher, 0.33.0), compact, standard or roomy sizes, and a monochrome tray and taskbar icon if you like; the app logo stays inside the search bar as its persistent action control. The theme pictures under Appearance are plain black and white (the interface style pictures keep their colours), and on Windows 11 the tray menu, and the screenshot plugin's menus, no longer have a square shadow round their rounded corners (0.45.0).
- **Interface size keys** (0.45.0): `Ctrl++` (also `Ctrl+=`, `Ctrl+Shift+=` and numpad +), `Ctrl+-` and `Ctrl+0` step through the four interface sizes (Dense, Compact, Standard, Roomy) in the search box, the search panel, Settings, the clipboard and the bar beside Open / Save dialogs, one step at a time, and a note says which one you are on; the settings window's text and controls follow it (Dense and Compact look alike there). The clipboard has its own size: there the keys change Settings › Clipboard › Clipboard size and `Ctrl+0` goes back to Follow interface size; in the large picture viewer `Ctrl++` / `Ctrl+-` zoom the picture and `Ctrl+0` resets it. Ignored while an input method is composing, with `Alt` or `Win` held, and while a hotkey is being recorded in Settings.
- **Settings**: searchable (`Ctrl+F`); changes apply at once. Since 0.37.0 in fewer, clearer categories: General (with updates, startup, backup, network, storage and diagnostics), Shortcuts, Appearance, Search scope, Result list, Integration (taskbar, file managers, folder menu, dialogs), Favorites, Clipboard, Plugins, AI assistants, Health and Gleaning. The folder menu's settings have a tab of their own under Integration, apart from the file managers; with the folder menu switched off, its other rows are hidden rather than greyed (0.51.0, #493).
- **Back and Forward in Settings**: two arrow buttons in the settings window's title bar work as a browser's do. Resting the pointer on one says where it goes (such as “Back to Appearance”, with `Alt+←`); a right click on either lists the places to jump to. `Alt+←` / `Alt+→`, the mouse's side buttons (over the title bar too) and a keyboard's browser Back / Forward keys do the same. Each place keeps its tab and scroll position, and a settings search is a step too: Back from a result returns to the search results, and Back again to where you were before searching. The history starts afresh each time the settings window is opened.
- **Scroll on to the next page**: at the bottom of a settings page one more wheel notch shows a small hint at the bottom (“Keep scrolling down for Shortcuts › Open WinShun”) and the next notch moves to the next tab, or to the next page in the sidebar when the page has no more tabs. At the top, scrolling up goes back the same way, landing at the bottom of the previous one. A fast flick that hits the end does not switch. Settings › Appearance › Size and layout › Settings wheel edge paging (0.45.0, #445, #441) has Off (the page never switches and no cue shows), Light (about 2 notches past the end), Standard (the default, about 3) and Steady (about 5, with a longer pause at the end). At the end the page edge glows and a small tab naming the next page fills as you scroll; a click on it switches at once, and a quick flick is held at full until the minimum time has passed.
- **Links between settings**: some rows lead to related settings on another page, jump there and scroll the row into view. Under Shortcuts › Open WinShun, the group Other feature shortcuts has Clipboard shortcuts (to Clipboard › Shortcuts), Folder menu shortcut (to Integration › Folder menu) and Open WinShun with Win+S (to Integration › Taskbar); Appearance has Clipboard size can be set separately (to Clipboard › Clipboard size); the Favorites page has Favorites in the folder menu (how favorites appear there, to Integration › Folder menu) and Favorites in the search bar (to Result list › Display and preview); Search scope › File contents has Index location (to General › Storage); Clipboard › Shortcuts has Letter jump (to Result list › Behavior); and the built-in cards for typing in Directory Opus, typing in OneCommander and the drop pie, on the Plugins page, have More settings. Shortcuts › Keys at a glance now also lists `Win+V` and `Win+S` (when turned on) and the folder menu's shortcut, and a click on a row there jumps to its setting.
- **Open animation**: Settings › Appearance › Open animation slides and fades the search box and, since 0.37.0, the clipboard in and out; turn it off and both appear at once. The slide takes about 0.14 s, with Mica from the first frame (0.43.0), and Settings opened from the search box waits for it to fade out instead of flashing behind it. With Windows' animation effects off, the small transitions inside (segmented buttons, the selected row) are off too.
- **Hover tips** (0.36.0): turn off Settings › Appearance › Hover tips and the icons of the kind strip, the plus buttons and the buttons on rows no longer pop up their explanations. The "i" explanations in Settings, and full names of rows too long to show, still appear. Under Settings › Appearance › Size and layout, once the switch is on, “Which hover tips to show” picks any of Interface (buttons, the kind strip, toolbars, keycaps; plugin tips too), Row actions (buttons and previews on result and clipboard rows, full times) and Menu paths (the folder menu's full paths) (0.45.0, #440); at least one stays on.
- **Window sizes** (0.40.0): the settings window, Screenshot settings and Image text search open at the size you last dragged them to, maximized if you left them so, the next start too, on the screen under the pointer and never larger than it. A double click on such a window's edge gives it its default size. Turn off Settings › Appearance › Remember window sizes and they open at their default size each start; the sizes kept are cleared.
- **File manager**: folders and file locations open in File Explorer, Total Commander, Directory Opus, XYplorer or Pulse (those installed are listed; a portable Total Commander, XYplorer or Pulse is remembered once it has run, so it can open folders while closed, 0.51.0), or in any other file manager whose commands you enter under Settings › Integration › File managers.
- **Backup**: choose a folder under Settings → General → Backup (a synced folder makes it a cloud backup); settings, favorites, dialog pins, your own web icons and plugins are backed up as they change, the last 10 kept, ready to restore.
- **Cloud backup** (the Cloud Backup plugin from the library): for a WebDAV address (Nextcloud, a NAS, 坚果云) or a private GitHub repository instead of a synced folder. Fill in its card; changed settings are uploaded by themselves, the last 10 kept at each place. Its card has a status line and a Test connection button (0.51.0, plugin 1.1.0, needs WinShun 0.46.0, #495) that only reads the list of backups and uploads nothing, saying the place was reached or why not (a wrong address or password, a repository that is not private). Type `cloud` and a space: Enter backs up now, and Enter on one of the backups listed below (then once more to confirm) restores it after saving the present settings on this computer. Passwords stay in Windows Credential Manager; nothing is uploaded to a public repository.
- **Move to another PC**: under Settings → General → Backup, choose “Export backup…” to save a ZIP, then “Restore from backup…” on the new PC. Automatic backups need not be enabled. The current configuration is saved locally first; enter plugin passwords again and check custom paths on the new PC. The clipboard history travels in a file of its own (Settings › Clipboard › Keeping › Back up and restore).
- **Updates**: announced in the tray (checked every 10 minutes, at almost no cost when nothing is new). A usual version reaches each PC at its own moment within a day of its release; one that fixes something important is announced within minutes, as “an important update”. Check for updates in the settings to see a new version at once. “Download and install” fetches the package, checks its SHA-256 and installs it (the portable copy swaps only its program files, never `data`, and keeps the package, the helper's copy and the update logs in its own `data\Updates` rather than `%LOCALAPPDATA%\WinShun\Updates`, 0.51.0, #484; a copy installed with Scoop offers “Update with Scoop” instead and lets `scoop update` do it). From one of the last few versions only what changed is downloaded (usually a few MB, not the whole package); if the program's files were changed here or the download does not go well, the full package is downloaded instead. Downloading the installer yourself still works.
- **Setup's last page** (0.45.0): the tray and the index service are started in the background before it, but nothing shows until you click Finish; with “Launch Win顺” ticked, the welcome guide (first install) or the search box (an upgrade) opens then; unticked, nothing opens. The first-run guide starts with the clipboard history and the screenshot on, the screenshot on `F1` (`Ctrl+Alt+A`, `Ctrl+Alt+S` or `Ctrl+Alt+X` when that is taken); the content index and taking `Win+V` stay off.

## winshun:// links

A `winshun://` link in a web page, a notes app such as Obsidian, a desktop shortcut or a script opens WinShun's search box with the words filled in, or its settings (0.33.0):

- `winshun://search/words`: the search box, searching for “words” at once; everything after `search/` counts, slashes too (`winshun://search/D:/Work/contract`).
- `winshun://search?q=words`: the same in the style of a web form (`+` is a space here); `winshun://search` alone just opens the box.
- `winshun://settings`, or `winshun://settings/<page>` for one page, by the names the AI tool `open_settings` uses (`general`, `shortcuts`, `appearance`, `scope`, `content` for Search scope › File contents, `results`, `taskbar`, `files_and_dialogs`, `favorites`, `clipboard`, `web`, `paste_file`). The older `advanced` and `startup` still work and open General.
- `winshun://settings/plugin/<id>` opens the settings at that plugin's card (0.38.0), as `winshun://settings/plugin/winshun.capture`. Search for the plugin's name with `settings` and press `Ctrl+Shift+C` on the row to copy it.

Spaces, `&`, `#` and `%` in the words are written percent-encoded (`%20` for a space). Links never open files. The link is registered for your own account, pointing at the WinShun in use, checked at each start; turn it off under Settings › Integration › File managers (“winshun:// links”, on by default), which also removes it, as uninstalling does.
