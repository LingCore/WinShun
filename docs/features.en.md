# WinShun features

Everything WinShun does, area by area. Back to the [README](../README.md#english); screenshots are in [docs/截图.md](截图.md). A step-by-step guide (in Chinese) is in [docs/使用说明.md](使用说明.md).

On a fresh install some extras start switched off: the search bar beside Open / Save dialogs, the folder menu, typing to search in File Explorer and Paste as file (each a card under Settings › Plugins › Installed › Built-in features), the clipboard history taking over `Win+V`, the taskbar search box and the system switches. Plugins described as in the plugin library are installed from Settings › Plugins › Plugin library.

## File search

- **Query history**. The clock button opens the last 100 completed queries. `Ctrl+Up` / `Ctrl+Down` browses them and restores the previous draft at the newest position. Settings can choose Alt with the arrows or disable the keys. Delete individual entries or clear the list. History follows the usage-recording switch.
- **Open windows**. In All, sorted by relevance, matching current window titles and program names appear first. Enter activates the selected window, including a minimized one.
- **Minimal empty search**. Enable Pure search mode under Result list › Display and preview › Keyboard hints to keep only the input bar when empty. Controls and results return as you type. The option starts off.
- **Merged scopes and panel controls**. Optionally merge All and Files and filter file kinds in All. Hold Ctrl to see kind keywords. Assign a direct panel hotkey under Open WinShun › Shortcuts, and use the panel's filter button to collapse its sidebar while retaining active filters.

- **Speed**: press Ctrl twice (or Alt or Shift twice, if you prefer); a search over three million files takes milliseconds.
- **Pinyin**: `ndbg` finds 年度报告; a mistyped homophone (年度报高) is retried by sound. A setting can switch the input method to English each time the search box opens, so letters go straight in.
- **Where**: all local drives, USB drives and external hard disks if you like (including disks that report themselves as fixed, such as most USB enclosures; an unindexed one that is plugged in is offered at the end of the list), and **NAS / SMB network shares and WebDAV folders** (a NAS's WebDAV, cloud drives such as Jianguoyun), still searchable while their server is off and reconnected by themselves after it restarts; turn on “Search file contents” on a location's card to search inside its files. On a PC without administrator rights it indexes only the folders you choose (see Administrator rights below).
- **Order**: your own files first, the date modified on each row, `Ctrl+S` for best match / newest / oldest, and More in the footer sorts by name, folder, type or size. Click a result once to select and twice to open, if you would rather not open one by mistake (a setting). Recent files are listed when the box is empty, or nothing if you like; the search can also start empty each time it opens.
- **Programs first**: `curl` lists `curl.exe` before the folder `curl` and `curl.h`; which file types go first is yours to change (exe, bat, cmd, ps1 and msi to begin with, like Listary's preferred file types).
- **Learned order**: one opening improves later matching searches for the same app or file, across Chinese names, pinyin and initials. Old preferences decay. Type `settings` or `config`, or press `Ctrl+,`, to open WinShun settings.
- **Keyboard navigation**: `Ctrl+J` / `Ctrl+N` moves down; `Ctrl+K` / `Ctrl+P` moves up; `Ctrl+U` / `Ctrl+D` pages up / down. `Ctrl+Shift+D` switches current-folder filtering.
- **Shortcuts**: `Ctrl+1`…`Ctrl+9` opens a visible result (or choose `Alt`). Numbers are visible by default in a separate column before the icons; choose hold-only or never in settings. Existing display choices are preserved. They follow the visible results after scrolling; while a Win顺 window is in front they are Win顺's, even if another app uses them as global hotkeys. Under Settings › Result list › Display and preview, “Keyboard hints” can hide the shortcuts help button at the right of the search box and the key hints in the footer; capture's All keys button can be hidden among the toolbar buttons.
- **Search panel**: too many hits? The small button at the box's corner or `Ctrl+E` grows the same window into a panel, as Listary has it: filters down the left (scope, kind, date modified, size, folder), sortable columns on the right; right-click headers to choose name, path, type, size, modification and creation times, folder or source, and drag to reorder or resize them; the layout is saved; with nothing typed it browses the whole index by those filters (milliseconds over three million files). `size:>10mb` and `dm:7d` work in the box too. **Quick filters** (as Everything's filters): save a query you use often under a name, such as `!$RECYCLE.BIN\` as "No Recycle Bin" or `ext:pdf size:>10mb`, with the `+` in the side bar; it becomes a chip that narrows whatever you type at a click, several at once all apply, and content searches skip the files they exclude. Give one a prefix (say `nobin`) and `:nobin report` applies it from the plain search box too, several at once and beside a kind's prefix. Edit them under Settings › Results › Kinds and filters. Press it again to collapse.
- **Long names**: a name that does not fit is shortened in the middle, keeping its extension and end ("…v3 final.xlsx"); rest the pointer on the row to see the full name, location, size, modified and created times. Drag the left or right edge of the search box to widen it (the width is remembered; double-click an edge for the default).
- **File sizes**: Settings › Result list › Display & preview can show sizes in the compact results, alongside modification dates or on their own. Off by default; sorting by size always shows sizes. Folders and unknown sizes stay blank.
- **Logo controls**: the WinShun logo on the left opens settings with a left click, toggles pinning with a middle click (`Ctrl+T` also works), and opens the position menu with a right click. Settings › Result list › Habits › Logo right click can make that one click straight to the top, the center or the last dragged position; the logo's tooltip names it. Drag it to move the window. A pin badge shows when pinned: clicks elsewhere and opened files keep the box up; `Esc` closes it.
- **Preview**: `Alt+P` on a result (or Preview in its menu) shows the file without leaving the launcher: pictures, text (UTF-8 or GBK, detected), Word, Excel, PowerPoint and PDF (through the same preview handlers as File Explorer's preview pane), what a folder holds; the arrows move it to the next row, `Alt+P` again (or the × on the preview) closes it; `Esc` closes the launcher and leaves the preview as it is, so it is back the next time the launcher opens (turn off Restore preview on reopen under Settings › Result list › File quick preview to close it with the launcher). QuickLook or Seer, when running in the background, shows it instead. The result preview shortcut can be changed to Space, a function key, or an unused chord in Settings; Shift+Space still types a space.
- **Thumbnails**: pictures, videos, PDFs and the like show their thumbnail instead of their type's icon, in the results and in the search bar beside Open / Save dialogs; Settings › Result list can turn them off.
- **Context menu**: right-click a row for its location, Copy path, Add to favorites and more; `Shift`+right-click (or More options in that menu) brings up Windows' own full context menu, as in File Explorer, for one row or several; after copy, cut or delete the search box stays open.
- **Scope remembered**: the scope you chose (All, Files, Content or a kind) comes back at the next start, unless Clear the search on every opening is on; a typed prefix or a plugin row does not change it.
- **By kind**: under **Files**, a row of kinds (folders, documents, pictures, videos, archives…); `Ctrl+Tab` steps through them, `+` adds your own.
- **Files you never want to see**: Settings › Search scope skips some types and file names, with `*` and `?` wildcards; by default the `~$` temporary files Office and WPS make beside open documents. Typing such a name in the box still finds it.
- **Drag out**: drag results into a chat, a mail or Explorer.
- **Live updates**: the USN change journal is read, so renamed, new and deleted files are found at once; unplugging a USB drive never says it is in use.
- **Large icons**: switch the search panel between a list and a thumbnail grid. Resize previews with the slider or `Alt`+wheel, select several file categories together, and keep the normal selection, menus and file dragging. The view and thumbnail size are remembered.
- **Query syntax**: `"exact phrase"`, `!exclude`, `!node_modules\`, wildcards `*` `?`, `ext:pdf,docx`, `folder\name`, and paths (`D:\My Files\`, `tools/out/`). Add OR groups (`report | summary 2026`, AND takes precedence), name anchors (`^IMG`, `.pdf$`), or `regex:^IMG_\d+\.(jpg|png)$`; invalid expressions explain the error. `Ctrl+R` turns on regex mode, where every word is a regex, as in Everything. `:pictures,videos` combines type keywords.
- **WSL file search**: add a Linux project or home folder under Settings › Search scope › Network & WSL. Installed distributions appear automatically. Search file and folder names alongside local files, including pinyin; indexed results remain available while WSL is stopped and update automatically when it runs again.
- **Remote scan controls**: each network or WSL folder has independent daily scan hours (including overnight windows) and a maximum depth. Depth 0 is unlimited; depth 1 lists only the chosen folder. Background name and content reads pause outside those hours; cached results remain searchable. Check now runs one manual name scan, still respecting depth. Both limits are off by default.

## Full-text search

- **Content details pane**: the `Ctrl+E` panel offers Summary, Hits, Text, native Preview and Report tabs. Read all available matches, refine hits and context, inspect Excel sheets with real row numbers, and copy, print or export text, CSV, HTML and XLSX. Full counts run on request; partial results are labelled.
- **What**: the **Content** scope searches inside txt, md, logs, source code and **Word, Excel, PowerPoint, PDF and WPS** files, showing the page, slide or sheet and row.
- **Quieter everyday searches**: **All** adds matches from the existing content index without launching document parsers. Choose **Search contents** when offered, or switch to **Content**, to read files that have not been indexed yet.
- **In one folder**: add a folder's name and a slash, `annual report abc/`, to search only in folders named abc (`/abc` last works too; `work/abc/` takes the one in work); folders of the same name are all searched and listed under the box, `Ctrl+Tab` picks one. Or pick a favorite folder there, or right-click a folder in the results → Search contents in this folder.
- **How**: ranked by relevance, with a content index for speed; UTF-8, UTF-16 and GBK are detected. The first content index reads text files straight from the disk through the index service, so antivirus does not check them one by one and it is done much sooner. Files over the size limit, in system folders or of unlisted text types are skipped; the list says how many of each, and one click searches them too.
- **Without the index service**: it works too, only slower, as the files are read as you search.
- **Safety**: documents are read by a separate process with restricted rights.

## Apps and settings

- **Apps**: everything in the Start menu (Store apps included), by name, pinyin, initials (`vsc`) or program file (`winword`).
- **Settings**: about 1,200 Windows settings pages and Control Panel items (`ncpa.cpl`, “network adapter”), plus Group Policy, Disk Management, hosts, AppData and more.
- Searching for files only? Turn off app and settings results in the settings, and All lists files and content alone.
- **System switches plugin**: enable it in Settings → Plugins. Off for fresh profiles; upgrades preserve the previous system-search choice. Dark mode, hidden files, file extensions, Bluetooth, WLAN, volume and mute, keep awake, each with its live state at the end of its row; `Enter` flips it in place and the box stays open, `Ctrl+Enter` opens its settings page. `bluetooth off`, `mute` and `volume 30` act in one step; `awake 1h` keeps the PC awake for an hour.

## Web search

install and enable Web search from the plugin library. `zhihu 显卡`, `baidu 天气`: a keyword and a space search that site. Manage sites, keywords, icons and suggestions on its plugin card; existing settings migrate on upgrade. Presets include Chinese sites, GitHub, YouTube and Wikipedia; add your own with `%s` in the URL, and import or export the list and icons. The site's search suggestions show below as you type (Enter searches one, Tab puts it in the box), and a site's icon can be an SVG file or pasted SVG code.

## Favorites

- Right-click → Add to favorites. They come first when the box is empty; give one a keyword to open it. Right-click a folder → Search in this folder to browse it in WinShun. Tab switches scopes by default; optionally choose to browse favorite folders with Tab in Settings → Result list → Display and preview.
- **Your own commands**: Settings › Favorites › Add command. Give it a keyword and put `{query}` in the command; what you type after the keyword goes there. With the keyword `code` and the command `"C:\Tools\Code.exe" {query}`, typing `code D:\my-project` and Enter hands that folder to the editor. No command prompt is involved, and searching or importing never runs a command. Each command can also be set to run silently (console programs, `.bat` and `.ps1` files open no black window) and to run as administrator.
- **Press `` ` `` while dragging**: hold the left button on files or folders (no need to drag yet; File Explorer, the desktop, Total Commander or another program) and press the key below `Esc` (it types nothing during the drag): your first 8 favorite folders appear round the pointer. Drag toward a folder to pick it, as in a marking menu, and let go to drop there: as in File Explorer, within a drive it moves and to another drive it copies, `Ctrl` copies and `Shift` moves. The progress and name-conflict windows are Windows' own, and `Ctrl+Z` in File Explorer undoes it. Let go in the middle or press `Esc` and nothing happens; press the key again or drag further away and it closes, and the drag goes on as usual. On by default; turn it off in Settings › Favorites (“Press ` while dragging files to bring up the favorites pie”). It does not work while WinShun itself runs as administrator.

## Plugins

- **Read guides in the app**. The plugin card opens bundled documentation inside settings, with scrolling and selectable text. Esc returns to settings.
- **Review status and consent**. The library shows official, source-reviewed, unreviewed native or unknown status. Unreviewed community native packages require individual consent on installation and every update. View source opens the publisher's page, and declining an update retains the installed version.
- **Shared host Qt**. Native MSVC x64 Release plugins can opt into the versioned Qt runtime contract introduced in 0.22.0; since 0.23.0 this includes plugins with the `elevated` permission. See the plugin development documentation for supported modules and deployment requirements.
- **Report a problem to the author**. Plugins by others are maintained by their authors. A card's "…" menu opens the Issues of the plugin's repository (the one the library lists, otherwise its homepage). A plugin without a homepage gets its listed repository as Homepage.
- **Resident limit**. At most 8 resident plugins stay running by default; past that the least recently used one exits and starts again when needed. Settings › Plugins › Resident plugins at once offers 4, 8, 16 or no limit.

- **Image text search** (optional plugin): searches images, scanned PDFs and embedded pictures in modern Word, Excel and PowerPoint files: once the index is built, type the words from a picture straight into the search box (in All, the first three picture rows follow the first five name rows), or use `ocr invoice` to list only picture and scan results. Selected folders are indexed offline with highlighted previews, pause and a storage limit. It shares the OCR component and keeps no image copies. Install from the plugin library; this package needs WinShun 0.20.0 (it is built with it). Since 1.0.2 it reads PDF pages whose text is drawn, upside-down pages and long pictures, also reads JFIF, GIF, HEIC and AVIF, and an installed plugin can read PDFs again. See [setup and format limits](../src/ocr-search-plugin/package/README.md).
- **Bundled**: `= 1+2*3`, `12 inch to cm`, `#ff8800`, timestamps, UUID, Base64, hashes; `kill` processes.
- **LAN transfer** (in the plugin library, to install when you want it): send files and text to and from phones and PCs on the same network that run [LocalSend](https://localsend.org), with no server or account. You are asked before anything is received; type `ls ` to send and receive, or right-click search results or clipboard history › Send over LAN… and choose a device. History selections, including multiple entries, send without changing the system clipboard (LAN transfer plugin 1.0.1 or newer).
- **Search by meaning** (in the plugin library, to install when you want it): `? last year's expense rules` finds a document that says “travel cost requests”. It uses the model you pick: Ollama or LM Studio on your PC uploads nothing; for SiliconFlow, Model Studio, OpenAI and others you enter your own key, and before the first run it says how much text would be sent and waits for your Enter. See [its guide](../src/semantic-plugin/package/README.md).
- **Break reminder** (in the plugin library, to install when you want it): a 20-second break every 20 minutes, every other one a 5-minute break. Thirty seconds before, a small bar at the top offers Postpone (once), Skip and Pause 1 hour; when it is due it waits for a pause in typing, dims every monitor with a countdown, and `Esc` ends it early. Strict mode leaves only a 3-second hold of `Esc`. Five minutes away counts as a break; full-screen games, slide shows and Do not disturb hold it back. Type `break` to see the time left, take a break now, pause until manually resumed across restarts, or pause for 1 or 3 hours. See [its guide](../src/break-plugin/package/README.md).
- **Explorer tabs** (in the plugin library, to install when you want it; needs Windows 11 22H2 or newer -- File Explorer on Windows 10 has no tabs, so it does nothing there): a folder that would open in a new File Explorer window opens as a tab of the window you used last instead, and that window comes to the front; a new window for a folder already open in a tab switches to that tab. Hold `Ctrl+Shift` while opening for a window of its own; `Ctrl+N` or "Open in new window" in an Explorer window still gives a window. Folders Win顺 opens become tabs too. Type `tabs` to see how many were merged or to pause it (a pause is kept across restarts). See [its guide](../src/explorer-tabs-plugin/package/README.md).
- **Translate** (in the plugin library, to install when you want it): `tr sentence` turns Chinese into English and anything else into Chinese, using your own key for DeepL, Microsoft Translator or an OpenAI-compatible service (each service keeps its own key), with presets for DeepSeek, Doubao / Volcengine Ark and Tencent Hunyuan. `dict word` shows model-generated definitions and examples. Nothing is sent without a key. Superseded requests are canceled, and Enter copies the selected item.
- **Browser bookmarks** (in the plugin library, to install when you want it): `bm words` searches the bookmarks of every Chrome and Edge profile; Enter opens one.
- **Plugin library**: Settings › Plugins › Plugin library has WinShun's own Screenshot and recording, LAN transfer, Search by meaning, Break reminder, Explorer tabs, Translate and Browser bookmarks, and plugins other people wrote (from [WinShun-plugins](https://github.com/LingCore/WinShun-plugins)); Choose Install and enable for a new plugin and review its permissions after the package is checked. Updates keep its enabled state. Features awaiting recovery after an upgrade can be retried or installed from a local package on the Installed tab. It fetches the library when that page is opened, on Refresh, or to install. Signed background update checks follow the Automatic updates setting. If GitHub cannot be reached, Settings › Advanced › Network proxy takes a proxy address by hand.
- **Your own**: zero-code `plugin.json`, scripts in any language, or resident processes, with SDKs for Python, PowerShell and C++. Plugins run under a memory limit with normal rights; only a plugin that asks for administrator rights runs as administrator, and only while WinShun itself does and after you confirm it once on its card. A command can have several keywords: type them into its card with spaces between; from eight installed plugins on, a box filters them. See [docs/plugins.en.md](plugins.en.md).

## Open and Save dialogs

- **Search bar**: a search bar under every file dialog; type a name (pinyin too), press Enter, and the dialog goes there; web page uploads, WPS dialogs and the "Browse For Folder" box of VBA macros too. The "Browse for folder" window of installers made with Inno Setup has it as well: a pick only fills in the path, and you press the installer's OK yourself (the Start Menu folder picker is left alone).
- **`Ctrl+G`**: jumps to the folder open in File Explorer, Total Commander, Directory Opus, XYplorer, Pulse or OneCommander, like Listary. OneCommander uses its active pane's folder, with no extra setup; dialog suggestions can also list its other open tabs, falling back to the active folder while tab state is out of sync.
- **Only the dialog's folder**: `Ctrl+Shift+D` in the bar, or "Only inside …" in its "…" menu, searches only the folder the dialog is showing and what lies in it; the folder's name appears before the text and follows the dialog. The same key, a click on that name or the menu brings the whole PC back. The choice is remembered.
- **Suggestions**: open folders, a path you just copied, favorites and recent folders.
- **Going there by itself**: optional, as the dialog opens, or only when you come back to it from the file manager.
- **Programs run as administrator**: with the index service installed, `Ctrl+G` and going there by itself also work in dialogs of programs run as administrator, including Windows XP style Open / Save dialogs and AutoCAD's own file window (the folder is put into the file name box, OK is sent once, and your file name is put back). Without the service, the path is copied for you to paste.
- **Blender**: enable the [file-dialog extension](../integrations/blender/winshun_file_dialog/README.md) to use WinShun in separate Open, Save As and Import windows. Save/Export confirmation stays in Blender. Tested on Windows x64 with Blender 5.2; see the [dialog compatibility notes](dialog-compatibility.md).

## In File Explorer

- **Direct folder entries**. Under Open WinShun › Dialogs › Folder menu, set 0–10 recent or open folders to show directly. Zero uses the submenu, and overflow entries appear under More. Menu density follows the interface size and long paths have hover tips.
- **Tessoa folders**. Ctrl+G can read the active folder of a specific Tessoa window using its v1 protocol, available in Tessoa 0.22.0 or newer.

- **Folder menu**: double-click empty space in File Explorer or on the desktop, then choose Favorites, Recent folders or Open folders. Favorites include folders, files, apps, system places and custom commands, with names and icons; hover for the full path or command. Choose a folder to navigate the same window (the desktop opens a new one), or click a command to run it; `{query}` receives the current folder and an explicit working directory takes priority. Right enters a page; Left, Backspace or Esc returns; Esc on the home page closes it. Long lists scroll and the menu keeps the source window's focus. Each group can be switched off in settings, as can how it opens (double left click, middle click), where (File Explorer, desktop) and each action at the end of the menu (Search here, Copy path, Command Prompt, PowerShell, Add this folder to favorites, WinShun settings).
- It never takes the focus: arrows, Enter, Esc and first letters work; a click elsewhere or another double click closes it. It stays out of the way while Listary runs.
- **In Directory Opus too**: WinShun can add its command to Opus's settings for you (Opus restarts once), and puts the old one back when turned off or uninstalled.
- **Type to search in Directory Opus**: enable it separately in Settings → Open WinShun → Dialogs (off by default). Start with a letter or digit in the file list to search, the focused tab's folder first (as in File Explorer), including either pane of a dual display. `Esc` returns to Opus; opening a folder or locating a result with `Ctrl+Enter` uses the original pane. Renaming, address bars, menus and Opus find modes starting with symbols keep their usual behavior.
- **By a shortcut**: when another program has the double click, or for Total Commander, XYplorer and Pulse, give the folder menu a shortcut in the settings and press it in any window: in File Explorer, on the desktop, in Directory Opus, Total Commander, XYplorer and Open / Save dialogs the folder picked opens in that window (in Pulse, where its “Folders opened from other apps” setting puts it: a new tab or a new window); anywhere else, in your file manager. Press it again to close the menu.
- **“Search here with WinShun”** on the right-click menu of folders, a folder's blank space and drives (under “Show more options” on Windows 11): the search window opens with that folder typed. It can be turned off.
- **Type to search**: type anywhere in a File Explorer file list and WinShun searches for what you typed, like Listary: what is in that window's folder (and its subfolders) comes first, the rest of the PC follows under a thin "Elsewhere" line; "Only in …" or `Ctrl+Shift+D` keeps to that folder, pressing it again keeps to this level alone (no subfolders), and a setting can make either the default. A Chinese input method composes as usual, and `Esc` goes back to File Explorer. A folder you pick opens in the same tab, so typing again goes one level deeper; `Ctrl+Enter` on a file or folder also goes, in that tab, to the folder holding it and selects it (when the file manager set in Settings is File Explorer); and the keys of Explorer's `Shift`+right-click menu stay with the menu. Turn it on in the settings (it replaces Explorer's own jump to a file by its first letters, so it is off by default).
- **Placement and selection (0.17.0)**: the search box opens beside the originating Explorer window when all of it fits there; otherwise (a large, centred or maximized window) it opens in the bottom right corner of the file list, as Listary's does, never in a corner of the screen. Neither changes its remembered position. On the few PCs where Windows will not let the search box to the front, Explorer keeps the focus and what is typed still goes into the box (past the input method: pinyin is searched as letters). Browsing a direct child selects and reveals it in the original tab while the search field keeps keyboard focus; nested and elsewhere results do not navigate Explorer.

## Clipboard history

- **Find a group**. Press `Ctrl+G` or the folder button, search group names, select with the arrows and press Enter. Continue typing to search inside the group. Esc restores the earlier content query and scope.
- **Hover preview**. Rest the pointer on an item for about 200 ms to see its text or picture. Move into the popup to keep reading. Scrolling or changing groups closes it, and Alt+P or the middle button can open the manual side preview.

- **Resize**: drag any edge or corner to change the clipboard window's width and height, including with the preview open. Sizes are remembered; double-click an edge to reset. Limited screen space temporarily reduces the window without overwriting your preferred size. Text follows Settings › Appearance › UI size by default, or pick its own size in Settings › Clipboard › Clipboard size (including a dense one-line-per-entry step). Copied image files show thumbnails too.
- **What**: text, pictures and files, opened with `Win+V` or your own shortcut, by the text cursor, without taking the focus.
- **Search**: pinyin, `@app` filters, and **words in copied pictures** (Windows recognition by default; install enhanced recognition for PaddleOCR, with better Chinese, English, numbers and small print. Images are processed on your PC).
- **Preview**: full text, pictures, HEX / RGB / HSL color values. The eye button (or `Alt+P`) opens and closes it; while it is open, the row under the mouse is shown. It is wider now, and the line beside it can be dragged, the width remembered.
- **Original image formats**: PNG, JPEG and GIF data supplied by the source are kept as received; bitmap-only copies become PNG. Drag pictures into a folder or paste them into File Explorer to save them in their stored format. Select several with Ctrl or Shift to save them together. GIF previews can play and pause.
- **Paste**: double-click or `Enter`, or one click as in Windows' own history (an option); larger picture thumbnails as another. Number hints on the icons are always visible by default and can be adjusted in Settings.
- **Into programs run as administrator**: Windows drops the keys a normal program sends them, so the index service presses the one paste chord for you (Settings › Clipboard › Paste into programs run as administrator, on by default). Without the service the entry is copied and you press `Ctrl+V`.
- **Paste without opening it**: Settings › Clipboard › Shortcuts › “Paste without opening the panel” (`Ctrl+1–9` or `Alt+1–9`) pastes the first nine entries straight into any program, format kept. Off by default; when on, those keys no longer do their usual job in other programs (switching browser tabs, say).
- **Hold and press again**, as in Ditto: Settings › Clipboard › Shortcuts › “Hold and press again, release to paste”. Keep the shortcut's Ctrl, Alt, Shift or Win held: each further press moves one entry down, and letting go pastes it; held about a second, letting go pastes the first entry; `Esc` while holding pastes nothing. Off by default.
- **Upload boxes**: in a Windows “Open” file box, pasting files from the clipboard history puts their full paths in the File name field, several at once if you like; then click Open.
- **Equations and embedded objects**: an equation copied alone from Word, or an embedded object, is kept as a picture entry (with its text, which you can search) and pasted back into Word as an equation or object you can still edit; a program that only takes pictures gets the picture. `Shift+Enter` pastes the equation as a line of text. (Tested with Word.)
- **Organize**: pins, groups, multi-paste in order, and `Alt+1`…`Alt+9`; pinned items can come first, and the order is yours to drag or move with `Ctrl+↑`/`↓`. `Ctrl+A` picks every listed entry, Delete all in the row menu clears them at once, and `Ctrl+Z` brings them back.
- **Copied files that are gone**: their entry says “no longer there”, and can be hidden or cleaned out automatically (pinned and grouped entries stay; a pulled-out USB drive does not count).
- **Import**: Settings › Clipboard › Keeping › Import clipboard history takes a Ditto database (one click if Ditto is installed), `.txt` text and `.csv` tables (GBK files saved by Chinese Excel are recognised); what is imported goes into a new group, is never cleaned out automatically, and entries you already have are skipped.
- **Privacy**: passwords from password managers are not kept, and the history stays on your PC.

## Screenshots and recording

The Screenshot and recording plugin: install it in Settings › Plugins › Plugin library, record your own shortcut under Settings on its card, and turn on `PrtScn` there too if you want it. Who had screenshots on gets it installed with the update, settings as they were.

- **Area and full-screen recording**: choose Record or press `Ctrl+R` after selecting an area, for MP4 or GIF. Switch between Area and Full screen on the controls; Full screen records the entire monitor containing the selection, including its taskbar, and Area restores the original selection. Pause and resume, choose quality, cursor and click highlights, and optionally show the shortcuts and mouse buttons pressed as keycaps in a corner (off by default; "All keys" records typing too). MP4 audio is optional and off by default; GIF is silent. Controls stay out of the recording. Choose a save folder, or record another take without replacing the previous file.
- **Toolbar and saving**: the toolbar has two rows: the common tools, undo/redo, pin, save, cancel and confirm next to the selection, and the line, highlighter, text recognition, QR, scrolling screenshot, recording, delay and the key list in a shorter second row (the rows swap when the toolbar sits above the selection). Drag the toolbar by its left grip together with its style panel. Choose the screenshot save folder and a shortcut to pin the latest screenshot in the screenshot's settings. After a save, click the notification to see the file selected in your file manager.
- **Choosing**: rest the pointer on a window or a button and it is outlined, with everything outside it dimmed; click to take it, or drag an area; the wheel makes the outline larger or smaller. Side panels and buttons in apps that draw their own interface, such as Settings and Calculator, are outlined too (not inside Chromium apps such as Chrome, Edge, VS Code and WeChat, where only the whole window is outlined; drag an area there). `WASD` moves the mouse pointer by one physical pixel (also while the left button is held, so the area follows) and `Shift+WASD` by ten; the arrow keys move the area and `Shift`+arrows resize it. `R` cycles through up to 10 distinct recent areas from this run on the current picture; `Shift+R` cycles in reverse; `,` and `.` step through past captures (the whole screens, the area and the annotations, editable again), the last 10 kept by default.
- **Magnifier and color**: the pixels under the pointer, enlarged; `C` copies the color under it and ends the capture, and `Shift` alone switches between `#RRGGBB`, `rgb()` and `hsl()`. Once an area is chosen, the magnifier shows only inside it.
- **HDR screens**: captures on an HDR screen keep their normal colors. Turn on “Also save an HDR picture on HDR screens” in the screenshot's settings (off by default) and `Ctrl+S` saves a `.jxr` of the same name beside the PNG, with the bright parts as bright as they were; Windows Photos shows it.
- **Copy the words**: `Shift+C` reads the words in the area and copies them.
- **Read text on screen**: record a separate “Read text on screen” shortcut under Shortcuts in the capture settings (none by default). Press it, drag over an area or click a window, and when you let go its text is read and copied, with no toolbar and no screenshot kept; a small card beside it says Copied and shows the first lines, and Edit opens the text to change and copy. It is also in the tray menu and under `cap` in the search box.
- **Shortcut hints**: while capturing, the bottom-left corner lists the keys that work right now: different before choosing, after choosing and with an annotation tool. It waits its turn: it fades in only after a short pause at the start, goes the moment you press a mouse button, and after you choose an area it appears once only if you stop for about 2 seconds, leaving again as soon as you move. It is hidden while you drag or type. When the area or the toolbar covers that corner it moves to the bottom right; when the pointer comes near it turns almost transparent. It never ends up in the picture. `?` shows or hides it for one capture, "Don't show again" turns it off, and "Show shortcut hints while capturing" in the screenshot's settings (Shortcuts) turns it back on.
- **Delay**: `Ctrl+Shift+D`, or Delay on the toolbar, counts down (the seconds are a setting) and freezes the screen only at the end, for menus and tooltips. “Include the mouse cursor” in the settings puts the pointer in the picture (off by default).
- **QR codes**: `Q` reads a QR code in the area and shows its text to copy; for a web address there is an Open link button, and nothing opens until you click it.
- **Marking up**: rectangle, ellipse, arrow, line, curve, path, pen, highlighter, text, numbers and redaction. Curve and path nodes remain adjustable, and the highlighter offers different drawing modes. Numbers can be `1 2 3`, `A B C`, `a b c`, Roman numerals or numbers in circles, and a few words can be typed beside one. Redaction is mosaic, blur, solid or Smooth (covered with the surrounding background, as if wiped away), as a box or a stroke; what is under it cannot be worked back out.
- **Smart redaction**: after you rest on an area, WinShun reads it on your PC and finds phone numbers, ID card and bank card numbers, e-mail addresses, keys and this PC's user name, and offers “N found · click to redact”; one click (or the Smart redact button, or `Shift+B`) covers them all and one `Ctrl+Z` takes it back. It can miss some, so look once more before you send.
- **Scrolling screenshots**: for a web page, a chat, a document or a file list longer than the screen, choose the area and press `Ctrl+L` (or Long screenshot on the toolbar): scroll manually while WinShun stitches the frames, then press `Enter` to open the result in the editor. Turn on Auto-scroll when needed. Content that only scrolls sideways, or keeps moving, does not suit it.
- **Finishing**: `Enter` copies it, into the clipboard history too, where the words in it can be searched; with a save folder chosen in the screenshot's settings, `Ctrl+S` or Save saves straight into it and the arrow beside Save offers “Save as…”; without one, `Ctrl+S` opens the native Save As dialog and the arrow offers “Save to previous folder” (Pictures\Screenshots). Cancelling Save As keeps the selection and annotations. “Pin screenshots when copying” also pins it on the screen whenever it is copied. A marked-up picture can be opened and changed again later, from the clipboard history, the search box or a pin, with multi-select, a color picker and cropping.
- **Pins**: `F3` pins it on the screen, always on top: zoom, change opacity, rotate and flip, fold it to a small tile, read its text, or drag over the text with `T` to copy it. What “Double-clicking a pin” does (back to 100%, close, fold or nothing) is a setting. Capture › Pin image in the tray menu, or the configurable Pin image shortcut, pins a clipboard image first; otherwise it restores the last screenshot at its original position with annotations. A click-through pin can be reached again by holding `Ctrl` over it, to drag it or use its right-click menu. `F3`, `Ctrl+S` and the keys inside a pin can be changed, or cleared, under Keys in the screenshot settings.
- **Text and search**: Recognize text on the toolbar shows the words in a picture to copy, to search with, or to search on the web; `jt` and a space in the search box list past screenshots by the text in them.
- **Presenter and whiteboard**: Screenshot › Presenter / whiteboard in the tray menu, or `cap whiteboard`; you can also record a hotkey for it in the screenshot settings under Shortcuts (none by default). It draws on the live desktop: pen, highlighter, arrow, text, numbers, and `X` for a laser pointer whose trail fades at once. `Esc` or a right click hands the mouse and keyboard back to the programs below (to flip a slide, say); `W` is a whiteboard and `K` a blackboard. The ink is pixels on the screen, so recordings and screen sharing need to capture the whole screen.
- **Yours to set**: what a double left click, the right, middle and side buttons do after you have chosen an area (copy, copy and pin, save, pin, read text and copy, search or search the web, cancel, step back), and which buttons the toolbar shows.

## Taskbar search box

WinShun's own search box on the Windows 11 taskbar, or a pinned WinShun icon instead (the only way on Windows 10). The box has a fixed place the icons never push around: the taskbar's left end with centred icons, left of the tray icons with left-aligned ones; a whole box, its icon and label, or its icon alone, as Windows' own search, narrower by itself when the taskbar fills up. Under Search box position you can keep it beside the tray with centred icons too. It works on its own or alongside Windows search; hiding Windows search, taking over `Win+S`, and searching as you type in the Start menu are all optional.

## AI assistants (MCP)

- **What**: WinShun is an MCP server. Claude Desktop, Claude Code, Cursor and VS Code connect in one click and search file names, file contents and recent changes.
- **Safety**: read-only by default, limited to what the AI client may see, with folders kept from AI and a call log.
- **Setting up**: tell the AI to “set up WinShun for me”; it asks a few questions and changes several settings in one go. A window asks you first, a notice at the bottom right says what changed and offers Undo for a few seconds; security-related settings always ask.
- **Command line `ws`**: search from a terminal, like Everything's `es`: `ws report` (names), `ws grep invoice` (contents), `ws text plan.docx` (a document's text), `ws recent --days 7`. AI agents that run commands (Claude Code, Codex) need less context with it than with MCP; `ws skill --install claude` installs its instructions. It shares MCP's switch and safety settings.

## Looks and settings

- **Interface font**. Choose a font in Appearance. It applies across all interface styles, light and dark, while menus follow the interface size.
- **Double-tap actions**. Choose search, clipboard history or a compatible enabled plugin action for a Ctrl, Alt or Shift double tap under Open WinShun › Shortcuts.
- **Preview handoff**. The content pane's native Preview tab can take over the current floating preview with its document layout. Preview-follow behavior is configurable and placement is steadier near screen edges.
- **On-demand UI**. The search panel and some row actions are created when needed, reducing the number of objects in ordinary search. Health focuses on current activity and memory use.

- **Interface styles**: Settings › Appearance › Interface style offers four looks for every window: Refined native (精修原生, the default: Windows 11's own, following the accent colour), Brand colours (品牌色彩), Soft tactile (轻拟物质感: raised keys, light depth) and Liquid Glass (液态玻璃: Windows' own Acrylic behind restrained glass surfaces, with two sliders for transparency and clarity), each in light and dark.
- **Looks**: light and dark themes following Windows, see-through Mica on Windows 11 (in the Refined native and Brand colours styles), Windows' own rounded corners or square ones, sharp icons at any scaling; compact, standard or roomy sizes, and a monochrome tray and taskbar icon if you like; the app logo stays inside the search bar as its persistent action control.
- **Settings**: searchable (`Ctrl+F`); changes apply at once.
- **File manager**: folders and file locations open in File Explorer, Total Commander, Directory Opus, XYplorer or Pulse (those installed are listed), or in any other file manager whose commands you enter under Settings › Open WinShun › Dialogs.
- **Backup**: choose a folder under Settings → Advanced (a synced folder makes it a cloud backup); settings, favorites, dialog pins, your own web icons and plugins are backed up as they change, the last 10 kept, ready to restore.
- **Move to another PC**: under Settings → Advanced → Backup, choose “Export backup…” to save a ZIP, then “Restore from backup…” on the new PC. Automatic backups need not be enabled. The current configuration is saved locally first; enter plugin passwords again and check custom paths on the new PC.
- **Updates**: announced in the tray; “Download and install” fetches the package, checks its SHA-256 and installs it (the portable copy swaps only its program files, never `data`; a copy installed with Scoop offers “Update with Scoop” instead and lets `scoop update` do it). Downloading the installer yourself still works.

## Keys

| Key | Action |
|---|---|
| Ctrl twice | Open / close the search bar (Alt or Shift twice instead, or another shortcut such as `Alt+Space`, can be set) |
| `Enter` / `Ctrl+Enter` / `Ctrl+Shift+Enter` | Open / show in folder / run as administrator |
| `Ctrl+C` / `Ctrl+Shift+C` | Copy the file / copy its path |
| `Ctrl+1`…`Ctrl+9` | Open the nth row (numbers visible by default; hold-only is optional) |
| `Tab` / `Shift+Tab` | Switch scope: All / Files / Content (forward / back) |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | In **Files**, step through the kinds; in **Content**, through the folders |
| `Ctrl+S` | Best match → newest first → oldest first (name, type and size are under More in the footer) |
| `Ctrl+J` / `Ctrl+N`, `Ctrl+K` / `Ctrl+P` | Move down / up; `Ctrl+U` / `Ctrl+D` pages up / down |
| `Ctrl+,` | Open WinShun settings |
| `Ctrl+E` / `Ctrl+T` | Expand to the search panel / pin the search box (stays up through clicks elsewhere) |
| `Ctrl+Shift+D` (opened by typing in a folder window) | Cycles: current folder first, only the current folder, only this level (no subfolders) |
| `Alt+P` / `Shift`+right-click | Preview the row / Windows' own context menu |
| `Ctrl+G` (in a file dialog) | Go to the folder shown in your file manager |
| `Win+V` / `Win+S` (once turned on) | Clipboard history / search above the taskbar |
| A shortcut you set (Settings › Open WinShun › Dialogs) | The folder menu in any window; again to close it |
