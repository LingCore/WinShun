Win顺 0.30.0 加入截图翻译：框选后点“翻译”，截图里的文字就在原来的位置换成译文。剪贴板里的文字可以直接修改，书签插件能搜浏览器的历史记录，截图时点一下就能遮住一行字，还多了字母直达和在搜索框里直接打开网址。

## 下载 · Downloads

- **WinShun-0.30.0-x64-setup.exe** 为标准安装版，覆盖升级保留设置、索引和剪贴板，增强 OCR 按需下载。
- **WinShun-0.30.0-x64-portable.zip** 为便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。
- **WinShun-0.30.0-x64-offline-setup.exe** 包含增强 OCR。官方可选插件从插件库安装。
- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 是同版本安装程序使用的增强 OCR 组件。
- **SHA256SUMS.txt** 提供上述四个文件的 SHA256。

The standard installer keeps settings, the index and clipboard history during an upgrade and downloads enhanced OCR when needed. For the portable edition, keep the existing `data` folder. The offline installer includes enhanced OCR. Optional official plugins are available from the plugin library. Scoop users can run `scoop update winshun` after the bucket update reaches them.

升级不用迁移任何东西，设置、索引和剪贴板历史都保留。截图翻译要先从插件库装好“翻译”插件，并填上你自己的翻译服务；Win顺 不自带翻译服务。

Nothing needs migrating: settings, the index and clipboard history are kept. Screenshot translation needs the Translate plugin from the plugin library and a translation service of your own; WinShun includes none.

## 新功能 · What's new

- 🌐 **截图翻译** 框选后，工具条上多了“翻译”：截图贴在原来的位置，里面的文字换成译文。原来的字用背景色盖掉，译文排在同一个地方，颜色和大小差不多，粗体还是粗体，按钮里居中的字还是居中；翻译时角上显示“正在翻译…”。按 `Tab` 在原文和译文之间来回看，右键菜单里有“显示原文 / 显示译文”和“复制译文”。已经贴在屏幕上的图，右键选“翻译”也行。界面、网页、文档这类底色平整的图效果最好；照片上的字会留下色块，斜着的字保持原样（#191）。

  **Screenshot translation** The capture toolbar has a new Translate button: the capture is pinned where it was taken, with its words replaced by the translation. The original words are covered with the background colour and the translation is set in the same place, in the same colour and about the same size; bold stays bold, and words centred in a button stay centred. "Translating…" shows in a corner meanwhile. `Tab` switches between the original and the translation, and the right-click menu has Show original / Show translation and Copy translation. A picture already pinned can be translated from its right-click menu too. It works best on flat backgrounds such as windows, web pages and documents; words on photos leave a colour patch and slanted lines are left as they are (#191).

- 🔤 **“识别文字”窗口里翻译** 只想要文字的话，“识别文字”窗口里也有“翻译”：上面是原文，下面是译文，可以先改一改或选中一部分再翻译（最多 3000 字），译文有复制按钮。屏幕上因为换行断开的一段话，会先接成一整句再翻译；菜单、列表这类短行保持一行一条。翻译用的是插件库里的“翻译”插件和你自己的服务（DeepL、微软 Translator、兼容 OpenAI 的模型）；插件或服务没设好时，窗口里会说明，并有按钮直达设置。鼠标按键动作里也多了“识别文字并翻译”，工具条上的“翻译”按钮可以在设置里隐藏（#191）。

  **Translating in the text recognition window** For plain text, the text recognition window has a Translate button: the original above, the translation below; edit or select part of the text first (up to 3,000 characters), and a button copies the translation. A paragraph the screen wrapped onto several lines is joined before it is translated, while menus and lists stay one item per line. It uses the Translate plugin from the plugin library with your own service (DeepL, Microsoft Translator or an OpenAI-compatible model); if the plugin or a service is missing, the window says so and has a button to the settings. "Recognize text and translate" is also among the mouse button actions, and the toolbar's Translate button can be hidden in the settings (#191).

- ✏️ **剪贴板里直接修改文字** 剪贴板历史里，文本记录的右键菜单多了“修改文字…”：直接在预览的位置改，改完保存。这条记录还在原来的位置，固定状态和备注都不变。原来带的格式（网页、Word 里复制来的）会去掉，之后粘贴的是改好的纯文本（#267）。

  **Edit a clipboard text entry** A text entry's menu in the clipboard history has Edit the text…: change it in place and save. The entry keeps its position, pin state and note. Formatting it was copied with (from a web page or Word) is dropped, so it pastes as the edited plain text (#267).

- 🕘 **搜浏览器历史** 浏览器书签插件 2.1.0 多了关键词 `bh`（也可以用 `ls`）：搜 Chrome、Edge 打开过的网页（在插件设置里另指定的 Chromium 系浏览器也一起读）。标题或网址里含每个词的网页都列出来，标题是汉字的可以用拼音；不打字就是最近打开的网页。默认关着，要到插件的设置里打开“搜索浏览历史”才读。浏览器开着也能搜，只在这台电脑上读，不上传（#160）。

  **Browser history** Browser bookmarks 2.1.0 adds the keyword `bh` (also `ls`): it searches the pages opened in Chrome and Edge (and in another Chromium-based browser named in the plugin's settings) by title or address, pinyin for Chinese titles too; with nothing typed it lists the pages opened last. Off by default: turn on "Search the browsing history" in the plugin's settings first. It works while the browser is running, reads only on this computer and uploads nothing (#160).

- 🖍️ **点一下就遮住一行字** 截图时选了打码工具（马赛克、模糊），鼠标移到图里的一行字上就会出现红框，点一下就把这一行整个盖住；再点一下（框变成蓝色的那行）取消。拖动还是照常画打码框（截图与录屏 1.1.15，#129）。

  **Click a line to hide it** With the redact tool (mosaic or blur) selected in a capture, a line of text is outlined in red as the mouse moves over it; one click hides that whole line, and another click on it (its outline turns blue) takes it off again. Dragging still draws a box as before (Screenshot and recording 1.1.15, #129).

- ⌨️ **字母直达** 设置 › 结果列表 里新增“字母直达”（默认关）。打开后，轻按一下 `Ctrl` 再松开（剪贴板里是 `Alt`，和数字键用的是同一个键），每一行前面出现一个字母，按字母就打开这一行，第九行以后也有，一只手就够。加 `Shift` 是打开所在位置（剪贴板里是粘贴为纯文本）。再轻按一下或按 `Esc` 退出。平铺视图和搜索面板里暂时没有字母（#175）。

  **Letter jump** A new setting under Settings › Result list, off by default. With it on, tap `Ctrl` by itself (`Alt` in the clipboard, the same key the number keys use) and every row in view shows a letter; press the letter to open that row, the rows past the ninth included, with one hand. With `Shift` it opens where the file is (in the clipboard: pastes as plain text). Tap again or press `Esc` to leave. The tile view and the search panel show no letters yet (#175).

- 🔗 **搜索框里直接打开网址** 装了“网页搜索”插件时，在搜索框里打一个网址（`github.com`、`baidu.com/s?wd=x`、`localhost:3000`、`192.168.1.1`，带不带 `https://` 都行），第一行就是“打开网址”，`Enter` 用浏览器打开。电脑里正好有同名的文件时，文件排第一；`main.py`、`notes.md` 这类更像文件名的不算网址（#171）。

  **Open a web address from the search box** With the Web search plugin on, typing an address (`github.com`, `baidu.com/s?wd=x`, `localhost:3000`, `192.168.1.1`, with or without `https://`) shows "Open the address" as the first row; Enter opens it in the browser. A local file of the same name still comes first, and names that look like files, such as `main.py` or `notes.md`, are not treated as addresses (#171).

- 📋 **打开时填入刚复制的文字** 设置 › 结果列表 里新增“打开时填入刚复制的文字”（默认关，可选 3、5 或 10 秒）：刚在别的程序里复制了一行文字，在这个时间内打开搜索框，就直接搜它，文字是选中的，打字就替换。复制的是多行文字或文件时不填，同一次复制只填一次（#171）。

  **Fill in what was just copied** A new setting under Settings › Result list, off by default, with 3, 5 or 10 seconds to choose from: if one line of text was copied in another program within that time, opening the search box searches it at once, selected so that typing replaces it. Multi-line text and files are not filled, and each copy is filled once (#171).

## 改进与修复 · Improvements and fixes

- **面板快捷键再按一次就关闭**：给“直接打开搜索面板”设的快捷键，面板开着并在最前面时再按一次就关闭（以前只能按 `Esc`）；开着的是小搜索框时，按它展开成面板（#330）。

  The hotkey set for "Open the full search panel" now closes the panel when pressed again while it is up and in front; before, only `Esc` did. With the small search box up, it expands the box into the panel (#330).

- **“此电脑”和“主文件夹”里也能直接打字搜索**：开着“在资源管理器里直接打字搜索”时，在“此电脑”、“主文件夹”（Windows 11）或“快速访问”（Windows 10）里打字，现在也会打开搜索框并搜整台电脑。回收站、控制面板、网络和搜索结果页里仍保留它们自己的按键（#329）。

  With "Type to search in File Explorer" on, typing on This PC, Home (Windows 11) or Quick access (Windows 10) now opens the box and searches the whole PC. The Recycle Bin, the Control Panel, Network and search results pages keep their keys (#329).

- 剪贴板开着时单按 `Alt`（按住看序号，或轻按），不再激活后面程序的菜单栏：以前在记事本上面开着剪贴板，松开 `Alt` 后记事本接着把粘贴用的 `Ctrl+V` 当成菜单命令（#175）。

  With the clipboard open, a tap or hold of `Alt` by itself no longer activates the menu bar of the program behind. Before, with the clipboard open over Notepad, the paste keys that followed were taken by Notepad as a menu command (#175).

- **插件在搜索框里改的设置，设置页跟着变**：插件可以把用户在搜索框里改的设置告诉 Win顺（`winshun/settings/update`），设置页的卡片和设置文件同步更新，两边不再各显示各的。只能改插件自己声明的文字、数字、开关和选项，密码、文件夹、快捷键不行（#332，感谢 @ra9fael 的 PR #333）。

  A plugin can now tell WinShun about a setting the user changed in the search box (`winshun/settings/update`): the card on the settings page and the settings file follow, so both show one value. Only text, number, switch and choice settings the plugin declared itself; not passwords, folders or hotkeys (#332, thanks to @ra9fael for PR #333).

- 插件的一行既能“填入搜索框”又带着别的操作时，底部提示和右键菜单现在写的是 `Enter` 真正会做的事；列表比窗口长时，按住数字键的修饰键，各行左边对齐（PR #333）。

  A plugin row that both fills the search box and has other actions now says in the footer and in its menu what `Enter` really does; in a list longer than the window, rows stay aligned while the number modifier is held (PR #333).

- **资源管理器标签页 1.1.1**：有人反馈连按两次 `Win+E` 仍是两个窗口，日志里是“没有别的窗口”（#331）。我们没能复现；按日志修了一处可能的原因（刚打开的窗口登记得太早时，之后一直不被当作可以并入的窗口），并让日志写明当时看到了几个窗口，方便继续查。

  Explorer tabs 1.1.1: a report that two presses of `Win+E` still gave two windows, logged as "no other window" (#331). We could not reproduce it; one likely cause is fixed (a window that registered too early was never again taken as one to merge into), and the log now says how many windows were seen, to go on from.

- “识别文字”窗口加宽，英文界面下按钮也放得下。

  The text recognition window is now wide enough for its buttons in English.

- 写插件的人：宿主多了一个工具 `translate_text`，插件可以把文字交给“翻译”插件翻译并拿回译文，说明见 `docs/plugins.md`。

  For plugin authors: the host has a new tool, `translate_text`, with which a plugin hands text to the Translate plugin and gets the translation back; it is described in `docs/plugins.md`.

- **截图与录屏 1.1.15** 截图翻译、“识别文字”窗口里的翻译，以及打码工具点一下遮住一行字。截图翻译用的是 Win顺 0.30.0 起提供的翻译接口，主程序也要升到 0.30.0。权限不变。

  Screenshot and recording 1.1.15: screenshot translation, translating in the text recognition window, and clicking a line with the redact tool to hide it. Screenshot translation uses the translation tool WinShun offers from 0.30.0, so the app needs 0.30.0 as well. Its permissions are unchanged.

- **浏览器书签 2.1.0** 多了 `bh` 搜浏览历史，默认关着，在插件设置里打开。它多读一种文件（浏览器的 `History`），仍在原来的“读取文件”权限之内，更新时不会再弹权限确认。

  Browser bookmarks 2.1.0: `bh` searches the browsing history, off until turned on in the plugin's settings. It reads one more kind of file, the browser's `History`, under the same "read files" permission it already has, so updating asks for no new approval.

- **翻译 2.2.2** 几行文字一起翻译时，每一行单独翻译，译文按原来的顺序一行一行交回来；截图翻译就靠它把译文对回原来的位置。一行文字的翻译和以前完全一样。

  Translate 2.2.2: several lines of text are translated each on its own and come back one line each, in order, which is how screenshot translation puts the translations back where the words were. A single line is sent exactly as before.

- **图片文字搜索 1.0.15** 用 Win顺 0.30.0 的共用代码重新打包，用法没有变化。

  Image text search 1.0.15: rebuilt with WinShun 0.30.0's shared code; no change in behaviour.

## 验证范围 · Verification

新功能用自动测试和真实的鼠标键盘操作验证，真实操作在一台干净的 Windows 10 22H2 虚拟机里做。截图翻译用一个模拟的翻译服务验证，没有接真实的 DeepL、微软 Translator 或大模型服务。“此电脑”和“主文件夹”里打字搜索（#329）在 Windows 11 的“主文件夹”页上没有试过。

The new features were checked with automated tests and with real mouse and keyboard input on a clean Windows 10 22H2 virtual machine. Screenshot translation was checked against a stand-in translation service, not against real DeepL, Microsoft Translator or language-model services. Typing on the Home page of Windows 11 (#329) was not tested.
