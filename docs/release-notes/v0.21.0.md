Win顺 0.21.0 让插件的结果也能在内容详情和预览里看，截图多了“识别屏幕文字”的专用快捷键，贴图和标注的滚轮缩放、调粗细更细更顺，在文件夹里打字可以只搜这一层，并新增“打开时切换为英文输入”开关。WinShun 0.21.0 lets plugin results show in the content details and the preview, adds a hotkey of its own for reading text on screen, makes wheel zooming of pins and sizing of annotations finer, lets typing in a folder search that level only, and adds a switch to type in English each time the search box opens.

## 下载 · Download

- **WinShun-0.21.0-x64-portable.zip** 为便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。也可以用 Scoop 安装：`scoop bucket add winshun https://github.com/LingCore/WinShun`，再 `scoop install winshun`。

- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 为增强 OCR 独立组件，可在识别设置中从本地安装。
- **SHA256SUMS.txt** 提供以上四个文件的 SHA256。

Requires 64-bit Windows 10 1809 or later, or Windows 11. Setup upgrades retain existing data. Preserve the portable copy's existing `data` folder. With Scoop, run `scoop bucket add winshun https://github.com/LingCore/WinShun` and then `scoop install winshun`. The offline setup includes enhanced OCR, while optional plugins remain separate downloads. Verify the downloads with `SHA256SUMS.txt`.

## 新功能 · What's new

- 🔎 **插件的结果也能看内容和预览** 会打开普通文件的插件结果（比如图片文字搜索），在内容详情和预览（`Alt+P`、空格）里按那个文件显示；不是文件的结果（比如邮件），插件可以声明 `details`，由 Win顺 向它要一段文字或它数据文件夹里的文件来显示，取不到时写“无法获取详情”。插件协议新增，Python 和 PowerShell SDK 已支持（C++ SDK 这一版没有），不需要新权限，说明见[插件文档](https://github.com/LingCore/WinShun/blob/v0.21.0/docs/plugins.md)（#202）。
  **Plugin results in details and preview**: a plugin result that opens a plain file (such as image text search) is shown as that file in the content details and the preview (`Alt+P`, Space). For results that are not files, such as emails, a plugin can declare `details` and WinShun asks it for a piece of text or a file in its data folder to show; if nothing comes back it says so. This is a new plugin protocol item, supported by the Python and PowerShell SDKs (not the C++ SDK in this version), and it needs no new permission. See the [plugin docs](https://github.com/LingCore/WinShun/blob/v0.21.0/docs/plugins.en.md) (#202).
- 📝 **识别屏幕文字，有自己的快捷键** 在截图设置 › 快捷键里另录一个“识别屏幕文字”（默认不设）：按下后拖选一块或单击窗口，松开就识别并复制，不出工具条，也不进截图历史；旁边的小卡片显示“已复制”和前几行字。托盘菜单和搜索 `cap` 里也能选“识别屏幕文字”。需要截图插件 1.1.3（#198）。
  **Read text on screen, with its own hotkey**: record a separate "Read text on screen" shortcut under Shortcuts in the capture settings (none by default). Press it, drag an area or click a window, and on release the text is read and copied, with no toolbar and nothing added to the screenshot history; a small card beside it shows "Copied" and the first lines. It is also in the tray menu and under `cap` in the search box. Requires capture plugin 1.1.3 (#198).
- 🔍 **贴图和标注的滚轮更细更顺** 贴图缩放每格幅度更小（60% 以下 5%，到 300% 为 10%），缩放时在左上角短暂显示百分比，`Ctrl`+滚轮调透明度也会显示百分比。标注工具用滚轮或 `[` `]` 调粗细、字号、马赛克格子，逐像素细调，范围更大（粗细 1–64、字号 10–120、格子 3–64），鼠标滚轮一格一档，不用等。需要截图插件 1.1.3（#164）。
  **Smoother wheel on pins and annotations**: pin zoom steps are smaller (5% below 60%, 10% up to 300%), the percentage shows briefly in the corner while zooming, and `Ctrl`+wheel shows the opacity. In the annotation tools the wheel or `[` `]` sets line width, text size and mosaic cell in fine steps over a wider range (width 1–64, text 10–120, cell 3–64), one step per mouse notch with no waiting. Requires capture plugin 1.1.3 (#164).
- ⌨️ **打开时切换为英文输入** 在设置 › 结果列表 › 操作习惯打开后（默认关），每次打开搜索框，中文输入法先切到英文，直接打字母或拼音首字母；想打中文就在框里切回，这次打开期间不再切换。关掉搜索框后恢复原来的输入状态（#201）。
  **Switch to English input on opening** (off by default): under Settings › Results › Habits, each time the search box opens the Chinese input method switches to English so letters go straight in. Switch back in the box to type Chinese; it stays that way for that opening. When the box closes, the input state is put back (#201).
- 📂 **在文件夹里打字，可以只搜这一层** 在文件夹窗口里打字打开 Win顺 后，`Ctrl+Shift+D` 在“当前文件夹优先”“只搜当前文件夹”“只搜这一层（不含子文件夹）”之间轮流换，也可以点列表最后一行的提示换；设置 › 打开 Win顺 › 对话框里可以把“只搜这一层”设成默认（#182）。
  **Search only this level when typing in a folder**: after opening WinShun by typing in a folder window, `Ctrl+Shift+D` cycles through current folder first, only the current folder, and only this level (no subfolders); the hint row at the end of the list works too. The default can be set under Settings › Open WinShun › Dialogs (#182).

## 修复与改进 · Fixes and improvements

- 双击空白处的文件夹菜单末尾多了“复制路径”，一键复制当前文件夹的完整路径；不想要可以在设置里关掉（#137）。
  The folder menu (double-click empty space) gains "Copy path" at the end, copying the current folder's full path in one click; it can be switched off in settings (#137).
- Directory Opus 里直接打字弹出的搜索框，放在正在打字的那一栏文件列表里，宽度和高度随这一栏收窄；以前在双栏窄栏里会伸进查看栏（#82）。
  In Directory Opus, the search box that appears when you type now sits inside the file list you are typing in and narrows to fit it. Before, in a narrow pane it reached into the viewer pane (#82).
- 截图插件 1.1.2 已单独发布：设置页第一次打开不再卡住。1.1.3 包含它。
  Capture plugin 1.1.2, released on its own, fixed the capture settings freezing on first open; 1.1.3 includes it.

## 升级与验证范围 · Upgrade and validation scope

“识别屏幕文字”快捷键、贴图百分比提示和标注滚轮细调在截图插件 1.1.3 里，从插件库更新，开着自动更新时会在后台更新。插件的 `details` 请求需要 Win顺 0.21.0；旧版 Win顺 上，带 `details` 的插件结果照常显示，只是内容详情和预览里不会去问。

The "Read text on screen" hotkey, the pin percentage hint and the finer annotation wheel are in capture plugin 1.1.3, updated from the plugin library, in the background when automatic updates are on. The plugin `details` request needs WinShun 0.21.0; on older WinShun, results with `details` still show as before, but the content details and preview do not ask for them.
