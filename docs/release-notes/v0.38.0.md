Win顺 0.38.0 让剪贴板里的文字也能贴到屏幕上，在搜索框里打“截图设置”就直达插件的设置。剪贴板可以只复制、粘贴预览里选中的一部分，打开位置多了“上次的位置”，菜单里的快捷键不开菜单也能按。“在终端中打开”可以选 PowerShell、Windows 终端、Git Bash 等，文件夹菜单的列宽跟着名字收紧，空文件夹和空文件在结果里一眼看得出，快捷筛选可以带自己的排序。

## 下载 · Downloads

- **WinShun-0.38.0-x64-setup.exe** 为标准安装版，覆盖升级保留设置、索引和剪贴板，增强 OCR 按需下载。
- **WinShun-0.38.0-x64-portable.zip** 为便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。
- **WinShun-0.38.0-x64-offline-setup.exe** 包含增强 OCR。官方可选插件从插件库安装。
- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 是同版本安装程序使用的增强 OCR 组件。
- **SHA256SUMS.txt** 提供全部附件的 SHA256。

The standard installer keeps settings, the index and clipboard history during an upgrade and downloads enhanced OCR when needed. For the portable edition, keep the existing `data` folder. The offline installer includes enhanced OCR. Optional official plugins are available from the plugin library. Scoop users can run `scoop update winshun` after the bucket update reaches them; with WinGet, `winget upgrade LingCore.WinShun` once the package has caught up.

升级不用迁移任何东西，设置、索引和剪贴板历史都保留。“剪贴板打开位置”原来选的保持不变。文字贴到屏幕要“截图与录屏”1.1.26，在 设置 › 插件 › 插件库 更新。从 0.35.0 起的版本软件内更新只下载变了的部分。

Nothing needs migrating: settings, the index and clipboard history are kept. Clipboard position keeps what you chose. Pinning text needs Screenshot and recording 1.1.26 from Settings › Plugins › Plugin library. Updating in the app from 0.35.0 or later downloads only what changed.

## 新功能 · What's new

- 📌 **文字贴到屏幕**：剪贴板历史里的文字、链接按 `F3`（贴到屏幕），或者复制一段文字后按贴图快捷键，文字做成一张卡片贴在屏幕上，换行、缩进照原样，代码用等宽字体；在卡片上按 `Ctrl+C` 复制的是原来的文字（截图与录屏 1.1.26，#388）。

  **Pin text on the screen**: `F3` (Pin to screen) on a text or link in the clipboard history, or the pin shortcut after copying some text, pins the words as a card, line breaks and indents kept, code in a monospaced font; `Ctrl+C` on it copies the words themselves (Screenshot and recording 1.1.26, #388).

- ⚙️ **搜索框直达设置**：打“设置”第一行就是 Win顺 设置；打插件名加“设置”（“截图设置”“translate settings”，打到 `set` 就行）直达那个插件的设置。它们能收藏、加关键词，右键可以复制 `winshun://` 链接（#389、#390）。

  **Settings from the search box**: “settings” puts WinShun's settings first; a plugin's name and “settings” (“capture set” is enough) opens that plugin's settings. They can be favorites with a keyword, and their menu copies a `winshun://` link (#389, #390).

- ✂️ **剪贴板只用一部分**：在侧边预览里拖选一段文字（文本文件的行、图片识别出的字也行），`Ctrl+C` 只复制这部分，`Enter` 只粘贴这部分，原条目不变（#375）。

  **Use part of a clipboard entry**: drag over part of the text in the side preview (a text file's lines or a picture's words too); `Ctrl+C` copies just that part and `Enter` pastes it, the entry staying whole (#375).

- 📍 **剪贴板打开位置多了“上次的位置”**：在 设置 › 剪贴板 选“输入光标旁 / 鼠标指针旁 / 上次的位置”，选最后一个就总在你上次拖到的地方打开，每块屏幕各记各的（#376）。

  **The clipboard can open where you last left it**: Settings › Clipboard › Clipboard position offers Beside the caret, Beside the pointer and Where it was last, remembered per screen (#376).

- ⌨️ **剪贴板菜单的键直接按**：右键菜单里写在旁边的 `F3`（贴到屏幕）、`Ctrl+E`（编辑）、`Ctrl+S`（保存为文件）不开菜单也能按，`Ctrl+T` 钉住窗口（#379）。

  **The clipboard menu's keys without the menu**: `F3` (Pin to screen), `Ctrl+E` (Edit) and `Ctrl+S` (Save as file) work with the menu closed, and `Ctrl+T` keeps the window open (#379).

- 💻 **“在终端中打开”可以选终端**：设置 › 结果列表 › 操作习惯 里选命令提示符、Windows PowerShell、PowerShell 7、Windows 终端、Git Bash、WSL，或者写一条自己的命令（#386）。

  **Choose the terminal for Open in Terminal**: Command Prompt, Windows PowerShell, PowerShell 7, Windows Terminal, Git Bash, WSL, or a command line of your own, under Settings › Result list › Behavior (#386).

- 📂 **文件夹菜单更紧凑**：每列宽度跟着名字走，不再留一大片空白；打开“文件夹的子列也列出文件”后，子列在文件夹后面列出文件，点一下就打开（#384）。

  **A tighter folder menu**: each column is as wide as its names; with A folder's column also lists its files on, a folder's files follow its folders and a click opens one (#384).

- 🫙 **空文件夹、空文件标出来**：搜索结果里，里面什么都没有的文件夹写着“空文件夹”，0 字节的文件写着“空文件”，不用点进去看（#391）。

  **Empty folders and files are marked**: results say Empty folder or Empty file, so there is no need to go in (#391).

- 🔀 **快捷筛选带排序**：每个快捷筛选可以定自己的排序（比如“大文件”按大的在前），开着它时列表就这样排；只打筛选前缀时切换排序也管用了（#392）。

  **Quick filters with a sort of their own**: give a filter its own order (largest first for Big files, say), in force while it is on; changing the sort now works with only a filter's prefix typed (#392).

- 🔤 **字母直达到处都能用**：剪贴板里 `Shift`+字母选中几条一起粘贴，对话框旁的搜索栏和文件夹里打字弹出的框也有字母（#357）。

  **Letter keys everywhere a list is**: `Shift`+letter picks several clipboard entries to paste together, and the dialog search bar and the box typed open in a folder show letters too (#357).

- 👁️ **剪贴板“再次打开时恢复预览”**：在 设置 › 剪贴板 › 粘贴动作与列表显示 打开后，关闭时开着的侧边预览下次打开会跟着回来（默认关，感谢 HL-SLC 的 PR #383）。

  **Restore the clipboard preview on reopening**: turned on under Settings › Clipboard › Paste actions and list display, a side preview left open comes back next time (off by default; thanks to HL-SLC for PR #383).

## 改进与修复 · Improvements and fixes

- **资源管理器里打字搜索时不再抢剪贴板的键**：开着“在资源管理器里直接打字搜索”，在资源管理器上打开剪贴板或文件夹菜单后按的第一个数字或字母，不会再被当成搜索（#385）。

  **Typing to search in File Explorer leaves the clipboard's keys alone**: the first digit or letter pressed in the clipboard or the folder menu over File Explorer is no longer taken for a search (#385).

- **Windows 10 上对话框搜索栏不再闪黑块**：列表展开或变长时那一帧的黑色没有了（#234）。

  **No black flash in the dialog search bar on Windows 10** when its list opens or grows (#234).

- **Word 里复制的公式是“带格式”**：剪贴板里显示公式原来的样子，类型和 WPS 的一样是“带格式”，不再当成图片，粘回 Word 还是能编辑的公式（#367）。

  **An equation copied in Word is formatted text**, showing as it looked like WPS's, no longer a picture, and pasting back into Word as an editable equation (#367).

- **自定义大小认单位**：搜索面板的自定义大小框里写 `40 KB`、`1.5 GB` 都行，只写数字还是按 MB 算；自定义日期写 `2026` 或 `2026-3` 就是那一整年、整月。读不懂的内容框下会标红线，不再悄悄不起作用（#394）。

  **Custom sizes take a unit**: the search panel's custom size boxes read `40 KB` or `1.5 GB`, a bare number still being MB; a custom date of `2026` or `2026-3` means that whole year or month. What a box cannot read is underlined in red instead of silently doing nothing (#394).

- **文件夹菜单滚轮一格滚 3 行**：子列里滚一格原来只走两行，长列表要滚很多下；现在一格滚的行数和 Windows 鼠标设置里的一样（默认 3 行），连着滚会累加（#384）。

  **A wheel notch in the folder menu moves 3 rows**, or as many as Windows is set to, instead of two; quick notches add up (#384).

- **文件夹菜单不再显示“已打开的文件夹 0”**：除了当前这个没有别的打开的文件夹时，这一项不出现（#393）。

  **The folder menu no longer shows “Open folders 0”** when no folder but the current one is open (#393).
