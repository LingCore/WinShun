Win顺 有了安装程序：双击安装，开始菜单里就有它，卸载也在 Windows 设置里。以后升级只要运行新的安装程序。WinShun now comes with an installer: run it and WinShun is in the Start menu, with uninstalling in Windows Settings. To upgrade later, just run the new installer.

## 下载 · Download

推荐下载 **WinShun-0.2.1-x64-setup.exe**，双击安装。想免安装的话，下载 **WinShun-0.2.1-x64.zip**，解压到固定位置后运行 `WinShun.exe`。需要 Windows 10 或 11（64 位）。

Get **WinShun-0.2.1-x64-setup.exe** and run it. Prefer no installation? Download **WinShun-0.2.1-x64.zip**, unzip it somewhere permanent and run `WinShun.exe`. Requires Windows 10 or 11, 64-bit.

## 新功能 · What's new

- 📦 **安装程序**：Windows 11 风格的安装向导，跟随系统的浅色、深色模式和显示语言；装在 Program Files 里，开始菜单有快捷方式，可选桌面快捷方式。
  **Installer**: a Windows 11 style setup wizard that follows your light or dark mode and display language; installs to Program Files with a Start menu shortcut and an optional desktop one.
- ⬆️ **升级更省事**：运行新版安装程序就行，它会先让正在运行的 Win顺 保存好索引再退出，设置和索引都保留。
  **Easy upgrades**: run the new installer; it lets the running WinShun save its index and exit first, and keeps your settings and index.
- 🗑️ **干净卸载**：在“设置 → 应用”里卸载，会一并去掉开机自启，并问你要不要删除设置和索引。
  **Clean uninstall**: uninstall from Settings → Apps; it removes the autostart too and asks whether to delete your settings and index.

## 从免安装版换成安装版 · Moving from the zip to the installer

1. 运行安装程序。正在运行的免安装版会被自动关闭。
2. 装好后，可以删掉原来解压的文件夹。设置、索引和最近使用记录都在原处，安装版直接接着用；开机自启也会自动换成安装版。

1. Run the installer. A portable copy that is running gets closed.
2. Once installed, you can delete the old unzipped folder. Settings, index and recent items stay where they are and the installed copy picks them up; autostart switches to it as well.

Windows may say “Windows protected your PC”: click **More info → Run anyway**. The app is not code-signed yet.
