Win顺 0.36.0 让新装的 Win顺 一上来就像 Listary 那样用：对话框旁的搜索框、双击空白处的文件夹菜单、资源管理器里直接打字搜索都默认开着。从 WPS 文字复制的公式从剪贴板历史粘回去还能编辑，WebP、HEIC 这类图片在剪贴板列表里也有缩略图，鼠标停在图标上弹出的说明可以关掉。这也是第一个能增量更新的版本：从 0.35.0 软件内更新只下载变了的部分。

## 下载 · Downloads

- **WinShun-0.36.0-x64-setup.exe** 为标准安装版，覆盖升级保留设置、索引和剪贴板，增强 OCR 按需下载。
- **WinShun-0.36.0-x64-portable.zip** 为便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。
- **WinShun-0.36.0-x64-offline-setup.exe** 包含增强 OCR。官方可选插件从插件库安装。
- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 是同版本安装程序使用的增强 OCR 组件。
- **SHA256SUMS.txt** 提供上述四个文件的 SHA256。

The standard installer keeps settings, the index and clipboard history during an upgrade and downloads enhanced OCR when needed. For the portable edition, keep the existing `data` folder. The offline installer includes enhanced OCR. Optional official plugins are available from the plugin library. Scoop users can run `scoop update winshun` after the bucket update reaches them; with WinGet, `winget upgrade LingCore.WinShun` once the package has caught up.

升级不用迁移任何东西，设置、索引和剪贴板历史都保留；从旧版升级的，这几个功能原来开着还是关着，照旧不变。

Nothing needs migrating: settings, the index and clipboard history are kept, and an upgrade leaves those features on or off as they were.

## 新功能 · What's new

- 🧭 **新装默认像 Listary**：对话框旁的搜索框、双击空白处的文件夹菜单、资源管理器里直接打字搜索，新装时都开着；不想要的在 设置 › 插件 › 已安装 的“内置功能”卡片上关掉（#372）。

  **Listary-style from the start**: the search bar beside Open / Save dialogs, the folder menu on a blank double click and typing to search in File Explorer are on for new installs; turn any of them off on its card under Settings › Plugins › Installed › Built-in features (#372).

- 🧮 **WPS 公式粘回去还能编辑**：从 WPS 文字复制的内容连同 WPS 自己的格式一起记下，从剪贴板历史粘回 WPS 时公式还是能编辑的公式，排版也和直接粘贴一样；粘到别的程序里照旧是文字和格式（#367，用 WPS 12.1 测过）。

  **WPS formulas paste back editable**: text copied in WPS Writer is kept with WPS's own format, so pasting it back from the history keeps formulas editable and the layout as a direct paste would; other programs get text and formatting as before (#367, tested with WPS 12.1).

- 🖼️ **剪贴板列表里的 WebP 缩略图**：复制的 WebP、HEIC、TIFF 等图片文件，只要 Windows 自己能打开，列表里就显示缩略图，不再只是文件图标（#373）。

  **WebP thumbnails in the clipboard list**: copied WebP, HEIC, TIFF and other picture files that Windows itself opens show a thumbnail in the list instead of the file icon (#373).

- 💬 **悬停提示可以关**：设置 › 外观 › 悬停提示，关掉后类型条、加号、行上的按钮等不再弹说明；设置里带“i”的说明和太长的名字照常显示（#368，截图与录屏 1.1.24、图片文字搜索 1.0.22 也跟着）。

  **Hover tips can be turned off**: Settings › Appearance › Hover tips; when off, the kind strip, plus buttons and row buttons no longer pop up explanations, while the "i" notes in Settings and names too long to show still do (#368; Screenshot and recording 1.1.24 and Image text search 1.0.22 follow it).

## 改进与修复 · Improvements and fixes

- **文件夹里打字也能带类型**：在资源管理器里打 `测试 :documents` 或 `documents: 测试`，只找文档，先列这个文件夹里的（#366）。

  **A kind while typing in a folder**: in File Explorer, `report :documents` or `documents: report` finds documents only, that folder's first (#366).

- **复制的图片文件也在“图片”分类里**：剪贴板里复制的全是图片文件时，“图片”分类里也找得到，“文件”分类里照样有，粘贴出来还是文件（#369）。

  **Copied picture files under Pictures**: when the copied files are all pictures, the clipboard's Pictures category lists them too, Files still does, and they paste as files (#369).

- **按文件名跳过的入口**：设置 › 搜索范围 › 不搜索的文件夹下面多了一行链接，直接到“名称和类型”里按文件名（可用 `*`）或扩展名跳过（#374）。

  **A way to skipping by name**: under Settings › Search scope › Excluded folders, a link leads to Names and types, where files are skipped by name (`*` works) or extension (#374).

- **第一次增量更新**：从 0.35.0 软件内更新到这一版，只下载和 0.35.0 相比变了的文件，对不上时自动改下完整包。

  **The first delta update**: updating in the app from 0.35.0 downloads only the files that changed since 0.35.0, falling back to the full package if anything does not match.
