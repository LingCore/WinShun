Win顺 0.27.3（自用构建）让「全部」搜索也能找到「应用 › 运行」里的程序（包含只在托盘里的），结果显示「运行」标签；同时修好从「全部」切回「运行」后页面可能一直为空的问题。 WinShun 0.27.3 (a personal build) lets the 全部 search find the programs listed in Apps › Running (the tray-only ones included), tagged 运行, and fixes the 运行 page staying empty after coming back from a 全部 search.

## 新功能 · What's new

- 🔎 **「全部」能搜到「运行」里的程序** 在「全部」里输入程序名，除了窗口和文件，还会列出「应用 › 运行」里的托盘程序；有窗口的程序仍显示窗口行。窗口行和托盘行右侧都带一个「运行」小标签，和「收藏」「最近」在同一位置。按 Enter 与在「运行」页一样：有窗口就切过去，只在托盘的就点它的托盘图标。托盘列表在后台读取并缓存两秒，打字不会因此变慢。

  **全部 finds the programs 运行 shows** Typing a program's name in 全部 lists the notification-area programs from Apps › Running beside the windows and files; a program with a window keeps its window row. Window and tray rows carry a small 运行 tag where 收藏 and 最近 sit. Enter does what 运行 does: switch to its window, or click its tray icon when it has none. The icons are read off the UI thread and cached for two seconds, so typing stays quick.

- 🐞 **修好「运行」页偶尔一直为空** 从「运行」切到「全部」再切回来时，如果窗口和托盘没有变化，页面会误以为网格里还是原来的运行列表，跳过了重画；如果「全部」当时是空的，运行页就一直是空白的，只有切换一下「常用 / 收藏 / 全部」才恢复。现在只有确认网格里就是运行列表时才跳过重画，否则一定重建。另加了一条日志，下次出现异常时可以确认窗口和托盘各读到多少。

  **The 运行 page no longer stays empty** Coming back from a 全部 search with the same windows and tray icons, the page took the grid for its own list and skipped redrawing it; when 全部 was empty, 运行 stayed blank until another 应用 sub-tab was chosen. Now the rows are kept only when the grid is known to show the 运行 list; otherwise they are built again. A log line now says how many windows and icons were read, should it happen again.
