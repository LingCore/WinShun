## 新功能 · What's new

- 📋 **剪贴板历史**：复制过的文字、图片和文件都能找回来。在设置 → 剪贴板里打开“用 Win+V 打开”，`Win+V` 出来的就是 Win顺的剪贴板，代替 Windows 自带的；也可以另设组合键，或从托盘菜单打开。`Enter` 粘贴回原来的窗口，`Shift+Enter` 粘贴为纯文本；能用拼音搜，按文本、链接、图片、文件分类，固定和分组的一直保留，多选后按顺序合在一起粘贴；颜色值显示成色块，图片和文件显示缩略图。密码管理器复制的密码不会被记录，历史只存在本机。
  **Clipboard history**: what you copy — text, pictures, files — comes back. Turn on “Open with Win+V” in Settings → Clipboard and `Win+V` opens WinShun's clipboard instead of Windows' own; or set another shortcut, or open it from the tray menu. `Enter` pastes into the window you were in, `Shift+Enter` as plain text; search with pinyin, filter by text, links, pictures or files, keep entries for good by pinning or grouping them, and pick several to paste as one, in order. Colour values show as swatches, pictures and files as thumbnails. Passwords from password managers are not kept, and the history stays on your PC.
- 📂 **对话框下方的搜索框**：“打开”“另存为”对话框（网页上传文件、选择文件夹也算）下面贴着一个搜索框：输入文件夹或文件的名字（拼音也行），回车，对话框直接转过去；也能直接输入路径，一级一级往下找。资源管理器正在显示的文件夹点一下或按 `Ctrl+G` 就到，和 Listary 一样；还可以让对话框出现时自动转过去（默认关）。
  **A search bar under file dialogs**: Open and Save As dialogs (uploads and folder pickers too) get a search bar: type the name of a folder or file (pinyin works too), press Enter, and the dialog goes there; or type a path and go down it folder by folder. The folder File Explorer shows is one click or `Ctrl+G` away, as in Listary, and dialogs can go there by themselves when they open (off by default).
- 💽 **机械硬盘建索引快得多**：从 FAT32 转换来的、很老的 NTFS 分区（簇只有 512 字节）以前只能逐个文件夹遍历，在机械硬盘上要好几分钟，现在也直接读主文件表。读主文件表时跳过空着的部分，几块盘同时读（同一块机械硬盘上的分区一个接一个），读得快了一倍左右；建索引时状态栏显示正在读哪个盘、读到多少。
  **Much faster indexing of hard disks**: old NTFS volumes and ones converted from FAT32 (with 512-byte clusters) used to be walked folder by folder, which took minutes on a hard disk; now their master file table is read directly too. Its free stretches are skipped and several disks are read at once (the volumes of one hard disk in turn), about twice as fast; while the index is built, the status line shows which drive is being read and how far.
- ⌨️ **其他**：设置里的快捷键框能录下 Alt+Space 和被其他程序占用的组合键，录的时候也不会触发它们。
  **Also**: the shortcut box in the settings records Alt+Space and combinations other programs hold, without setting them off.
