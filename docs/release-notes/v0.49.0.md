Win顺 0.49.0：新插件“本地模型”在自己电脑上跑 AI 模型，翻译和“按意思找”可以完全离线；截图“复制为表格”认得合并单元格，粘进 Excel 就是表格；钉住的搜索框让位给刚打开的文件，可以设成一直钉住，打开过的结果标“已打开”；结果行尾的按钮自己选、自己排；读网络共享不再拖慢文件管理器；复制整屏截图少占约 200 MB 内存（#467）。

- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 是同版本安装程序使用的增强 OCR 组件。
- **SHA256SUMS.txt** 提供全部附件的 SHA256。
- 国内下载慢的话，[CNB 镜像](https://cnb.cool/lcstp/WinShun/-/releases)上有同样的文件。

The standard installer keeps settings, the index and clipboard history during an upgrade, carries the screenshot and recording component, and downloads enhanced OCR when needed. For the portable edition, keep the existing `data` folder. The offline installer also includes enhanced OCR; the other optional official plugins are in the plugin library. Scoop users can run `scoop update winshun` after the bucket update reaches them; with WinGet, `winget upgrade LingCore.WinShun` once the package has caught up. From mainland China, the [CNB mirror](https://cnb.cool/lcstp/WinShun/-/releases) has the same files.

升级不用迁移任何东西，设置、收藏、贴图和剪贴板历史都保留；以前关掉过“显示删除按钮”的，升级后仍然不显示。截图与录屏 1.1.39 一起更新（随安装包带着）。插件库里新增本地模型 1.0.0，翻译 2.3.0、按意思找 1.1.0 加上了本地模型；开发工具 1.0.9、鼠标手势 2.1.7、图片文字搜索 1.0.34 随新版的共用代码重新构建，插件库会自动更新它们。从 0.36.0 起的版本软件内更新只下载变了的部分。

Nothing needs migrating: settings, favorites, pins and clipboard history are kept, and a delete button that was switched off stays off. Screenshot and recording 1.1.39 comes along (it ships with the installer). The plugin library has the new Local models 1.0.0, and Translate 2.3.0 and Search by meaning 1.1.0 that use it; Developer tools 1.0.9, Mouse gestures 2.1.7 and Image text search 1.0.34 are rebuilt with this version's shared code, and the plugin library updates them by itself. Updating in the app from 0.36.0 or later downloads only what changed.

## 新功能 · What's new

- 🧠 **本地模型：断网也能翻译、按意思找文件**：在插件库装新插件“本地模型”，在它的卡片上点“下载”（默认 Qwen3.5 2B，约 1.2 GB，断了能接着下），或者选自己的 `.gguf` 模型文件（Ollama、LM Studio 下好的也行）。然后把“翻译”的服务选成“本地模型（离线）”，`tr`、截图翻译、鼠标手势的翻译就都在这台电脑上完成，文字不出本机；翻译的结果边出边显示。“按意思找”同样可以选“本地模型（离线）”，再下载嵌入模型（约 610 MB），建索引和查找都不上传文档内容。有显卡用显卡，没有用 CPU；5 分钟不用自动释放内存。

  **Local models: translate and search by meaning with no network**: install the new Local models plugin from the plugin library and click Download on its card (Qwen3.5 2B by default, about 1.2 GB, resumable), or pick a `.gguf` file of your own (one from Ollama or LM Studio too). Set Translate's service to Local model (offline), and `tr`, capture translation and the gestures' translation all happen on this PC, with the words shown as they come. Search by meaning takes Local model (offline) as well, with an embedding model of about 610 MB: indexing and searching upload nothing. It uses the GPU when there is one, else the CPU, and frees the memory after 5 minutes unused.

- 📊 **截图“复制为表格”认得合并单元格**：截一张表格，识别文字后选“复制为表格”，粘进 Excel、WPS 或 Word 就是表格：合并的单元格还是合并的，一格里的几行字还在一格，表上面的标题和下面的备注各占一行，0 开头的编号和很长的数字不会变样。有线的表格按画出来的线读，没线的由随插件带的表格模型（7 MB，在本机运行）读（截图与录屏 1.1.39）。

  **Copy as a table knows merged cells**: capture a table, read its text and choose 复制为表格; pasted into Excel, WPS or Word it is a table: merged cells arrive merged, a cell of several lines stays one cell, a title above and a note below get rows of their own, and codes with a leading zero or long numbers stay as they are. A ruled table is read from its drawn lines, one without by a table model that comes with the plugin (7 MB, on this PC) (Screenshot and recording 1.1.39).

- 📌 **连着打开好几个结果查看**：钉住（`Ctrl+T`）的搜索框以前会盖住刚打开的文档，现在打开后自动让到后面，点它、按快捷键或点任务栏按钮再回到最前。叫回搜索框时列表原样不动，不重新搜索、不跳回第一行；从结果里打开过的文件和文件夹，名字后面标“已打开”。想一直钉住，在 **设置 › 结果列表 › 操作习惯** 打开“一直钉住搜索框”（默认关）。预览窗口标题栏多了放大键（双击标题栏也行），占满屏幕高度来看。

  **Opening results one after another**: a pinned search box (`Ctrl+T`) used to cover the document just opened from it; it now stands back and comes over the other windows again when you click it, press its shortcut or its taskbar button. Brought back, the list is as you left it (no new search, no jump to the first row), and files and folders opened from it are tagged 已打开. **Settings › Result list › Habits › 一直钉住搜索框** keeps it pinned from the start (off by default). The preview's header has an enlarge key (or double-click the header) for the screen's whole height.

- 🎛️ **结果行尾的按钮自己选**：**设置 › 结果列表 › 结果行按钮** 里选要哪些按钮、排成什么顺序，拖动调整，点一下取消。除了原来的六个，还能加上预览、复制名称、收藏。不显示的按钮右键菜单里都还有。

  **Choose a row's buttons**: **Settings › Result list › Row buttons** picks which buttons a result's row shows and in which order (drag to move, click to take out). Preview, Copy name and Favorite can be added to the six there were; whatever is not shown stays in the right-click menu.

- ⌨️ **插件命令可以有自己的快捷键**（#466）：插件卡片上每个命令的关键字旁边可以录一个快捷键，在任何程序里按下，搜索框就带着这个关键字打开，接着打字就行；再按一次关闭。

  **A shortcut of its own for a plugin command** (#466): beside each command's keyword on the plugin's card a shortcut can be recorded; pressed in any program, the search box opens with that keyword typed, and pressed again it closes.

- 🔀 **类型标签可以拖着换顺序**：“文件”里的类型标签（“文件夹”也算）按住往旁边拖就换位置，**设置 › 结果列表 › 文件类型** 里也能上移下移，`Ctrl+Tab` 跟着同样的顺序。

  **Type chips in any order**: drag a type chip in Files (文件夹 too) to another place, or move it up and down under **Settings › Result list › File types**; `Ctrl+Tab` follows the same order.

## 改进与修复 · Improvements and fixes

- **读网络共享不再拖慢文件管理器**：你在用电脑时，读共享从一次一个文件夹开始，实测确实更快才加宽；每小时的自动核对等你离开电脑再做（最多等 2 小时）。排除文件夹可以写映射盘符（`Z:\素材`），也可以排除整个共享。

  **Reading a network share no longer slows the file manager**: with someone at the computer a share is read one folder at a time, wider only where that is measurably faster, and the hourly pass waits until you are away (2 hours at most). An excluded folder may be written by a mapped drive's letter (`Z:\rushes`), and a whole share can be excluded.

- **内存**（#467）：复制一张整屏截图时，Win顺 的瞬时内存从约 340 MB 降到约 150 MB，截图插件从 336 MB 降到 251 MB；识别图片文字时找文字行改成分条进行，峰值少一半。设置窗口开着时，离开半分钟的页面会收起，不再越开越大。

  **Memory** (#467): copying a full-screen capture peaks at about 150 MB in WinShun instead of 340 MB, and at 251 MB instead of 336 MB in the capture plugin; finding the lines of text in a picture works in strips, at half the peak. Settings pages left for half a minute are put away while the window is still open.

- **截图**：开着标注工具时，在空白处双击同样完成截图（按设置复制或其他动作），鼠标右键、中键、侧键设的动作也照常执行，不用先放下工具；只有正在画的时候不执行。

  **Captures**: with an annotation tool on, a double click on the bare picture finishes the capture as set, and the actions set for the right, middle and side buttons run too, with no putting the tool down first; only in the middle of drawing they do not.

- **剪贴板**：全屏独占的游戏上（Windows 10）呼出剪贴板不再看不见（#452）；点一下搜索框就能用输入法打字，双拼、五笔也能搜中文；打开“保留重复项”后，同样的内容连着复制两次就是两条。

  **Clipboard**: over a game in exclusive full screen (Windows 10) the panel no longer opens unseen (#452); a click in the search field lets an input method compose there; with 保留重复项 on, the same thing copied twice running is two entries.

- **系统右键菜单**：选中的文件不在同一个文件夹时，`Shift`+右键（或“更多选项”）也给出它们共同的菜单，比较工具的“比较”能用了（#464）。

  **System menu**: files picked in several folders get one menu together on `Shift`+right-click (or 更多选项), so a diff tool's Compare shows (#464).

- **缩略图**：装了相应软件的类型（CorelDRAW 的 `.cdr`、`.stl`、`.svg` 等）也显示缩略图。

  **Thumbnails**: types a program installed here makes thumbnails of (CorelDRAW's `.cdr`, `.stl`, `.svg` and the like) show them.

- **软件内更新**：安全软件正在扫描刚下载的安装包时会等它扫完，不再把好的安装包当成“没有通过检查”删掉；真被拦下时说明是被这台电脑上的程序拦下了，并给出下载页的链接。

  **Updating in the app**: a new package being scanned by security software is waited for instead of being deleted as "failed the check"; one that really is blocked is said to be blocked by a program on this PC, with a link to the download page.

- **文件对话框**：跳到文件夹后，你自己点到别处的焦点不会再被抢回文件名框。

  **File dialogs**: after going to a folder, a focus you put elsewhere in the dialog is no longer taken back to the file name box.
