## 新功能 · What's new

- ⌨️ **给剪贴板里常用的一条设快捷键**（和 Ditto 一样）：右键一条选“设置快捷键…”，设置会打开到这一条，按下想用的组合键（比如 `Ctrl+Alt+1`）。之后在任何程序里按它，直接粘贴这一条，不用打开剪贴板，也不管它排第几；格式和平时粘贴一样。设了的放进“固定”，不会过期，列表里那一条右边显示它的快捷键，**设置 › 快捷键 › 按键一览** 也列着。一个快捷键只给一条；和 Win顺 自己的快捷键冲突、被别的程序占用时，设置里那一条下面用红字说明。改或去掉在右键菜单或 **设置 › 剪贴板 › 快捷键 › 单条内容的快捷键** 里。

  **A shortcut for one clipboard entry** (as in Ditto): right-click an entry, choose 设置快捷键…, and settings open on it; press the keys you want (`Ctrl+Alt+1`, say). Those keys then paste that entry into any program without opening the clipboard, wherever it stands in the list, formatted as a usual paste. The entry goes into Pinned so it never expires, shows its keys at the right of its row and in **Settings › Shortcuts › Keys at a glance**. One shortcut, one entry; keys that clash with WinShun's own or are taken by another program are explained in red under the entry. Change or remove them from the entry's menu or **Settings › Clipboard › Shortcuts › Shortcuts for single entries**.

- 📋 **保留重复项**：**设置 › 剪贴板 › 记录** 打开“保留重复项”（默认关），同样的内容再复制一次也记成新的一条，不再合并到原来那条。紧接着复制同样的内容（连按两次 `Ctrl+C`）仍只记一条，从剪贴板粘贴出去也不算复制。

  **Keep duplicates**: turn on Keep duplicates under **Settings › Clipboard › Recording** (off by default) and copying the same content again adds a new entry instead of moving the old one up. The same content copied twice in a row (`Ctrl+C` pressed twice) is still one entry, and a paste from the clipboard is not a copy.

- 🗜️ **新插件“压缩包搜索”**：装上后，zip、7z、rar、tar.gz 等压缩包里的文件也能按名字搜到，跟在普通结果后面；输入 `zip 名字`（或 `压缩包 名字`）只看压缩包里的。`Enter` 打开压缩包，`Ctrl+Enter` 把这一个文件解压出来打开，`Shift+Enter` 打开所在文件夹，在“内容”里选中一行右边直接预览。后台用最低的磁盘优先级只读文件列表、不解压，进度在插件卡片上，可以暂停。要 Win顺 0.47.0，从插件库安装。

  **New plugin, Archive search**: installed, files inside zip, 7z, rar, tar.gz and other archives are found by name after the ordinary results; `zip name` (or `压缩包 name`) lists those alone. `Enter` opens the archive, `Ctrl+Enter` unpacks that one file and opens it, `Shift+Enter` shows the archive's folder, and in Content the pane on the right previews the file. Only each archive's list of files is read, in the background at the lowest disk priority, without unpacking; progress is on the plugin's card and can be paused. Needs WinShun 0.47.0; install it from the plugin library.

- 🖊️ **截图画笔点一下就是一个点**：画笔、荧光笔在图上点一下留一个圆点，不用拖；拿着它们时鼠标指针就是笔尖的大小和颜色，编辑图片时也一样（#461）。标注工具栏最前面多了“选择”按钮，点它放下正在用的工具，回到选择和移动（截图与录屏 1.1.37）。

  **A click with the capture pen is a dot**: the pen and the highlighter leave a dot where you click, no drag needed, and while either is held the pointer is its tip in its size and colour, in the picture editor too (#461). A Select button first on the annotation toolbar puts the current tool down to select and move again (Screenshot and recording 1.1.37).

## 改进与修复 · Improvements and fixes

- **全屏游戏里打开剪贴板面板不再一闪就没**：独占全屏的游戏为了让面板出来会退出全屏并最小化，以前面板把这当成“换了别的程序”而自己收起。现在面板留着并拿到键盘；粘贴或按 `Esc` 后面板先收起，再把游戏恢复回来（#452）。

  **The clipboard panel stays up over a full-screen game**: a game in exclusive full screen leaves it and minimizes so the panel can show, and the panel used to take that for another program coming forward and hide. Now it stays and has the keys; after a paste or `Esc` it goes first and the game is brought back (#452).

- **休息提醒“提前多少秒提醒”设成 0**：到点直接休息，不再先闪一下“马上开始…”的提示条（休息提醒 1.1.4）。

  **Break reminder with its notice at 0 seconds**: the break starts when due, without the “starting now…” bar flashing first (Break reminder 1.1.4).

- **插件开发**：只给插件的工具 `list_files`，分页列出名称索引里某几种扩展名的全部文件（压缩包搜索用它）。

  **Plugin development**: a plugin-only tool, `list_files`, lists every file of some extensions in the name index, a page at a time (Archive search uses it).
