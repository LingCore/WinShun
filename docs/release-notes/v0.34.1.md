Win顺 0.34.1 修好了 Windows 10 上闲着时不归还内存的问题：在较早的 Windows 10 上，Win顺 放着不用也一直占着两三百 MB，现在和 Windows 11 上一样，闲下来就降到十来 MB。

## 改进与修复 · Improvements and fixes

- **Windows 10 上闲着时又会归还内存了**：Win顺 闲下来会把用不着的内存还给系统，判断要不要还，看的是任务管理器“内存”那一列的数字。较早的 Windows 10（比如 1809 LTSC，以及没装 2023 年 9 月累积更新的版本）读这个数一直是 0，Win顺 以为自己占得很少，就从来不归还，一整天都占着两三百 MB。现在读不到时改看整个工作集，闲下来照样降到十来 MB；设置里“现在就归还”按钮显示的数字也一样处理。截图与录屏、图片文字搜索两个插件用的是同一段代码，一起修了。

  **Memory is given back on Windows 10 again**: when idle, WinShun returns the memory it does not need, judged by Task Manager's Memory figure. Older Windows 10 builds (1809 LTSC, say, or without the September 2023 cumulative update) always report that figure as 0, so WinShun thought it held almost nothing and never gave anything back, keeping two or three hundred MB all day. Where it cannot be read, the whole working set is used instead, and an idle WinShun drops to about ten MB again; the figures by the Give back now button in the settings are read the same way. Screenshot and recording and Picture text search use the same code and are fixed too.

## 验证范围 · Verification

修复在 Windows 10 22H2 虚拟机上实测：Win顺 放着不动约 20 秒后自动归还，主进程降到 6–8 MB；临时强制走旧系统那条路，同样降到 6–8 MB，150 秒内没有反复归还。真正的 1809 没有条件测。开发机上把 0.34.0 用应用内更新真实升级到 0.34.1（49.6 秒），新版本以普通权限启动，索引服务、开机自启、设置和搜索历史都在；安装程序在文件被占用的五种情形下也都实测通过。

The fix was tried on a Windows 10 22H2 virtual machine: left alone, WinShun gave its memory back after about 20 seconds, the main process dropping to 6–8 MB; with the older-Windows path forced in a test build, the same, and no repeated trims within 150 s. A real 1809 was not available. On the development PC 0.34.0 was really updated to 0.34.1 through the in-app update (49.6 s); the new version started with normal rights, and the index service, autostart, settings and search history were intact. Installing and upgrading with files held in five different ways also passed.
