## 新功能 · What's new

- 🧭 **直达系统设置**：输入“适配器”“网卡”或 `ncpa.cpl` 就能打开“网络连接”。Windows 设置的页面、控制面板的项目和任务（约 1200 个）按名称、关键词和拼音都能搜到，还有磁盘管理、组策略、启动文件夹、hosts 所在文件夹这类开始菜单里没有的入口。在“全部”里和应用排在一起，标着“系统”。
  **Straight to Windows settings**: type 适配器 (adapter), 网卡 (network card) or `ncpa.cpl` to open Network Connections. Pages of Settings and Control Panel items and tasks (about 1,200) are found by name, keyword and pinyin, along with tools and folders the Start menu lacks, such as Disk Management, Group Policy, the Startup folder and the folder of the hosts file. In All they sit with the apps, tagged System.
- ✅ **多选**：按住 Ctrl 点击逐个选，按住 Shift 点击或按 Shift+↑↓ 选一段；打开、打开所在位置、复制、复制路径、删除都对所有选中项生效，Esc 先取消选择。
  **Select several**: Ctrl+click picks rows one by one, Shift+click or Shift+↑↓ takes a range; open, show in folder, copy, copy path and delete then act on all of them, and Esc clears the selection first.
- 🗂️ **搜索范围精简为“全部 / 文件 / 内容”**：“全部”依次列出应用和系统设置、文件、文件夹、文件内容；“文件”只有文件和文件夹。用 Tab / Shift+Tab 切换，Ctrl+数字不再切换范围。
  **Three scopes: All, Files, Content**: All lists apps and Windows settings, then files, folders and file contents; Files has files and folders. Switch with Tab / Shift+Tab; Ctrl+number no longer switches scopes.
- 🕘 **管理最近使用**：右键某一项选“从最近使用中移除”，底栏可以一键清空；设置 → 打开 Win顺 里也可以不再记录。
  **Manage Recent**: right-click an item and choose Remove from recent, or clear them all from the footer; Settings → Open WinShun can stop recording them.
- 🪟 **云母效果**：Windows 11 上，搜索框和设置窗口的背景透出桌面壁纸的颜色。设置 → 外观 → 透明效果可以选关、开或自动（自动在内存不超过 16 GB 时关闭）。
  **Mica**: on Windows 11, the search bar and the settings window take on the colours of your wallpaper. Settings → Appearance → Transparency effects can be Off, On or Auto (off with 16 GB of RAM or less).
- 🖱️ **其他**：搜索框能拖到屏幕下方，结果列表显示放得下的行数；触摸滑动和拖动松手后的列表也不再抖动；Ctrl+点击改为多选，不再打开所在位置。
  **Also**: the search bar can be dragged low on the screen, and the list shows as many rows as fit; the list no longer shakes after a touch flick or a drag; Ctrl+click now selects instead of showing the item in its folder.
