Win顺 0.37.0 带来新插件“开发工具”：搜索框里打 `json` 就能格式化、压缩、转义剪贴板里的 JSON，还能打开窗口树形查看。截图识别出的表格可以一格一格地复制进 Excel，只装了 WPS 的电脑也能预览 Word、Excel、PPT 里的文字。设置的分类更少、更好找。剪贴板跟着“弹出动画”滑入淡出，打开时卡住半分钟的问题也修好了。

## 下载 · Downloads

- **WinShun-0.37.0-x64-setup.exe** 为标准安装版，覆盖升级保留设置、索引和剪贴板，增强 OCR 按需下载。
- **WinShun-0.37.0-x64-portable.zip** 为便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。
- **WinShun-0.37.0-x64-offline-setup.exe** 包含增强 OCR。官方可选插件从插件库安装。
- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 是同版本安装程序使用的增强 OCR 组件。
- **SHA256SUMS.txt** 提供全部附件的 SHA256。

The standard installer keeps settings, the index and clipboard history during an upgrade and downloads enhanced OCR when needed. For the portable edition, keep the existing `data` folder. The offline installer includes enhanced OCR. Optional official plugins are available from the plugin library. Scoop users can run `scoop update winshun` after the bucket update reaches them; with WinGet, `winget upgrade LingCore.WinShun` once the package has caught up.

升级不用迁移任何东西，设置、索引和剪贴板历史都保留。设置换了分类，原来的选项都还在，找不到时在设置里按 `Ctrl+F` 搜。从 0.35.0、0.36.0 软件内更新只下载变了的部分。

Nothing needs migrating: settings, the index and clipboard history are kept. Settings are grouped differently, every option is still there, and `Ctrl+F` in Settings finds any of them. Updating in the app from 0.35.0 or 0.36.0 downloads only what changed.

## 新功能 · What's new

- 🧰 **开发工具插件**（插件库新插件）：搜索框打 `json` 加空格，剪贴板里的 JSON 直接格式化、压缩或转义后复制；`Enter` 打开窗口，左边原文、右边树形，能搜键名和值、复制路径。日志里夹着的、转义过的、一行一段的 JSON 都认得，也可以把 JSON 直接粘进搜索框，`.json` 文件右键“用 JSON 工具查看”。

  **Developer tools plugin** (new in the plugin library): type `json` and a space, and the JSON on the clipboard is copied formatted, minified or escaped; `Enter` opens a window with the text beside a tree to search names and values and copy paths. It finds JSON inside log lines, escaped JSON and one-per-line JSON; JSON pasted into the search box works too, and `.json` files have View in JSON tool on their menu.

- 📊 **截图文字复制为表格**：识别出的字排成表格（几列上下对齐）时，多一个“复制为表格”，粘进 Excel、WPS 表格一格一格排好（截图与录屏 1.1.25）。

  **Copy a screenshot's words as a table**: when the recognized words stand in columns, Copy as a table pastes them cell by cell into Excel or WPS (Screenshot and recording 1.1.25).

- 📄 **只装 WPS 也能预览 Office 文档**：电脑上没有 Word、Excel、PowerPoint 的预览程序，或文件是从网上下载的，预览就显示文档里的文字，按页、幻灯片、工作表分段，Excel 带行号。

  **Office documents preview without Office**: where this PC has no preview handler for Word, Excel or PowerPoint (only WPS, say), or the file came from the internet, the preview shows the document's text by page, slide or sheet, with Excel's row numbers.

- ⚙️ **设置分类更少更清楚**：合成 12 类——常规（含更新、开机启动、备份、网络、存储与诊断）、快捷键、外观、搜索范围、结果列表、系统整合（任务栏、文件管理器、对话框）、收藏夹、剪贴板、插件、AI 助手、运行状况、拾穗计划。

  **Fewer, clearer settings categories**: twelve in all — General (updates, startup, backup, network, storage and diagnostics), Shortcuts, Appearance, Search scope, Result list, Integration (taskbar, file managers, dialogs), Favorites, Clipboard, Plugins, AI assistants, Health and Gleaning.

## 改进与修复 · Improvements and fixes

- **剪贴板也有弹出动画**：和搜索框一样跟着 设置 › 外观 › 弹出动画，从旁边滑入，关闭时淡出；关掉就一按即出（#377）。

  **The clipboard opens like the search box**: it follows Settings › Appearance › Open animation, sliding in and fading out; turned off, it appears at once (#377).

- **带公式的文字按原样显示**：从 WPS、Word 复制的带公式或图片的内容，在剪贴板列表和预览里显示复制时的样子，粘贴照旧（#367）。

  **Text with a formula shows as it looked**: content copied from WPS or Word with formulas or pictures shows in the clipboard list and preview as it looked; pasting is unchanged (#367).

- **剪贴板里一个文件的预览和搜索一样**：复制了一个文件或文件夹，剪贴板的侧边预览（`Alt+P`）和搜索结果的预览显示得一样，文档按原样显示（#324）。

  **One copied file previews as in the search**: with one file or folder copied, the clipboard's side preview (`Alt+P`) shows it as the search's preview does (#324).

- **打开剪贴板不再卡住半分钟**：条目很多又换了窗口大小时，有的电脑上打开剪贴板会卡 30 秒左右（#111）。

  **The clipboard no longer hangs for half a minute** on opening after a resize with many entries on some PCs (#111).

- **对话框搜索框**：自己学过的文件窗口（如 ArcGIS 的“添加数据”）里 `Ctrl+Enter` 转到文件夹并把文件名留在框里；以管理员身份运行的程序的对话框里，选中文件后连文件名一起填好，由你点打开或保存（#353）。

  **Dialog search bar**: in a learned file window (ArcGIS's Add Data, say) `Ctrl+Enter` goes to the folder and leaves the name in the box; in dialogs of programs run as administrator, a picked file goes there with its name filled in, Open or Save left to you (#353).

- **链接到同一磁盘的文件夹也按链接的路径收录**：用 `mklink` 建的、指向已经索引的磁盘里某个文件夹的链接，在链接的路径下也搜得到，Total Commander 里也显示大小（#364）。

  **Folder links to an indexed disk are listed under the link too**, so their files are found there and Total Commander shows their size (#364).

- **长截图的预览不会截进去**：滚动截图时盖在选区上的预览不再出现在结果里，还能拖开（截图与录屏 1.1.25，#378）。

  **The long screenshot's preview stays out of it**: the preview over the region is no longer captured and can be dragged aside (Screenshot and recording 1.1.25, #378).

- **“不记录的程序”连剪贴板都不打开**：设置 › 剪贴板 里列出的程序复制时，Win顺 不再打开剪贴板，和它们互不打扰。

  **Programs left out are left alone**: when a program listed under Settings › Clipboard copies, WinShun does not even open the clipboard.

- **资源管理器标签页 1.1.5**：读不到资源管理器窗口时，在日志里记下加载进来的外来 DLL，便于找出原因（#331）。

  **Explorer tabs 1.1.5** logs the DLLs from elsewhere when it cannot read File Explorer's windows, to find the cause (#331).
