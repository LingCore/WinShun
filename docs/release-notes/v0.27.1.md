## 新功能 · What's new

- ▶️ **应用 › 运行** 「应用」页的类型条最左边是「运行」，列出当前有窗口的程序（图标 + 窗口标题，带数量）；Enter 或点击直接切到那个窗口，已经最小化的会还原；右键与其它应用一致（复制窗口标题）。列表在前台时每 1.5 秒自动刷新。

  **Apps › Running** A 运行 choice at the left of the Apps strip: the windows open now (icon, title, count). Enter or a click switches to one, restoring it if minimized; the list refreshes every 1.5 s while shown.

- 📌 **记住范围标签** 选择「全部 / 内容 / 应用」后，关闭再打开（或重启）仍停在同一个标签；即使开启“每次打开时清空搜索”，也只清空文字与筛选，不再强制回到「全部」。

  **The scope tab is remembered** After choosing 全部, 内容 or 应用, opening again (or restarting) stays there. With "clear on open" on, only the words and filters are cleared, not the tab.

- ⬆️ **同步上游 0.27.0** 内容搜索的正则表达式与多词任一匹配、解压路径窗口的搜索框、命令关键词找文件、插件说明预览、截图输入宽高与锁定形状、桌面打字搜索、范围标签合并成一个按钮、结果行删除按钮可关闭、按程序记住“以管理员身份运行”等，见上游 0.27.0 的发布说明。

  **Upstream 0.27.0 merged** Regular expressions and either-of words in the Content search, the archivers' extraction path bar, commands finding files by their words, a plugin's README before installing, a typed capture size and a locked shape, typing on the desktop, the scope tabs as one button, result rows without the delete button, and programs remembered as run as administrator. See the upstream 0.27.0 notes.
