Win顺 0.41.0 带来鼠标手势 2.0：先选中文字再画一下就能复制、搜索、翻译；画圈、推到屏幕角落、在屏幕边上来回蹭、按住右键滚滚轮都能设成动作，还能只在某个程序、某个角落里生效，关机重启也能用手势（先倒数 5 秒，可以取消），手势在新的设置窗口里画出来就能设。新插件“缩写展开”：打 `cmd` 加空格就换成 `command`。剪贴板可以选打开时显示哪一类；收藏圆盘里的收藏多了按 `Tab` 翻页；捐赠按钮可以挪到拾穗计划页。修好了数据文件夹里的插件搜不到、设置换分类不够快、长截图后屏幕上留下空框。

## 下载 · Downloads

- **WinShun-0.41.0-x64-setup.exe** 为标准安装版，覆盖升级保留设置、索引和剪贴板，增强 OCR 按需下载。
- **WinShun-0.41.0-x64-portable.zip** 为便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。
- **WinShun-0.41.0-x64-offline-setup.exe** 包含增强 OCR。官方可选插件从插件库安装。
- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 是同版本安装程序使用的增强 OCR 组件。
- **SHA256SUMS.txt** 提供全部附件的 SHA256。

The standard installer keeps settings, the index and clipboard history during an upgrade and downloads enhanced OCR when needed. For the portable edition, keep the existing `data` folder. The offline installer includes enhanced OCR. Optional official plugins are available from the plugin library. Scoop users can run `scoop update winshun` after the bucket update reaches them; with WinGet, `winget upgrade LingCore.WinShun` once the package has caught up.

升级不用迁移任何东西，设置、收藏和剪贴板历史都保留。更新后第一次启动会把各个磁盘重新读一遍（索引里多记了要留下的文件夹），这段时间搜索照常可用。鼠标手势 2.0 要 Win顺 0.41.0，在 设置 › 插件 › 插件库 更新；它新要三项权限（让 Win顺 帮它关机重启睡眠、让 Win顺 帮它读选中的文字、把译文放到剪贴板），更新时会问你；1.0 里改过的手势会自动搬过去。从 0.36.0 起的版本软件内更新只下载变了的部分。

Nothing needs migrating: settings, favorites and clipboard history are kept. The first start after the update reads the disks again (the index now keeps the folders it must keep), and searching works meanwhile. Mouse gestures 2.0 needs WinShun 0.41.0; update it from Settings › Plugins › Plugin library. It asks for three more permissions (WinShun shuts down, restarts or sleeps for it; WinShun reads the selected words for it; a translation can go to the clipboard), which the update asks you about; gestures changed in 1.0 are carried over. Updating in the app from 0.36.0 or later downloads only what changed.

## 新功能 · What's new

- 🖱️ **鼠标手势 2.0**：
  - **选中文字再画**：先选中一段字，按住右键往下画是复制、往上是网页搜索、往右是翻译（译文显示在气泡里，点一下复制）；没选中文字时还是平常的手势。选中的文字由 Win顺 读，不经过剪贴板，剪贴板里原来的东西不会被换掉。浏览器、VS Code、微信等用 Chromium 做的程序和 Firefox 里不读（一读它们就会变慢），在那里还是平常的手势。
  - **更多画法**：画圈（顺时针、逆时针）；同一个手势在屏幕四个角上画可以做不同的事，比如只有在右下角画圈才关机；把鼠标推到屏幕角落停一下（触发角）、在屏幕边上来回蹭几下（摩擦边）；按住右键滚滚轮默认切换标签页。
  - **按程序设置**：某个手势在某个程序里换成别的动作，或者在那里关掉它。
  - **更多动作**：标签页、窗口置顶、显示桌面、任务视图、切到上一个窗口、复制粘贴、媒体和音量、锁屏、关闭屏幕、睡眠、关机、重启、注销，还有按任意组合键、打开程序或网址、输入一段文字。关机、重启、注销、睡眠先在屏幕中间倒数 5 秒，按 Esc 或点“取消”就不做。
  - **新的设置窗口**：插件卡片上点“设置”，在画板上用右键画一下，选它要做的事就行；分成手势、选中文字时、角落和屏幕边、程序、常规几页。画到一半按 Esc 反悔，松开什么都不做。

  **Mouse gestures 2.0**: select some text and draw down to copy, up to search the web, right to translate (in a bubble; a click copies it), without touching the clipboard. Browsers, VS Code, WeChat and other Chromium programs, and Firefox, are not read (asking them makes them slower): the plain gestures hold there. Circles; the same gesture can do something else in a corner of the screen (a circle in the bottom right to shut down); hot corners and rubbed screen edges; the wheel with the right button held switches tabs. Rules per program. More actions: tabs, keep on top, desktop, task view, last window, editing, media and volume, lock, screen off, sleep, shut down, restart and sign out (those four count down 5 seconds first; Esc cancels), any keys, opening a program or address, typing text. A new settings window from the plugin's card: draw on its pad with the right button and pick what it does. Esc while drawing takes it back.

- ⌨️ **缩写展开**（新插件，插件库）：在任何地方打 `cmd` 再按空格、回车、Tab 或标点，就换成 `command`；缩写和内容在插件卡片上自己写，一行一条，内容可以有好几行；紧接着按退格撤回。输入法在打中文时、Win顺 自己的窗口里、以管理员身份运行的窗口里不展开，也可以列出不用的程序。输入 `缩写` 列出、暂停（#403）。

  **Text expander** (new plugin, in the plugin library): type `cmd` and a space, Enter, Tab or a punctuation mark anywhere and it becomes `command`; the abbreviations are yours, one per line, and may run over several lines; Backspace right after takes it back. Not while the input method composes Chinese, in WinShun's own windows or in windows run as administrator, nor in programs you list. `expander` lists and pauses them (#403).

- 📋 **剪贴板打开时显示哪一类**：在 设置 › 剪贴板 › 打开时显示 选“全部”“上次看的”“文字”“链接”“图片”“文件”“固定”或某个分组；也可以右键某个分类选“打开时显示这里”（#404）。

  **The clipboard opens on the tab you choose**: All, the last one, Text, Links, Pictures, Files, Pinned or one of your groups, under Settings › Clipboard › Open on; or right-click a tab and pick Open here (#404).

- 🗂️ **收藏圆盘翻页**：拖文件时按 `` ` `` 出来的收藏圆盘，收藏超过 8 个时分页显示，按 `Tab` 下一页、`Shift+Tab` 上一页（#405）。

  **Pages on the favorites pie**: with more than 8 favorites the pie you open with `` ` `` while dragging shows them 8 at a time; `Tab` turns to the next page and `Shift+Tab` back (#405).

- ❤️ **捐赠按钮可以挪走**：设置窗口标题栏的“捐赠”旁边多了一个 ×，点一下把它挪到拾穗计划页，那里也能放回来（#402）。

  **The donate key can move**: the × beside Donate in the settings window's title bar moves it to the Gleaning page, where it can be put back (#402).

## 改进与修复 · Improvements and fixes

- **数据文件夹里的插件搜得到了**：Win顺 的数据文件夹不进索引（里面的文件变得太勤），插件装在里面，搜插件的文件夹就找不到。现在数据文件夹里的 `plugins` 照常进索引；你自己排除了的照旧排除（#406）。

  **Plugins in WinShun's data folder are found**: the data folder stays out of the index (its files change too often), so the plugins inside it could not be found. Its `plugins` folder is now indexed, unless you excluded it yourself (#406).

- **设置换分类更快**：按下去就换（不用等松开），高亮先到位，没打开过的页面在鼠标停上去时就先准备好。

  **Switching settings categories is quicker**: the category changes on the press, the highlight moves first, and a page not yet opened is prepared while the pointer rests on it.

- **长截图后不再留下空框**：长截图结束后，屏幕上原来预览的地方有时留下一个空的圆角框（截图与录屏 1.1.29）。

  **No empty frame after a long screenshot**: an empty rounded frame could stay where the preview had been (Screenshot and recording 1.1.29).

- **给插件作者**：插件的文字设置可以是多行的（`"multiline": true`）；设置项可以藏起来只由插件自己的设置窗口改（`"hidden": true`）；新的 `power` 工具（权限 `system:power`）让 Win顺 替插件关机、重启、睡眠；新的 `selected_text` 工具（权限 `selection:read`）让 Win顺 替插件读前台窗口里选中的文字（插件的沙盒碰不到别的程序的窗口）。见 [插件文档](../plugins.md)。

  **For plugin authors**: a text setting can have several lines (`"multiline": true`); a setting can be hidden from the card and changed only by the plugin's own window (`"hidden": true`); the new `power` tool (permission `system:power`) has WinShun shut down, restart or sleep for a plugin; the new `selected_text` tool (permission `selection:read`) has WinShun read the words selected in the window in front (a plugin's sandbox keeps it from other programs' windows). See the [plugin docs](../plugins.en.md).
