## 新功能 · What's new

- 📌 **剪贴板打开时就钉住**：要连着粘贴好几条时，到 **设置 › 剪贴板 › 记录 › 粘贴动作与列表显示** 打开“打开时钉住”，剪贴板一打开就是钉住的，粘贴后不收起；按 `Esc` 关掉，`Ctrl+T` 临时取消。默认关着。

  **Clipboard opens pinned**: to paste several entries one after another, turn on 打开时钉住 under **Settings › Clipboard › Record › Paste actions and list display**; the clipboard then opens pinned and stays after pasting. `Esc` closes it, `Ctrl+T` unpins it for the moment. Off by default.

- 💻 **终端开在这个文件夹里**（#430）：在文件夹窗口或资源管理器里打字搜索时，打 `cmd`、`powershell`、`pwsh`、`wt`、`git bash` 或 `wsl`，在找到的终端上按 `Enter`，它就开在当前这个文件夹里，和在资源管理器地址栏里输入 `cmd` 一样；`Ctrl+Shift+Enter` 以管理员身份。其他程序照常打开。

  **A terminal opens in this folder** (#430): typing in a folder, Enter on `cmd`, `powershell`, `pwsh`, `wt`, `git bash` or `wsl` opens that terminal in the folder, as typing `cmd` in Explorer's address bar does; `Ctrl+Shift+Enter` as administrator. Other programs open as before.

- 🔍 **预览里一眼看到搜的词**（#482）：文本和代码文件的预览里，搜的词垫上一层底色并加粗，第一处所在的那一行整行衬出来并滚到眼前。以前只换颜色，夹在上了色的代码里不显眼。结果列表照旧只给字上色。

  **Searched words stand out in the preview** (#482): in a text or code file's preview the words searched for get a fill under them and bold type, and the first one's line a band across, scrolled into view. They used to change colour only, lost among the code's own colours. Result lists stay as they were.

- 🖼️ **大图模式可以排序**（#483）：面板切到“大图”时没有列头，排序放到了底栏左边：**最匹配**、**最新**、**最早**，“更多”里还有名称、所在文件夹、类型、大小，现在按哪种排一眼能看到；`Ctrl+S` 照常轮换。

  **Order chips for large icons** (#483): the panel's thumbnail grid has no column headers, so the footer now carries the order: best match, newest, oldest, and under More name, folder, type and size, the one in use shown; `Ctrl+S` still cycles them.

- 🔌 **插件卡片上的“测试连接”**（#495）：翻译、按意思找、云备份填好服务和密钥后，卡片上点“测试连接”，连上了写“连接正常”和用时，连不上直接写明原因（密钥不对、模型没下载、本机模型服务没启动、地址或密码不对等）。翻译只发一个单词 hello，按意思找发一小段文字，云备份只读备份列表、不上传（翻译 2.4.0、按意思找 1.2.0、云备份 1.1.0）。

  **Test connection on plugin cards** (#495): once a service and key are set, Translate, Search by meaning and Cloud backup have a Test connection button on their cards; it says 连接正常 and how long it took, or why it failed (a wrong key, a model not downloaded, the local model server not running, a wrong address or password). Translate sends the single word hello, Search by meaning one short text, and Cloud backup only lists the backups, uploading nothing (Translate 2.4.0, Search by meaning 1.2.0, Cloud backup 1.1.0).

## 改进与修复 · Improvements and fixes

- **搜索**：模糊匹配开着时，打 `tim` 排在前面的是 TIM，不再是天天打开的 System Informer：模糊猜到的程序只有为这几个字选过它才往前排，光是常用不算。面板在“内容”范围下也写一共找到多少个文件，还在找时写“已找到 N 个文件，还在找…”（#476）。预览开着时把搜索框清空、什么都没列出，预览窗口跟着关掉（#492）。

  **Search**: with fuzzy matching on, `tim` puts TIM first, not System Informer opened every day: a fuzzy guess moves up only for having been chosen for this text, not for being used a lot. The panel counts the files of a content search too, 已找到 N 个文件，还在找… while it runs (#476). With the preview open, emptying the box so nothing is listed closes the preview (#492).

- **截图**：打码时点一行字，手稍微滑了几个像素也算点中，不再画出一个小框把后面的点击挡住；选了别的样式再点已经盖住的一行，会换成新样式，同样的样式再点才取消（#499）。`Shift+C` 识别文字并复制后，选区旁出现小卡片，显示复制了什么，点“编辑”可以改了再用（#489）。演示时从桌面直接打开黑板是黑色的，不再是白色（#485）。公式识别窗口的关闭按钮又有图标了（截图与录屏 1.1.41）。

  **Captures**: a click on a line of text to hide it still counts when the hand slipped a few pixels, instead of drawing a tiny box that caught the next clicks; a hidden line clicked with another style takes that style, and only the same style unhides it (#499). After `Shift+C` copies the text read, a small card beside the selection shows what was copied, with 编辑 to change it (#489). The black board opened straight from the desktop while presenting is black, not white (#485). The formula window's close button has its icon again (Screenshot and recording 1.1.41).

- **便携版和文件管理器**：便携版的 Total Commander、XYplorer、Pulse 运行过一次后 Win顺 记住它在哪，之后它关着也能用它打开文件夹。便携版更新下载的包和更新日志放在 `data\Updates`，不再写到系统盘（#484）。

  **Portable copies**: a portable Total Commander, XYplorer or Pulse is remembered after it has run once, so folders open in it while it is closed. The portable edition keeps its update downloads and log in `data\Updates`, off the system drive (#484).

- **设置**：插件页的两个筛选框右边有清空的 ×，旁边写“N 个插件，筛选后显示 M 个”：从别处点链接跳到插件库，筛选框里留着的名字不会再让人以为只有一个插件。关掉“文件夹菜单”时，它下面的几行跟着收起（#493）。

  **Settings**: both filter boxes on the plugin pages have an × to empty them, and the line beside says how many plugins there are and how many the filter shows, so a name left there by a link no longer looks like a library of one. Turning the folder menu off folds its rows away (#493).

- **稳定性和诊断**：有人在睡眠唤醒后闲着时崩溃，记录指向 Qt 分步回收界面内存的那段代码；Win顺 和带界面的插件改成一次回收，避开这一处（#490，这边没能复现，先这样观察）。剪贴板里 32 位的图片存成文件时，第四个字节写成不透明，有的程序打开时不会再是一片空白（#497）。检查更新时服务器的回答记进诊断日志，方便查“为什么没提示更新”（#487）。

  **Stability and diagnostics**: a crash while idle after sleep pointed at Qt's garbage collection done in steps between events; WinShun and its plugins with windows now collect all at once, avoiding that code (#490; not reproduced here, being watched). A 32-bit clipboard picture saved to a file has its fourth byte written opaque, so some programs no longer open it blank (#497). What the update service answered goes into the diagnostics log, to tell why no update was offered (#487).
