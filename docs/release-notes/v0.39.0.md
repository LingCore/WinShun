Win顺 0.39.0 让设置里的收藏夹像资源管理器一样点列头就排好顺序，排之前的顺序一键恢复。插件页改成一张张卡片，点开看详情；插件关键词的搜索也记进搜索历史。修好了一类会让 Win顺 闪退的图片：很长很细的截图读字时不再占掉几个 GB 内存，万一程序意外退出，下次启动会记下当时停在哪里，方便排查。设置窗口的标题栏多了一个“捐赠”按钮。

## 下载 · Downloads

- **WinShun-0.39.0-x64-setup.exe** 为标准安装版，覆盖升级保留设置、索引和剪贴板，增强 OCR 按需下载。
- **WinShun-0.39.0-x64-portable.zip** 为便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。
- **WinShun-0.39.0-x64-offline-setup.exe** 包含增强 OCR。官方可选插件从插件库安装。
- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 是同版本安装程序使用的增强 OCR 组件。
- **SHA256SUMS.txt** 提供全部附件的 SHA256。

The standard installer keeps settings, the index and clipboard history during an upgrade and downloads enhanced OCR when needed. For the portable edition, keep the existing `data` folder. The offline installer includes enhanced OCR. Optional official plugins are available from the plugin library. Scoop users can run `scoop update winshun` after the bucket update reaches them; with WinGet, `winget upgrade LingCore.WinShun` once the package has caught up.

升级不用迁移任何东西，设置、索引、收藏和剪贴板历史都保留，收藏的顺序不会变，点了列头才会排。截图里读字的修复要“截图与录屏”1.1.27，图片文字搜索要 1.0.24，在 设置 › 插件 › 插件库 更新。从 0.36.0 起的版本软件内更新只下载变了的部分。

Nothing needs migrating: settings, the index, favorites and clipboard history are kept, and the favorites keep their order until a column header is clicked. The fix for reading words in screenshots needs Screenshot and recording 1.1.27, and Image text search 1.0.24, from Settings › Plugins › Plugin library. Updating in the app from 0.36.0 or later downloads only what changed.

## 新功能 · What's new

- 🗂️ **收藏夹点列头排序**：设置 › 收藏夹 的列表上面有“名称、修改日期、类型、大小”四个列头，点一下就按这一列排好，再点一次反过来，第三次回到原来的顺序。排好的就是收藏的顺序，搜索框、收藏图标、收藏圆盘都跟着变；排序前的顺序记着，点右边的“恢复默认”随时回去，收藏一个也不少（#397）。

  **Sort favorites by a column**: Settings › Favorites has Name, Date modified, Type and Size headers over the list. A click sorts by that column, again the other way, a third time back to the order you had. The sorted order is the favorites' order everywhere (search box, icons, drag pie), and Restore order brings back the order from before the first sort without removing any (#397).

- 🧩 **插件页排成卡片**：设置 › 插件 的已安装、插件库和内置功能排成一张张卡片，窗口宽时一行 4 张；卡片上看得到简介、关键词和开关，点开是这个插件自己的一页，设置项、权限、说明都在里面。打开设置页也更顺，不再卡一下。

  **Plugins as tiles**: Installed, Plugin library and Built-in features under Settings › Plugins are tiles, four in a row in a wide window, each with its description, keywords and switch; click one for the plugin's own page with its settings, permissions and readme. The page also opens without the hitch it had.

- 🕘 **插件关键词的搜索也进搜索历史**：比如算式 `= 3*7`，在搜索历史里再选一次就重新算出结果；`md5`、`sha256`、`b64` 这类常输入密码的不记（#395）。

  **Plugin keyword searches in the search history**: a sum such as `= 3*7` is kept and works again when chosen; `md5`, `sha256` and `b64`, where passwords get typed, are not kept (#395).

- ❤️ **设置窗口标题栏的“捐赠”**：觉得 Win顺 好用，点它到作者的爱发电页面支持一下；鼠标移上去它会动起来。

  **Donate** in the settings window's title bar opens the author's Afdian page, for anyone who wants to support WinShun; it comes alive under the pointer.

## 改进与修复 · Improvements and fixes

- **很长很细的图片不再让 Win顺 闪退**：剪贴板里或截图读字时，三万多像素宽、几十像素高这样的长条图原来要占几个 GB 内存，有的电脑上会直接退出，而且每次启动两分钟后又退出。现在它和普通截图占得差不多；某张图读字时程序意外退出过两次，就不再读它。截图与录屏 1.1.27、图片文字搜索 1.0.24 一起修了。

  **Long thin pictures no longer end WinShun**: reading the words in a strip tens of thousands of pixels wide and a few dozen high took several GB, and some PCs quit, again two minutes after every start. Such a picture now takes about what a screenshot does, and a picture that ended the program twice is not read again. Screenshot and recording 1.1.27 and Image text search 1.0.24 have the same fix.

- **闪退时记下停在哪里**：程序万一意外退出，下次启动会把当时停在哪个模块和位置、在做什么（比如正在读一张多大的图，不含图的内容）记进诊断包，导出发给开发者就能查到原因。

  **Where it stopped, after a crash**: should WinShun end unexpectedly, the next start records in the diagnostics where it stopped and what it was doing (the size of a picture being read, say, never its content), for the developer to find the cause.

- **点插件卡片上的“设置”时，插件没在运行也能打开**：Win顺 先把它启动起来，再打开它的设置窗口（感谢 ra9fael 的 PR #396）。

  **Settings on a plugin's tile works when the plugin is not running**: WinShun starts it first, then opens its settings window (thanks to ra9fael for PR #396).

- **英文界面补齐**：插件卡片和插件设置打不开时的提示有了英文。

  **English everywhere on the plugin tiles**, and for the message when a plugin's settings cannot be opened.
