Win顺 0.44.0：设置窗口能像浏览器一样后退、前进，标题栏上的箭头、`Alt+←/→`、鼠标侧键都行，回去还在原来的标签和位置；页面滚到底再往下滚就到下一页；相关的设置之间多了跳转，“系统整合”里文件夹菜单单独成一页。托盘图标的左键、中键可以自己选做什么，还可以设一个快捷键直接打开设置。Win顺 截图记不记进剪贴板历史可以单独设；搜不到东西时会告诉你排除目录、已跳过的文件里有没有，点一下这次也搜；搜索结果可以以管理员身份在终端中打开（#425）。列表滚动后 1–9 编号跟着看得到的行走，对话框旁的搜索框也有编号。钉住的搜索框在任务栏上显示 Win顺 的图标，剪贴板的预览和看大图窗口有了边框和阴影。

The standard installer keeps settings, the index and clipboard history during an upgrade and downloads enhanced OCR when needed. For the portable edition, keep the existing `data` folder. The offline installer includes enhanced OCR. Optional official plugins are available from the plugin library. Scoop users can run `scoop update winshun` after the bucket update reaches them; with WinGet, `winget upgrade LingCore.WinShun` once the package has caught up. 升级不用迁移任何东西，设置、收藏和剪贴板历史都保留。托盘图标左键照旧打开搜索框，中键单击现在默认打开设置。以前关了“记录图片”的，新的“记录截图”也是关着的，和原来一样不记 Win顺 截图。文件夹菜单的设置从 设置 › 系统整合 › 文件管理器 挪到了新的“文件夹菜单”标签，设置本身没变。截图与录屏 1.1.32、鼠标手势 2.1.2、开发者工具 1.0.4、图片文字搜索 1.0.29 跟着更新了共用的窗口代码，插件库会自动更新它们。从 0.36.0 起的版本软件内更新只下载变了的部分。

Nothing needs migrating: settings, favorites and clipboard history are kept. A left click on the tray icon still opens the search box; a middle click now opens Settings by default. If 记录图片 was off, the new 记录截图 starts off too, so WinShun screenshots stay out of the history as before. The folder menu's settings moved from Settings › Integration › File managers to a new Folder menu tab, unchanged. Screenshot and recording 1.1.32, Mouse gestures 2.1.2, Dev tools 1.0.4 and Picture text search 1.0.29 come with the shared window code; the plugin library updates them by itself. Updating in the app from 0.36.0 or later downloads only what changed.

## 新功能 · What's new

- ⬅️ **设置窗口能后退、前进**：标题栏上多了两个箭头，鼠标停上去会说回到哪里，右键列出走过的地方、点一下直接过去。`Alt+←`、`Alt+→`、鼠标侧键（在标题栏上也行）和键盘上的浏览器后退、前进键都能用。回去时还是原来的标签和滚动位置；设置里搜索也算一步，从搜索结果点进某个设置后，后退回到搜索结果，再后退回到搜索之前的地方。每次打开设置窗口重新开始记。

  **Back and Forward in Settings**: two arrows in the title bar say where they go when you rest on them, and a right click lists the places you have been, one click away. `Alt+←`, `Alt+→`, the mouse's side buttons (over the title bar too) and a keyboard's browser Back and Forward keys work as well. Going back brings the same tab and scroll position; a settings search is a step too, so Back from a setting you opened from the results goes to the results, and Back again to where you were before searching. Each time Settings opens, the history starts afresh.

- ⏬ **滚到底再滚，就到下一页**：设置页面滚到最下面后再往下滚一格，底部提示“继续向下滚动，切到「…」”，再滚一格就到下一个标签，标签走完到左边的下一页；往上滚同样回到上一页的底部。快速甩到底不会误切。

  **Scroll on to the next page**: at the bottom of a settings page one more notch shows "keep scrolling down for …", and the next one goes to the next tab, or the next page once the tabs run out; scrolling up at the top goes back to the bottom of the one before. A quick flick to the end does not switch.

- 🔗 **相关的设置之间能直接跳过去**：快捷键页的“其他功能的快捷键”列出剪贴板、文件夹菜单和 `Win+S` 的设置，点一下就到，那一行滚到眼前；外观页能跳到剪贴板的大小，收藏夹页显示收藏在文件夹菜单和搜索框里怎么显示，搜索范围能跳到索引位置，Directory Opus、OneCommander 和拖放圆盘的卡片上有“更多设置”。快捷键 › 按键一览 也列出 `Win+V`、`Win+S` 和文件夹菜单的快捷键。系统整合 里文件夹菜单单独成了一个标签。

  **Links between related settings**: the shortcuts page's 其他功能的快捷键 lists the keys of the clipboard, the folder menu and `Win+S`, each a click away with its row scrolled into view; Appearance links to the clipboard's size, Favorites shows how favorites appear in the folder menu and the search box, Search scope links to the index location, and the Directory Opus, OneCommander and drop pie cards have 更多设置. Shortcuts › 按键一览 lists `Win+V`, `Win+S` and the folder menu's key too. The folder menu has a tab of its own under Integration.

- 🖱️ **托盘图标左键、中键自己选**：在 设置 › 系统整合 › 任务栏 › 托盘图标 里，左键单击（默认打开搜索框）和中键单击（默认打开设置）可以分别设成打开搜索框、完整搜索面板、剪贴板、设置、截图历史，暂停或恢复记录剪贴板，已启用插件的动作，或者什么都不做。右键还是托盘菜单。

  **Choose what the tray icon's clicks do**: in Settings › Integration › Taskbar › 托盘图标, the left click (the search box by default) and the middle click (Settings by default) can each open the search box, the full panel, the clipboard, Settings or the screenshot history, pause or resume clipboard recording, run an enabled plugin's action, or do nothing. Right click is still the tray menu.

- ⌨️ **一个快捷键打开设置**：设置 › 快捷键 › 打开 Win顺 里的“打开设置”，比如设成 `Alt+X`，按一下打开设置窗口，设置窗口在最前面时再按一下关掉。默认不设。

  **A key for Settings**: 打开设置 in Settings › Shortcuts, `Alt+X` say, opens the settings window, and closes it again when it is in front. None by default.

- 📸 **Win顺 截图记不记进剪贴板历史，单独设**：设置 › 剪贴板 › 记录 里“记录图片”下面多了“记录截图”：全部（复制、贴图、保存的截图都记）、仅复制时（只记点了复制的）、不记录（复制照样能粘贴，只是不进历史）。“记录图片”只管别的程序复制的图片了。

  **WinShun screenshots in the clipboard history, on their own**: under 记录图片 in Settings › Clipboard › 记录, the new 记录截图 is 全部 (copied, pinned and saved screenshots), 仅复制时 (only those you copy) or 不记录 (a copy still pastes, it just stays out of the history). 记录图片 is about pictures copied elsewhere now.

- 🔍 **排除目录、已跳过的文件里的也能找**：按名字搜不到，或者有些结果在不搜索的文件夹（比如 `%TEMP%`、Windows 的缓存文件夹）、已跳过的文件类型里时，搜索框会提示“排除目录里有 N 项”“已跳过的文件里有 N 项”，点“这次也显示”就列出来，“排除设置…”直接去改。输入排除目录里的路径时可以“这次也搜它”，输入没索引的文件夹可以“加入索引”；明确输入跳过的扩展名（比如 `report.bak`）时直接显示。搜索面板里也一样。

  **Found in excluded folders and skipped files too**: when a name search finds nothing, or some matches sit in folders you skip (`%TEMP%` and Windows' cache folders, say) or in skipped file types, the search box says so ("N in excluded folders", "N among skipped files"); 这次也显示 lists them and 排除设置… goes to the setting. A path inside an excluded folder offers 这次也搜它, a folder outside the index 加入索引; typing a skipped extension outright (`report.bak`) shows those files. The search panel does the same.

- 🛡️ **以管理员身份在终端中打开**：搜索结果的操作菜单（右键、`→` 或 `Ctrl+O`）里，“在终端中打开”下面多了“以管理员身份在终端中打开”；按住 `Shift` 点行尾的终端按钮也一样。文件就打开它所在的文件夹，用的是设置里选的终端（#425）。

  **Open in Terminal as administrator**: a result's action menu (right click, `→` or `Ctrl+O`) has 以管理员身份在终端中打开 right below 在终端中打开, and `Shift`+click on the row's terminal button does the same. A file opens its folder, in the terminal chosen in the settings (#425).

- 🔢 **编号跟着滚动走**：列表滚动后，1–9 编号标在看得到的那几行上，`Alt+1` 打开看得到的第一行，剪贴板也一样；对话框旁的搜索框也有编号（“序号提示”三处共用）。滚动时底部显示看到第几项（比如 `6–10 / 18`），滚动条跟着亮起来；鼠标停在编号上会说明按它做什么。

  **Numbers follow the scroll**: scrolled, the 1–9 numbers mark the rows in view, so `Alt+1` opens the first one you see, in the clipboard too; the box beside Open and Save dialogs has them as well (one 序号提示 setting for all three). While scrolling, the bottom shows where you are (`6–10 / 18`, say) and the scroll bar lights up; resting on a number says what pressing it does.

## 改进与修复 · Improvements and fixes

- **钉住的搜索框在任务栏上有图标了**：按 `Ctrl+T` 钉住后，任务栏按钮、缩略图和 `Alt+Tab` 里显示的是 Win顺 的图标，不再是空白的默认图标；窗口重建后也保持原来的边框和样式。

  **The pinned search box has its icon on the taskbar**: pinned with `Ctrl+T`, its taskbar button, thumbnail and `Alt+Tab` show WinShun's icon instead of the blank default; its frame and style also survive the window being made anew.

- **剪贴板的预览和看大图窗口有了边框**：鼠标停在剪贴板条目上弹出的预览、看大图的窗口，有了和菜单一样的边框、阴影和圆角；搜索历史菜单和快捷键提示的边缘也补上了。鼠标手势的卡片和气泡在 Windows 10 上画出 1 像素的边（鼠标手势 2.1.2）。

  **Frames for the clipboard's preview and picture viewer**: the preview that pops up over a clipboard entry and the large picture viewer have the menus' border, shadow and corners; the search history menu and the shortcut tip get their edge too. Mouse gesture cards and bubbles draw a 1 px edge on Windows 10 (Mouse gestures 2.1.2).

- **用键盘操作剪贴板、搜索框和文件夹菜单后不再等钩子收尾**：收起键盘钩子挪到它自己的线程上做，界面和随后的粘贴不再等它。

  **No more waiting for the keyboard hook to wind down**: after the clipboard, the search box or the folder menu took keys, the hook is taken off on its own thread, so neither the window nor the paste right after waits for it.
