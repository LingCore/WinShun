## 新功能 · What's new

- 📜 **滚动不再抖动**：用滚轮滚动结果列表时，文字和图标不再上下跳动，停下前的那一段也稳稳的（在 125%、150% 这类缩放下最明显）。
  **Steady scrolling**: scrolling the result list with the wheel no longer makes text and icons jitter, right up to where it stops (most visible at scales such as 125% and 150%).
- ⚡ **托盘菜单第一次打开更快**：输入法会在后台提前准备好，第一次右键托盘图标不再明显慢于之后。
  **Faster first tray menu**: the input method is made ready in the background, so the first right-click on the tray icon is no longer noticeably slower than later ones.
