## 新功能 · What's new

- 🔎 **代替任务栏上的 Windows 搜索**：设置 → 打开 Win顺 → 任务栏 里是一张四步的卡片，做好的一步自动打勾。打开“在任务栏上放 Win顺 的搜索框”（Windows 11），任务栏图标旁边就多了一个搜索框：点它直接打字，结果从任务栏后面滑出来，中文输入法的候选条也在框上。按住框左边的图标可以把它拖到任务栏别的空地上，开关程序时它跟着图标一起挪。不想占地方，也可以只固定一个按钮（Windows 会问是否固定，选“是”）。还没打字时，上面一排是最常用的 6 个应用。还可以用 `Win+S` 打开（`Win+Shift+S` 截图照常可用），或者在开始菜单里直接打字也用 Win顺 搜索。
  **In the place of Windows search on the taskbar**: Settings → Open WinShun → Taskbar has a four-step card that ticks off each step done. Turn on “Put WinShun's search box on the taskbar” (Windows 11) and a search box appears beside the taskbar icons: click it and type, the results slide out from behind the taskbar, and the input method's candidates sit on the box. Hold the icon at its left to drag it elsewhere along the taskbar; it moves with the icons as programs open and close. Or just pin a button (Windows asks whether to pin it: say yes). Before you type, the top row has the six apps you open most. `Win+S` can open it too (`Win+Shift+S` still takes screenshots), and so can typing in the Start menu.
- 📅 **修改日期和只找文件夹**：每个文件和文件夹的名字右边写着上次修改的时间（今天 14:32、昨天、周三……），鼠标停在上面看完整日期；在 **文件** 和 **文件夹** 里点底栏的排序按钮，最近修改的排在前面。选中 **文件** 时旁边出现 **文件夹**，点它或接着按 `Tab` 就只列文件夹。名字和输入完全一样的排在最前；文件和文件夹各排各的，默认文件在前，设置里可以改成文件夹在前。
  **Dates, and folders alone**: every file and folder shows when it was last changed (today 14:32, yesterday, Wednesday…), the full date on hover; in **Files** and **Folders** the sort button in the footer puts the newest first. With **Files** selected, **Folders** appears beside it: click it, or press `Tab` again, for folders only. A name that is exactly what you typed comes first; files and folders rank apart, files first by default, folders first if you like.
- 🔢 **数字键直接打开**：按住 `Ctrl` 片刻，每行右边标出序号，按 `Ctrl+1`～`Ctrl+9` 打开看得见的第几行。设置 → 结果列表 里可以改成 `Alt` 或关掉。别的程序把这些键设成了全局快捷键也没关系：搜索框在前面时归 Win顺，设置里写出被占用的是哪几个。剪贴板还是 `Alt+1`～`Alt+9`，也可以改成 `Ctrl`。
  **Number keys open a row**: hold `Ctrl` for a moment to see the row numbers, then `Ctrl+1`–`Ctrl+9` opens that visible row. Settings → Result list switches it to `Alt` or off. Other programs' global hotkeys on these keys don't get in the way while the search box is in front, and the settings name the keys they hold. The clipboard keeps `Alt+1`–`Alt+9`, or `Ctrl` if you prefer.
- ⚙️ **设置可以搜索**：设置窗口左上角的搜索框（或按 `Ctrl+F`），输入拼音、首字母或常说的叫法（“自启”“剪切板”）就列出相关的选项，开关直接能用；找不到时列出相关的 Windows 设置。“打开 Win顺”分成了快捷键、任务栏、对话框、启动与历史几页，另有“结果列表”一页。
  **Search the settings**: the box at the top left of the settings window (or `Ctrl+F`) finds options by pinyin, initials or everyday words, from every page, their switches working in place; with nothing found it lists matching Windows settings. “Open WinShun” is split into tabs, and there is a new “Result list” page.
- 📂 **Total Commander 和 Directory Opus**：“打开”“另存为”对话框里的 `Ctrl+G`、自动转过去和搜索框的建议，也认这两个文件管理器正在显示的文件夹；设置里还可以选从 Win顺 打开文件夹时用它们。
  **Total Commander and Directory Opus**: in Open and Save dialogs, `Ctrl+G`, the automatic jump and the bar's suggestions also take the folder they show; you can also have WinShun open folders in them.
- ⚡ **内容索引快得多**：第一次建立文件内容索引从半小时左右缩短到几分钟，占用的磁盘也更小。
  **A much faster content index**: building the file content index the first time takes minutes instead of about half an hour, and it takes less disk space.
- ✨ **其他**：剪贴板打开时不再抢走焦点，VS Code 的 `Ctrl+P`、浏览器地址栏的下拉建议都还开着，粘贴就落在里面；剪贴板在后台保存，不卡界面；安装完成时 Win顺 已经在运行，点“完成”马上就能用；按 `Ctrl+Alt+Del` 锁屏后不再一直监听鼠标；最近项目在慢的磁盘上不再拖慢列表。
  **Also**: the clipboard no longer takes the focus, so VS Code's `Ctrl+P` and a browser's address-bar suggestions stay open and the paste lands there; the clipboard saves in the background without stalling; WinShun is already running when the installer's last page comes up; locking the screen with `Ctrl+Alt+Del` no longer leaves the mouse listened to; and recent items on a slow drive no longer hold up the list.

## 升级提示 · Upgrading

升级后第一次启动，Win顺 会把每块 NTFS 磁盘重新读一遍来补上修改日期，一般只要几秒，期间照常搜索。

On the first start after upgrading, WinShun reads each NTFS disk once more to add the dates, usually in a few seconds; you can keep searching meanwhile.
