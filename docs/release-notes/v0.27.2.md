## 新功能 · What's new

- 🧩 **托盘图标进入「运行」** 「应用 › 运行」先列有窗口的程序，再把通知区域里没有窗口的图标按名称排在后面，每格带一个托盘角标。图标取自窗口、正在运行的程序或已安装的应用；输入的词同时过滤窗口和托盘两边的格子。

  **The notification-area icons join 运行** Apps › Running lists the programs with windows first, then the notification-area icons that have none, by name, each with a tray badge. A tile's picture comes from the window, the running program or the installed app; the words typed narrow the windows and the tray icons alike.

- 🖱️ **点一下就到** 程序有自己的窗口就切过去（最小化的会还原）；没有窗口就直接点它的托盘图标，鼠标指针原地不动。需要双击才响应的托盘（如 LiteMonitor、WGestures）会自动改用真实双击，并记住这个图标，以后一下就打开。

  **One click gets there** A program with a window of its own is switched to (restored if minimized); without one, its tray icon is clicked where it is and the pointer does not move. A tray that answers only to a double click (LiteMonitor, WGestures) is given one at once, and remembered, so one click opens it from then on.

- 🪟 **托盘项自己的菜单** 右键托盘格子可以切换到窗口、打开所在位置、复制名称或复制完整路径，与窗口项的操作在同一处。

  **The tray row's own menu** A right click on a tray tile switches to its window, reveals the program, or copies the name or the full path, beside what a window row offers.

- 🐞 **微信不再被同名窗口抢走** 另一个程序的窗口标题里只含有图标名字时（比如「微信 · (myscoop)…」），不会再被当成这个托盘项的窗口；微信的托盘项现在打开的是微信本身。

  **A window merely named like the icon no longer takes it** When another program's window only holds the icon's name in its title ("微信 · (myscoop)…"), it is not taken for that icon's window any more; the WeChat tray tile now opens WeChat itself.
