## 新功能 · What's new

- 🌐 **中英双语**：设置 → 外观里选“跟随系统 / 简体中文 / English”，切换后立即生效，不用重启。默认跟随 Windows 的显示语言。
  **English and Chinese**: pick System, 简体中文 or English under Settings → Appearance; it switches at once, no restart. By default it follows the Windows display language.
- 🎨 **主题切换**：浅色、深色或跟随系统，在预览图上点一下，整个窗口淡入淡出地换过去。
  **Light or dark theme**: or follow Windows. Click a preview and the whole window cross-fades to it.
- 🔔 **检查更新**：每次启动和之后每 12 小时到 GitHub 看一眼，有新版本时在托盘提示，打开就能看到改了什么，点“去下载”在浏览器里打开下载页。托盘菜单里可以“检查更新…”，设置 → 高级里可以关掉自动检查。
  **Update checks**: at every start and every 12 hours WinShun asks GitHub for the latest version. A new one is announced from the tray with what changed, and Download opens its page in your browser. Use Check for updates… in the tray menu, or turn automatic checks off in Settings → Advanced.
- 🏷️ **显示版本号**：设置窗口左下角和托盘菜单里都能看到当前版本。
  **Version shown**: in the corner of the settings window and in the tray menu.
- 🐞 **修复右键菜单**：在搜索结果上点右键，菜单现在能正常弹出了。
  **Right-click menu fixed**: right-clicking a search result opens its menu again.

## 从 0.1.0 升级 · Upgrading from 0.1.0

1. 在托盘图标的右键菜单里选“退出”。
2. 把下载的压缩包解压，用里面的 `WinShun` 文件夹覆盖原来的文件夹。
3. 运行 `WinShun.exe`。设置、索引和最近使用记录都会保留。

以后的版本，Win顺 会自己提醒你。

1. Choose Exit from the tray icon's menu.
2. Unzip the download and copy its `WinShun` folder over the old one.
3. Run `WinShun.exe`. Settings, the index and recent items carry over.

From now on WinShun tells you about new versions itself.
