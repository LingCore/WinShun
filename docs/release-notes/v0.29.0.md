Win顺 0.29.0 让找应用和用右键更顺手：按“设置 › 应用”里的名字就能找到软件，“应用”标签里能直接切换已经打开的窗口；资源管理器里右键图片可以贴到屏幕，自己的命令也能放进文件的右键菜单。剪贴板里图片那一行可以和文字一样高，一次复制的几张图片能看到缩略图。修好了界面字体选英文名不生效的问题。

## 下载 · Downloads

- **WinShun-0.29.0-x64-setup.exe** 为标准安装版，覆盖升级保留设置、索引和剪贴板，增强 OCR 按需下载。
- **WinShun-0.29.0-x64-portable.zip** 为便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。
- **WinShun-0.29.0-x64-offline-setup.exe** 包含增强 OCR。官方可选插件从插件库安装。
- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 是同版本安装程序使用的增强 OCR 组件。
- **SHA256SUMS.txt** 提供上述四个文件的 SHA256。

The standard installer keeps settings, the index and clipboard history during an upgrade and downloads enhanced OCR when needed. For the portable edition, keep the existing `data` folder. The offline installer includes enhanced OCR. Optional official plugins are available from the plugin library. Scoop users can run `scoop update winshun` after the bucket update reaches them.

剪贴板的“大图片缩略图”开关变成了“图片缩略图”的三档选择，原来开着的升级后是“大”，不用重新设置。

The clipboard's "Large picture thumbnails" switch is now a choice of three sizes; where it was on, the upgrade keeps "Large".

## 新功能 · What's new

- 🔎 **按安装时的名字找应用** 输入“设置 › 应用”里列出的软件名就能找到它的程序，即使开始菜单里的快捷方式叫别的名字：`microsoft office`、`office 2024` 找到 Word、Excel、PowerPoint，`7-zip 25` 找到 7-Zip File Manager。应用自己的名字仍然排在前面（感谢 @csdjk，#323）。

  **Apps found by the name they were installed under** The name Settings › Apps lists a program by finds its apps, whatever their Start menu shortcuts are called: `microsoft office` or `office 2024` finds Word, Excel and PowerPoint, `7-zip 25` finds 7-Zip File Manager. An app's own name still comes first (thanks to @csdjk, #323).

- ▶️ **“应用”标签里切换已打开的窗口** “应用”标签（设置 › 结果列表 里打开）的最左边多了“运行”：把现在开着的窗口排成图标，`Enter` 或点一下就切过去，最小化的会还原，不会再启动一个；打字可以筛选，窗口开了关了列表跟着变（感谢 @w3c0929，#312）。

  **Switch to open windows from the Apps tab** A new first choice, Running, in the Apps tab (turned on under Settings › Results) lists the windows open now as tiles: Enter or a click switches to one, restoring it if minimized, instead of starting the program again. Typing narrows them, and the list follows windows as they open and close (thanks to @w3c0929, #312).

- 📌 **右键图片贴到屏幕** 开着“截图与录屏”插件时，在资源管理器里右键图片文件，多了“贴到屏幕（Win顺）”，点一下就把这张图贴在屏幕上；选了几张就各贴一张。Windows 11 上在“显示更多选项”里（#128）。

  **Pin a picture from its right-click menu** With the Screenshot and recording plugin on, a picture file's right-click menu in File Explorer offers "Pin to screen (WinShun)"; several chosen are each pinned. Under "Show more options" on Windows 11 (#128).

- 🧩 **自己的命令放进文件右键菜单** 设置 › 收藏夹 里的命令多了一个选项“显示在文件和文件夹的右键菜单里”（默认不勾，命令里要有 `{query}`）。勾上后，右键文件或文件夹，“Win顺 命令”里选它，就把完整路径交给 `{query}`，不用再手打路径。Windows 11 上在“显示更多选项”里（#61）。

  **Your own commands in the right-click menu of files** A command under Settings › Favorites can be shown in the right-click menu of files and folders (off unless ticked; the command needs `{query}`): picking it under "WinShun commands" hands the full path to `{query}`. Under "Show more options" on Windows 11 (#61).

- 🖼️ **剪贴板里的图片：行高三档，多张图片有缩略图** 设置 › 剪贴板 的“图片缩略图”有 小 / 标准 / 大 三档，选“小”时图片那一行和文字行一样高。在资源管理器里一次复制几张图片，现在显示第一张的缩略图，角上标出一共几张（感谢 @eq1024，#328）。

  **Pictures in the clipboard: three row sizes, thumbnails for several picture files** "Picture thumbnails" under Settings › Clipboard has Small, Standard and Large; Small keeps a picture's row as high as a text row. Several pictures copied in File Explorer show the first one's thumbnail with their number on its corner (thanks to @eq1024, #328).

## 改进与修复 · Improvements and fixes

- **界面字体选英文名不生效**：同一款字体有中文名和英文名（“霞鹜文楷” / “LXGW WenKai”），选了英文名那一项，重启后还是默认字体。现在两个名字都认，字体列表里每款字体只列一次（感谢 @seewhychan、@zh-y-h，#325）。

  A font chosen under its English name ("LXGW WenKai") was gone after a restart, where its Chinese name (霞鹜文楷) worked. Either name now works, and the list has each font once (thanks to @seewhychan and @zh-y-h, #325).

- 开着“在资源管理器里直接打字搜索”时，按住 `Caps Lock` 再按字母不再弹出搜索框：把 `Caps Lock` 当组合键用的改键工具（CapsLock+、AutoHotkey、PowerToys）不会再被抢键。`Caps Lock` 只是开着（打大写字母）时照常搜索（感谢 @another-le，#318）。

  With typing in File Explorer on, a letter pressed while Caps Lock is held down no longer opens the search box, so tools that use Caps Lock as a modifier (CapsLock+, AutoHotkey, PowerToys) keep their keys. Caps Lock merely switched on still searches (thanks to @another-le, #318).

| 浏览器书签 · Browser bookmarks | 2.0.5 |

- **浏览器书签 2.0.5** 名字或所在文件夹是汉字的书签可以用拼音找：首字母、全拼或混着打都行，`bm xjtu`、`bm xian` 都能找到“西安交通大学”，`bm wa` 找到放在“网安”文件夹里的书签。浏览器自带的“书签栏”“其他书签”和网址不读拼音。匹配超过 50 条时先排序再取前 50。权限不变（感谢 @another-le，#317）。

Browser bookmarks 2.0.5: bookmarks whose title or folder is Chinese are found by pinyin (initials, whole syllables or a mix): `bm xjtu` and `bm xian` find 西安交通大学, `bm wa` what is filed under 网安. The browser's own folders and addresses are not read as pinyin, and more than 50 matches are ranked before the first 50 are taken. Its permissions are unchanged (thanks to @another-le, #317).
