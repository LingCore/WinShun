Win顺 0.20.0 主要是修复和体验打磨：截图设了保存目录后一键直接保存，文件夹快捷菜单的设置重新整理并可以挑选菜单里的操作，剪贴板的直接粘贴不再漏键，搜索栏 Logo 下半部分也能点到了。WinShun 0.20.0 is mostly fixes and polish: capture saves straight into your chosen folder, the folder menu settings are tidier and let you choose which actions it offers, direct clipboard paste no longer drops keys, and the lower half of the search logo is clickable again.

## 下载 · Download

- **WinShun-0.20.0-x64-setup.exe** 为标准安装版，覆盖升级保留设置、索引和剪贴板，增强 OCR 按需下载。
- **WinShun-0.20.0-x64-portable.zip** 为便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。也可以用 Scoop 安装：`scoop bucket add winshun https://github.com/LingCore/WinShun`，再 `scoop install winshun`。
- **WinShun-0.20.0-x64-offline-setup.exe** 包含增强 OCR，官方可选插件仍从插件库下载。
- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 为增强 OCR 独立组件，可在识别设置中从本地安装。
- **SHA256SUMS.txt** 提供以上四个文件的 SHA256。

Requires 64-bit Windows 10 1809 or later, or Windows 11. Setup upgrades retain existing data. Preserve the portable copy's existing `data` folder. With Scoop, run `scoop bucket add winshun https://github.com/LingCore/WinShun` and then `scoop install winshun`. The offline setup includes enhanced OCR, while optional plugins remain separate downloads. Verify the downloads with `SHA256SUMS.txt`.

## 新功能 · What's new

- 💾 **截图一键保存到指定文件夹** 在截图设置里选了保存目录后，保存按钮、`Ctrl+S` 和设为“保存”的鼠标动作不再弹窗，直接存进该目录，下拉箭头里改为“另存为…”；没选目录时仍弹出“另存为”。保存后点一下“截图已保存”的通知，会打开文件夹并选中这张图。需要截图插件 1.1.1。
  **One-step capture saving**: with a save folder chosen in the capture settings, the Save button, `Ctrl+S` and a mouse action set to Save write straight into that folder without a dialog, and the arrow beside Save offers "Save as…". Without a folder, the Save As dialog still appears. Clicking the "Screenshot saved" notice opens the folder with the picture selected. Requires capture plugin 1.1.1.
- 🗂️ **文件夹快捷菜单设置重新整理** 设置里是一个总开关，下面分别选触发方式（双击鼠标左键、鼠标中键，现在可以单独关掉左键双击）和触发位置（资源管理器、桌面），每组至少留一项。
  **Tidier folder menu settings**: one main switch, then separate choices for how it opens (double left click or middle click; the double click can now be turned off on its own) and where (File Explorer or the desktop). Each group keeps at least one choice.
- ✂️ **挑选菜单里的操作** 菜单末尾的“在此搜索”“命令提示符”“PowerShell”“收藏这个文件夹”“Win顺 设置”可以分别关掉，默认都有。
  **Choose the menu's actions**: "Search here", "Command Prompt", "PowerShell", "Add this folder to favorites" and "WinShun settings" at the end of the menu can each be turned off. All are on by default.

## 修复与改进 · Fixes and improvements

- “文件”“文件夹”范围里不再出现插件关键词的提示行，因为在那里按回车运行不了；自定义命令本来就不出现（#193）。
  The plugin keyword hint rows no longer appear in the Files and Folders scopes, where Enter could not run them. Custom commands were never shown there (#193).
- 搜索栏 Logo 的下半部分点不到：切过“文件”范围后，被收起的类型条挡在上面。现在整个 Logo 都能点（#162、#173）。
  The lower half of the search logo could not be clicked after visiting the Files scope, because the collapsed type strip sat on top of it. The whole logo works again (#162, #173).
- 剪贴板的 `Ctrl` / `Alt` + 数字直接粘贴有时漏给前台程序，比如在浏览器里切标签页没反应。现在数字键只在 Win顺 自己的窗口真正在最前面时才让出来（#195）。
  Direct paste with `Ctrl` / `Alt` + digit sometimes took keys meant for the program in front, such as switching browser tabs. The digit keys now step aside only while a WinShun window is really in front (#195).
- “按住连按快捷键，松开粘贴”：点一下快捷键后按住修饰键约 1 秒再松开，就粘贴第一条；以前要把整个组合一直按着才算（#199）。
  "Hold and press again, release to paste": after tapping the hotkey, holding the modifier for about a second and letting go pastes the first entry. Before, the whole combination had to stay held (#199).

## 升级与验证范围 · Upgrade and validation scope

截图插件 1.1.1 与图片文字搜索插件的补丁版本一起在插件库发布（共享的窗口命中代码有改动），开着自动更新时会在后台更新（图片文字搜索 1.0.4 要 Win顺 0.20.0 或更新版本，旧版 Win顺 继续用 1.0.3）。截图插件 1.1.1 在旧版 Win顺 上也能用，只是点“截图已保存”通知时不会选中那张图，需要 Win顺 0.20.0。

The capture plugin 1.1.1 and a patch release of image text search (some shared window hit-testing code changed) are published to the plugin library with this release, update in the background when automatic updates are on (image text search 1.0.4 needs WinShun 0.20.0 or newer; older WinShun keeps 1.0.3). Capture 1.1.1 also runs on older WinShun, but clicking the "Screenshot saved" notice only selects the picture on WinShun 0.20.0.
