下载下面的 **WinShun-0.2.2-x64-setup.exe**，双击安装。已经装了旧版的，直接运行它就能升级，设置和索引都保留。需要 Windows 10 或 11（64 位）。

Download **WinShun-0.2.2-x64-setup.exe** below and run it. If an older version is installed, running it upgrades in place and keeps your settings and index. Requires Windows 10 or 11, 64-bit.

## 新功能 · What's new

- 🖱️ **拖动更跟手**：拖动搜索框时窗口始终跟着鼠标，不再在屏幕中线和默认高度上“顿”一下；松手时离得近，会自动滑到中线或默认高度上。
  **Smoother dragging**: the search bar follows the pointer the whole way instead of catching on the centre line and the default height; let go close to them and it glides into place.
- 🧩 **“全部”里列出所有找到的应用**：和“应用”范围找到的一样多、顺序一样，都排在文件前面（以前最多 3 个）。指向文件夹的开始菜单快捷方式不再算作应用。
  **Every app found, in All**: the All scope lists the same apps as the Apps scope, in the same order, before any file (it used to show three at most). Start menu shortcuts to folders no longer count as apps.
- ⚡ **托盘菜单打开更快**：右键托盘图标时不再先去查询任务计划程序。
  **Faster tray menu**: right-clicking the tray icon no longer waits on Task Scheduler first.
- 🔢 **状态栏更好读**：索引数量取整显示，如“已索引 323 万项”“3.2M items indexed”。
  **Easier-to-read status line**: the index size is rounded, as in “3.2M items indexed”.
- 🌙 **其他**：深色模式下“拾穗计划”页的背景调暗了；结果行按钮的图标更大更清晰；“拾穗计划”里的 Win顺 链接到 GitHub 项目页。
  **Also**: the Gleaning page's backdrop is dimmer in dark mode; result row button icons are larger and sharper; WinShun's entry on the Gleaning page links to its GitHub page.
