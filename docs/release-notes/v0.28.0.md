Win顺 0.28.0 先修一个启动问题：0.27.0 在没有装过 VC++ 运行库的电脑上打不开，这一版把运行库带全了。用中文输入法时，拼音还没选字就开始搜索；没有结果时可以直接用网页搜索；复制的文本文件在剪贴板里能看到内容，不想让人看到的条目可以遮住；资源管理器里选中文件，右键“发送到”就能用局域网传输发到手机。贴图有了编辑、识别文字、收到顶边的按键。

## 下载 · Downloads

- **WinShun-0.28.0-x64-setup.exe** 为标准安装版，覆盖升级保留设置、索引和剪贴板，增强 OCR 按需下载。
- **WinShun-0.28.0-x64-portable.zip** 为便携版。解压运行 `WinShun.exe`，升级时保留原来的 `data` 文件夹。
- **WinShun-0.28.0-x64-offline-setup.exe** 包含增强 OCR。官方可选插件从插件库安装。
- **WinShun-ocr-ppocr-v6-ort1.30.0-x64.zip** 是同版本安装程序使用的增强 OCR 组件。
- **SHA256SUMS.txt** 提供上述四个文件的 SHA256。

The standard installer keeps settings, the index and clipboard history during an upgrade and downloads enhanced OCR when needed. For the portable edition, keep the existing `data` folder. The offline installer includes enhanced OCR. Optional official plugins are available from the plugin library. Scoop users can run `scoop update winshun` after the bucket update reaches them.

0.27.0 打不开（提示找不到 `MSVCP140_2.dll`，或错误 0xC0000135）的电脑，直接安装这一版即可。剪贴板数据库多了一列（“遮住内容”），升级时自动加上；退回 0.27.0 仍能读取。

If 0.27.0 did not start (a missing `MSVCP140_2.dll`, or error 0xC0000135), installing this version is all that is needed. The clipboard database gains one column (for hidden entries), added on upgrade; 0.27.0 still reads it.

## 新功能 · What's new

- 🈶 **拼音没选字就出结果** 用中文输入法在搜索框里打字（或者在文件夹里直接打字），拼音还在候选窗里、没选字的时候，结果就按这些字母出来了，`weixin` 不用先上屏就能找到“微信”。以前要选了字或切到英文才有结果，Windows 10 自带的微软拼音默认是中文模式，看起来就像“打字没反应”（#157）。

  **Results while an input method is still composing** With a Chinese input method, the letters still in the candidate window are searched at once, in the search box and when typing in a folder: `weixin` finds 微信 before a candidate is chosen. Until now nothing was listed before that (#157).

- 🌐 **没有结果时用网页搜索** 在 **设置 › 插件 › 网页搜索** 打开“没有结果时用网页搜索”（默认关）：什么都没搜到时，列表里出现一行“在 … 中搜索”，按 `Enter` 用排在第一位的网站搜；网站列表里点“置顶”可以换成别的。关键词也可以写在后面：`天气 baidu` 和 `baidu 天气` 一样（感谢 @christubuntu，#320）。

  **A web search when nothing is found** "Search the web when nothing is found" under Settings › Plugins › Web search (off by default) adds a row that searches with the first site in the list; "Move to top" on a site makes it that one. A keyword may also come last: `weather g` works as `g weather` does (thanks to @christubuntu, #320).

- 📄 **剪贴板里看得到复制的文本文件的内容** 复制单个文本类文件（txt、md、代码、日志等）后，剪贴板的预览里直接显示文件开头的内容，鼠标悬停的小窗和右侧预览栏都有。鼠标要在一行上停得久一点才弹出预览（0.4 秒，搜索结果里 0.2 秒），划过时不再误触发（感谢 @hanxuan5820，#324）。

  **A copied text file's content in the clipboard** One text file copied (txt, md, code, logs…) shows its beginning in the clipboard's preview, both the hover preview and the pane. The pointer rests a little longer on a row before a preview opens (thanks to @hanxuan5820, #324).

- 🙈 **剪贴板条目可以遮住** 在一条记录上右键选“遮住内容”：列表和预览里只显示圆点，搜索也搜不到它的内容，粘贴照常；再选“显示内容”恢复。给它加个备注就能认出是哪一条。录屏、演示、共享屏幕时不会露出密码（#260）。

  **Clipboard entries kept from view** "Hide content" in an entry's menu shows dots in the list and the preview and keeps its text out of the search; pasting is unchanged, and "Show content" brings it back. A note tells you which one it is (#260).

- 📤 **右键“发送到”用局域网传输** 装了“局域网传输”插件后，在资源管理器里选中一个或多个文件，右键 › 发送到 › 局域网传输（Win顺），直接打开设备列表，选手机或电脑按 `Enter` 发送，不用先复制。Windows 11 上这一项在“显示更多选项”里（#180）。

  **Send to › LAN transfer (WinShun)** With the LAN transfer plugin on, files chosen in File Explorer go to the plugin's device list from Send to in the right-click menu (under "Show more options" on Windows 11) (#180).

- 🗂️ **搜索面板空着时可以不列文件** **设置 › 外观 › 尺寸与布局** 的“搜索面板空着时列出全部文件”，默认开，和以前一样；关掉后直接打开搜索面板时不再列出整个索引，输入后才出结果（感谢 @hxchtiewei，#321）。

  **An empty search panel without the whole index** "List all files in the empty search panel" under Settings › Appearance › Size and layout, on by default as before; off, the panel lists nothing until something is typed (thanks to @hxchtiewei, #321).

## 改进与修复 · Improvements and fixes

- **0.27.0 在没有装过 VC++ 运行库的电脑上打不开**（缺 `MSVCP140_2.dll`）。运行库现在整套随程序安装，打包时逐个检查每个程序和库依赖的文件是否都在包里，缺了就不出包。在一台全新的 Windows 10 上用安装包验证。

  0.27.0 did not start on a PC without the Visual C++ runtime (`MSVCP140_2.dll` was missing). The whole runtime now ships with the program, and packaging fails if any program or library needs a file that is not in the package. Checked with the installer on a freshly installed Windows 10.

- 安装和应用内更新在进程很多的电脑上会无声地停几十秒（实测 547 个进程时 27 秒），现在只有几秒。

  Setup and in-app updates paused silently for tens of seconds on a PC with many processes (27 s with 547 of them); now a few seconds.

- 在资源管理器里直接打字弹出的搜索框，在 Windows 10 上实测后重做：搜索框带着结果一次出现，不再先小后大；大小变化时不再露出黑块；位置贴着窗口底边、让开滚动条（#234）。

  The box a key typed in File Explorer opens, reworked after runs on Windows 10: it appears once, with its results, shows no black while its size changes, and sits at the window's bottom edge clear of the scroll bar (#234).

- 鼠标按着文件或拖动文件时按键（比如拖文件时按 `` ` `` 弹出收藏圆盘），不再同时弹出“直接打字搜索”的搜索框（感谢 @hanxuan5820，#327）。

  A key pressed while a file is held or dragged (the drop pie's key) no longer opens the typing search box as well (thanks to @hanxuan5820, #327).

- 图片里的二维码内容现在也算作这张图的文字：剪贴板里搜得到，截图历史里也显示（#305）。

  The content of a QR code in a picture is among the picture's words: found by the clipboard search and shown in the screenshot history (#305).
