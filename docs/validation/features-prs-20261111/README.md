# 三个新功能和三个 PR（2026-11-11）

构建目录 `build\feat3`，部署 `dist\feat3\WinShun`。界面检查用程序自带的离屏检查（`WinShun.exe --preview-results <目录> --file-metadata --file-gallery --scale 1.5`、`--preview-settings <目录> --file-types`），不占用正在运行的 Win顺；截图没有入库。

## 功能

| 功能 | 自动测试 | 界面检查 |
|---|---|---|
| 预览按语法上色、Markdown 轻渲染、搜索词标出（#291） | `tst_syntax` 7 项：各语言族的注释／字符串／数字／关键字，跨行的块注释和多行字符串，JSON／YAML／INI／XML，Markdown 标题、强调、代码块、链接，搜索词合并 | 真实预览窗口：代码、Markdown、JSON、纯文本各一个文件，浅色深色各看一遍；搜索词所在行自动滚入视野 |
| 结果里就地重命名（#285）：`F2` 或右键“重命名” | `tst_core renameNames`：非法字符、保留名、句点结尾、过长、同名、选中范围 | 真实主窗口：`F2` 开框并选中扩展名之前的部分；带冒号的名字被拒、框留着；回车后磁盘上的文件和那一行都改名；`Esc` 只关框；再改回去 |
| 剪贴板条目加备注，按备注搜到（#267、#285） | `tst_clipboard notes`：单行化和长度上限、按备注／按文字／拼音搜到、重启后保留、删除后撤销保留、同内容再复制保留 | 真实剪贴板窗口：右键“加备注…”打开输入框（窄窗口里完整显示），备注以粗体排在条目前面 |

顺带修了一个老问题：预览里滚动过一个长文本再切到下一个文件时，被复用的行会显示上一个文件的文字（行号相同的行不刷新）。现在每行随内容重新取文字。

没做的：直接修改剪贴板条目的文字（要多行编辑器），多选时的批量重命名入口（仍用插件）。

没测的：三个功能在真实的常驻程序里用真实键盘鼠标操作（当时另一个会话的测试副本在运行，Win顺 只能开一份）；重命名遇到需要管理员权限的文件夹、文件被占用；英文界面。
