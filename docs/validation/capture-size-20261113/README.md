## 做了什么

- 选区旁的尺寸标签可以点，或按 `F`，打开尺寸面板：输入宽、高，锁定比例，从预设里选，增删预设。
- 框选之前按 `F`：选预设尺寸在光标处得到固定大小的选区；选预设比例则锁住比例再拖。
- 锁定比例时，拖出选区、拖手柄、`Shift`+方向键、输入数字都保持比例。

## 过程中修掉的问题

- 锁定比例时另一个数慢一拍：`textEdited` 比绑定属性更新得早，改为直接读输入框文字。
