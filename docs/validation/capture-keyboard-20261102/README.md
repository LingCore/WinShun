# 截图 WASD 精调与最近区域验证（2026-11-02）

## 交互契约

- `WASD` 每次移动选区 1 个物理像素；未框选时微调鼠标。按住可以连续调整。`Shift+WASD` 复用方向键已有的宽高调整规则，固定左上角，调整右边／下边；宽高最小 1 像素，不越过所在显示器。
- 确认截图时在插件进程内存中记录区域坐标，最多 10 个不同区域；重复使用的区域移到最前。取消和延时不记录，插件重启清空。图片历史的保存数量和区域坐标记录分别管理。
- `R` 首次恢复最新区域，继续按从新到旧循环；`Shift+R` 反向。长按 R 的自动重复不会连续翻动。恢复使用当前显示的冻结画面，可以微调后再完成；不自动复制。
- 屏幕断开时跳过对应区域；已有标注时先完成或用 Esc 放弃，防止直接丢失。文字和序号输入、绘制／拖动手势不触发区域快捷键。
- 截图界面的矩形、箭头使用数字键 `1`、`3` 或工具栏；独立图片编辑器保留 `R`、`A`。延时改为 `Ctrl+Shift+D`，保存 `Ctrl+S`、录屏 `Ctrl+R` 保留。
- 底部键盘提示常驻显示恢复序号，成功恢复不再弹出会与尺寸标签重叠的提示。

## 环境与结果

Windows、MSVC x64、C++20、Qt 6.12.0。独立构建目录 `build/capture-keyboard-20261102`；复用现有下载好的依赖，不覆盖安装目录和用户数据，不写系统剪贴板、不注册全局快捷键。

- `build-final.txt`：截图插件和相关测试构建成功，无编译警告。
- `regression-tests.txt`：15 组 CTest 回归全部通过，涵盖 CaptureSession、标注模型／文档、阶段 7 几何、100% / 125% / 150% / 175% / 200% 下的软件与 D3D11 截图绘制，以及空闲图形资源回收。
- `final-session-tests.txt`：最终区域提示调整后的 CaptureSession 回归通过。
- `native-zh-150-final/preview.log`：中文浅色、150%、D3D11 的真实截图控制器验证通过，0 个 Qt 警告。
- `native-en-dark-200-final/preview.log`：英文深色、200%、D3D11 同一路径通过，0 个 Qt 警告。
- 已查看两次最终 `selection-keyboard.png`，底部文案与序号完整可读，尺寸标签没有重叠；`selection-export.png` 是实际导出的选区。

真实链路由 `--preview-capture-tools <目录> --selection-keys --renderer d3d11` 复现：先显示独立生成的全屏背景，经生产 Capture / Grabber 冻结，向真实 QML 窗口发鼠标和键盘事件，经生产 Capture 导出；复制回调只在验证进程里接收图片。当前单屏 SDR 实际走 BitBlt，不把它报告为 WGC 验证。

每个真实验证分别完成 12 次不同选区并确认只留 10 个，检查完整正向循环、首尾循环和反向切换；恢复后用 WASD 与 Shift+WASD 调整，逐像素比较导出图与当前冻结图的对应区域；背景换色后恢复区域，确认没有使用旧图片。同时检查 `1`／`3` 工具键、文字输入 `wasdr`、Ctrl+Enter 完成文字和 R 对已有标注的保护。

多屏坐标恢复、断屏跳过和缩放精度有自动化几何测试；本次没有真实双屏混合 DPI 或 HDR 设备验证。现有安装版和正在运行的插件保持原状，本次未发布。
