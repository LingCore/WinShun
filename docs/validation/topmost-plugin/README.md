# 窗口置顶插件（winshun.topmost）验证

## 1.0.0

2026-11-25，Windows 11 Pro 26200，150% 缩放，工作树 `window-top`。

| 验证 | 结果 |
|---|---|
| `ctest -R "^tst_topmost$\|^tst_pluginsdk$"` | 通过。哪些窗口算用户的窗口；在测试自己建的隐藏窗口上置顶、取消、重复置顶、窗口已销毁；标题与程序名的读取和筛选 |
| `wsbench --plugin build\window-top\library-plugins\winshun.topmost --query "置顶 "` | 通过真实的 `WinShunPluginHost`（中完整性、作业内）列出 13 个打开的窗口；`wsbench` 不替插件注册快捷键，插件按“宿主不支持”记日志（错误码 50） |
| `python drive.py <WinShunTopmost.exe> <输出目录>`（本目录的脚本，模拟宿主按协议驱动插件进程，目标是脚本自己开的一个测试窗口，不发送任何键鼠输入） | 18 项全部通过：`initialize` 后先报 `winshun/hotkeys` 再调 `register_hotkeys`；按标题筛到测试窗口；`Enter` 置顶（`WS_EX_TOPMOST` 置位）并回 `hide`；再查询时排在最前、写着“已置顶”；`hotkey` 通知取消置顶、再次置顶；快捷键被占用（1409）时写日志；筛不到时给一行说明；进程号对不上的旧结果行不改任何窗口；`shutdown` 后测试窗口自动取消置顶，进程自行退出（退出码 0） |

提示条实拍（150%）：置顶 [pin.png](pin.png)，取消置顶 [unpin.png](unpin.png)。

## 描边（1.1.0）

2026-11-25，Windows 11 Pro 26200，150% 缩放（2560×1600），工作树 `topmost-border`。

| 验证 | 结果 |
|---|---|
| `ctest -R "^tst_topmost$"` | 通过。描边的粗细与圆角（100%–175%、各种圆角偏好、Windows 10 直角）、不画的情况（不可见、全屏）、最大化按工作区裁剪、四条的矩形；在测试自己建的隐藏窗口上：加、重复加、移除、清空、置顶位被别人摘掉、窗口销毁后描边窗口都随之消失 |
| `python border.py <WinShunTopmost.exe> <输出目录>`（本目录的脚本，按协议驱动插件进程，目标是脚本自己开的测试窗口，只用 `SetWindowPos` / `ShowWindow` 摆窗口并读屏幕像素，不发送键鼠输入） | 31 项全部通过：置顶后四条正好在窗口可见边缘上，3 px 强调色、圆角处沿弧线、线以内和圆角以外不着色；紧贴目标窗口之上的 Z 序；移动加缩放后跟随并按新尺寸重画；最小化消失、还原回来；最大化为直角并贴工作区四边；铺满显示器时不画；被另一个置顶窗口盖住的部分不透出来，盖的窗口关掉后恢复；换强调色后重画；设置关掉后消失且窗口仍置顶，再打开回来；被别的程序取消置顶、在插件里取消、窗口关闭，描边都随之消失；`shutdown` 后进程自行退出 |
| `python drive.py …`（1.0.0 的 18 项） | 仍全部通过 |

实拍（150%）：[border.png](border.png)，左上角放大 [border-corner.png](border-corner.png)。
