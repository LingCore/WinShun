# 验证证据目录

本目录用于存放**当前仍被测试/发布流程直接引用的验证夹具**，以及**新任务按规范精选保留的验证证据**。

## 保留约定

- 每次任务建独立子目录 `docs/validation/<任务名>/`，不往 `docs/` 根目录或本目录平铺散落文件。
- 仅放精选 README、关键截图（单图 ≤ 300 KB，必要时裁剪或转 JPEG）、日志关键片段与小型结果文件，单目录合计 ≤ 5 MB。
- 原始截图包、录屏 GIF/MP4、全尺寸原图和整份日志不入库（放素材项目或 GitHub Issue 附件并在 README 注明位置）。
- 过往历史版本的验证记录已由 Git 历史及对应发版 Tag 永久保存，不再长期滞留于当前工作树。
