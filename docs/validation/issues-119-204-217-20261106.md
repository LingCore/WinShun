# #119 / #204 / #217 实现与验证

2026-11-06，Windows 11 x64、Qt 6.12.0、MSVC 2022 Release。本轮选择三个搜索与阅读体验问题；保留其他批次和并行工作的修改，没有发布版本或回复、关闭 GitHub issue。

## #204：搜索词历史

- 保存最近 100 条非空搜索词，保留大小写、引号、筛选前缀和内部空格，重复项移到最前。查询在打开结果或收起搜索窗口时记录，不逐字写盘。
- 默认 Ctrl+↑/↓ 翻阅；设置 → 打开 Win顺 → 启动与历史，可选 Alt+↑/↓ 或关闭。回到最新位置恢复翻阅前的草稿，编辑输入会结束本次翻阅。
- 搜索框及完整面板的时钟按钮打开历史列表；支持方向键、Enter、Esc、Delete、单条删除和长文本提示。列表不夺走搜索框焦点。
- 沿用使用记录总开关；关闭后不记录、不提供历史入口。清空或删除当前查询后，收起窗口不会重新写回刚删除的记录。插件命令、系统命令、资源管理器内嵌输入不记录。
- `QueryHistory` 与排序用的 `History` 分开，使用 `QSaveFile` 原子写入同一数据目录的 `query-history.json`；限制单条长度和读取文件大小，损坏文件不会阻止搜索。

## #119：补齐范围合并与关键词提示

- 设置 → 结果列表 → 显示与预览，新增“合并‘全部’和‘文件’”，默认关闭，保留原来的使用方式。
- 开启后，在“全部”常驻类型筛选；无类型限制时仍由原搜索引擎显示应用、文件和文件夹，应用排在前面。选中文件类型后只显示相应文件，取消最后一个类型恢复“全部”。文件夹筛选和内容搜索保持可达。
- Tab 跳过合并后的重复范围，启用内容搜索时可往返切换。完整面板同步隐藏独立“文件”范围。
- 按住 Ctrl 显示类型关键词；名称和关键词共用稳定宽度，避免筛选栏跳动。也修复了内容/文件类型模型切换瞬间的未定义图标与色号绑定。
- 本轮没有重新实现此前已有的最近项目数量、网格视图及灵活的类型前缀解析。

## #217：插件说明在应用内阅读

- “说明”入口读取插件目录中的 README.md、README.html、README.htm 或 README.txt，在设置窗口内打开阅读器，不再启动外部编辑器。
- 使用 Qt 文档解析与现有主题组件，可滚动、选字复制、用 PageUp/PageDown 翻页，Esc/Q 或关闭按钮返回设置。再次打开重新读取并回到顶部。
- 支持 UTF-8 与带 BOM 的编码；文件超过 1 MiB 或读取失败时给出可见错误。
- 说明是被动文档，不执行脚本，不加载外部/本地图片资源；图片保留替代文字。仅用户点击的 HTTP(S) 网页链接可交给浏览器，其他协议与相对文件链接不作为可执行链接保留。这里支持基本文档排版，不是完整网页浏览器。
- 文件路径核对插件目录边界；富文本不强制黑色正文或固定默认字号，跟随当前界面主题。

## 验证边界

测试均使用临时数据目录。搜索与设置窗口放在屏幕外且不激活；会计算真实屏幕位置的原生历史弹窗在显示前经 DWM cloak 隐藏，并检查隐藏状态。键盘事件只发给本进程的 QML 控件，没有注入系统键鼠、写入用户剪贴板或操作正在运行的 Win顺。

索引和插件文档采用隔离夹具；不把它们称为用户真实索引/第三方插件的端到端验证，也没有验证用户当前桌面的全局热键或实际浏览器跳转。现有索引、用户配置、安装目录均未被替换。
