# #329 “此电脑”里直接打字搜索；#330 面板快捷键再按一次关闭（2026-11-14）

分支 `features-1114`，构建目录 `build/features-1114`（Release，Qt 6.12.0）。

## #330

原因：“直接打开搜索面板”的快捷键每次都只做“打开”，不看面板是不是已经开着。现在和主快捷键用同一套判断：面板开着并在最前就关闭；开着的是小搜索框就展开成面板；被别的窗口挡着就拿到最前；刚按下、窗口还没显示出来时的重复按键不算“再按一次”。

- `tst_core shortcutAgain`：通过。
- Win10 22H2 虚拟机，面板快捷键设为 Alt+1：按一次面板打开（`vm-330-panel-open.png`），再按一次关闭（`vm-330-pressed-again-closed.png`），第三次又打开。

没有覆盖：报告人实际用的 Alt+`（代码里认这个键，没有单独实测）；“再次按下快捷键时”选“展开为搜索面板”时的组合；Windows 11。

## #329

原因：以前“此电脑”“主文件夹”这类没有具体文件夹的页面，按键一律还给资源管理器（设计如此）。现在“此电脑”“主文件夹”（Windows 10 的“快速访问”）里打字搜整台电脑；回收站、控制面板、网络、搜索结果页保持原样。

- `tst_core searchTyping`：通过（三个页面认得出，大小写不论；回收站、此电脑下的磁盘、普通路径不算）。
- Win10 22H2 虚拟机：资源管理器切到“此电脑”，点一下文件区，打 `rep`：搜索框出现在文件列表右下角，列出整台电脑上的 report_*.txt（`vm-329-typing-on-this-pc.png`）。日志里是 `Explorer typing: folder ""`，之后照常显示。

没有覆盖：Windows 11 24H2（报告人的系统）上的“此电脑”和“主文件夹”；Windows 10 的“快速访问”；回收站里按键确实还给资源管理器（只有单元测试和未改动的原有路径）。
