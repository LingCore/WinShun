## #236：二级文件夹菜单的路径提示

截图与生产 QML 对照后确认：原来的 HoverTip 画在菜单窗口内部，只有一两行的二级菜单容不下长路径提示。

- 新增 `MenuPathTip.qml`，沿用现有主题，用独立、不接受焦点、不拦截鼠标的工具提示窗口显示路径。
- 长路径换行；提示按屏幕可用区域选择上下位置并约束四边。离开条目、切换页面或关闭菜单时隐藏。
- 没有为了容纳提示而扩大短菜单，也没有修改系统文件夹或桌面设置。

`tst_foldermenu shortPagePathTip` 在 100% 和 150% 缩放各执行两个数据行：屏幕左上、右下。
使用生产菜单 QML 和单条子菜单，检查完整测试路径、未截断文本、提示几何、窗口标志与关闭联动，全部通过。
这是离屏平台的布局和绘制验证，没有冒充真实桌面焦点路由测试。

## #237：选择界面字体

入口：**设置 → 外观 → 尺寸与布局 → 界面字体**。

- 默认保留阿里巴巴普惠体；提供已安装字体，微软雅黑 UI、微软雅黑置于列表前部，可键入名称定位。
- 使用 Qt Quick Controls 的可编辑 ComboBox，沿用主题颜色，限制列表高度并保留滚动与键盘操作。
- 示例立即预览；点击“重启后应用”或下次启动时统一应用。不会自动重启。
- 字体选择保存于 `Appearance/UiFont`。字体不存在时回到默认显示并说明原因，保留原选择供便携配置回到原电脑后使用。
- 将主程序的字体加载集中到 `UiFont`，保留中文安装路径的数据加载、垂直 hinting、渲染器抗锯齿设置。
- 独立剪贴板进程通过已验证对端 PID 的管道，在创建 QML 前接收当前字体；收藏圆盘也使用当前生效字体。
- 补齐中英文文案；窄窗口下字体选项上下排列，浅色列表选中项保持可读。

验证发现：只调用 `QGuiApplication::setFont()` 不会更新已经创建的普通 QML Text。
因此采用即时示例加明确重启入口，避免同一次运行中出现新旧字体混用。

`tst_uifont` 在 FreeType、GDI 两种引擎下各通过三个测试：启动字体和缺失字体回退、混排字形、不同缩放下标题字重。
`tst_settings uiFontPreference` 验证默认值、已安装字体、不可用字体和恢复默认的配置往返。

真实 `SettingsWindow.qml`、`SettingsEditor`、临时配置与真实剪贴板子进程共执行三组检查：

| 场景 | 检查数 | 结果 |
| --- | ---: | --- |
| 中文、浅色、100%、920 DIP 宽 | 16 | 通过，0 QML 警告 |
| 英文、深色、150%、760 DIP 宽 | 16 | 通过，0 QML 警告 |
| 以 Microsoft YaHei UI 启动 | 16 | 通过，0 QML 警告 |

检查涵盖生产选择控件的接受与选择处理、保存、即时示例、重启提示、未知输入、恢复默认、启动搜索框字体、下拉列表与截图。
额外验证真实独立剪贴板窗口的搜索框字体；子窗口一直隐藏，未申请服务租约，未启用剪贴板采集，没有执行粘贴或改写剪贴板内容。
