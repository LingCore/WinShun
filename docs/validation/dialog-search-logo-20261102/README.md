# 搜索入口 Logo 补齐与核查

> 后续调整（2026-11-02）：外侧装饰 Logo 和开关已退休，见[移除记录](../remove-edge-logo-20261102/README.md)。本页保留当时的实现及验证，不代表当前装饰窗口行为。

2026-11-02，Windows 11，Qt 6.12.0，MSVC 2022 x64 Release，D3D11。

## 原因和改动

此前 #162 修改的是 `SearchBar.qml`，覆盖主搜索框和搜索面板。用户截图中的对话框旁搜索栏来自独立的 `DialogBarWindow.qml`，仍画着放大镜。外观中的 `Appearance/SearchLogo` 控制栏外装饰，不能改变栏内图标，因此开启该选项也没有替换效果。

现将这一处改成与主搜索栏相同的内置 `resources/logo.svg`。Logo 保持原图标的中心点，以 20 个逻辑像素显示；调整两侧间距，使输入文字仍从 x=40 开始。继续使用对话框搜索栏原有的焦点、右键菜单和附着方式，不给它添加主窗口的固定/居中动作。

用户追问是否还有遗漏后，继续核对所有代表程序身份的入口，另补齐：

- 外观设置的 `AppearancePreview.qml` 仍用放大镜，已换成同一矢量资源，覆盖紧凑、标准、宽松三档。
- 原生任务栏搜索框的仅图标形态仍使用 `IDI_SEARCH`，改为与完整搜索框共用 `logoBitmap()`，保持原有尺寸、点击区域、缓存及彩色/单色设置。
- 固定入口 `WinShunSearch.exe` 的资源从 `search.ico` 改为 `app.ico`；主程序移除不再使用的 `IDI_SEARCH` 资源。同步旧架构说明，避免继续引用原方案。

设置查找、插件/功能卡片、引导中的“文件内容搜索”和菜单里的搜索动作仍使用放大镜，属于功能语义，不代表程序身份。剪贴板头部是粘贴图标；任务栏完整搜索框原本已经使用程序 Logo。**后续更正**：剪贴板搜索栏的首图标也属于品牌入口，已改为同一程序 Logo，见[补齐记录](../clipboard-logo-20261102/README.md)。栏外装饰开关继续保持现有职责，不影响内置 Logo。

## 防止再漏

同一视觉入口可能由不同生产组件实现。修改共用界面设计时，应列出主搜索框、搜索面板、对话框旁搜索栏等真实入口，分别确认实际组件和截图，不能把一个组件的检查当成所有入口的验证。装饰开关与栏内身份标识是不同职责，保持明确说明；设置中的普通搜索字段不属于这次品牌入口替换范围。
