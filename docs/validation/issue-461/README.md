# #461 画笔单击圆点、指针显示笔尖，以及工具条的“选择”按钮

验证日期 2026-11-25，本机离屏预览（`WinShunCapture.exe --preview-capture-tools … --renderer d3d11`）与单元测试；没有用真实鼠标在桌面上操作。

## 改了什么

- **单击出圆点**：画笔、自由荧光笔按下后没拖动就松开，留下一个与笔画同宽的圆点（以前什么都不留）。手抖在起拖距离内的几个点不算，圆点落在按下的位置。
- **指针显示笔尖**：画笔、自由荧光笔、打码画刷在能落笔的地方，十字指针换成笔尖圆点：直径就是屏幕上的笔画宽度，颜色同笔迹（荧光笔、打码画刷半透明），外面白、暗两圈保证在任何底色上看得见；不到 12 逻辑像素的细笔另加四个刻度方便找。改粗细、改颜色、编辑窗口缩放后立即跟着变。
- **“选择”按钮**：工具条最前面加一个鼠标指针按钮，没有工具时高亮；点它放下当前工具，回到能点选、移动、修改已有标注的状态（和 `Esc`、右键、再点一次当前工具一样）。

## 说明

- `--brush` 里另有两条断言（“常用行不在选区旁”“可见像素与导出不一致”）失败，在 main 的构建上同样失败，是这个预览原有的问题：样例里工具条盖住了第三条笔画。本次没有改它。
- `--edit-window` 报 1 条 `Window frame: the window has a new native handle` 警告，来自窗口边框组件，与本次改动无关。
- 系统指针不进截图，所以笔尖光标用导出的样张和断言验证，没有屏幕实拍。
