## 自动测试

- `tst_updatedelta`（新增）：生成后还原，结果和新版本逐个文件一致；增量安装程序和每个文件都被锁住（不能写、删、改名，可以读）；“只为我安装”跳过索引服务；本机文件改过、缺了、换成别的内容时干净地失败；坏包（不是 zip、未知 schema、`..`、绝对路径、写 `data`、大小写重名、摘要错、大小错、没有 WinShun.exe、缺数据、补丁损坏）全部拒绝且不留文件；目标已存在、取消；发布说明隐藏行的生成和解析；`offer()` 只认本版本的包名，地址和镜像由完整包换文件名得到。通过。
- `tools/verify-installer.ps1`：原有 5 项加新增 `delta-setup`（增量安装程序从拿住的 `payload` 安装、没有服务文件，MCP 中转仍是最后写、只写一次）。6/6 通过。
- `scripts/release.ps1` 的增量步骤：跳过“旧版本能否使用增量”的检查后单独运行，对 GitHub 上真实的 v0.34.2、v0.34.1 便携包生成并按 Win顺 的代码还原、逐个文件比对。通过（见上表）。

## 没有覆盖的

- “只为我安装”的副本走增量的真实升级（单元测试和 `verify-installer` 的 `delta-setup` 覆盖了跳过服务文件；没有卸载本机所有用户版去实测）。
- 线上 lcstp.com 转发隐藏行：已确认它逐字转发 v0.34.2 的说明正文，带隐藏行的说明要等第一次带增量包的发布后再核对。
- 已发布的旧版本（0.34.2 及以前）不认识这一行，照旧下载完整包；第一个能用增量的版本发布之后，再下一个版本才会真正生成增量包。
