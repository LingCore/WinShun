## #185：纯净搜索模式

- 默认关闭；入口是“设置 → 结果列表 → 显示与预览 → 键盘提示 → 纯净搜索模式”。
- 空查询或只有空白时，浮动搜索框只保留输入栏；输入或输入法组字时恢复范围、展开、历史等按钮，输入提交后显示结果。清空后收起。
- 从搜索控制器清除空查询结果，避免隐藏收藏后仍被 Enter 打开；不删除收藏、最近记录或搜索历史。
- Tab 等原有键盘操作保留，完整搜索、文件夹内搜索和任务栏入口保留原有呈现。窄任务栏框也按任务栏入口处理。
- 设置通过现有保存和通知链路立即生效，沿用现有主题及控件，没有另建一套布局系统。
- 本轮处理 issue 后续反馈中的纯净模式；完整快捷键编辑页和空状态微组件不在本轮范围内，不能据此将整个 issue 视为完成。

## #222：社区原生插件收录

- 插件库条目新增显式 `review: "unreviewed-native"`；检查、条目生成、索引生成、更新流程和两份编辑器 Schema 同步。
- 仅显式类别允许社区 exe/dll；路径、入口、大小、链接、重复文件、Release 身份及哈希检查仍保留。普通脚本规则、官方原生白名单独立保留。
- 要求 `minWinShun >= 0.22.0`，避免旧客户端不显示确认界面。包和条目都检查最低版本。
- 作者不能自行声明 `official`/`reviewed`，也不能在后续投稿中移除未审核标记。新原生版本走维护者核对；寄存在本仓库的社区旧插件不会被标成“官方”。
- 客户端展示官方、已审核源码、未审核原生或未知审核状态；未知原生包按需确认处理，未知枚举值不静默接受。审核文字也参与筛选。
- 首次安装和每次更新均经安装确认；可“查看来源”，仅接受 HTTP(S) 链接。拒绝首次安装不安装文件，拒绝升级保留旧版本；安装不自动启用。
- 后台自动安装和“全部更新”均排除这类包；同权限更新也不能绕过。风险标志随实际下载结果保存，刷新索引不会改变已下载包的确认要求。
- 文案明确区分文件完整性和代码审核；没有声称哈希、公开源码或 Actions 构建能保证代码安全。

## #239：显式共享宿主 Qt

- 清单字段：`runtime.qt: "host"`、`runtime.qtVersion: "6.12"` 或 `"6.12.0"`；缺省继续自带依赖。
- 只支持 MSVC x64 Release 原生 exe。主次版本必须一致，第三段为最低补丁版本；启动前检查版本及保证提供的运行时文件。
- 在生产 runner 的子进程环境中配置 PATH、平台插件和 QML 模块路径，提供 `WS_QT_DIR`/`WS_QT_QML_DIR`，保留原子进程 PATH 的后续条目；不改系统或宿主环境。
- 支持普通静态导入 Qt 的 exe，无需延迟加载；Qt Core/Gui/Qml/Quick、Basic Controls 和 Layouts 是本轮契约。
- 首版明确拒绝共享 Qt 与 `elevated` 同用，不从可写便携目录加载管理员代码，也不静默降权。
- 更新主仓库插件文档和 SDK 开发提示；契约标明待发布、最低 0.22.0。
