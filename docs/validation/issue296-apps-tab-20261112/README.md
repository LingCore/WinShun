# 应用标签（GitHub #296，PR #302）

2026-11-12，分支 `pr-302`（贡献者 w3c0929 的 `apps-tab` 加维护者的后续修改）。

## 做了什么

- 设置 › 结果列表新增“显示‘应用’标签”，默认关。打开后范围标签最后多一个“应用”：全部、文件、内容、应用。
- 应用排成图标网格；搜索框下的芯片选常用、收藏、全部，Ctrl+Tab 切换，选择会记住。
- 输入文字按“全部”里找应用的方式匹配（拼音、首字母、别名），只在当前芯片的范围里找。
- 图标右上角的星标加入或移出收藏夹；右键菜单、Enter、管理员运行等都是结果行原有的。
- 展开的搜索面板和文件对话框的搜索条里没有这个标签；从面板回到搜索框时回到“应用”。

## 验证

构建目录 `build/issue296`，Qt 6.12.0，Release。

| 项目 | 结果 |
| --- | --- |
| `WinShun.exe --preview-results <dir> --apps-grid`（本机真实应用：常用 51、全部 277，7 列） | 通过，0 条断言失败 |
| 同上加 `--dark --size compact` | 通过 |
| `--pure-search`（回归） | 断言通过；退出码 2 是原有的“new rows … ms”计时提示 |
| `ctest -R "tst_settings\|tst_launchernavigation\|tst_favorites"` | 10/10 通过 |

`--apps-grid` 检查的内容：开关关着时没有标签、Tab 到不了、也设不进去；打开后“应用”是第四个也是最后一个标签，Shift+Tab 从“全部”到它；网格成为窗口的列表，芯片条显示三项；Ctrl+Tab 换芯片并记入状态文件；← → ↑ ↓ 和 Page Down 沿图标移动，翻页后顶上不留半行；星标加入、移出收藏夹，“收藏”跟着变；输入 `jsq` 找到计算器；找不到时只显示网格自己的一行字；进面板让位给“全部”，回搜索框回来；关掉开关后标签消失。

没做的：没有在真实窗口里用鼠标和键盘实测（只做了离屏检查），没有在 125%／150% 缩放下量像素。
