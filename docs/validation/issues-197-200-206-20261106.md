## #197：用键盘查找剪贴板分组

- 剪贴板窗口新增文件夹按钮和 `Ctrl+G`，进入独立的分组查找模式。可沿用原搜索词，也可直接改写；支持中文名称、英文大小写不敏感匹配和多个词。
- 上下键选择，Enter 进入分组，继续输入即为组内内容搜索。Esc 返回进入前的内容查询和范围。
- 以稳定的分组 ID 切换；不存在的分组不改变范围。空分组能正常进入。无匹配项时 Enter 不执行内容粘贴。
- 分组列表沿用现有主题、列表高亮、字号和滚动条，并兼容剪贴板倒序布局。当前分组名称显示在内容搜索框提示中。
- 录入文本、分组导航和粘贴动作保持明确的状态边界；独立显示进程同步接入方法返回值和通知。Win顺 自己持有 Ctrl+G 时，剪贴板正在接管输入则优先查找分组，否则仍走原来的对话框跳转。
- 同步补充中英文文案及“按键一览”。分组名匹配目前是名称子串匹配，组内内容继续沿用原有搜索能力。

验证过程中，独立显示进程测试发现 `groupSearchRequested` 缺少接收端事件放行；已补齐，并通过真实子进程和管道往返复测。

## #200：文件夹菜单直接显示条目

入口：设置 → 打开 Win顺 → 对话框 → 文件夹菜单。

- 最近文件夹、已打开文件夹分别设置直接显示数量，范围 0–10。默认 0 保留二级菜单；正数显示前 N 项，剩余项放入“更多…”。
- 直接显示的小节标题不可选，键盘导航跳过它。进入“更多…”后仍显示原分组名，条目的动作 ID 和路径提示保持不变。
- 最近文件夹列表上限由 5 增至 20；已打开文件夹去除原来的 5 项截断，保留去重和当前目录排除。
- 无剩余条目时不显示多余的“更多…”，空组保持禁用状态。无效数量恢复原值，两个数量独立保存。
- 检查英文 150% 缩放时发现同区域已有的六个操作开关超出页面，改用 Flow 包裹现有选择控件；每个开关的行为及保存方式不变。

## #206：直接打开完整面板、隐藏筛选侧栏

入口：设置 → 打开 Win顺 → 快捷键 → 直接打开搜索面板。

- 新增独立全局快捷键，默认未分配。可设置例如 `Ctrl+Alt+F`；录制、清除、冲突提示与现有快捷键设置保持一致。
- 快捷键直接走完整面板打开路径，在显示前完成面板布局，并沿用搜索框焦点处理。已钉住的窗口也能进入面板。
- 面板搜索栏新增筛选按钮，可显示或隐藏侧栏。结果区域回收侧栏宽度，偏好写入 `Panel/SidebarVisible`，重建控制器后保留。
- 隐藏侧栏不清除查询或筛选条件。有条件生效时按钮保持强调色和标记，提示文字明确说明筛选仍生效。
- 按钮支持鼠标、Tab、Enter、Space 和辅助功能操作，激活后焦点回到搜索框。已登记到原生标题栏控件命中区域，避免鼠标点击被误判为拖窗。

- 测试使用临时配置、数据库和本线程的程序副本，没有退出或操纵用户/Claude 的 Win顺，也没有发送系统级键盘输入。
