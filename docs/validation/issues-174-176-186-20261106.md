# #174、#176、#186：预览交互与文件管理器联动

2026-11-06，Windows 11 x64、Qt 6.12.0、MSVC 2022 Release。

本轮选择 [#174](https://github.com/LingCore/WinShun/issues/174)、[#186](https://github.com/LingCore/WinShun/issues/186) 和 [#176](https://github.com/LingCore/WinShun/issues/176)。前两项改善高频阅读操作，第三项补齐现有 Ctrl+G 工作流。避开用户指定正在处理的 #204、#217、#119，也未将工作区已有修复算成本轮成果。

## 实现

### #174：剪贴板悬停预览

- 停留约 200 ms 后，以独立小窗显示当前条目；计时从进入条目开始，轻微手抖不会不断重置。
- 复用 `ClipPreview` 和现有主题，短文本收紧高度，长文本限高后可滚动，图片按比例显示。位置跟随条目，受显示器可用区域约束；优先放在余量较大的一侧。
- 不改变键盘选中项或剪贴板主窗口几何。鼠标移入预览可继续阅读，移开、滚动列表、切换分组、打开菜单、拖动或隐藏窗口时清理临时状态。
- 保留 Alt+P、中键和按钮手动展开侧栏。关闭剪贴板后不再恢复上次展开状态。
- 隐藏的侧栏不重复读取悬停内容；临时窗口由 Loader 管理创建和销毁。

### #186：搜索预览摆放与切换

- 原实现每次窗口位置变化都重新选边；现在记住侧边，在最小可读宽度附近允许最多 48 DIP 的有限重叠，避免小幅拖动反复换边。重叠只补足所缺宽度，避免跨阈值时突然变宽。
- 增加上方空间，竖屏底部没有左右或下方空间时可向上显示。覆盖模式也记住靠哪一侧。
- 从文件切到全部等范围时，关闭旧结果的浮动预览；保留进入内容详情时交给嵌入预览标签页的原有行为。
- 搜索结果悬停计时不再被同一行内的每次鼠标移动重置。Office 等处理程序的防误启动等待保持不变，不声称缩短了处理程序自身的加载时间。

### #176：Tessoa 当前目录查询

- 接入 [Tessoa 公开的 v1 管道协议](https://github.com/Tessoa/Listary.FileAppPlugin.Tessoa/blob/main/Listary.FileAppPlugin.Tessoa/TessoaQuery.cs)，上游说明要求 Tessoa 0.22.0 或更新版。
- 按窗口进程识别 `tessoa.exe`，向 `tessoa.q.<pid>` 发送具体 HWND，并核对管道服务端 PID。
- 使用既有文件管理器工作线程、RAII 句柄和重叠 I/O；整次传输有 600 ms 预算，连接等待最多 300 ms，响应上限 1 MiB。
- 拒绝相对路径、非法 UTF-8、内嵌 NUL、换行及越界响应。空答复、无服务和超时均返回空，不缓存旧目录。
- 同一查询接入 `frontFolder` 和 `openFolders`，供 Ctrl+G、对话框建议及原有自动跳转使用。本轮没有新增 Tessoa 的默认打开/定位文件选项。

## 验证与边界

- `tst_previewplacement`：17 个有效数据行通过，覆盖左右、下方、上方、负坐标副屏、边缘摆放、大小变化及反复跨过换边阈值；另有 init/cleanup 两项。
- `tst_shelllaunch tessoaProtocol tessoaAbsentAndLookalike tessoaProductionDiscovery`：12 个有效测试通过。包含真实命名管道、分段 UTF-8 响应、UNC、空答复、错误数据、超时，以及临时复制为 `tessoa.exe` 的独立进程经过生产识别和查询路径。夹具没有展示窗口，也不读写用户目录。
- `tst_previewinteractions`、`tst_previewinteractions_scaled`：加载真实 ClipboardWindow、ClipPreview、Clipboard 控制器和临时 ClipStore；检查停留时序、内容对应、长文本滚轮、图片高度、离开条目、重新打开、搜索范围切换和内容详情交接。只发送进程内 Qt 输入事件，不注入全局按键，不采集或改写系统剪贴板。
- 离屏平台实测为浅色，不能因为传了 `--dark` 就算深色验证。其 `propagateSizeHints` 是平台不支持原生尺寸协商的已知提示，测试只豁免这一条精确消息，其他 QML/运行告警仍计为失败。
- 使用 `CreateDesktop` 创建不切换到前台的独立 Windows 桌面，补测真实 Windows QPA 的 150% 英文深色界面。短文本、长文本和图片截图已逐张检查；同一套交互检查通过，没有 QML 运行告警。该验证不等同于在用户当前输入框里测试粘贴或全局键盘转发。
- 新增预览组件及修改过的 ClipPreview、ClipboardWindow 通过 qmllint；ClipboardPage 有原有的 `currentItem.order` 和 `page` 名称提示。

独立构建目录：`build/issues-174-176-186`。日志、原始文件快照及私有桌面启动脚本：`build/issues-174-176-186-evidence`。使用说明同步更新；只构建主程序和相关测试，没有执行全套测试。
