# 安装程序：被占用的文件不再卡住升级（2026-11-12）

起因是 #300（应用内更新停在 “Preparing to Install”，像卡死），以及此前的 #68、#97、#274：只要有程序占着安装目录里的文件，升级就失败或要用户自己处理。

## 改了什么

`installer/WinShun.iss` 的 `PrepareToInstall`：

1. 关掉 Win顺、停索引服务，再结束所有**从安装目录运行**的程序（按路径，不碰别处的副本）。
2. 直接问文件本身还能不能被替换（独占打开试一次），不再以 Restart Manager 的名单为准（它会把只是在读的安全软件也列进去）。
3. 还被占着的，等几秒（Win顺 自己的程序最多 90 秒），页面上写明在等谁。
4. 之后仍被占着的程序、库、字体文件改名为 `名字.wsold` 挪开，继续安装。占用它的程序接着用旧的那份。
5. 既打不开又挪不动（被独占打开）才停下：已挪开的放回原名，旧版本完整，日志写 `Update blocked by:`，Win顺 的通知说明是谁。
6. `.wsold` 在本次安装结束、下次安装开始、卸载时清理；为所有用户安装时，仍被占着的登记为下次重启删除。

## 实测

`tools/verify-installer.ps1`：同一份脚本以 `/DTestInstall` 编译（独立 AppId 和程序名，不提权，不留快捷方式、[Run]、卸载项），在本机真实安装“版本 1”，制造占用，再像应用内更新那样静默运行“版本 2”的安装程序，每次限时 60 秒。结果见 [passed.json](passed.json)：

| 情形 | 结果 | 用时 |
|---|---|---|
| 正常升级 | 升级完成 | 11 秒 |
| 自己的程序和安装目录里的助手还在运行（不理会退出请求） | 都被结束，升级完成 | 38 秒（其中 15 秒是等它自己退出） |
| 别的程序加载着安装目录里的库不放（#300 的情形） | 升级完成，那个程序没被动；旧库挪成 `.wsold`，它放开后下一次安装清掉 | 12 秒 |
| 别的程序在读一个文件（像安全软件那样） | 升级完成 | 12 秒 |
| 文件被独占打开 | 12 秒内放弃（退出码 7），日志指出是谁；版本 1 完整，已挪开的库放回原名；放开后再装成功 | 12 秒 |

对照（[without-the-fix.json](without-the-fix.json)）：把“改名挪开”那一步临时关掉再跑，后三种情形全部失败（退出码 7，版本 2 没装上），说明测试确实抓得住原来的问题。

## 本机真实升级（同日，用户同意后）

`tools/verify-installed-upgrade.ps1`：本机 Program Files 里装着的 0.23.0（为所有用户安装，带索引服务）正在运行，另一个程序（PowerShell）加载着安装目录里的 `Qt6Core.dll` 不放，然后像应用内更新那样以普通权限启动新安装包（`/SILENT /SUPPRESSMSGBOXES /NORESTART /SP- /ALLUSERS`，由它自己弹 UAC）。安装包由 `scripts/release.ps1` 从 `1b737934` 构建，打包前的五项测试通过。

| | 结果 |
|---|---|
| 升级（[live-upgrade.json](live-upgrade.json)） | 退出码 0，19.8 秒；版本 0.23.0 → 0.25.0，卸载项同步为 0.25.0 |
| 被占的文件 | 5 个（`Qt6Core.dll` 和它带起来的 4 个运行库）改名为 `.wsold`，新文件装入；占用它们的程序没被结束 |
| 新版本 | 装完自动在托盘启动，普通权限（不是管理员） |
| 索引服务 | 运行中，路径仍是安装目录里的那份 |
| 自启任务、设置文件、搜索历史 | 没有变化；索引照常更新 |
| 仍被占着的 `.wsold` | 5 个都登记为下次重启删除 |
| 占用放开后再装一次（[live-again.json](live-again.json)） | 退出码 0，19.1 秒；`.wsold` 全部清掉，新版本照常启动 |

## 没有覆盖的

- 测试版用的是替身程序（Windows 自带的小程序和库的副本），不是真的 Win顺：真实程序响应 `--quit`、索引服务的停止与重新注册、[Run] 里启动新版本，都不在这套测试里。
- 应用内更新的完整链路（检查、下载、校验、`WinShunUpdate.exe` 守着安装程序）没有走：本机实测是按它的参数直接启动安装包。
- “下次重启删除”只核对了已登记，没有重启验证。
- “只为我安装”的真实升级、双击安装包走向导页面的升级，没有在本机做。
- #300 报告人那种“已经结束但杀不掉”的僵尸进程没有造出来；用“加载着库不放的另一个程序”代替，对安装程序来说是同一种占用。
