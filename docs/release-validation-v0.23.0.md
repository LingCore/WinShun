## 本轮修正

第一次构建与测试发现三处问题，修正后从干净提交重新构建：

- `tst_pinclipboard` 编译失败。#269 合并后，贴图保留原图像素、显示时再适配，`readClipboard` 不再接收位置参数；测试仍按“存成缩小图”的旧接口和旧断言编写。现在按新行为断言原尺寸和中心位置。
- AI 设置表里“使用记录”一行仍叫“记住打开过的项目”，设置窗口在 0.22.0 已改名为“记住搜索和打开过的项目”。AI 用 `open_settings` 定位这一行时会落空。表格和英文翻译已同步。
- `tst_core` 的个人文件夹优先级用例把临时目录建在 `%TEMP%` 下。它位于隐藏的 `AppData` 里，文件被按“隐藏目录”排序，用例在本机必然失败；产品逻辑本身正确。用例改到测试程序目录下。

发布时未纳入：`tst_displaygeometry` 的 `explorerTooLargeToKeepClearOf`（#203 加入）在本机失败，换回 v0.22.0 的 `Placement` 同样失败。发布后查明是测试过时、与缩放无关：965d315 起，搜索框在文件列表上方以 460 宽的紧凑尺寸打开（#82），由 QML 按 `boxWidth` 调整窗口宽度；测试里没有 QML，窗口仍是 760 宽，右边伸出了列表。产品行为符合预期，未改动；测试在 `35a7f81` 改为按 `boxWidth` 调整宽度，并断言 460，150% 下全部 10 项通过。
