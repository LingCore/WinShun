# 配色规则

Win顺 所有颜色令牌定义在 `src/app/qml/Theme.qml` 及各风格 `themes/<style>/Look.qml`（强调色实心底由 `SystemTheme::accentFill()` 计算）。新增界面一律引用令牌，不写死颜色值。

## 规则

1. **彩色实心底上的文字和图形一律白色**（`Theme.accentText`，浅/深色均为 `#FFFFFF`），包括高亮按钮、当前子标签、插件命令标签、开关圆点、主题卡对勾/单选点、剪贴板序号。
2. **强调色分两种用途**：
   - `Theme.accent`：彩色文字、图标、细线、下划线、焦点线、选中竖条（深色主题下提亮以保证可读性）。
   - `Theme.accentFill`：白字或白色图形的实心底，从强调色出发动态加深直至白字对比度 ≥ 4.5:1（兼容亮黄、亮绿等系统强调色）。不要拿 `Theme.accent` 当白字底（深色默认 `#2B9DFF` 仅 2.85:1）。
3. **危险色分两种用途**：`Theme.danger` 用于文字和图标（深色柔和红 `#FF99A4`）；`Theme.dangerFill`（`#C42B1C`）用于白字确认删除按钮的实心底，不用柔和粉当底。
4. **浅色标签**（“随包”“AI”“应用”）：`Theme.badge`（强调色 10–16% 透明）做底，`Theme.accent` 做字。
5. **状态色只用于文字和图标**：`success` / `caution` / `danger` 不作实心底。
6. **灰字三级**：`text` 正文、`subtext` 说明、`faint` 提示与占位文字（Fluent 深色 `#8A8A8A`、浅色 `#7A7A7A`，卡片上 ≥ 3:1，不要再调淡）。选中的行、磁贴上也一样：`text`、`subtext` ≥ 4.5:1，`faint` ≥ 3:1。
7. **边框与键帽**：
   - 边框用中性灰 1 逻辑像素（`cardBorder`、`controlBorder`、`windowEdge`），不用蓝边或 2 px；选中态靠底色与强调色竖条表达。
   - 键帽不描边，靠中性灰底（`Theme.keycap`，浅色 `rgba(0,0,0,0.06)`，深色 `rgba(255,255,255,0.07)`）显形，底色不能退回窗口背景色。
   - 选中的芯片与钉住图钉保留 1 px `chipBorder`，确保浅色主题下白底选中块清晰可见。
8. **纯图标分段按钮**（如列表 / 大图）：选中时改变图标颜色并配中性底面，不沿用文字分页下划线；文字分页保留各风格自身选中标识。预览 / 菜单入口在打开期间持续标记，不随鼠标移走消失；键盘焦点独立保留。
9. **选中要一眼看出，且明显强于悬停**（GitHub #474）：键盘所在的行（`rowHighlight`）、磁贴和选中的芯片、卡片（`Theme.selection`）与所在底色的 CIELAB ΔE 浅色 ≥ 6.5、深色 ≥ 9，与悬停（`Theme.hover`）浅色 ≥ 4.5、深色 ≥ 6。底色按纯色、Mica 和偏色 Mica 都算；深色要得更多，因为暗处同样的差距在暗屏、差屏上最先看不见。白色浮起面（brand 浅色、tactile）靠 1 px 描边或托盘衬出，取面和描边里更显眼的一个。改 `rowSelected`、`selection`、`hover`、托盘或灰字时跑 `ctest -R ^tst_appearance$`：`rowStates` 量各风格真实高亮部件画出的像素，`selectionTokens` 量令牌叠在底色上的结果，同时核对上面的文字对比度。

## 对比度参考（默认蓝 `#0067C0`；深色卡片 `#2B2B2B`，浅色卡片 `#FBFBFB`）

WCAG 2.1 目标：正文 ≥ 4.5，提示和大字 ≥ 3，实心形状与底色区分 ≥ 3。

| 组合 | 深色 | 浅色 |
|---|---|---|
| 正文 `text` / 卡片 | 12.8 | 16.7 |
| 说明 `subtext` / 卡片 | 5.9 | 6.5 |
| 提示 `faint`（深 `#8A8A8A`，浅 `#7A7A7A`）/ 卡片 | 4.1 | 4.1 |
| 蓝字 `accent` / 卡片 | 5.0 | 5.5 |
| 蓝字 / `badge` 标签底 | 3.9 | 4.7 |
| 白字 / `accentFill`（深 `#0076DD`，浅 `#0067C0`） | 4.5 | 5.7 |
| `accentFill` 底 / 卡片 | 3.1 | 5.5 |
| 白字 / `dangerFill` `#C42B1C` | 5.7 | 5.7 |
| 红字 `danger` / 卡片 | 7.0 | 5.5 |
| 绿字 `success` / 卡片 | 7.0 | 5.3 |
| 黄字 `caution` / 卡片 | 10.7 | 5.1 |

## 验证方法

- 离屏渲染检查两套主题：`WinShun.exe --preview-settings <dir> --dark --scale 1.5` 与 `--scale 1.25`（浅色），加 `--renderer d3d11`。
- 量化对比度：从截图中取底色与字色，按 sRGB 线性化后的相对亮度 `0.2126 R + 0.7152 G + 0.0722 B` 计算 WCAG 对比度。
- 像素对齐检查：在 125% / 150% / 175% 下核对四边线宽，详见 [UI 踩坑](pitfalls/ui-qml-and-windows.md)。
