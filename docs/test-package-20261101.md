## 原机复测

优先把便携包解压到全新目录，使用其中新的 `data`，不复制旧版索引、剪贴板或配置。正常启动前先保存工作并自行退出原来的 Win顺，避免单实例把操作交给旧程序。安装包包含相同代码，但本轮本机不会实际覆盖安装或更换服务。

### #111 双屏窗口

1. 在设置中记下 Windows 版本、两屏分辨率、缩放、刷新率、布局以及 Win顺 渲染器。
2. 打开搜索窗口，按住拖动区从主屏拖到另一屏，再拖回来，观察指针过接缝时是否整窗突然跳位。
3. 打开设置窗口，以相同方式往返拖动，单独记录跨屏是否有明显停顿。
4. 如仍失败，记录操作时间、复现频率及哪一种窗口，并导出诊断日志。搜索窗口跳位与设置窗口停顿分别报告。

本机此前已由用户确认搜索跳动消失、设置无明显停顿；报告者的 Windows 10、100% 双屏环境仍需原机确认。

### #150 圆盘不出现

1. 使用普通权限启动，确认“收藏圆盘”已开启，收藏一个测试文件夹。
2. 在资源管理器中按住一个临时文件，分别尝试按住不动、开始拖动、移动后立即按反引号／`·` 键（通常在 Esc 下方）。
3. 观察圆盘是否出现；先按 Esc 取消，再松开鼠标，避免把测试文件实际放入收藏目录。
4. 若不出现，记录鼠标或触摸板、文件来自桌面／资源管理器／其他管理器、键盘布局和操作时间，随后到“设置 → 高级 → 诊断日志”导出诊断包。

本包补充了触发、Raw Input、OLE 目标及辅助进程状态诊断。本机通过不代表原报告已经修复。

### #69 更新及插件连接

1. 检查更新，并打开插件库刷新列表。当前服务器正式版本仍为 0.16.0，提示没有更新本身不算失败。
2. 若连不上，分别记录更新检查、插件列表、插件包下载中的哪一步失败，以及错误提示和时间。
3. 导出诊断日志，同时附测试包标识和网络代理模式。本机已验证两个版本接口、两个镜像及原站的插件索引和小插件包；原机失败及大安装包持续下载仍需分别判断。
