# 图片文字搜索插件

实现位置 `src/ocr-search-plugin`，插件 ID `winshun.ocr-search`。这是开发版功能，公开插件库分发和新版本发布不在本次实现任务中。

## 边界

宿主只增加通用 `commands[].contentSearch` 接口与结果合并，未将 OCR、文档图片解析、数据库或管理窗口放进主程序。没有安装／启用提供者时，不启动插件任务。

插件复用现有小启动器／Qt DLL 模式：小启动器只从插件目录、`WS_APP_DIR` 和系统目录加载 DLL；Qt 与公共控件跟随宿主。源码和字节码一起保留，避免依赖 QML 私有 C++ ABI。UI 公共组件使用同一份 Theme、TitleBar、WindowFrame 等源码。

解析、识别和预览在插件自己的工作进程中执行，继承插件作业与普通用户令牌。`processes` 权限用于允许该子进程。每轮索引复用一个工作进程及其 OCR 实例；单文件 60 秒，取消／崩溃／超时结束该进程。预览使用独立的 30 秒工作进程。父进程只接收有界 JSON；索引响应包含文字与位置，预览响应包含临时有界 PNG，不写图片缓存。

## 索引和查询

SQLite WAL，每个调用线程独立连接，查询使用只读连接。文件表记录规范路径、原路径、大小、毫秒修改时间、SHA256、模型／流程版本、遍历代数、状态及原因。页表将文件位置映射到去重图片记录，图片记录保存压缩文字与识别框。中文单字／双字和 ASCII 三字片段继续复用 `grams` 规则，但关系不再逐条存入普通表：`asset_terms` 使用 FTS5 contentless、`detail=none`、`columnsize=0`，仅保存压缩候选倒排表。片段键编码为十六进制词元；不额外存正文、词频和词偏移。每个查询词先筛出候选图片，再按文件交集，最后验证压缩文字；不同页仍可分别满足不同词。片段过滤只用于排除，不能代替文字核验。

更新单文件使用事务。读取期间文件变化、取消或异常则回滚；成功后提交。相同文件内容可复制位置记录，相同图片共享识别结果。只在目录完整遍历后清理未见文件；离线目录和遍历失败保留未检查记录。排除目录及移除范围立即撤掉对应索引。查询还会核对现有文件大小和毫秒时间，预览复核同一时间戳。

数据库大小通过 `max_page_count` 约束，按数据库实际 `page_size` 换算容量。回收没有页引用的图片时，先从存储的压缩文字重建完全相同的词元，提交 FTS5 删除命令；删除倒排关系与图片记录处于同一事务。随后合并倒排段，循环执行增量回收直到空闲页耗尽或不再前进，最后截断 WAL。QSQLITE 对零列的 `incremental_vacuum` 不提供 `next()` 继续步进，单次执行可能只回收一页，不能把“命令成功”当成文件已经缩小。短期 WAL、共享 OCR 组件和原始文件不属于数据库页数限额；显示占用包含数据库、WAL 和 SHM。活跃读事务可能推迟 WAL 截断。

数据库 `user_version=2`。版本 1 的迁移在单事务内直接从已有识别文字构建倒排表，再移除旧 `grams` 表；不读取原文件，不重新 OCR，资产 ID 与高亮框保持不变。容量不足等失败回滚迁移，更高版本数据库拒绝打开。迁移成功后回收旧表空闲页。模型／文字语义没有变化，因此不递增 `ocr-search-2` 流程标识。研究依据、迁移与容量回归、优化前后体积见 [2026-11-02 存储验证](validation/ocr-storage-20261102/README.md)。

搜索、预览分别使用有界线程池和取消令牌，GUI 不等待旧查询／旧解码完成。返回时核对令牌和预览版本。后台进度限频，防止未改动的大目录遍历向 GUI 排队大量信号。

## 宿主协议

`commands[].contentSearch: true` 声明一个内容提供者。关键词查询保持原协议；内容查询的 `trigger` 为 `content`。只在 Content 或显式开启内容检索的 All 中派发；Files / Folders 不派发。关键词独占列表时不调用其他内容提供者。提供者在原生结果之后合并，最多 200 行，不占普通推送的 3／6 行配额；同一文件已有原生结果时去重。

`filters` 保留原有日期、大小、扩展名及目录条件，并提供 `contentEnabled`、`contentWords`、`contentPick`、`excludedExtensions`、`excludedFileNames`。关键词、目录选择、排除文件类型／名称和异步过期结果分别有测试或生产路径验证。

## 已知边界

详见 [插件说明](../src/ocr-search-plugin/package/README.md)。首版不承诺所有历史 Office/WPS 格式和所有图片编码。Office 按图片关联读取原图，不复现裁剪、遮挡和整页版式；PDF 按实际页面渲染。文件重命名复用依靠内容指纹，而不是宿主 NTFS EntryId。仅大小和修改时间均未变化的改写需要手动检查。大数据量结论必须区分真实 OCR 样本与合成索引查询基准，不能据小样本承诺比 AnyTXT 缩小固定比例。

后续修改模型、文字归一化或图片定位语义时，应递增 `ocr-search-2` 流程标识，使已有文件重新检查；数据库结构变动同时更新 `user_version` 和迁移策略，不能覆盖较新数据库。PPT 位置按 presentation 的实际顺序解析，不把 slide 文件名编号当作页码。
