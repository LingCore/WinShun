## 第一次用

1. 从 [Releases 页面](https://github.com/LingCore/WinShun/releases/latest) 下载安装程序，双击安装。Windows 提示“已保护你的电脑”时，点 **更多信息 → 仍要运行**。
2. 全新配置第一次启动会显示两页引导。第一页选择 **搜索与索引**（是否建立内容索引）、**打开 Win顺**（双击 Ctrl / Alt / Shift 或自定义快捷键，可先试用）；点 **下一步**，第二页选择 **剪贴板历史**（说明本机记录和保留规则，可选是否用 Win+V）、**截图**（录制快捷键，确认后下载组件并核对权限）。可点 **上一步** 返回，之前的选择会保留。
3. 翻页不保存或启用功能，最后点 **开始使用** 才统一生效。文件名索引保存在本机，下次启动继续使用并跟踪变化；首次建立需要一点时间。内容索引开启后，首次会在后台读取所选范围内的受支持文件，随后主要更新变化的文件。
4. 也可点 **稍后设置**，先用文件名搜索和双击 Ctrl，内容索引、剪贴板历史、截图保持关闭。以后可在设置中逐项开启。升级已有配置不会重新引导，也不会改变原来的开关。
5. 截图组件下载或启用失败时，引导会显示原因并允许重试，或选 **稍后安装** 继续搜索。组件成功下载后，仍需明确同意其权限才会启用。搜索快捷键和截图快捷键不能重复。
6. 用选好的按键打开搜索框；默认是 **连按两下 Ctrl**。直接打字就能搜索，再按相同按键或 `Esc` 关闭。

> 双击 Ctrl 和别的软件冲突（比如 Listary、PowerToys 的“查找鼠标”）？在 **设置 › 打开 Win顺** 的“双击哪个键”里可以改成双击 Alt 或双击 Shift（输入法用 Shift 切换中英文的，双击会切换两次，最后回到原来的状态），“用哪一边”可以只认左边或右边，也可以换成别的组合键，比如 `Alt+Space`。双击 Alt 只认单独按下又放开的 Alt：`Alt+Tab` 这类组合、按住不放、配合鼠标用的都不算。

右键托盘图标可以打开设置、重建索引、暂停记录剪贴板、退出。

托盘菜单最上面一行会说 Win顺 正在做什么：“正在加载索引…”（读上次存的索引，不是重新建）、“正在建立文件索引，已收录 N 项”、“正在建立内容索引 1,234 / 5,000，约 3–5 分钟”。剩余时间要看够 30 秒的速度才给，给的是范围；不足一分钟写“快好了”，最后合并整理时写“正在整理，快好了”；你在搜索、用电池或在用电脑时，写“你在搜索，先停一下”“在用电池，先暂停”“你在用电脑，放慢了”。第一次建文件索引、重建索引、第一次建内容索引这类超过 2 分钟的大活结束时，托盘会弹一条通知，比如“内容索引建好了，用了 6 分钟。现在可以搜文件里的字了。”；日常每 15 分钟的小轮次不通知。

### 没有管理员权限：“只为我安装”

公司电脑、没有管理员权限的账户也能用。运行安装程序时，会问装给“所有用户”还是“只为我”；当前账户不是管理员时，“只为我安装”排在前面、默认选中（以前装过的，升级时照原来的装法，不再问）：

- **为所有用户安装**（要管理员同意）：带索引服务，索引整个磁盘，最快。
- **只为我安装**（不要管理员权限）：不装索引服务，Win顺 只索引你选的文件夹，也不往系统里写别的东西。开机自启在不能建计划任务时会改用登录项。
- 同一台电脑上两种装法不能并存：已经为所有用户装了，再运行只为我的安装程序会提示直接用它；反过来也一样，要先卸载另一份。

只索引选中的文件夹时：

- **选哪些**：**设置 › 搜索范围 › 文件夹** 里的“索引哪些地方”有三个选项：自动、整个磁盘、只索引选中的文件夹。“自动”的意思是没有索引服务、又不是管理员时，只索引选中的文件夹。装了索引服务或以管理员直读时，总是索引整个磁盘，第三项会变灰并写明原因。
- **索引的文件夹**：一开始是桌面、文档、下载、图片、视频、音乐和 OneDrive 这些常用位置。点“添加文件夹…”挑一个，或直接从资源管理器把文件夹拖进来，或点下面“常用位置”里的一个。每个文件夹一张卡片，写着状态、有多少项、上次核对的时间；可以“立即核对”或移除。网络位置不能加在这里，要加到“网络共享”里。
- **实时更新**：选中的文件夹里新建、改名、删除的文件马上就能搜到。
- **定时核对**：每天把这些文件夹再整个走一遍，补上没跟上的改动，可改成每小时、每 4 小时或只在启动时。到点后等你离开电脑一会儿才核对，不会在你用电脑时打扰你。
- **搜到范围外的文件夹**：在搜索框里打一个不在索引里的文件夹，下面会提示“这个文件夹不在索引范围内”。点“这次也搜它”只搜这一次；点“加入索引”以后一直收录。搜出来的结果很少时，也会提示一次“只索引了你选的文件夹，可能有别的地方没搜到”，可以点“设置文件夹…”，或点“不再提示”。
- **内容搜索**：照样能用，没有索引服务时直接读文件，慢一些。

整盘索引也可以自己选磁盘：在 **设置 › 搜索范围 › 磁盘** 的“索引哪些磁盘”里选“自己选择”，勾上要收录的盘。不勾的盘会退出索引，再勾上会重新收录；一个都不勾就不索引本机磁盘，网络和 WSL 位置仍单独管理。移动硬盘还需打开“包括 U 盘和移动硬盘”。暂时没连接的盘会保留你的选择。

如果用 `mklink` 建了目录链接或目录联接，在 **文件夹** 页把链接所在的路径加进来，例如 `C:\工作\资料链接`。管理员运行或使用索引服务时也能加；程序会补充收录链接里的内容，按这个路径显示结果并跟踪变化。普通文件夹已包含在整盘索引中，不会重复扫描。磁盘选择和排除规则按添加的链接路径判断；移除索引只移除搜索记录，不会删除原文件。

### 索引服务装在哪里

索引服务是个很小的系统服务，只在为所有用户安装时才有。便携版在 **设置 › 搜索范围 › 磁盘 › 索引方式** 里也能装上它：为了安全，Win顺 会把服务程序复制一份放进 `%ProgramFiles%\WinShun Service`（只有管理员能改），不会让服务直接从你能随便改动的文件夹（下载、桌面）里运行。以前装过的便携版，设置里会提醒，点“修复”就换成安全的位置。便携版（含 Scoop 装的）换了新版本后，如果索引服务是这份 Win顺 装的、版本比它旧，Win顺 会弹一次通知：点通知就开始更新，Windows 确认一次就好；也可以在同一行点“更新索引服务”。每个版本只提醒一次，记在设置文件 `[Launcher]` 的 `ServiceUpdateHinted` 里。

### 用 Scoop 安装、更新、卸载

习惯用 [Scoop](https://scoop.sh) 管理小工具的话：

```powershell
scoop bucket add winshun https://github.com/LingCore/WinShun
scoop install winshun
```

装的是便携版：设置、剪贴板和索引存在 Scoop 的 `persist\winshun\data` 里，换版本、重装都留着。开始菜单里有 “WinShun”（快捷方式用英文名：系统代码页不是中文的电脑上，Scoop 建不出带汉字的快捷方式），终端里可以直接用 `ws`。开机自启、资源管理器右键菜单等登记的是 Scoop 的 `current` 目录，`scoop update` 之后依然有效。Scoop 不装索引服务，需要索引整个磁盘时到 **设置 › 搜索范围 › 磁盘 › 索引方式** 里装。

- **更新**：有新版本时，更新提醒里的主按钮是“用 Scoop 更新”：Win顺 先退出，在新打开的 PowerShell 窗口里运行 `scoop update` 和 `scoop update winshun`，成功后用新版本重新打开；没成功时窗口里会写明原因，原来的版本照旧打开。也可以自己运行 `scoop update winshun`（Scoop 在 Win顺 或 AI 工具启动的 `WinShunMcp.exe` 还开着时会拒绝更新，先关掉它们）。全局安装（`scoop install -g`）要管理员权限，更新提醒里改为显示命令（`scoop update winshun -g`）和“复制命令”按钮。Scoop 装的 Win顺 不会用 Win顺 自己的“下载并安装”替换文件，以免 Scoop 记的版本对不上。
- **卸载**：`scoop uninstall winshun`。Scoop 在删文件之前会让 Win顺 运行 `WinShun.exe --uninstall-cleanup`：关掉运行中的这一份，取消它登记的开机自启、右键菜单、PATH 里的 `ws` 文件夹、Directory Opus 的双击命令，以及它装的索引服务（Windows 会问是否允许管理员权限）；另一份 Win顺（比如装在 Program Files 里的）登记的东西一概不动，Win+V、Win+S 在有另一份时也留给它；还给 Windows 时，没有打开的文件夹窗口就顺手重启资源管理器，马上能用，开着的话下次登录后生效。设置和索引仍在 `persist` 里，要连数据一起删用 `scoop uninstall winshun -p`。`scoop update` 不会触发这个清理。

## 搜文件

### 打字就出结果

- 打文件名的一部分就行，不用打全：打 `报告` 能找到“2024 年度报告.docx”。
- **拼音也行**：`ndbg`（首字母）、`niandubaogao`（全拼）都能找到“年度报告”，可以混着打。
- **打错同音字也能找到**：打成“年度报高”找不到时，Win顺 会自动按读音再找一遍。
- **多个词用空格隔开**，顺序不限：`报告 2024` 要求两个词都有，也可以有一个出现在所在文件夹的名字里。

### 搜索词历史与窗口切换

搜索框和完整面板中的时钟按钮打开最近 100 条搜索词。默认用 `Ctrl+↑` / `Ctrl+↓` 翻阅，在 **设置 → 打开 Win顺 → 启动与历史** 可改成 `Alt+↑` / `Alt+↓` 或关闭。翻到最新位置时恢复之前的输入草稿。历史列表支持 Enter 使用、Delete 删除单条和清空记录。

历史保存已完成的常规查询，在打开结果或收起搜索窗口时写入，并遵循使用记录总开关。

在“全部”范围按匹配程度搜索时，当前顶层窗口的标题和程序名也参与匹配，结果标为“已打开”。Enter 切换到所选窗口，最小化的窗口也能找回。

### 选哪个结果

- `↑` `↓` 移动，`Enter` 打开。
- `Ctrl+Enter` 打开文件所在的文件夹，并选中这个文件。
- `Ctrl+Shift+Enter` 以管理员身份运行。
- **打开结果的备用键**：觉得每次打开都要去按 `Enter` 太远，可以在 **设置 › 结果列表 › 操作习惯** 的“打开结果的备用键”里录一个左手顺手的键（比如 `Alt+Q`、`F1`），它和 `Enter` 一样打开选中的结果，`Enter` 照常可用。默认不设。空格不能选：它要用来分开几个词。
- **数字键直达**：按 `Ctrl+1`～`Ctrl+9` 直接打开第几行（设置里可以改成 `Alt`）。结果左侧的序号列默认一直显示；在 **设置 › 结果列表** 的“序号提示”里可以改成按住修饰键时显示或不显示，启动器和剪贴板共用这个设置。已有配置保留所选模式。
  - 别的程序也用这些键当全局快捷键时（比如 PixPin 的 `Ctrl+1` 截图），Win顺 的窗口在前面时按下去归 Win顺，其余时候仍归那个程序。只有你给 Win顺 自己设成快捷键的组合仍是那个快捷键，对应的序号加删除线。
- **键盘提示**：搜索框右下角的快捷键帮助按钮和底栏上的按键提示（Enter、Ctrl+Enter、Tab 等）都可以隐藏。在 **设置 › 结果列表 › 显示与预览** 的“键盘提示”里，关掉“显示快捷键帮助按钮”或“显示底栏按键提示”。
- `Ctrl+C` 复制文件（可以粘贴到资源管理器、微信），`Ctrl+Shift+C` 复制路径。
- 结果可以直接**拖出去**：拖进微信、邮件、资源管理器都行。
- **右键**一行有更多操作：打开位置、复制路径、加入收藏、在终端中打开等。也可按 `→` 或 `Ctrl+O` 打开当前行的操作菜单，用 `↑` / `↓` 选择、`Enter` 执行，`←` 或 `Esc` 关闭菜单并回到原来的结果。`→` 只在光标位于搜索词末尾、未选中文字且输入法没有组词时打开菜单；其余时候照常编辑文字。大图标视图中开始用方向键浏览后，`←` / `→` 继续在图片间移动，用 `Ctrl+O` 打开菜单。按住 `Shift` 右键，或者点菜单里的“更多选项”，出现的是 Windows 自己的右键菜单（和资源管理器里一样），选中几行也行；复制、剪切、删除之后搜索框不关。
- **多选**：`Shift+↓`、`Ctrl+单击`、`Shift+单击` 都能选多行，再一起复制或拖出去。
- **缩略图**：图片、视频、PDF 等显示缩略图，代替类型图标；“打开”“另存为”对话框旁的搜索框里也一样。不想要的话，在 **设置 › 结果列表** 里关掉“显示图片缩略图”。

### 名字太长

名字放不下时，在中间缩短，扩展名和结尾留着（“…第二版.xlsx”）。

- 鼠标在这一行上停一下，显示完整的名字、位置、大小、修改时间和创建时间。搜索面板的名称列、对话框旁的搜索框里也一样。
- 想一眼看全：拖动搜索框的左边或右边把它调宽，宽度会记住。双击边缘恢复默认，或者在 **设置 › 外观 › 搜索框宽度** 里点“恢复默认宽度”。
- 想一次多看几条：在 **设置 › 外观 › 搜索框显示行数** 里填 4–20，默认 8 行。结果超过这个行数就滚动查看；屏幕下方放不下时自动少显示几行。在文件夹窗口里直接输入时的小搜索框最多 6 行。

### 范围：全部 / 文件 / 内容

搜索框右上角有三个范围，按 `Tab` 往后切，`Shift+Tab` 往前切：

| 范围 | 搜什么 |
|---|---|
| **全部** | 文件、文件夹、应用、系统设置、网页、收藏，混在一起按匹配度排 |
| **文件** | 只要文件和文件夹 |
| **内容** | 搜文件里的文字，见[搜文件里的文字](#搜文件里的文字) |

在 **文件** 里，搜索框下面有一排类型：文件夹、文档、图片、视频、压缩包、程序……按 `Ctrl+Tab` 依次切换，或者直接点。点 `+` 可以加自己的类型，比如把 `xlsx`、`xls`、`csv` 叫做“表格”。

也可以直接输入类型条件：`:folder 报告` 只找文件夹，`:pictures 猫` 只找图片，单独输入 `:documents` 列出文档。关键字不区分大小写，在 **设置 › 结果列表 › 文件类型** 可修改或留空停用。0.17.0 也接受 `folder: 报告`、`报告 :folder` 和 `报告 folder:`，条件可放在独立词的位置；引号内、不认识的条件和盘符 `C:` 保留原文。删除条件会回到之前的范围，直接点击类型则替换条件、保留搜索文字。

### 用前缀搜索指定文件夹

在 **设置 › 结果列表 › 文件类型** 新增类型，例如：

| 字段 | 示例 |
|---|---|
| 名称 | 工作 CSV |
| 扩展名 | `csv` |
| 搜索前缀（:） | `cw` |
| 范围 → 搜索范围 | `H:\__work__`（可输入路径或点击“选择文件夹…”） |

随后输入 `cw:`（或 `:cw`），无需再输入文件名，即可列出该文件夹及子文件夹内**已索引**的 CSV；输入 `cw: 报告` 可继续按名称筛选。点击该类型也使用相同范围。清空范围恢复整个索引，不会更改全局索引范围；目标文件夹需已被索引收录。

多个类型一起选中时，扩展名与目录范围分别合并；只要其中有一个类型不限范围，就搜索整个索引。面板“位置”或输入的完整路径与类型范围同时生效，不能用它们搜出类型范围之外的文件。结果按现有分页加载，最多显示 4096 条，并非一次无限列出。

### 排序

按 `Ctrl+S`，或者点底栏左边的按钮，在三种排序之间切换：

- **最匹配**：名字最像的在前，你自己的文件排在系统目录、`node_modules` 前面。
- **最新**：最近修改的在前。
- **最早**：最早修改的在前。

底栏上的“更多”还有四种：**名称**、**所在文件夹**、**类型**（按扩展名）、**大小**（大的在前或小的在前）。选了以后，底栏上显示一个简短的名字（文件夹、大在前、小在前），`Ctrl+S` 仍在前三种之间轮换。文件和文件夹分成两组各自排，先放哪一组在 **设置 › 结果列表 › 文件和文件夹的顺序** 里选；文件夹的估算大小只用于面板显示，按大小排时仍跟着那一侧，彼此按匹配度排。输入了一个文件夹的路径（比如 `D:\My Files\`）时，列出来的里面的内容也照这里选的顺序排；按“最匹配”排则和以前一样，文件夹本身在最上面。

**单击还是双击**：结果怕点错的话，在 **设置 › 结果列表 › 点击结果** 选“双击打开”：单击只选中一行，双击或按 `Enter` 才打开。按住 `Ctrl` 或 `Shift` 点击、右键、拖出去都不受影响。

**收藏文件夹与 Tab**：默认按 `Tab` 切换搜索范围，选中收藏文件夹时也一样。习惯用 `Tab` 进入收藏文件夹的话，在 **设置 › 结果列表 › 显示与预览 › 选中收藏文件夹时按 Tab** 选“进入文件夹”：只在“全部”范围选中可用的收藏文件夹时进入，`Shift+Tab` 仍反向切换范围，插件和网页的补全规则不变。也可以在任意可用文件夹的结果上右键“进入此文件夹搜索”，在 Win顺 内列出其中内容，再继续输入搜索；`Enter` 仍然打开文件夹。

**程序优先**：按最匹配排时，名字差不多的结果里，程序和脚本排在前面：搜 `curl`，`curl.exe` 排在文件夹 `curl` 和 `curl.h` 前面。优先哪些类型，在 **设置 › 结果列表 › 优先显示的文件类型** 里改（默认 exe、bat、cmd、ps1、msi，用分号或逗号隔开），留空就不优先。

修改时间比现在晚一天以上的文件（相机、别的电脑上时钟错了的），按时间排序时排在最后。

**右边的信息**：在 **设置 › 结果列表 › 显示与预览** 打开“显示文件大小”，精简搜索窗口就会显示大小，无需展开面板；默认关闭，按大小排序时始终显示。大小和修改日期可分别开关，同时显示时上下排列。精简窗口的文件夹大小留空；展开搜索面板后，文件夹会异步显示以“≈”标记的索引大小估算，不读取磁盘、不下载云文件，也不包含未索引内容。索引中有文件大小未知时显示“未知”，空文件夹显示约 0 B。普通文件大小未知时留空，空文件显示为 0 B。打开“较早的日期也显示时间”，较早的文件也会带上时分。按 `Ctrl+E` 展开搜索面板时，会沿用当前的排序字段和方向。

### 什么都不打的时候

在 **设置 → 结果列表 → 显示与预览 → 键盘提示** 可打开“纯净搜索模式”。空查询只显示输入栏，输入后恢复操作、范围和结果，清空后再次收起。默认关闭。原有收藏和历史记录保留，Tab 和 Ctrl+E 等键盘操作继续可用。

搜索框是空的时候，列出你**最近打开**的或**最近修改**的文件，可以在底栏或设置里换，也可以不列最近项目。0.17.0 在 **设置 › 结果列表 › 显示与预览** 中可设置最近打开的数量（1–200 项），默认 5 项；“不输入时显示收藏”独立控制收藏和命令是否提前列出，关闭后仍能按名称或关键词搜索。

0.17.0 也支持英文程序名的单词或驼峰首字母，例如 `hsm` 找到 `HiBit Startup Manager.exe`。字母须按单词顺序，从首个单词开始；这项补充用于程序和开始菜单应用，不把普通文档任意扩展为字符子序列匹配。

如果不想让别人看到你上次搜了什么，在设置里打开“每次打开时清空搜索”。

用字母（拼音首字母、英文名）搜索比打中文更快的话，在 **设置 › 结果列表 › 操作习惯** 打开“打开时切换为英文输入”：每次打开搜索框，中文输入法先切到英文，直接打 `wx` 就能找到微信；想打中文时在框里照常切回中文，这次打开期间不再切换。关掉搜索框后，输入法恢复成打开前的样子，原来的程序不受影响。默认关闭。

### 常打开的排在前面

Win顺 记得你输入什么字、打开了哪一项。同一个词选择两三次后，文件、程序和系统设置会按相同规则提升，便携程序也能排到程序和系统设置前面。之后改选别的项目几次，新选择会接替它；输入的字不同，互不影响。开头一样也算：打过 `bg`，再打 `b` 或 `bgs`，也会把它往前放。常打开的比刚打开一次的更靠前，很久没打开的会慢慢往后。`size:`、`dm:`、`ext:` 这类筛选和 `abc/` 这样的文件夹不算在字里。只记字和打开了哪一项，不记别的；在设置里关掉“记住打开过的项目”就不再记；“清除最近使用记录”会把这些一起清掉。

### 搜索语法

| 写法 | 意思 |
|---|---|
| `报告 2024` | 两个词都要有，顺序不限 |
| `ndbg`、`niandubaogao` | 拼音首字母、全拼，可以混用 |
| `"年度 报告"` | 引号里的当成一个整体 |
| `!草稿` | 排除名字里有“草稿”的 |
| `!node_modules\` | 排除这个文件夹里的 |
| `*.pdf`、`报告?.docx` | 通配符：`*` 任意多个字，`?` 一个字 |
| `ext:pdf,docx` | 只要这些扩展名 |
| `报告 \| 总结 2026` | “报告”，或者同时含“总结”和“2026”（空格 AND 优先于 OR） |
| `^IMG`、`.pdf$`、`^README.md$` | 名字开头、结尾、整个名字精确匹配，忽略大小写 |
| `regex:^IMG_\d+\.(jpg\|png)$` | 按正则表达式匹配名字；`regex:"含空格的表达式"` 保留表达式中的空格；0.17.0 也接受短写 `re:` |
| `!regex:^temp` | 排除匹配该正则的名字 |
| `:pictures,videos 假日` | 同时搜索图片和视频；使用设置里为文件类型配置的关键字 |
| `项目\readme` | 在名字里有“项目”的文件夹下面找 readme |
| `D:\My Files\`、`tools/out/` | 路径直达：按回车进去，列出里面的东西，接着打字在里面找 |
| `size:>10mb`、`size:1mb..5mb` | 按大小（见[搜索面板](#搜索面板筛选和排序)） |
| `dm:7d`、`dm:today`、`dm:2026-01` | 按修改时间 |

`|` 需要单独写在两个空格之间；引号里的 `"a | b"` 是普通短语，`ext:png|mp4` 仍表示扩展名列表。每个 OR 分支都可以带自己的扩展名、大小、日期和排除条件。暂不支持布尔括号；正则内的括号照常使用。正则只匹配文件名，不做拼音扩展，也不搜索文件正文；无效表达式会显示原因，改正后直接继续搜索。完整加引号的 `"regex:["` 可以按字面查找。正则默认不分大小写，表达式前加 `(?-i)` 就区分，如 `regex:(?-i)^IMG`。

**正则模式**：习惯 Everything 的“启用正则表达式”的话，在搜索框里按 `Ctrl+R`（或在 **设置 › 搜索结果 › 显示与预览** 里打开“正则模式”），之后在“全部”和“文件”里打的每个词都按正则匹配名字，不用再写 `regex:`；搜索框右边出现 `.*` 标记，点它或再按 `Ctrl+R` 关掉，重启后仍记着。和 Everything 一样，空格仍分开几个条件，`ext:`、`size:`、`dm:`、`!` 排除和两边带空格的 ` | ` 照常可用，表达式里要有空格就加引号。正则模式下不做拼音扩展，也不把输入当路径；“内容”搜索不受影响。

### 搜得到哪里

- **WSL 内部文件**：打开 **设置 › 搜索范围 › 网络与 WSL**，点检测到的发行版用户目录，或点“选择文件夹…”挑具体的项目；也可以粘贴资源管理器里的路径，例如 `\\wsl.localhost\Ubuntu\home\用户名\项目`（`\\wsl$\...`、带引号的“复制为路径”也认）。默认只收录添加的位置里的文件名和文件夹名，支持拼音搜索，Linux 中大小写不同的文件分别保留；文件内容要搜的话，见下面的“网络和 WSL 里的文件内容”。WSL 停止时已收录的结果仍可搜索，卡片会显示“未运行”；需要时点“启动并索引”，后台不会为核对主动启动发行版。运行时自动核对 Linux 内部的新增、改名和删除，通常约半分钟，大目录按扫描耗时放宽间隔；也可以点“立即核对”。建议添加项目或用户目录，收录整个发行版时不深入 `/proc`、`/sys`、`/dev`、`/run`、`/mnt`，避免虚拟目录和重复收录 Windows 磁盘。

- **扫描时段和层数**：网络与 WSL 里每个文件夹的“扫描设置”可以单独限制每天哪段时间扫描（可以跨午夜）和最多往下几层；0 表示不限，1 层只读这个文件夹本身。时段外暂停后台读取文件名和内容，已有结果照常能搜；“立即核对”临时扫描一次文件名，仍按层数限制。默认都不限。

- 所有本地磁盘。U 盘、移动硬盘在设置里可以选择收录；没收录的 U 盘插着时，列表末尾会提示你顺手搜一下它。
- **NAS 和局域网共享文件夹**：在设置里加进来，就和本地文件一起搜；服务器关机时，收录过的文件照样搜得到。服务器重启或网络恢复后，一般几分钟内会自己连回来；点卡片上的“立即核对”马上再试一次，卡片会先显示“正在连接 …”，再显示结果。
- **WebDAV 文件夹**（NAS 的 WebDAV、坚果云这类网盘，或用 Windows 映射成盘符的 WebDAV 盘）：把网址直接粘贴到 **设置 › 搜索范围 › 网络与 WSL**，例如 `https://nas:5006/dav/资料/`、`https://dav.jianguoyun.com/dav/`；映射好的盘符（`R:\资料`）也能加，会按它的网址收录。WebDAV 用的是 Windows 自带的 WebClient 服务：服务被禁用时卡片会提示怎么改回来。服务器不会通知文件变化，卡片上写着多久核对一次，急的话点“立即核对”。服务器在不在则几分钟看一次，打开搜索框时也会再看一眼（一分钟最多一次），所以服务器关了，几分钟内卡片和结果就会标“离线”。同一个文件夹换个写法（网址、`\\nas@5006\DavWWWRoot\资料`、盘符）再加，会提示已经添加过了；加了整个服务器，里面的文件夹就不用再加。超过 50 MB 的文件 Windows 默认打不开，只收录名字。
- **网络和 WSL 里的文件内容**：默认只收录名字。想搜某个位置里文件的内容，就打开它卡片下方的“搜索文件内容”：电脑空闲时会把文本文件和 Word、Excel、PDF 等文档的内容读进索引，卡片上写着读了多少。读好以后搜索直接用读到的内容，不再连服务器，服务器关机时也搜得到。网络共享（`\\服务器\共享`）上改过的文件，几秒内就重读；同一个文件一直在改（比如日志），最多 10 分钟重读一次。WebDAV 和 WSL 不会告诉 Win顺 哪个文件改了，按卡片上的核对间隔重读。太大的文件只收录名字：大小上限和本机的文件内容设置一样，文本文件另外最多读 16 MB。用手机热点等按流量计费的网络时，暂停读取内容，卡片上会写明，文件名照常更新。内容搜索里还有没读过内容的网络文件时，列表末尾会提示，点“设置…”就到这里。
- 新建、改名、删除的文件马上就能搜到，不用等。
- **没有管理员权限的电脑**：只索引你选的文件夹，见[第一次用](#没有管理员权限只为我安装)。
- **“用 Win顺 搜索此处”**：从资源管理器带着一个文件夹打开时，名字相近的文件夹（比如 F1 和 F11）不会混在一起：最近打开的东西里，也只有这个文件夹里的排在前面。
- **不想看到的文件类型**：设置 → 搜索范围 → “跳过的文件类型”里填扩展名（例如 `wbk`、`bak`，WPS 的备份文件），这些文件就不再出现在搜索结果和内容搜索里。文件还在索引里，加上或去掉马上生效；自己输入 `ext:bak`，或在“文件”里选了包含它的类型，还是找得到。
- **不想看到的文件名**：同一处的“跳过的文件名”里填文件名，`*` 代表任意几个字、`?` 代表一个字，不分大小写，只管文件、不管文件夹。默认已经填了 `~$*`，Office 和 WPS 打开文档时在旁边生成的 `~$` 开头的临时文件不会出现在结果里；也可以加 `Thumbs.db`、`*.tmp~` 之类。同样马上生效；搜索框里输入的词本身就是这样的名字（例如 `~$报告`），还是找得到。只想看所有这类文件时输入 `"~$"`（带引号）；不带引号的 `~$` 是“以 ~ 结尾”的意思。

## 搜索面板：筛选和排序

在 **设置 → 结果列表 → 显示与预览** 可打开“合并‘全部’和‘文件’”，在“全部”直接筛选文件类型。默认关闭。按住 Ctrl 可查看类型关键词。

在 **设置 → 打开 Win顺 → 快捷键** 可给“直接打开搜索面板”分配独立快捷键。面板搜索栏的筛选按钮收起或显示左侧栏，当前筛选条件会保留，按钮上的标记提示仍有条件生效。

结果太多、想慢慢挑的时候，用搜索面板。

- **打开**：按 `Ctrl+E`，或者点搜索框右上角的展开按钮（两个斜箭头）。同一个窗口会展开成大面板，已经打的字、选的范围都还在。
- **收回**：再按 `Ctrl+E`，或者点面板右上角的按钮。

### 左边：筛选

| 筛选 | 选项 |
|---|---|
| 范围 | 全部、文件、文件夹、内容 |
| 类型 | 文档、图片、视频、音频、压缩包、程序、电子书、代码，还有你自己加的类型 |
| 快捷筛选 | 你自己存的条件，见下面 |
| 修改时间 | 今天、最近 7 天、最近 30 天、今年，或者自定义起止日期 |
| 大小 | 小于 1 MB、1～100 MB、100 MB～1 GB、大于 1 GB，或者自定义范围 |
| 位置 | 收藏的文件夹，或者点“选择文件夹…”挑一个 |

几个筛选可以叠在一起用。点“清除全部”一次全取消。

**类型可以多选**：依次点“图片”和“视频”，两类文件会一起显示；再次点某类取消它，点“不限”恢复所有类型。普通搜索框下方的类型条也支持同样的操作，选择会保存。

**快捷筛选：把常用条件存起来**（和 Everything 的筛选器一个意思）。有些条件隔三差五要用，又不想每次打一遍，比如“别显示回收站里的”。点筛选里的“＋ 快捷筛选”，起个名字、写上条件，它就成了筛选里的一项（带漏斗图标）：点一下套用，再点一下取消，搜索框里的字不动。

| 名称（随便起） | 条件 | 作用 |
|---|---|---|
| 排除回收站 | `!$RECYCLE.BIN\` | 回收站里的不显示 |
| 不看依赖 | `!node_modules\ !.git\` | 这两类文件夹里的不显示 |
| 大 PDF | `ext:pdf size:>10mb` | 只看 10 MB 以上的 PDF |
| 今年的表格 | `ext:xlsx,xls,csv dm:thisyear` | 只看今年改过的表格 |

- 条件的写法和搜索框里完全一样，见[搜索语法](#搜索语法)；`!名字\` 是“不要这个文件夹里的东西”，名字不分大小写，写一部分也行。
- 同时开几个，就要**全部满足**（开了“排除回收站”和“大 PDF”，看到的是回收站以外的大 PDF）。
- 搜“内容”时同样有效：被排除的文件不会去读。
- 先在搜索框里把条件试好再点“＋ 快捷筛选”，条件会自动带过去，只需要起名字。
- 改名、改条件、排顺序、删除都在 **设置 → 结果列表 → 类型与筛选**。
- **不展开面板也能用：给它一个搜索前缀。** 在设置里那一行的“搜索前缀”填一个词（例如 `nobin`），之后在搜索框里输入 `:nobin 报告`（或 `报告 nobin:`）就套用这条筛选，普通搜索框和面板里都行；可以同时写几个，也可以和类型前缀一起用（`:nobin :pic 截图`）。只输入 `:nobin` 会列出它放行的全部文件。前缀不分大小写，不能和文件类型的前缀重复；在面板里按住 Ctrl 可以看到每条筛选的前缀。
- 点出来的筛选和其他筛选一样，只在面板里生效，关掉面板就取消；“清除全部”也会把它们关掉。用前缀打出来的，字还在搜索框里就一直有效。
- 注意：回收站默认根本不进索引（**设置 → 搜索范围** 里“跳过的文件夹名称”有 `$Recycle.Bin`），所以平时本来就搜不到它。想“平时能搜到、偶尔排除”，先把它从跳过的名称里删掉，再存一个上面那样的快捷筛选。

**不打字也能用**：只选筛选条件，就会列出整台电脑上符合条件的文件。比如只选“大于 1 GB”，就能看到硬盘上所有的大文件；再点“大小”列头排一下，最大的在最前。

### 右边：按列排序

默认显示 **名称 / 路径 / 大小 / 修改时间**。右键列头可开关列，还可显示类型、创建时间、所在文件夹和来源；名称列始终保留。拖动列头调整顺序，拖动列间分隔线调整宽度，配置会自动保存。点列头排序，再点一次倒过来；列太多时可横向滚动。右键菜单的“恢复默认列”可还原布局。

插件返回日期和大小时，也会显示在对应列，参与排序和筛选；未提供这些信息的旧插件仍可使用。

### 大图浏览图片和视频

点面板右下角的两个按钮切换“列表”和“大图”（四个方块那个），以缩略图网格浏览。拖动按钮左边的滑块，或按住 `Alt` 滚动鼠标滚轮，可在 96–320 的尺寸范围调整缩略图；普通滚轮继续滚动结果。视图和大小会保存，缩放保留当前浏览位置。

单击选择、双击打开，`Ctrl` / `Shift` 多选、右键菜单、拖出文件、方向键和翻页继续可用。点“列表”回到按列浏览。缩略图异步读取，图片保持原比例；视频和 PDF 使用 Windows 的缩略图处理程序，缺少处理程序或没有可用缩略图时显示文件图标。网络文件及离线项目不会为缩略图下载内容。

### 直接在搜索框里写条件

不想点筛选的话，也可以把条件直接写在搜索框里，普通搜索框和面板里都能用：

| 写法 | 意思 |
|---|---|
| `size:>100mb` | 大于 100 MB |
| `size:1mb..5mb` | 1 MB 到 5 MB 之间 |
| `size:large` | 用 Everything 的叫法表示大小档 |
| `dm:today` | 今天修改的 |
| `dm:7d` | 最近 7 天修改的 |
| `dm:2026-01` | 2026 年 1 月修改的 |
| `报告 size:>1mb dm:30d` | 名字有“报告”、大于 1 MB、最近 30 天改过的 |

面板的大小和位置会被记住。下次双击 Ctrl 打开的还是普通搜索框，需要时再按 `Ctrl+E` 展开。想少按一次键：在 **设置 › 打开 Win顺 › 再次按下快捷键时** 选“展开为搜索面板”，搜索框打开后再按一次打开它的快捷键（自己设的组合键，或双击 Ctrl、Alt、Shift），就会展开成面板，已输入的字保留；面板里再按一次，或按 `Esc`，才关闭。

## 钉住和移动搜索框

平时搜索框像菜单一样：点了别处、打开了文件，它就自己收起来。想一边看一边搜的时候，可以把它**钉住**：

- 按 `Ctrl+T`，或者用鼠标中键点击搜索栏左侧的 Win顺 Logo。钉住后 Logo 上显示图钉标记，底栏也会提示。
- 钉住后，点别的窗口、打开文件，搜索框都留着，并且一直在最上层。
- 按 `Esc` 照样关闭；下次打开还是钉住的。再按 `Ctrl+T` 取消。重新启动 Win顺 后恢复成不钉住。
- 钉住时搜索框在别的窗口后面，双击 Ctrl 会把它拿到前面来，位置不变。

**Logo 操作**：左键点击搜索栏左侧的 Win顺 Logo 打开设置，中键切换钉住状态；右键打开位置菜单，可选“靠上”“居中”和“恢复上次拖动位置”（面板中不提供“靠上”）。居中后仍能恢复上次手动拖动的位置，窗口尺寸和搜索内容保持不变。钉住表示保持显示，不锁定位置。

在 **设置 › 结果列表 › 操作习惯 › 右键 Logo 的行为** 中，可将右键改为直接靠上、直接居中或恢复上次拖动位置，一次点击回位；默认仍打开位置菜单。选择“靠上”时，展开的搜索面板会居中。从临时停靠位置归位时，会退出该次临时定位。此设置决定右键的动作，手动拖动位置继续单独记住，窗口下次打开时仍沿用现有的位置记忆。Logo 的悬停提示会显示当前右键动作。

**移动与展开**：按住 Logo 或顶部小横条拖动窗口，所有主题的独立搜索框和搜索面板都会显示横条。松手后靠近中线时会吸附并记住位置。搜索输入区、类型条和底栏的空白不再用于拖动，可正常框选文字。双击顶部小横条切换搜索框与搜索面板；右侧展开／收回按钮和 `Ctrl+E` 同样可用。

**切换范围**：搜索栏保留并排的“全部”“文件”“内容”按钮（以当前设置为准），一次点击即可切换。`Tab`／`Shift+Tab` 继续沿用原有补全、进入文件夹及范围切换逻辑。范围切换提示放在按钮悬停说明中，底栏仍保留补全、进入文件夹等操作提示。

## 重命名

在文件或文件夹的结果上按 `F2`（或右键选“重命名”），名字就地变成输入框，扩展名之前的部分已经选好，直接打新名字，`Enter` 生效，`Esc` 取消。名字里有不能用的字符、或那里已经有同名文件时，底栏会说明原因，输入框留着让你改。改名和在资源管理器里改一样，可以在资源管理器里按 `Ctrl+Z` 撤销。一次改一个；要批量改名，用插件库里的“批量重命名”。

## 预览文件

完整面板的“预览”标签页可接过当前浮动预览，保持文档布局。在预览设置中可选择预览跟随条目选择的方式。靠近屏幕边缘移动搜索框时，预览会尽量保持原来的摆放侧边。

在结果上按 `Alt+P`（或者右键选“预览”，或者**用鼠标中键点那一行**，不会打开文件），不用打开就能看一眼文件，搜索框也不会关。再按一次或再中键点同一行关闭。在 **设置 › 结果列表 › 显示与预览 › 预览快捷键** 可改为空格、功能键或未占用的组合键；再按一次关闭。选空格时，刚输入完文字，空格照常输入；用方向键或鼠标选过结果、或已打开预览后，空格才开关预览，再输入任何字符又回到输入空格；`Shift+空格` 任何时候都输入空格。输入法正在选词时，空格仍交给输入法。录制时 `Esc` 取消，`Backspace` 清除，也可以恢复默认。此设置只影响搜索结果，剪贴板的预览键保持原有用法，但中键点一条同样开关预览、鼠标停留同样换内容。

- **能预览的**：图片；文本和代码（自动识别 UTF-8、GBK）；Word、Excel、PowerPoint、PDF（用和资源管理器预览窗格同样的预览程序，所以要装了对应的软件）；文件夹显示里面有几个文件夹、几个文件。别的文件显示大图标和类型、大小、时间。
- **设计稿**：Illustrator 的 `.ai`、Photoshop 的 `.psd` / `.psb` 直接按图片显示，不用装 Adobe 软件。`.ai` 的图案在大画板上只占一小块时，自动去掉周围的空白，让图案占满预览；和图片一样，滚轮放大缩小，双击在“适合窗口”和原始大小之间切换。`.psd` 显示的是文件里自带的合成图（Photoshop 保存时默认带上）。很老的 `.ai`（Illustrator 8 及以前）和 32 位通道的 `.psd` 画不出来，仍交给系统里装的预览程序。
- **代码和文档上色**：代码（C/C++、C#、Java、JavaScript、Python、Go、Rust、脚本等）、JSON、YAML、INI/TOML、XML/HTML 按语法上色；Markdown 的标题放大加粗，粗体、斜体、代码、链接和引用各有样式，标记符号变淡。搜索的词在文本里加粗标出，预览会自动滚到第一处。
- **换一个文件**：按 `↑` `↓` 换一行，预览跟着换。预览开着时，鼠标在某一行上停一下（约 0.1 秒），预览就临时换成那一行，选中的行不变；按方向键回到选中的行。鼠标只换内容，不会自己打开或关闭预览。
- **预览窗口的位置**：放在搜索框旁边空着的一侧，和搜索框顶端对齐，不挡结果列表；两边放不下时尝试下方或上方，竖屏底部也能完整显示。小幅拖动时允许少量重叠，避免预览来回换边；实在无处放置才贴边覆盖一小块。切换搜索范围会收起旧结果的浮动预览。
- **关闭预览**：再按当前配置的预览键（默认 `Alt+P`），或者点预览窗口的叉。按 `Esc` 关的是整个搜索框；预览开着的话，下次打开搜索框时预览还在，显示第一个文件。剪贴板预览会在关闭后收起，下次打开不自动恢复。不想让预览跟着回来，在 **设置 › 结果列表 › 文件快速预览** 关掉“再次打开时恢复预览”，搜索框收起时预览就一起关掉。
- **QuickLook、Seer 用户**：如果后台开着 QuickLook 或 Seer，Win顺 会交给它们来预览，每次按预览快捷键打开（上次没关的预览不会在打字时自己弹出来）。较老的 Seer（如 2.8）收到文件却什么都不显示，Win顺 等一两秒没见到它的窗口，就改用自己的预览，直到 Seer 重新启动。不想交给它们的话，在设置的“预览文件”里改成“内置”。
- 从网上下载的文件，和资源管理器一样，为了安全只显示文件信息，不调用预览程序。

## 搜文件里的文字

想不起文件名、只记得里面写了什么时，用 **内容** 范围（按 `Tab` 切过去）。

**全部** 范围会自动补充已有内容索引中的命中，只用一个读取线程核对，不会批量打开 Word、PDF 等文档。尚未索引、已经修改、文档缓存不可用，或搜索词太短、无法用索引缩小范围时，会显示“还有 … 个文件未搜索内容”；点“搜索内容”保留当前搜索词并切到 **内容**，再直接读取。搜索面板的列表和大图模式也有这个入口。内容索引关着时，直接使用 **内容** 搜索仍然可用；想让 **全部** 也能快速找到内容，可以打开内容索引。

- **能搜的文件**：
  - 纯文本：txt、md、log、csv、json、各种代码；
  - 文档：Word、Excel、PowerPoint、PDF、WPS。
- **结果**：显示命中的那一行。文档会告诉你在第几页、第几张幻灯片、哪个表的第几行。
- **打开到命中的那一行**：在内容结果上按 `Enter`、双击、按数字键或右键“打开”，文本文件用 VS Code、Notepad++、Sublime Text 等常见编辑器（见下面“匹配列表”）打开时直接停在命中的那一行，不用再搜一遍；别的编辑器和文档（Word、PDF 等）照常打开。
- **怎么搜**：可以写多个词，用引号找整个短语，结果按相关度排。
- **只在某个文件夹里搜**：在词后面写文件夹名和斜杠。
  - `年度报告 财务/`：只在叫“财务”的文件夹里找；
  - `工作/财务/`：只要“工作”下面的那个“财务”；
  - 同名的文件夹有好几个时，搜索框下面会列出来，按 `Ctrl+Tab` 挑一个；
  - 也可以点下面的收藏文件夹，或者在结果的文件夹上右键“在此文件夹中搜内容”。
- **没搜到的文件**：太大的、系统目录里的、类型没列进来的，默认不搜；搜完会告诉你各有几个，点一下就临时把它们也搜了。要搜哪些类型、大小上限是多少，在设置里改；大小上限可以小到 KB，直接打 `50k`、`1.5m`、`2g` 也行。

没有索引服务（比如“只为我安装”）时，**内容** 搜索也能用，直接去读文件，只是慢一些。

内容索引默认是关着的（新装的）：这时 **内容** 直接去读文件，慢一些。想搜得快，在 **内容** 范围搜索框下面那一行，右端的“内容索引”开关点一下打开；关掉会清空索引。旧版升上来的，原来开着的还是开着。

### 在面板中阅读全部匹配

按 `Ctrl+E` 展开搜索面板，切到 **内容**。右侧的 **内容详情** 跟随所选文件；左侧按钮可以开关，分隔线可以拖动，也能聚焦后按左右键调整宽度。开关、宽度和最后使用的标签页会记住。窗口较窄时详情占用整个内容区，点 **返回列表** 回到原来的结果。

- **匹配**：显示文件中每个关键词的全部已读取匹配。词条显示次数，点一下可暂时关闭；上方可继续输入条件，并选择区分大小写、全词或正则。附加条件筛选命中行，上下文仅帮助阅读，不改变计数；可设置 0–3 行上下文，相邻段落会合并，页、幻灯片、工作表及稀疏行号的边界仍保留。
- **文本**：直接读取提取好的文字，支持选中文字或复制全部文本。Excel 可切换工作表，保留真实行号，以分隔符区分已有单元格；暂不还原 A/B/C 列位置和原始格式。Word 的页标记来自提取器，不能视为重新排版后的页码。
- **摘要**：显示当前命中文件、候选进度、搜索耗时、索引状态及超限／读取失败等情况。按类型和文件夹显示分布；点 **统计全部匹配** 才会继续执行完整统计，可随时停止。
- **预览**：使用本机文件预览处理程序显示原始外观；没有处理程序或加载失败时会提示，可改看文本或打开文件。当前从处理程序默认位置打开，未实现各处理程序专用的跳页／跳工作表。
- **报告**：选择当前结果、所选文件或完整搜索，勾选文件列表、逐处匹配和上下文，点 **生成报告**。完成后可复制、打印，或保存为文本、CSV、HTML、真正的 `.xlsx`。修改选项后要重新生成，避免保存旧范围的快照。取消不产生半份报告，保存失败保留原文件。

插件给出的结果也能看：会打开文件的行（比如图片文字搜索的结果）按那个文件显示，算进命中文件和报告；不是文件的行（比如插件列出的邮件），插件支持时由它提供文字或文件，标题是这一行的标题，取不到时提示“无法获取详情”。在这样的行上点 **打开**，和在列表里按 `Enter` 一样。预览窗（`Alt+P`、空格）也一样。

`Ctrl+Shift+1…5` 切换以上标签，`Ctrl+F` 进入匹配筛选，`F3`／`Shift+F3` 前后跳转。匹配列表中按 `Enter` 或双击可打开文件；默认关联为 VS Code 一族（VS Code、VSCodium、Cursor、Windsurf）、Notepad++、Notepad2／3／4、Sublime Text、Zed、EmEditor、JetBrains 系列（IDEA、PyCharm、WebStorm、CLion、Rider、GoLand 等）或 gvim 的文本文件会直接跳到该行。原来的 `Ctrl+1…9`／`Alt+1…9` 仍用于打开对应文件。

普通搜索保留结果上限，不会为了右窗格自动计算整库的匹配次数。完整统计最多处理 20,000 个命中文件；详情最多 250,000 行／处匹配，读取文字沿用 16 MiB 文本上限；逐处报告最多 100,000 条、32 MiB 正文，每字段最多 32,767 字符。达到限制、提取文本不完整或文件读取失败时会明确标注，数字不能当作完整全文总数。详情关闭时不启动额外的读取；改动文件后可点 **刷新** 重新读取。

打开后第一次建内容索引要把文件读一遍。安装版由索引服务直接从磁盘读文本文件，杀毒软件不用一个个检查，很快就好；Word、PDF 这些文档，和便携版没装索引服务时，还是一个个打开，开着杀毒软件会慢一些。之后只读改过的文件，就很快了。隔了几天才开 Win顺、磁盘的变更记录已经接不上时，要再核对一遍哪些文件改过：安装版从磁盘的文件表一次查清，只读改过的；便携版没装索引服务时一个个查看，机械硬盘上会花几分钟。

## 打开应用和系统设置

- **应用**：开始菜单里的所有应用都能搜，包括 Microsoft Store 应用。名字、拼音、首字母（`vsc` 找到 VS Code）、程序名（`winword`）都行。拼音至少打两个字母；只打一个字母时，打开过的应用里有字以它开头的也会列出来（用 `yy` 打开过“网易云音乐”，之后打 `y` 它就在前面）。
- **系统设置**：打“网卡”、`shipeiqi`（适配器）或 `ncpa.cpl` 都能直接打开网络连接，打“卸载”出应用列表。大约 1200 个 Windows 设置页和控制面板项，还补了组策略、磁盘管理、hosts、AppData 这些开始菜单里找不到的。
- **用不上可以关**：只拿 Win顺 找文件的话，在 **设置 › 搜索结果 › 显示与预览** 里关掉“搜索应用”和（或）“搜索系统设置”，“全部”里就只有文件、文件夹和内容（下面的系统开关也跟着“搜索系统设置”一起关）。收藏夹里的应用照常列出。
- **找 Win顺 反馈**：打 `winshun`、“反馈”、`issue` 或“讨论”，列出“Win顺 反馈问题”和“Win顺 讨论区”，回车在浏览器里打开。

## 系统开关

打“蓝牙”“深色”“音量”这类词，结果行的右端会直接显示现在是开还是关。按 `Enter` 就地切换，搜索框不关，马上看到结果；按 `Ctrl+Enter` 打开对应的 Windows 设置页。也可以点行尾的开关。

能开关的有七个：深色模式（应用和系统一起切）、显示隐藏的文件、显示文件扩展名、蓝牙、WLAN、音量和静音（默认输出设备）、保持唤醒。

| 打什么 | 会怎样 |
|---|---|
| `蓝牙`、`深色模式`、`音量` | 出一行，行尾是现在的状态；`Enter` 切换（音量行的 `Enter` 是静音 / 取消静音） |
| `开蓝牙`、`关蓝牙`、`bluetooth off` | 明确地打开 / 关闭；已经是那个状态就只在底栏说一声 |
| `关闭深色`、`浅色`、`深色` | 切到浅色 / 深色 |
| `静音`、`取消静音` | 静音 / 取消静音 |
| `音量 30` | 音量设为 30，同时取消静音 |
| `音量 +10`、`音量 -5` | 在现在的音量上加减 |
| `保持唤醒` | 电脑不睡眠、屏幕不关，直到你结束 |
| `保持唤醒 1小时`、`保持唤醒 到 18:00` | 到点自动结束 |
| `结束保持唤醒`、`关闭保持唤醒` | 结束 |
| `蓝牙设置` | 直接出“打开蓝牙设置”一行 |

- **音量**：行上按 `Alt+←` / `Alt+→` 每次减 / 加 5（加的时候顺带取消静音）。
- **保持唤醒**：开着的时候，空搜索框的列表最上面多一行“保持唤醒”，托盘图标的提示和右键菜单里也有；点菜单里打勾的那一项就结束。这一行不是默认选中的，打开搜索框直接按 `Enter` 仍是重开上次的东西。到点结束时不弹通知；退出 Win顺，它也随之结束。合上盖子、按电源键，电脑照样会睡眠。
- **别的情况**：开关行不会出现在空搜索框的列表里，免得打开窗口顺手按 `Enter` 就切了开关。没有这个设备（比如没有蓝牙）或权限不够时，这一行没有开关，写明原因，`Enter` 打开设置页；失败时第二行用红字说明。
- **深色模式**：切的是 Windows 的主题。Win顺 自己的外观如果在设置里固定成了浅色或深色，不会跟着变，要跟着变就改成“跟随系统”。
- **WLAN**：关掉会断网，当前正靠它上网时，底栏会写“会断网”；再按一次就开回来。

在关键词后面加个空格，就在那个网站上搜：

## 收藏夹

- 在结果上右键“加入收藏夹”。不打字时，收藏的排在最前。
- 给收藏起个**关键词**，以后一打关键词就能打开。
- 文件夹结果上右键“进入此文件夹搜索”，可在 Win顺 内接着搜。也可在 **设置 › 结果列表 › 显示与预览** 中选择按 `Tab` 进入收藏文件夹；默认按 `Tab` 仍切换搜索范围。

### 拖文件时按 ` 键：收藏圆盘

在文件或文件夹上按住左键（不用先拖动；从资源管理器、桌面、Total Commander 等别的程序都行），按一下 `Esc` 下面那个键（英文状态下是 `` ` ``，中文输入法下是 `·`，按哪个都一样，拖动时它不会打出字来），指针周围会弹出你的前 8 个收藏文件夹。

- **朝哪个文件夹的方向拖**就选中哪个，不用拖到它上面，松开文件就放进去。
- 和资源管理器一样：同一个盘里是移动，到别的盘是复制；拖的时候按住 `Ctrl` 是复制、按住 `Shift` 是移动。下面那行会写清楚松开会做什么。
- **中间**松开，或者按 `Esc`，什么也不做。再按一次那个键，或者拖远一点，它就收起，可以接着拖到别的地方。
- 在屏幕边上叫出来，圆盘会整个挪进屏幕，指针跟着跳到中间，照常往外选就行。

移动或复制由 Windows 自己来做，在资源管理器里按 `Ctrl+Z` 能撤销。灰色的文件夹放不进去（不存在了、文件本来就在那里、不能放进自己里面），下面那行会写原因。名字太长的收藏会从中间省略，可以在 **设置 → 收藏夹** 里点开它起个短名，表单里会显示圆盘上的样子。不想要这个功能，在 **设置 → 收藏夹** 关掉“拖文件时按 ` 键，弹出收藏圆盘”。Win顺 以管理员身份运行时，圆盘由普通权限的辅助进程处理，操作方法相同；收藏和外观改动会同步过去。开机自启时如果资源管理器还没起来，辅助进程会等它起来再启动；辅助进程意外退出也会自动重新启动。只有资源管理器已经运行一会儿、辅助进程仍然反复启动不了时才会显示通知，写明原因，点通知可以马上重试。

### 自定义命令

在 **设置 → 收藏夹 → 添加命令** 中填写名称、关键词和命令，可以点“选择程序…”选文件。含空格的程序路径要加双引号；工作文件夹可选，支持 `%环境变量%`。

图标默认从程序自动提取，搜索结果和收藏列表一起显示；填写命令时能看到预览。点“选择图标…”可使用 PNG、ICO、SVG，或从另一个程序、快捷方式提取；点“恢复自动”重新跟随当前命令。自定义图标随收藏保存，移动或删除原图片也不影响，导出收藏和设置备份都会带上。改完点“保存”才生效，取消会保留原图标。

例如关键词 `code`，命令 `"C:\Tools\Code.exe" {query}`：在“全部”搜索里输入 `code D:\我的项目`，回车就把 `D:\我的项目` 作为一个参数交给编辑器。`{query}` 自动处理空格和引号，不用再加引号。不含 `{query}` 的命令可直接通过关键词启动。命令与普通收藏一起编辑、排序、导入导出；导入或搜索不会自动运行命令。

程序和参数直接交给 Windows；需要命令提示符或 PowerShell 语法时，应在命令中明确填写相应程序。不要把不信任的文字交给解释器执行。

每条命令的表单里还有两个开关：

- **静默执行**：控制台程序、`.bat`、`.cmd` 和 `.ps1` 运行时不弹出黑色窗口，它们的输出也不显示。`.bat`、`.cmd` 由命令提示符运行，`.ps1` 由 Windows PowerShell 运行（`-NoProfile -NonInteractive -ExecutionPolicy Bypass`），所以脚本里不能等你回答问题，要问的会直接失败。自带窗口的程序（记事本、浏览器这类）不受影响，照常显示；文档、快捷方式和找不到的程序也照常打开。不用在命令里再写 `powershell -WindowStyle Hidden`：那样窗口已经出来了，只是随后才被藏起来，会闪一下；静默执行是一开始就不创建窗口。批处理的参数里有 `& | < > ^ % !` 或引号时（比如 `{query}` 后面打的字），这次不运行，免得命令提示符把它们当成自己的命令。
- **以管理员身份运行**：每次运行先弹出 Windows 的权限确认，点“否”就什么也不做，也不报错。和静默执行一起用时，确认框里显示的是 Win顺（由它代为无窗口地启动你的程序），不是那个程序；脚本（`.bat`、`.ps1`）不静默而要管理员权限时也一样，由 Win顺 代为启动，脚本才在你填的工作文件夹里运行（直接提权的命令提示符和 PowerShell 总是从 System32 开始）。管理员身份运行的程序用的是 Windows 给它的环境变量，不带 Win顺 自己继承来的临时变量。

## 插件

插件卡片的“说明”在设置窗口内打开插件自带的文档，可滚动、选择文字复制，按 Esc 返回。内置功能区域可折叠。

**插件出了问题找谁**：别人写的插件由作者自己维护。在插件卡片的“…”菜单点“向作者反馈问题”，会打开作者仓库的 Issues（插件库登记的仓库；不是从插件库装的，按插件写的主页）。Win顺 本身和官方插件的问题照常到 Win顺 的 Issues。插件没写主页时，“主页”打开插件库登记的仓库。

**同时常驻的插件**：常驻插件默认最多同时留 8 个，超过时最久没用的先退出，再用到时自动重新启动。在 **设置 › 插件** 的“同时常驻的插件”里可以改成 4、16 或不限。

插件库标明官方、已审核源码、未审核原生或未知审核状态。未审核的社区原生包在安装和每次更新时单独确认，可点“查看来源”检查发布页面。拒绝更新会保留已有版本，这类更新由用户逐项处理。

**发现和制作**：在 **设置 › 插件 › 插件库** 浏览、筛选并安装社区插件，也可以点“创建插件”从现成模板开始。“复制 AI 开发提示”把协议、SDK、验证和投稿要求交给编程助手；每个新模板目录里也有同一份 `DEVELOPMENT.md`。创建的插件默认关闭，开启前仍会展示权限。开发细节见[插件文档](plugins.md)。

**更新**：**设置 › 高级 › 更新** 里的“自动更新”开着时，Win顺 每天顺便查一次你装的插件有没有新版本。不要新权限的更新会自动装上（正在运行的，下次启动 Win顺 时换上；也可以在插件库点“立即更新”）。要新权限的不会自动装：设置里“插件”上的数字或托盘里的“N 个插件有新版本…”会带你到插件库里筛好的列表，点“更新并允许”一步装好、保持开启；点“取消”旧版照常用。插件库页的“全部更新”只更新不要新权限的插件。

插件页最上面有一行提示“N 个插件有新版本”，点“查看”到插件库里看，点“全部更新”更新不要新权限的；需要新权限的更新会先请你确认。“自动更新”关着时，这一行改写成“自动更新已关，新版本等你点更新”。插件库里的“只看可更新”列出的就是上面这个数字数的那些插件。放在开发文件夹里的插件副本不算新版本，不进这个数字，也不能在这里更新。

**权限**：自己装的插件第一次打开时会逐行列出它要的权限，同意了才用。以后更新的新版本要更多权限，这个插件会先停下来：卡片上的开关显示关着，黄字写明多要了什么，不会运行，关键字和菜单项也暂时没有。打开开关、看过新的权限并点“打开”，它才继续用（之前因为连续崩溃被停用的，同意后也一并重新开始）；点“取消”就是关着，下次打开会再问一遍。随 Win顺 安装的插件不用再问。

**以管理员身份运行（`elevated`）**：插件平时都用普通权限。声明了 `elevated` 的插件，只在 Win顺 自己以管理员身份运行时才跟着以管理员身份运行，这样才能操作以管理员身份打开的窗口。第一次要在这个插件的卡片上点一次“确认”，点过才会用管理员身份运行；Win顺 不是管理员时，它照常用普通权限，从不为插件弹 Windows 的权限确认（UAC）；这时插件卡片上会写明它现在以什么身份运行，旁边有“以管理员身份重新启动 Win顺”的按钮，搜索框里打“管理员”“提权”或 `admin` 也能找到这一项（只重启这一次；想每次都这样，在 **设置 › 搜索范围 › 磁盘 › 索引方式** 里选管理员直读）。细节见[插件文档](plugins.md)。

### 图片文字搜索

在 **设置 › 插件 › 插件库** 安装“图片文字搜索”。插件包的最低版本就是构建它的 Win顺 版本，现在的 1.0.4 要 Win顺 0.20.0 或更新版本。进入插件设置，添加要识别的目录，按需排除子目录，安装共享增强 OCR 组件后点击“开始更新”。已完成索引可离线搜索，自动更新每 5 分钟检查变化，也可暂停并保留已有结果。

输入 `ocr 关键词`，Enter 打开原文件，Ctrl+Enter 查看图片及命中高亮，Shift+Enter 打开所在文件夹。也可在插件窗口搜索、缩放和复制识别文字。“内容”范围以及开启内容搜索的“全部”范围会同时查询该索引，所以在“全部”里不用打 `ocr`，直接输入图片里的字就行：前 5 条名称结果之后，接着是前 3 条图片文字结果，其余的排在最后。

1.0.2 起还读了更多东西：文字被画成线条的 PDF 页（设计图、CAD 图纸）、上下颠倒的页面、很长的图（聊天记录、网页长截图），以及 JFIF、GIF、HEIC、AVIF 图片；空格、繁体和简体、一两个字母或数字的短词也不再影响搜索。已装的插件现在又能读 PDF 了，升级后只补读以前漏掉的文件。文件覆盖和识别边界见[插件说明](../src/ocr-search-plugin/package/README.md)。

“图片文字搜索”和社区 “OCR Studio” 默认都使用 `ocr`。同时安装时，在插件卡片中把其中一个关键字改为其他名称，例如 `imgocr`，卡片会提示占用情况。关键字框里可以写多个词，用空格分开，每个词都能触发（例如 `ocr imgocr`）；带引号的不接受，输入框会标红并写明原因；改过之后旁边的“默认”恢复插件自己的关键字。已装的插件满 8 个时，列表上方有筛选框，按名称、关键字和说明筛选。

## “打开”“另存为”对话框

在别的软件里点“打开”“另存为”，或者在网页上传文件时：

Blender 需要先通过「偏好设置 › 获取扩展 › 从磁盘安装」启用 [Win顺文件对话框扩展](../integrations/blender/winshun_file_dialog/README.md)，并在 Win顺 设置中开启对话框搜索栏。适用独立的打开、另存为和导入窗口；主界面内嵌的文件/资产浏览器不接管。打开窗口可用 Ctrl+Enter；保存和导出仍点 Blender 的原生按钮。扩展 ZIP 的构建与已验证范围见 [兼容说明](dialog-compatibility.md)。

- **对话框旁边的搜索框**：打文件夹或文件名（拼音也行），回车，对话框直接转过去，不用一层层点。WPS 的对话框也认。新装默认关，在 **设置 › 插件** 的“对话框搜索框”卡片上，或 **设置 › 打开 Win顺 › 对话框** 里打开。
- **只搜对话框当前的文件夹**：在搜索框里按 `Ctrl+Shift+D`，或点右边“…”菜单里的“只搜“某文件夹”里面”，就只找对话框正显示的那个文件夹和它下面的内容；搜索框前面会出现“文件夹名 ›”，对话框换了文件夹它跟着换。再按一次 `Ctrl+Shift+D`、点一下那个名字，或在菜单里选“搜索整个电脑”就恢复。这个选择会记住，下次打开对话框还是这样。对话框停在“此电脑”这类不是真实文件夹的位置时照常搜整个电脑。
- **结果操作菜单**：同样支持 `→` / `Ctrl+O` 打开，`↑` / `↓` 选择、`Enter` 执行，`←` / `Esc` 返回结果；`→` 仍只在光标位于末尾、未选中文字且输入法没有组词时打开菜单。
- **`Ctrl+G`**：转到资源管理器（或 Total Commander、Directory Opus、XYplorer、Pulse、OneCommander、Tessoa）正在显示的那个文件夹。Tessoa 需要 0.22.0 或更新版，按具体窗口读取当前活动位置；欢迎页、此电脑、压缩包内部等没有真实目录的页面不会回退到旧路径。OneCommander 读取当前活动面板的路径，不需要额外配置；对话框的建议和自动跳转也支持。Pulse 刚换了文件夹时，可能要等它两三秒。
- **不打字时**：列出开着的文件夹、刚复制的路径、收藏和最近用过的文件夹。
- **自动转过去**：可以设成对话框一出现就转到资源管理器的文件夹；或者先停在上次的位置，等你从资源管理器切回来时再转。
- 拖动对话框或调整它的大小时，旁边的搜索框先藏起来，松手后出现在新的位置。
- 搜索框、Logo 和它展开的菜单跟随对话框的窗口层级，紧贴在对话框上面，不独立常驻置顶：贴图这类无关的置顶窗口仍在它们上面。以管理员身份运行的程序的对话框例外：普通权限的 Win顺 和它之间隔着 Windows 的权限隔离，这时它们改为置顶，只在这个对话框在前面时显示。“搜索框的位置”选“自动”时优先下方：能放下搜索框和两行结果就留在下方，列表再按空间显示更多行；放不下才换到侧边，回到下方需要多出一段余量，避免拖动几像素就来回换边。选“下方”时，只要对话框下面放得下搜索框本身，它就一直在下方，下面放不下列表时列表往上展开；连搜索框都放不下才换到侧边。选“左边”或“右边”时，那边放不下也会自动换位置。
- **Inno Setup 安装器的“浏览文件夹”**：支持搜索文件夹并填入路径，仍由你点击安装器的“确定”。开始菜单快捷方式分组的选择框不接管。
- **管理员窗口（以管理员身份运行的程序）**：普通权限的 Win顺 本来够不到这类对话框（Windows 的 UIPI 隔离）。装了索引服务时，Win顺 交给服务的助手代为跳转——现代“打开 / 另存为 / 选择文件夹”对话框、Inno Setup 选择器、新旧两种“浏览文件夹”、没有地址栏的旧式“打开 / 另存为”和 AutoCAD 自己的文件窗口都能直接跳到文件夹，Ctrl+G 也一样（只跳转，绝不替你打开或保存文件，也不往“打开”对话框填文件名）。旧式窗口和 AutoCAD 没有地址栏，跳转的办法和你手动做的一样：把文件夹填进文件名框、按一次确定，再把你原来填的文件名放回去；填进去的路径以 `\` 结尾，只可能是文件夹。服务替装它的那份 Win顺 跳转：安装版装到哪个文件夹都行，便携版在设置里自己装上服务后也能跳。没有服务时、服务是另一份 Win顺 装的时，或者新版“浏览文件夹”的树里看不到要去的盘（比如没有“此电脑”），仍是选中后复制路径、提示你在对话框里手动粘贴。这保留了 Windows 的权限隔离。没有服务能替这份 Win顺 跳转时，这类程序的对话框第一次在前面停一会儿（约 1.5 秒），Win顺 会弹一次通知说明原因：便携版点通知直接到装索引服务的那一行（只要一次管理员权限），也可以以管理员身份运行 Win顺；服务是另一份 Win顺 装的时，提示以管理员身份运行这一份。每个程序只说一次，最多 3 个程序，一次运行只说一次，记在设置文件 `[Launcher]` 的 `AdminDialogHinted` 里。

## 在资源管理器里

### 双击空白处

在 **设置 → 打开 Win顺 → 对话框 → 文件夹菜单** 可分别设置直接显示的最近文件夹和已打开文件夹数量，范围 0–10。默认 0 使用二级菜单，超过直接显示数量的条目集中到“更多…”。菜单字号和行高跟随外观中的界面大小，长路径可悬停查看。

在资源管理器或桌面的**空白处双击**，弹出一个文件夹菜单。“收藏夹 / 最近的文件夹 / 已打开的文件夹”各有二级页面。收藏夹包含收藏的文件夹、文件、应用、系统位置和自定义命令，显示名称与图标，悬停可查看完整路径或命令。选文件夹时，当前窗口就转过去（桌面上开新窗口）；点自定义命令即可执行，`{query}` 接收当前目录，明确填写的工作目录优先。菜单里还能在当前文件夹里搜、把它加进收藏。

- **新装默认关**：在 **设置 › 插件** 的“文件夹菜单”卡片上，或 **设置 › 打开 Win顺 › 对话框** 里的“文件夹快捷菜单”打开总开关“在资源管理器或桌面弹出文件夹快捷菜单”。下面两行分别选**触发方式**（双击鼠标左键 / 鼠标中键，可同时选）和**触发位置**（资源管理器 / 桌面）；总开关关着时这些选项是灰的。
- 方向键、回车、首字母都能用，长列表可滚动到最后一项。右方向键进入；左方向键、退格或 `Esc` 返回；首页 `Esc` 关闭。点别处或再双击也会关闭，菜单不抢走原窗口的焦点。
- **菜单里列哪几类**：在 **设置 › 打开 Win顺 › 对话框** 里，“菜单里列出收藏夹 / 最近的文件夹 / 别的窗口里的文件夹”三项可以各自开关，至少留一项。关闭收藏夹入口也会隐藏其中的命令。
- **菜单里的操作**：同一页的“菜单里的操作”可以分别决定菜单末尾要不要“在此搜索”“复制路径”（把当前文件夹的完整路径当文字复制，不带引号；“此电脑”等没有路径的位置不显示）“命令提示符”“PowerShell”“收藏文件夹”“Win顺 设置”，默认都有。
- **Directory Opus 里也能双击**：在 **设置 › 打开 Win顺 › 对话框** 里打开“在 Directory Opus 的空白处双击”，Win顺 替你在 Opus 的设置里加好命令（Opus 会重启一下）；关掉或卸载时换回原来的。
- 双击被别的软件占了，或者想在 Total Commander、XYplorer、Pulse 里用？在设置里给文件夹菜单设一个快捷键（“用快捷键弹出文件夹菜单”），在任何窗口里按一下就弹出，再按一次关闭。
- 在 Pulse 里选了文件夹，开在哪儿由 Pulse 决定：它默认“智能”，刚用过的窗口不打扰，会开一个新窗口；想在原来的窗口里开新标签，到 Pulse 的设置里把“从其他程序打开的文件夹”改成“标签页”。

### 右键“用 Win顺 搜索此处”

在文件夹、文件夹的空白处、磁盘上右键，选“用 Win顺 搜索此处”，搜索框带着这个文件夹打开，接着打字就只在里面找。Windows 11 上在“显示更多选项”里。设置里可以关掉。

### 直接打字搜索

在资源管理器的文件列表里**随便打字**，Win顺 就弹出来，带着你打的字搜。和 Listary 一样，**这个窗口所在文件夹里的（包括子文件夹）排在最前**；一条写着“其他位置”的细线下面，是电脑上别处找到的。

- **只搜这个文件夹**：点细线右边的“只搜 …”，或按 `Ctrl+Shift+D`。列表最后的提示行“只在 … 里搜”右边的“也搜其他位置”换回来。只管这一次搜索。
- **只搜这一层，不含子文件夹**：只搜这个文件夹时，再按一次 `Ctrl+Shift+D`，或点列表最后一行“包含子文件夹里的”右边的“只搜这一层”，就只列直接放在这个文件夹里的文件和文件夹，子文件夹里的不列；那一行变成“没有搜子文件夹里的”，点右边的“含子文件夹”换回来。`Ctrl+Shift+D` 按“当前文件夹优先 → 只搜当前文件夹 → 只搜这一层”的顺序轮流换，也只管这一次。
- 想每次都只搜当前文件夹，或每次都只搜这一层：在 **设置 › 打开 Win顺 › 对话框** 里把“在文件夹里打字时”改成“只搜当前文件夹”或“只搜这一层”。
- 这个文件夹里一个都没找到时，细线上写“… 里没有，以下在其他位置”。
- 切到“内容”搜文件里的字时，只在这个文件夹里找。自己打的路径（`D:\资料\ 报告`、`abc/`）、右键“用 Win顺 搜索此处”也照旧只在那个文件夹里找。
- 中文输入法照样能用，拼音会在 Win顺 的搜索框里继续组字。
- 按 `Esc` 回到资源管理器。
- 原窗口旁边放得下整个搜索框时，搜索框放在旁边，不挡原窗口；放不下（窗口很大、居中或最大化）时，像 Listary 一样出现在文件列表的右下角，宽度和高度随文件列表收窄，不会跑到屏幕角落。这只管这一次，不改变记住的常用位置。
- 少数电脑上 Windows 不让 Win顺 的搜索框到最前面（多见于装了拦截“模拟按键”的安全软件时）。这时资源管理器保留焦点，打的字照样送进搜索框，接着打也行；只是不经过输入法，拼音会直接当字母搜（按拼音也能找到中文名）。点一下搜索框就和平时一样了；点别处或切到别的窗口，搜索框照常收起。用快捷键或双击 Ctrl 打开搜索框时也一样。
- 在结果之间用上下键移动时，原目录的直接子项会在原资源管理器标签页中同步选中并滚动到可见位置，键盘焦点仍留在搜索框。重新输入关键词后，即使结果条数和选中行号不变，也会跟随新的结果。子目录里的结果或“其他位置”的结果不会让资源管理器切换目录，底部提示会写成“Ctrl+Enter 在原窗口定位”：按下后原标签页就转到那个文件夹并选中它；收起搜索框后停止同步。
- 选中的结果是文件夹时，在原来的标签页里打开，回到文件列表，接着打字就再往里一层，和 Listary 一样。
- 资源管理器里按 `Shift` 右键弹出的老式右键菜单，菜单里的字母键照常用，不会被 Win顺 抢去。
- 改名、地址栏、资源管理器自己的搜索框里打字不会触发；按着 `Ctrl`、`Alt`、`Win` 时也不会。
- **默认关**：它代替了资源管理器自己的“按首字母跳到文件”。在 **设置 › 打开 Win顺** 里打开“在资源管理器里直接打字搜索”。

**Directory Opus**：在 **设置 › 打开 Win顺 › 对话框** 打开“在 Directory Opus 里直接打字搜索”，或在 **设置 › 插件 › 已安装 › 内置功能** 打开对应卡片。这是独立开关，默认关闭。文件列表有焦点时，从字母或数字开始输入，就用 Win顺 搜，当前标签的文件夹里的排在最前（和资源管理器一样，`Ctrl+Shift+D` 只搜它）；双栏分别按输入所在的标签确定路径。`Esc` 回到 Opus，打开文件夹或 `Ctrl+Enter` 定位文件时回到原文件列表。搜索框出现在正在输入的那一栏文件列表的右下角，宽度和高度随这一栏收窄；这一栏比搜索框最窄时还窄，多出的部分先盖在另一栏文件列表上，尽量不挡查看器。习惯全盘搜索的话，在“在 Directory Opus 里搜索的范围”里选“整个电脑”，搜索框里就不再带当前路径（默认是“当前文件夹”）。`*`、`/`、`>` 等符号起头仍交给 Opus 自己的查找模式，改名、地址栏、筛选框、目录树和菜单里的输入也保持原样；带 Ctrl、Alt、Win 的组合键不接管。取不到真实文件夹（例如虚拟位置或压缩包），就把输入还给原来的文件列表。

### 粘贴为文件

复制了一段文字或一张图片，想存成文件：在资源管理器的文件列表或桌面上按 `Ctrl+V`，或者在空白处右键选“粘贴为文件”（Windows 11 在“显示更多选项”里）。文件就放在这里，名字已经选中，直接打新名字、回车。不用先新建一个文本文档再粘贴进去。

- **存成什么**：看内容。普通文字存 `.txt`；从 Excel、WPS 复制的单元格存 `.csv`，Excel 直接能打开；还认 JSON、整页网页（`.html`）、SVG、XML、注册表（`.reg`，双击就能导入）、批处理（`.bat`）、Shell 和 Python 脚本。图片存 `.png`：截图、网页上复制的图都行，透明的地方保留。
- **叫什么**：普通文字用第一句有内容的话（标题前的 `#`、列表前的 `-` 去掉），网页用它的标题，太长就截短；表格、JSON、脚本、图片这些用类型加时间，比如“表格 2026-10-24 163015.csv”“图片 2026-10-24 163015.png”。已经有同名文件时在后面加 (2)、(3)。
- **从 Win顺 的剪贴板里选**：`Ctrl+V` 那种方式开着时，资源管理器或桌面在前面，在剪贴板面板里选一条文字或图片按回车，也是存成文件。
- **装了腾讯桌面整理**：在它盖着的桌面上点过之后，`Ctrl+V` 归它管，不会存成文件；按 `Win+D` 回到桌面后可以。
- **复制的是文件**：`Ctrl+V` 照旧是资源管理器自己的粘贴。改名、地址栏、搜索框里的 `Ctrl+V` 也不受影响。
- **受保护的文件夹**（比如 Program Files）：Windows 会请你确认管理员权限。压缩包里、“此电脑”这种不是文件夹的地方放不了，右键时会说一声。
- 资源管理器的 `Ctrl+Z` 撤销不了这一步；不想要了，直接删掉这个文件。
- **默认关**：在 **设置 › 插件** 的“粘贴为文件”卡片上打开。`Ctrl+V` 和右键菜单可以只留一个；`Ctrl+V` 要 Win顺 开着，右键菜单不用。

## 剪贴板历史

**备注**：在一条记录上右键选“加备注…”，在分类那一行出现的输入框里打一句自己的话（比如“学校 收件地址”），`Enter` 保存。备注用粗体显示在这条记录前面，搜索时打备注里的词（拼音也行）就能找到它；再次右键选“改备注…”，清空后回车就是去掉备注。删除后撤销、重启都会保留。

**查找分组** 点文件夹按钮或按 `Ctrl+G`，输入分组名称，用方向键选择，Enter 进入分组，再输入即可在组内查找内容。Esc 恢复进入分组查找前的查询和范围。

**悬停预览** 鼠标停留在条目上约 200 ms，文字或图片在小窗显示。移入预览可继续阅读，滚动或切换分组时收起。Alt+P、中键和按钮可手动展开侧栏。

复制过的文字、图片、文件都记下来，随时找回来再贴。

图片支持 **GIF、PNG、JPEG（JPG）、BMP／Windows 位图**。来源提供 GIF 原始数据时，会完整保留动画；预览里可以播放、暂停，列表只显示静态缩略图。关闭预览或隐藏窗口会释放动图资源；系统关闭动画效果时默认暂停，仍可手动播放。照片按自身方向显示。若来源程序只把 GIF 的一帧放进剪贴板，只能记录这一帧，无法恢复原动画。

关闭“记录剪贴板历史”后，会停止监听、释放历史缓存和窗口；图片识别会在当前任务结束后释放模型。已有记录仍保留在本机，重新开启就能继续用。关闭期间仍可复制截图；导入历史会完成当前导入，再释放缓存。剪贴板随程序安装，目前不能单独卸载；截图是插件，不用可以卸载。

- **打开**：在设置里打开“用 Win+V 打开，代替 Windows 自带的剪贴板”后按 `Win+V`；不想换掉 Win+V 的话，也可以自己设一个快捷键，比如 `Win+Alt+V`。如果开关是关的、Win+V 却没反应，设置页会提示“注册表里关掉了它，不是 Win顺 设的”，点“还给 Windows”即可恢复（`Win+S` 同理）。卸载 Win顺 时也会把 Win+V 还给 Windows 并重启资源管理器，卸载完马上就能用系统自带的剪贴板；开着文件夹窗口时会先问你（重启会关掉它们），选“否”就在下次登录后恢复。它开在输入光标旁边，不抢焦点。
  - 光标靠近屏幕下边、下面地方不够时，它开在光标上方，并且上下翻过来：搜索框和最新的一条挨着光标，越往上越早，`↑` `↓` 照屏幕上的方向走。在 **设置 › 剪贴板** 的“搜索框位置”选“远离光标”，则条目挨着光标，搜索框在窗口另一头。不想翻转，关掉“开在光标上方时翻转”，开在光标上方时也和平时一样从上往下排。
- **粘贴**：双击或 `Enter` 粘贴；`Shift+Enter` 粘贴为纯文本；`Alt+1`～`Alt+9` 直接粘贴第几条。序号跟着滚动走：从窗口里第一条露出一半以上的算起，和启动器一样。
  - 要粘贴进去的程序以管理员身份运行（比如被别的工具以管理员身份启动的钉钉），而 Win顺 没有，Windows 不让 Win顺 替它按 `Ctrl+V`：内容会复制好，回到那个程序自己按 `Ctrl+V`。让那个程序以普通权限运行即可直接粘贴。
  - **按住快捷键连按，松开粘贴**（和 Ditto 一样）：在 **设置 › 剪贴板 › 快捷键** 打开“按住连按快捷键，松开粘贴”（默认关）。用快捷键打开剪贴板后先别松开里面的 Ctrl、Alt、Shift 或 Win，每再按一下快捷键的那个键（比如 `Win+Alt+V` 的 `V`）就往下选一条，松开就粘贴选中的那条，和按 `Enter` 一样。整个快捷键按着不放约一秒再松开，粘贴第一条。要粘贴时底部会提示“松开粘贴 · Esc 取消”。按着的时候按 `Esc` 什么也不粘贴：还没往下选就直接关掉；选过了就停在那一条，可以接着用方向键选，再按 `Esc` 关掉。按一下马上松开还和原来一样，只是打开。开着这一项时，按着修饰键再按快捷键是往下选，不再关掉剪贴板；松开以后再按照常关闭。以管理员身份运行的程序在前面时同样可用（要开着“粘贴到以管理员身份运行的程序”，由索引服务代为粘贴）：剪贴板在那里要拿焦点，连按和松开由它自己的窗口来认。Win顺 自己的窗口（比如启动器）在前面时这一项不起作用，再按一下快捷键就关掉。
- **调整大小**：拖动剪贴板窗口的四边或四角，自由调整宽度和高度；预览展开时也可调整，预览与列表仍各自保留宽度。松手后自动记住尺寸，下次打开继续使用；双击窗口边缘恢复默认宽度与自动高度。屏幕或光标旁的空间不足时临时缩小，不覆盖已记住的尺寸。文字大小默认随“设置 › 外观 › 界面大小”，也可在“设置 › 剪贴板 › 剪贴板大小”里单独选：跟随界面大小、密集（每条一行的小字）、紧凑、标准、宽松。双击粘贴会取消待打开的预览，避免窗口先展开再粘贴。
- **不打开面板直接粘贴**：设置 › 剪贴板 › 快捷键，找到“不打开面板直接粘贴”，选择 `Ctrl+1–9` 或 `Alt+1–9`。在其他程序里直接粘贴“全部”列表的前九条，沿用“固定优先”顺序，不受上次搜索或分组影响；保留原格式。默认关闭，开启后会占用这些键在其他程序里的操作（例如浏览器切换标签页）。已被其他全局快捷键占用的数字会在设置里提示，其余数字仍可用。打开面板后使用上方单独设置的“面板内数字键粘贴”。
  - 想像 Windows 自带的剪贴板那样**点一下就粘贴**（比如用手机远程操作电脑时），在 **设置 › 剪贴板** 打开“单击粘贴”。打开后，鼠标移到一条上出现的按钮从“粘贴”变成“预览”；按住 Ctrl 或 Shift 点击仍是多选。
- **上传文件**：在 Windows 的“打开”文件选择框里，从剪贴板历史粘贴文件，会把完整路径填进“文件名”，多选文件也可以。确认后再点“打开”；不会把文件复制到对话框当前显示的文件夹。应用自己绘制的上传窗口仍按其自身支持的格式粘贴。
- **公式和嵌入的对象**：Word 里单独复制的公式、文档里嵌入的对象，记成一条带图的历史（公式的文字也搜得到），粘回 Word 里还是能编辑的公式或对象，只认图片的程序拿到的是图片；`Shift+Enter` 把公式粘贴成一行文字。（用 Word 测过。）
- **搜索**：打字就能搜，拼音也行；`@wx` 只看从微信里复制的。**图片里的字也能搜**（在本机识别，不联网）。标准包先使用 Windows 支持的识别语言；在 **设置 › 剪贴板 › 记录 › 增强文字识别** 安装约 12 MB 的增强组件，可改善中英文、数字和小字。支持下载、本地 ZIP 安装、取消和失败重试，安装后不需要重启。剪贴板和截图共用一份组件。断网电脑可下载完整离线安装包，或从其他电脑拷贝组件 ZIP。旧版已有的模型继续使用。
- **预览**：鼠标在条目上停留约 0.2 秒，旁边自动显示大小随内容调整的小窗，不挪动列表，也不改变键盘选中项；长内容可滚动，移到其他条目会更新，离开条目和预览后收起。按 `Alt+P`、中键点击条目或点眼睛按钮，仍可手动展开侧边预览，查看全文、大图和颜色值；拖动中间竖线可调宽，双击恢复默认。关闭剪贴板后，两种预览都会收起，下次打开从列表开始。觉得图片缩略图太小，可在 **设置 › 剪贴板** 打开“大图片缩略图”。
- **保存为文件**：右键一条，或用 `Ctrl` / `Shift` 选好几条后右键，选“保存为文件…”，再选一个文件夹（如果剪贴板是在资源管理器上打开的，默认就是那个文件夹，否则是上次选的），每条存成一个文件，存完在文件夹里全部选中。
  - 文字按“粘贴为文件”的规则定格式（`.txt`、`.json`、`.html`、`.bat` 等），文件名取第一行；链接存成双击就能打开的网址快捷方式（`.url`）；图片保持原格式；复制过的文件和文件夹复制一份过去，已经被删掉的会跳过并提示。
  - 重名不覆盖，自动加 (2)、(3)。
  - 选了几条文字，菜单里还有“合并保存为一个文件…”：拼成一个文本文件，中间的分隔和多选后一起粘贴时一样（换行、空格、逗号等，在剪贴板底部切换）。
- **拖出**：按住一条拖到文件夹、桌面或聊天窗口，就是上面那样的文件；选好几条后从选中的那条起拖，就一起拖出去，文字、图片、文件混着选也行。图片按原格式保存（GIF 保留动画，JPEG 保留原文件；截图和位图保存为 PNG）；在资源管理器里打开剪贴板，粘贴图片也沿用相同格式。动图复制时同时提供原文件和静态兼容图片，由目标程序决定采用哪种；右键“编辑首帧”会以第一帧进入静态图片编辑器。
- **整理**：
  - 固定常用的，可以让固定的排在最前；顺序可以拖动，或者用 `Ctrl+↑` `Ctrl+↓` 调整；
  - **粘贴后位置不变**：平时从列表里粘贴一条，它会跳到最前面。想让列表顺序固定，在 **设置 › 剪贴板** 打开“粘贴后保持位置”：粘贴不再挪动条目（分组里的，以及打开“固定优先”后固定的，本来就按自己的顺序排，粘贴不会挪动）。重新复制同样的内容仍会排到最前。粘贴过的条目图标右下角带一个蓝色对勾（关着时刚粘贴的就在最前，不需要标记），粘贴也算“用过”，不会因为“保留天数”到期被删；
  - 分组；
  - 多选后按选的顺序一起粘贴；
  - 清理：`Ctrl+A` 选中列表里的全部（固定的和分组里的不选，在某个分组的页签里则选中那一组）；搜索框里有字时，第一次 `Ctrl+A` 全选文字，再按一次才选条目。选好按 `Delete` 一起删。右键一条，菜单里的“删除全部 N 条”删掉列表里所有的（有搜索词就只删搜到的，固定和分组的保留）。删错了按 `Ctrl+Z` 一次全部恢复；
  - 钉住剪贴板窗口，一条接一条地往表格里填。
- **已经不在的文件**：复制过的文件后来被删掉或移走，那条记录会标“已不存在”。在 **设置 › 剪贴板** 的“已不存在的文件记录”里可以选“自动隐藏”（不显示，搜索还能找到，仍占条数上限）或“自动清理”（隔一阵再确认一次后删掉，不占条数）。固定的、分组里的不动；U 盘拔了、网络盘断了时不算不存在。
- **隐私**：密码管理器复制的密码不记录；历史只存在本机。托盘菜单里可以暂停记录。

## 截图

截图、录屏和贴图是 Win顺 的插件“截图与录屏”，不随安装包自带，要用时在 **设置 › 插件 › 插件库** 里装上。装好后在插件卡片上点“设置”（或托盘菜单 **截图 › 截图设置…**），打开截图设置窗口，录一个快捷键（不录也行，从托盘菜单点“开始截图”）；想让 `PrtScn` 键也截图，打开“用 PrtScn 键截图”。以前的版本里开着截图的，升级后 Win顺 自动从插件库装上它，设置照旧。

截图设置窗口里的选项按 **快捷键、截图、鼠标、贴图、打码、工具条** 分类，一次显示一组；分类可用左右方向键切换。下面说的“设置里”，都是指这个窗口。

- **选**：按快捷键后屏幕定住。鼠标移到窗口或按钮、输入框上，它就被框出来，框外立即变暗、框内保持原图，点一下选中；滚轮往上把框扩大到整个窗口、整个屏幕，往下缩回去。也可以按住拖出一块。
- **调**：拖八个小方块改大小，拖中间移动；方向键每次移动选区 1 个物理像素，`Shift`+方向键改大小；`WASD`（W 上、A 左、S 下、D 右）挪的是鼠标光标，每次 1 个物理像素，`Shift+WASD` 每次 10 个，任何时候都有效，包括按住左键拖选区、拖边框或画标注时（拖动的那一角、边和标注终点跟着光标走）；按住可连续调整。125%、150%、200% 缩放下仍按物理像素调整，框不越过当前屏幕边界，宽高最小 1 像素。旁边写着选区的实际像素大小。
- **放大镜**：跟着鼠标，显示放大的像素、坐标和颜色；按 `C` 复制颜色，截图随即结束（已画的标注和按快捷键结束时一样暂存一会儿，可从托盘菜单找回），单按一下 `Shift` 换写法（`#RRGGBB`、`rgb(r, g, b)`、`hsl(h, s%, l%)` 轮着来，Win顺 记着你用的是哪种；按着 `Shift` 去按别的键、点鼠标、滚滚轮都不算）。选好区域后，放大镜只在选区和它的蓝框上出现，移到选区外、工具条上就收起，拖边框时又出来。`WASD` 一次挪鼠标 1 个物理像素（`Shift` 为 10 个），没有选区时方向键也一样。嫌放大镜挡眼，可以在截图设置里关掉“框选时显示放大镜”（关掉后 `C` 复制颜色和 `Shift` 换写法也不再起作用）。
- **识别文字并复制**：`Shift+C` 识别选区里的文字，直接复制到剪贴板（还没有选区时识别鼠标下框出来的那块）。
- **识别屏幕文字（只取字，不截图）**：在截图设置“快捷键”分类的“识别屏幕文字”里录一个快捷键（默认不设，免得和别的程序抢键；不设时从托盘菜单 **截图 › 识别屏幕文字**，或在搜索框输入 `cap` 选“识别屏幕文字”）。按下后屏幕定住，只有变暗的遮罩、框出的窗口和放大镜，没有工具条和尺寸标签：拖出一块，或单击框出来的窗口、按钮，松开鼠标就识别并把文字复制到剪贴板，屏幕马上恢复；`Enter` 识别鼠标下框出来的那块，`Esc` 或右键取消，再按一次快捷键也取消。识别时选区旁边出现一张小卡片：先是“正在识别…”，然后是“已复制识别的文字”和前三行字，或者“没识别到文字”。卡片不抢焦点，可以直接去原来的程序 `Ctrl+V`；几秒后自己消失（鼠标放在上面时不消失），点 × 立刻关掉，点“编辑”打开识别文字窗口，改好再复制或拿去搜索（那个窗口按 `Esc` 关）。这样取的字不进截图历史，不算“最近截图”，也不会贴图、保存。没装增强文字识别时，和 `Shift+C` 一样打开识别文字窗口提示安装，装好后接着识别这一块。打开了“全屏时不响应截图快捷键”时，这个快捷键也一样让开。和其他截图快捷键设成同一个键时，设置里会提示，那个键仍归原来的功能。
- **快捷键提示**：截图时屏幕左下角有一张小卡片，列出此刻能用的按键，跟着你在做什么变：框选前是滚轮、`WASD`、`R`、`,` `.`、`Shift+C`、`Esc`（有最近选区、开着截图历史、装了文字识别时才列对应的那行）；选好区域后是复制、保存、贴图、方向键、长截图和录屏，用 `R` 恢复的选区还写着第几个；拿着标注工具时是 `Shift`、`[` `]`、撤销重做、删除和关掉这个工具的键。它什么时候出来、什么时候走：
  - 开始截图后，鼠标键都没按、停了约 0.4 秒才淡入；这期间移动鼠标、滚滚轮、按键都不影响它。
  - 按下鼠标任何一个键（开始框选、右键、中键）它立刻消失，拖选区、调大小、画标注、打字时都不出来。
  - 选好区域后不会马上冒出来；停下来约 2 秒没有移动、按键、点击才淡入这时能用的键，一动就走。每次截图最多出来这一次。
  - 按 `?`（或 `F1`）随时手动显示或隐藏；手动显示的一直留着，直到再按一次、按下鼠标或截图结束。
  - 延时截图倒数后打开的那次、长截图和录屏时都不自己出来；用 `R` 恢复选区、用 `,` `.` 翻看之前的截图算作操作。每次截图都重新开始。

  选区、工具条或选区大小挡住左下角时换到右下角，两边都挡就先不出来；鼠标或放大镜靠近时变得几乎透明，移到卡片上的按钮上才恢复。它只在截图界面上，不会出现在复制、保存的图片里。点卡片上的“不再显示”就不再自己出来（点它不会开始框选；以后截图时按 `?` 仍能临时看，卡片上那个按钮变成“一直显示”），也可以在截图设置的“快捷键”分类里开关“截图时显示快捷键提示”。关掉提示后，用 `R` 恢复的选区仍在屏幕底部写着第几个。
- **最近选区**：进入截图后按 `R` 恢复上次的区域，继续按 `R` 从新到旧循环，`Shift+R` 反向切换，旁边显示第几个。最多记住本次插件运行中最近 10 个不同区域，相同区域提到最前；取消和延时不计入，重启插件后清空。只恢复区域坐标，截取的是这次冻结的画面；恢复后可以继续微调，按 `Enter` 才完成。区域回到原来的显示器，已断开的显示器会跳过；当前有标注时先完成或用 `Esc` 放弃标注。
- **翻看之前的画面**：截图时按 `,` 翻到上一次截图时的整个屏幕，选区和标注都在，可以重新框选、接着改标注，再复制、保存或贴图；继续按 `,` 往前翻，按 `.` 往回翻，翻过最近一次就回到这次的画面（这次已画的标注还在；停在之前的画面上按 Esc 时，找回刚放弃的标注拿到的也是这次画的）。屏幕排布变过的那些会跳过。默认留最近 10 次，在截图卡片“截图”分类的“截图时翻看之前的画面”里可选 10、30、100 次或关闭；这些整屏画面只存在本机的数据文件夹（`capture-history`），选“关闭”会把已存的一并删掉。截好的图本身照常在剪贴板历史里，用 `jt` 关键词也能找。
- **控件识别**：鼠标移到窗口上，除了子窗口，还会向 Windows 的“界面自动化”问一声，把设置、计算器这类自己画界面的程序里的侧栏、按钮也框出来。Chrome、Edge、VS Code、微信这类 Chromium 程序不问：一被问到，它们就会打开整套无障碍支持（VS Code 会切到“已为屏幕阅读器优化”，要重启才恢复），所以它们只框子窗口或整个窗口，需要时手动框选。问是在后台做的，最多等 150 毫秒，超时（程序没反应）就只用普通子窗口，鼠标不会卡；提权运行的程序里问不到。设置里“识别 WinUI 等程序里的控件”可以关。
- **延时截图**：`Ctrl+Shift+D` 或工具条的“延时”：关掉这次截图，屏幕右上角出现倒计时，到点才冻结屏幕，用来截菜单、悬停提示。托盘菜单 **截图 › 延时截图 › 3 / 5 / 10 秒** 是直接开始倒计时。倒计时里再按一次截图快捷键，或点那个数字，就取消。倒计时的窗口在拍照前就撤掉，不在图里。秒数在设置里选，`Ctrl+Shift+D` 用的就是它。
- **二维码**：`Q` 或工具条的“二维码”：读出选区里的二维码，在小窗口里显示文字，可以复制；是网址（http、https）时多一个“打开链接”按钮，点了才打开，从不自己打开。选区里没有二维码时窗口会说没找到。
- **带鼠标指针**：设置里的“截图带上鼠标指针”（默认关）打开后，冻结的画面里画着按下快捷键那一刻的指针，复制、保存、贴图的图里都有它。
- **HDR 屏幕**：在开着 HDR 的屏幕上截图，复制和保存的都是普通图片，亮的地方收进白色以内，颜色不发灰。想留下 HDR 原样，打开截图设置“截图”分类里的“HDR 屏幕上同时保存 HDR 图片”（默认关）：`Ctrl+S` 保存时在 PNG 旁边再存一份同名的 `.jxr`（JPEG XR，和 Xbox Game Bar 的 HDR 截图是同一种格式），用 Windows 自带的“照片”能按 HDR 看，画上的标注和鼠标指针也在里面。复制、贴图、截图编辑窗口、长截图和录屏不变；一张整屏的 `.jxr` 有几 MB。
- **完成**：`Enter`、双击选区或工具条最右边的对勾（复制）：复制到剪贴板并关闭，截图也进剪贴板历史，图里的字可以搜。`Ctrl+S` 或保存按钮：在截图设置里选了保存目录时，不弹窗口，直接存进该目录，自动命名并避开已有文件，保存按钮旁的小下拉箭头里有“另存为…”。没选保存目录时弹出 Windows“另存为”窗口，选择位置和文件名，默认生成 PNG 文件名；小箭头里的“保存到旧路径”不弹窗口，直接存入“图片\屏幕截图”。取消“另存为”窗口后选区和标注仍在，可以继续调整；“另存为”不会更改设置的保存目录。保存后右下角的通知里点一下，就在文件管理器里打开所在文件夹并选中这张图（文件没了就只打开文件夹）。
- **退出**：`Esc` 或右键先取消选区，再按一次退出；截图时再按一次快捷键也退出。
- **工具条**：选好区域后，选区下面是一排只有图标的按钮，鼠标停一下会显示名字和快捷键。从左到右：九个标注工具｜撤销、重做｜长截图、延时、二维码、识别文字｜贴图、保存｜全部按键（?）｜取消（叉）、复制（主题色底、白色对勾，最右边，最常用）。编辑窗口里是同一排（没有长截图、延时、二维码）。
- **标注**：选好区域后，工具条分两行：靠近选区的第一行放常用的，有矩形（`1`）、椭圆（`E`）、箭头（`3`）、画笔（`P`）、文字（`T`）、序号（`N`）、打码（`B`），以及撤销、重做、贴图、保存、取消和确定；不常用的在第二行，有直线（`L`）、荧光笔（`M`）、识别文字、二维码、长截图、录屏、延时和“？”（全部按键），第二行比第一行短，左边对齐。工具条在选区上方时，两行上下对调，第一行仍紧挨选区。九个工具也可以按 `1`–`9` 选。再按一次同一个键就关掉工具；截图界面的 `R`、`A` 分别用于恢复选区、向左微调，独立编辑窗口仍可用 `R`、`A` 选矩形、箭头。输入法开着中文时这些键也直接起作用，不会变成拼音。
  - 画：在选区里拖。按住 `Shift`：矩形、椭圆画成正方形、正圆，直线和箭头吸附 15°，画笔和荧光笔画直线。序号和文字点一下就放。画到一半按 `Esc` 只取消这一笔。
  - 连续折线：在直线工具的样式面板选“折线”，单击加节点，鼠标移动预览下一段；双击、`Enter` 或右键结束，点起点闭合。`Backspace`、`Delete` 或 `Ctrl+Z` 退回上一个节点，`Esc` 取消这条折线；整条线只占一步撤销。按住 `Shift` 加点时吸附 15°，画完仍能拖动各个节点。
  - 曲线：直线和箭头都可选“曲线”。先拖出起终点，再拖动两个圆形控制点调弧度；移动端点时相邻控制点一起移动。保存后重新编辑仍能调整曲线。
  - 荧光笔：可选“涂画”“直线”“矩形”。直线拖一下划重点，矩形拖出一整块文字区域；覆盖后黑色正文仍然可读。三种方式共用颜色，矩形不显示笔宽。
  - 改：画完的东西自动选中，可以拖动、拖手柄改形状、方向键挪 1 像素（`Shift` 10 像素）、`Delete` 删除；没有工具时点一下图形就能选中它。第二行是样式面板：颜色、粗细、填充、字号、粗体、底框、文字描边（无边/细/中/粗，点描边旁的色块后可选描边颜色，默认自动：深色字配白边、浅色字配深边；加了底框的文字不描边）、打码的样式和格子大小。`[` `]` 或滚轮调粗细、字号、马赛克格子（逐像素细调：粗细 1–64、字号 10–120、格子 3–64；鼠标滚轮每一格一档，不用等；面板里没有的值会在预设旁边显示数字）；`Ctrl+[` `Ctrl+]` 上移下移一层。每个工具各记一套样式，下次截图还在。
  - 文字：点一下写，微软拼音等输入法照常用，拼音看得见、候选窗跟着光标。`Esc` 先取消拼音，再按一次写完；`Ctrl+Enter` 也是写完。双击文字再改。
  - 序号：自动按顺序编，删掉中间一个后面自动补上。面板里能改起始值、“另起一组”从 1 重新数；双击一个序号可以单独改它的号。面板右边五个按钮选这一组的写法：`1 2 3`、`A B C`（Z 后面是 AA）、`a b c`、`I II III`（罗马数字，到 3999）、圈里的数字（空心圆圈，数字用颜色）；选中一个序号时改的是它那一组，没选就改正在用的一组，下次截图还用上次选的写法。
  - 序号旁边的字：放下一个序号后可以直接接着打字，字出现在序号右边，和文字一样微软拼音等输入法照常用；`Enter` 或 `Esc` 写完（Esc 先取消拼音），也可以直接点下一个位置继续放下一个序号。字跟着序号走，放序号加打字算一步撤销；不打字就没有字。序号工具开着时点一下序号，或没有工具时双击序号右边的字，可以再改；双击序号圆圈本身还是改号。
  - 打码：马赛克、模糊、纯色、抹平（用四周的底色盖住，像擦掉了一样），形状可以是“框”或“涂抹”（沿着鼠标走过的地方打码，笔宽 16 / 24 / 36），用的是区域外面的像素，里面的原样子不参与计算，所以还原不出来。打码总在最下面一层，不会盖住后画的箭头和文字。
  - 智能打码：选好区域停一会儿（约 0.3 秒），Win顺 在后台读图里的字，找到手机号、身份证号（校验位对的才算）、银行卡号（校验过的才算）、邮箱、密钥（sk-、ghp_、AKIA 开头的，password=、密码：后面的值）、本机用户名和电脑名，工具条边上就提示“发现 N 处 · 点此打码”。点一下，或在打码工具里点“智能打码”，或按 `Shift+B`，全部盖上，一次 `Ctrl+Z` 全撤。`$TOKEN`、`****`、`<your-key>` 这种占位的不算。已经盖住的不会再盖。识别只在本机进行，图和文字都不会发出去；自动找的可能有漏，发出去前再看一眼。设置 › 截图 里可以关掉自动识别（那样点“智能打码”时才识别）、加上 IP 和 MAC 地址、把所有文字都盖住、填自己的词。编辑窗口里同样有。
  - 打码之后，复制、保存、贴图的图和截图历史里认出来的字都是打码后的，在搜索框里搜不到被盖住的手机号。
  - 撤销 `Ctrl+Z`、重做 `Ctrl+Y`（工具条上也有）。`H` 隐藏或显示工具条；工具条挡到要画的地方时，拖动中它会自己让开。
  - 有标注时，`Esc` 先把选区和标注一起放下（边上写着“Ctrl+Z 恢复”），再按一次退出；再按一次截图快捷键也会直接关掉，不问你。关掉后这次的标注留 10 分钟，托盘菜单 **截图 › 找回刚放弃的标注** 把它贴回原处。
  - 复制、保存、贴图用的都是标注后的图。带标注的截图在剪贴板历史里还留着一份可以再编辑的文件（带着原图，包括被打码的部分，只在你这台电脑上；从 Win顺 出去的图都是打过码的）；用 `Ctrl+S` 保存或 `F3` 贴图的截图也记进截图历史。
- **再编辑**：截过的图可以再打开改。搜索框里 `jt` 找到那张图，按 `Shift+Enter`（或右键 › 编辑）；剪贴板窗口里的图片右键 › 编辑（任何图片都行，不是截图也行，那时这张图就是底图）；贴图上右键 › 编辑。会开一个普通窗口，工具条、样式面板和截图时一样，标过的东西都还能选中改，被裁掉和被打码盖住的原图也还在。
  - **看图**：`Ctrl`+滚轮、`Ctrl`+加号 / 减号缩放，`Z` 在“适合窗口”和 100% 之间切换（右下角的百分比点一下也一样）；滚轮上下滚动，`Shift`+滚轮左右；按住空格拖动或用中键拖动来平移。100% 时一个图像像素就是一个屏幕像素，和导出的图逐像素一样；改粗细用 `[` `]` 或 `Alt`+滚轮。长图只为看得见的部分画图，打开很快。
  - **裁剪**：没有选工具时，拖图片的边或角；选了工具时，从图外面拖它。可以撤销（`Ctrl+Z`），下次打开还能把裁掉的部分拖回来。
  - **多选**：`Shift`+点击加选或去掉，在空白处拖一个框框住要选的，`Ctrl+A` 全选。多选后可以一起拖动、改颜色、删除；`Ctrl+D` 复制一份（稍微挪开一点）。`I` 是吸管：点图上的一点取它的颜色（样式面板上也有按钮）；面板最右边的按钮恢复默认样式。
  - **完成**：`Enter`（或“复制”）把改好的图复制，作为一条新历史，原来那条不动，新的也能再编辑；一处没改就直接按 `Enter` 只是把原来那条再复制一次、移到最前，不多出一条。`Ctrl+S` 和截图时一样：选了保存目录就直接存进去（下拉箭头里有“另存为…”），没选就弹出“另存为”（下拉箭头可直接保存到旧路径）；取消保存窗口继续编辑。`F3` 贴图，“取消”或关窗口不留任何改动。从贴图进来时 `Enter` 是“完成”，直接换掉那张贴图里的图，位置和大小不变，之后还能再点“编辑”接着改。
  - **Esc**：有改动时放弃全部改动（边上写着“Ctrl+Z 恢复”），再按一次关闭窗口。
- **贴图**：工具条上的“贴图”或 `F3`：截图留在屏幕原处，1:1 不缩放，一直在最上面。按住拖动；滚轮以鼠标处为中心缩放（10%–800%，60% 以下每一格 5%，60%–300% 每一格 10%，往上每格 20%、50%，每次缩放都在贴图左上角短暂显示当前百分比），双击回到 100%（截图设置里的“双击贴图”可改成关闭、收起或不做什么）；`+` / `-` 键同样缩放；拖四个角之一自由缩放（比例不变）；方向键挪 1 个像素，`Shift`+方向键挪 10 个；`Ctrl`+滚轮调透明度（同样短暂显示百分比）。`Ctrl+C` 复制，`Ctrl+S` 存到“屏幕截图”，`Esc` 关掉。
  - **改按键**：截图时的“贴到屏幕”（默认 `F3`）和“保存”（默认 `Ctrl+S`），还有贴图里的关闭、复制、保存、收起、选字、转和翻，都能在截图设置的“按键”分类里改成别的键，也可以清除不用（清除后工具条按钮和右键菜单照样能用）。截图时字母和数字要带上 `Ctrl` 或 `Alt`；和截图快捷键或别的程序的全局快捷键撞了的键不能选。本说明里写的都是默认键。
  - **转和翻**：`R` 向右转 90°，`Shift+R` 向左转，`H` 左右翻转，`V` 上下翻转（也在右键 › 旋转与翻转里）；转的时候以图的中心为准，转四次回到原样、一个像素不差。转过、翻过的图不能再用原来的标注编辑，只当一张普通图。
  - **收起**：`空格` 或鼠标中键把贴图收成一块小缩略图（右键 › 收起 › 收成小块）；右键 › 收起 › 收到屏幕顶边是收成屏幕顶边（那块屏的工作区上沿）的一个小条，几张挨着排开。点一下就展开，位置、大小、像素都和收起前一样（拖过小块的话，展开在小块去的地方）。收起时只留图的 PNG 字节和缩略图，原来的大位图放掉，所以贴很多张又用不着时可以收起来省内存。
  - **选字复制**：`T`（或右键 › 选择文字）先把图里的字读出来（要有文字识别模型，贴图上方左下角有提示），然后在图上拖：碰到的整行字被框出来，松开鼠标就复制成文字（拖到一行的一部分，只取那一部分）；`Esc` 退出这个模式。
  - **一起管**：右键 › 关闭其他（只留这一张）、全部贴图 › 隐藏 / 显示全部贴图、全部置顶、关闭全部贴图。托盘菜单 **截图** 里也有隐藏 / 显示、全部置顶、关闭全部。新贴一张图时，隐藏着的会一起回来。设置里可以各录一个快捷键：“隐藏 / 显示全部贴图的快捷键”和“找回穿透贴图的快捷键”（默认都没有）。
  - **穿透**：右键还有另存为、识别文字、置顶、鼠标穿透（点击会穿过它落到后面的窗口）。穿透的贴图把光标放上去**按住 `Ctrl`** 就又能操作：拖动、右键菜单（里面可以取消穿透），松开 `Ctrl` 又穿透（边框会变深一点，表示现在能操作；`Ctrl`+滚轮仍是调透明度，要缩放先取消穿透）。也可以从托盘菜单 **截图 › 取消所有贴图的穿透** 或设好的“找回穿透贴图的快捷键”一次全部恢复。
- **识别文字**：工具条上的“识别文字”或贴图右键菜单：图里的文字显示在旁边的小窗口里，可以选中、修改；“复制全部”放进剪贴板，“用它搜索”把选中的文字（没选就是全部）放进 Win顺 的搜索框，“网页搜索”用同样的文字在网页搜索列表里排第一的网站上搜（设置里的“网页搜索”，默认百度，调整顺序就换了）。需要增强文字识别组件；未安装时会显示安装入口并保留原图，安装后自动继续识别，不必重新截图。识别过程离线进行。
- **长截图**：比屏幕还长的网页、聊天记录、文档、文件列表，选好区域后按 `Ctrl+L` 或点工具条上的“长截图”，Win顺 一边滚动一边截，拼成一张长图。选区就是要滚动的那一块，比如浏览器里网页的部分；不拖选区时，按 `Ctrl+L` 用的是鼠标下框出来的那块。已经有标注时不能开始（先完成或放弃标注）。
  - 开始后显示实时内容，保留原来的选区和强调色边框；贴屏幕边缘时，边框也保持在屏幕内。选区旁的控制条一直保留“完成”“取消”“复制”“保存”“贴图”和“自动滚动”，右侧单独显示长图预览，“预览”按钮可收起或展开；拖动控制条的标题区可挪开它。边框、控制条和预览都不会被拍进去；焦点还在原来的程序上。
  - **自动滚动**（开关默认关）：需要时手动开启，Win顺 自己往下滚，每次滚大约半屏，等画面停稳再拍下一张；滚到底、或到上限（3 万像素高）就停，不用按键。它不挪你的鼠标；一种办法滚不动就换下一种，都不行时提示“自动滚动不起作用，请自己滚动”。
  - **自己滚**（默认）：可以往上或往下滚，也可以从中间向两头接；截聊天记录时可从底部往上滚。回看已截取的内容不会重复添加，预览跟随最新增长的一端。滚完按 `Enter` 或点“完成”；`Esc` 或“取消”放弃。自动滚动开关在本次运行中沿用用户上次的选择，Win顺 重启后恢复关闭。截图的快捷键这时也等于“完成”。这两个键只在长截图进行中归 Win顺，结束就还给原来的程序。
  - 吸在顶上的标题栏只在最上面留一份，吸在底部的栏和“回到顶部”这类浮动按钮只在最下面留一份；往回滚的部分不会重复加进去。显示“需要接回”时慢慢往回滚一点，接上后再继续；自动滚动时个别片段可能按已知位移推测拼接，控制条会提示检查预览。手动滚动时接不上的帧不会强行加入。
  - **以管理员身份运行的程序**：Win顺 替它滚不了，面板提示“这个程序以管理员身份运行，请手动滚动，滚完点‘完成’”。这时 `Enter` 和 `Esc` 会被那个程序收到（Windows 的规定），所以要点“完成”或“取消”。
  - 点控制条的“复制”“保存”“贴图”可直接输出当前长图；按 `Enter` 或点“完成”则在编辑窗口里打开，继续标注、裁剪、打码。点击结束时会收齐已到达的最后一帧，再输出。
  - 拼得不对时点控制条上的“诊断”复制诊断信息，把文字贴到 issue 里；设置 › 高级 里导出的诊断包也带着这些记录。里面只有滚动办法、位移、分数这些数字和程序的名字（比如 msedge.exe），没有画面、没有窗口标题。
  - 不太适合的：只能左右滚的内容、一直在动的画面（视频、动画）；一些老程序（没有为高分辨率屏幕适配、又是平滑滚动的列表），一行行长得一样时可能拼错，这时关掉自动滚动、自己慢慢滚好一些。
- **工具条上的按钮**：在截图设置“工具条”分类的“工具条上的按钮”里点一下显示或隐藏撤销、重做、长截图、延时、二维码、识别文字、贴图、保存、取消、复制和“全部按键”入口（就是工具条上从左到右的顺序），默认全显示；标注工具一直显示。隐藏的按钮快捷键照样能用（撤销 `Ctrl+Z`、重做 `Ctrl+Y`、复制 `Enter`、保存 `Ctrl+S`、贴图 `F3`、长截图 `Ctrl+L`、二维码 `Q`、延时 `D`、取消 `Esc`），识别文字没有快捷键，隐藏后可以设给鼠标键。编辑窗口的工具条不受这个设置影响。
- 想选好就走，打开“选好就复制”：松开鼠标或点一下窗口就复制并关闭。
- **复制并贴图**：打开“复制截图时同时贴图”，按 Enter、点复制或用鼠标动作复制时，会同时把图贴在屏幕上；和“选好就复制”一起开，框选松手就能完成两件事。只想偶尔用，可以单独给鼠标键设置“复制并贴图”。标注仍保留，截图历史只记录一次。
- **框选之后的鼠标操作**：区域选好后，鼠标的几个键各做什么，在截图设置“鼠标”分类的“框选后的鼠标操作”里分别选：**双击左键**（默认复制并关闭）、**右键**（默认后退，回到重新框选）、**中键**、**侧键（后退）**、**侧键（前进）**（这三个默认什么都不做）。可选的有：复制并关闭、复制并贴图、保存、贴图、识别文字、识别文字并复制（读出图里的字放进剪贴板，右下角提示一下）、识别文字并搜索（字送进 Win顺 的搜索框）、识别文字并网页搜索（字拿去网页搜索列表里排第一的网站搜）、取消截图、无；右键还多一个“后退（重新框选）”。正在标注（选了标注工具、正在画或写字）时，右键用来撤回当前这一笔，其他键不动作，不走这里的设置；`Esc` 随时可以后退。
- **移动截图工具条**：按住工具条最左侧的竖向三个圆点拖动，工具条和样式面板一起移动，保持在当前屏幕内。本次截图中调整选区、按 `H` 隐藏再显示都会保留位置；重新框选后恢复自动摆放。
- **截图历史**：在搜索框里打 `jt` 加空格，列出截过的图（最新的在上面），每行有缩略图、时间、大小和图里识别出的文字开头；接着打字就按图里的文字筛选，拼音也行（`jt hy` 找有“会议”的截图）。`Enter` 复制并粘贴回原来的窗口，`Ctrl+Enter` 贴到屏幕，`Alt+P` 预览，`Delete` 从历史删除（`Ctrl+Z` 撤销）。截图历史就是剪贴板历史里的截图，在剪贴板窗口里这些图片带个“截图”小标签。关键词在 **设置 › 剪贴板** 的“截图历史关键词”里改（截图插件开着时才有这一项）；插件关着时 `jt` 不起作用。
- **贴图快捷键**：在截图设置的“贴图”分类里录制“贴图的快捷键”，也可从托盘菜单 **截图 › 贴图** 操作。优先贴剪贴板里的图片（包括在文件管理器里复制的图片文件），放在鼠标所在的屏幕内；大图会缩小到工作区内。没有新图片时，把最近截过的图贴回原位置，保留标注；刚复制完截图也会保留它的标注，不当作一张普通图片。默认不设快捷键，没有截过图也能直接贴剪贴板图片。剪贴板被占用或图片读不出来时会提示重试。
- **保存文件夹**：截图设置的“截图”分类可选择截图保存目录，截图、编辑窗口和贴图的快速保存共用。点“使用系统默认”恢复系统“屏幕截图”文件夹；“另存为”仍可临时选择其他位置。
- **区域／全屏录屏**：截图后框选区域，点工具条“录屏”或按 `Ctrl+R`。准备浮条上可一键切换“选区／全屏”：全屏录制原选区所在的整块显示器，包含任务栏；切回选区会恢复原范围，声音、画质等设置保留。录制开始后范围锁定，“再录一段”沿用当前模式和范围。浮条上还可直接选择 MP4 / GIF、系统声音和麦克风；点齿轮展开画质、鼠标、按键显示、倒计时和保存位置。声音默认关闭。可开启“点击高亮”（默认关）：主键显示橙色圈，次键显示紫色圈，半秒内淡出；暂停、选区外和控制条上的点击不显示。还可以在视频角落用键帽显示按了什么：“鼠标按键”（默认关）显示在选区里按下的是左键、右键、中键还是侧键；按键可选“不显示按键”（默认）、“仅快捷键”（Ctrl、Alt、Win 组合键和 Esc、Enter、F1 等功能键，打的字不显示）或“全部按键”（打的字也会录进视频，包括密码，输入密码前请先暂停）。每行约 2.5 秒后淡出，同一组合连按显示“×3”这样的次数，MP4 和 GIF 都有，暂停时清空。前台是 Win顺 自己的窗口（录屏控制条、启动器、设置）时按的键和点击、截图快捷键，以及以管理员身份运行的程序里的按键和点击不显示；剪贴板面板不占用焦点（前台还是你正在用的程序），录制时在它的搜索框里打的字会录进视频。画质分为“小体积”（15 帧/秒，保留原尺寸，适合文字和简单操作）、“标准画质”（默认，30 帧/秒）和“更清晰”（30 帧/秒，文件可能更大）。点“开始录制”，默认三秒倒计时；可关闭倒计时，或在倒计时中点“立即开始”。录制中只保留计时、体积、暂停／继续和停止，暂停切换时宽度不变；点“停止并保存”或再次按截图快捷键结束，自动保存 MP4。采集、编码和 GIF 转换在独立工作进程中运行；硬件编码启动失败或无响应时自动尝试兼容的软件编码。工作进程连续 10 秒没有进展，或停止后 10 秒仍未完成，会结束该次任务并恢复操作；GIF 转换失败时保留原始 MP4；录制中途异常时尽量保留已产生的文件，并显示错误。控制条不录入视频。保存后可播放、复制文件、打开文件夹，或点“再录一段”沿用选区继续录，前一段文件会保留。录屏目录在开始前点齿轮更改，默认是系统“视频”里的 WinShun 文件夹。展开选项后按 Esc 只收起选项，再按才取消；保存目录不可写时会自动展开选项。用于短时操作演示，暂不提供剪辑、摄像头或视频历史。
- **GIF 录制**：准备面板切换到“GIF 动图”。小体积、标准、更清晰分别为 10 / 15 / 20 帧每秒，最长边 960 / 1280 / 1920 像素，小选区不放大。GIF 不含音频，会自动循环；停止后后台生成并显示进度。转换失败会保留原始 MP4 并给出位置。
- **贴到屏幕**：启动器里图片文件（png、jpg、bmp、gif、webp）的右键菜单，和剪贴板历史里图片的右键菜单，都有“贴到屏幕”：图贴在鼠标旁边，和截图的贴图一样用。要开着截图插件；关掉插件会把所有贴图一起关掉。
- **光标不对或卡顿**：框选时指针不见了、变成黑块或红条，或者框选后偶尔卡一下，请到 **设置 › 高级 › 诊断日志** 点 **导出诊断日志**，把 `WinShun-diagnostics.zip` 发给开发者。里面只有耗时、数字和指针设置，没有窗口标题和截到的文字。
- 关掉或卸载截图插件后它不占内存，也不占快捷键。接管了 `PrtScn` 时，Win顺 退出（插件跟着退出）就把 `PrtScn` 还给 Windows 原来的设置，下次启动再接管；关掉这一项也一样恢复。

### 演示和白板

截图插件里的“演示 / 白板”：直接在**正在使用的桌面**上画（不是截下来的静止画面），讲课、开会共享屏幕、录操作视频时圈重点、用激光笔指；需要时切成白板或黑板写写画画。

- **打开**：托盘菜单 **截图 › 演示 / 白板**，或在搜索框输入 `cap` 选“演示 / 白板”；也可以在截图设置的“快捷键”分类里录一个“演示 / 白板的快捷键”（默认不设，免得和别的程序抢键）。画的时候再按一次快捷键就结束；结束时笔迹不保留。
- **画**：屏幕上方是一条小工具条：画笔、荧光笔、箭头、直线、矩形、椭圆、文字、序号｜激光笔｜颜色和粗细｜撤销、重做、清屏｜白板、黑板｜穿透｜收起、结束。工具的按键和截图时一样（`P` 画笔、`M` 荧光笔、`T` 文字……，也可以按 `1`–`8`），`[` `]` 或滚轮改粗细，`Ctrl+Z` / `Ctrl+Y` 撤销、重做。第一次用是画笔，以后记着上次的工具、颜色和粗细（和截图的分开记）。
- **激光笔**：`X` 或工具条上的红点。按住拖动，留下一道很快变细、消失的红色轨迹，不留在画面上，也不进撤销。
- **穿透**：按 `Esc`、点右键或工具条上的“穿透”，笔迹留在屏幕上，鼠标和键盘回到下面的程序（比如翻 PPT），刚才在前台的程序也回到前台。再按演示快捷键或点工具条上同一个按钮（这时叫“回到画笔”）接着画。`Esc` 和右键是“退一步”：正在写字就先写完，选中了东西就先取消选中，开着白板就先关白板，都没有才穿透；不会清掉笔迹，也不会结束演示。
- **白板、黑板**：`W` 白板、`K` 黑板，再按一次关掉，只盖住鼠标所在的那块屏幕。板子上的笔迹和桌面上的分开，关掉板子后桌面上的还在。开着板子时不能穿透。
- **清屏**：工具条上的垃圾桶，或没有选中东西时按 `Delete`，清掉这块屏幕当前那一层的笔迹；清屏也是一步撤销，`Ctrl+Z` 能找回。
- **工具条**：左边的点点可以拖着走，`H` 收起成一小截、再按展开；位置按屏幕记住。工具条不抢前台，穿透时也能点。
- **录屏和屏幕共享**：笔迹就是屏幕上的像素，OBS、会议软件的屏幕共享和插件自己的录屏都能录到。**要选“显示器采集”或“共享整个屏幕”**；只选某个窗口（OBS 的“窗口采集”、会议软件的“共享窗口”）录不到笔迹。第一次打开演示时工具条下面也会提示一次。工具条也会被录进去，录之前可以按 `H` 收起。
- 多块屏幕各画各的，缩放不同也没关系；屏幕插拔或改缩放时演示会结束。开始菜单、Alt+Tab 等系统界面会盖在笔迹上面。

## 任务栏搜索框

在 **设置 › 打开 Win顺 › 任务栏** 的“任务栏上的 Win顺”里三选一：**搜索框**（Win顺 自己的搜索框，Windows 11）、**固定图标**（固定在任务栏上的 Win顺 图标）、**关闭**。Windows 10 只能固定图标。点它，结果在任务栏上方淡入淡出。

- **位置**：搜索框的位置是固定的，不跟着图标挪。任务栏图标居中时在最左边（左边有小组件按钮就在它右边），图标靠左时在托盘图标左边。打开、关闭程序时它不动，只有托盘变宽这类少见的情况才换个位置。习惯把鼠标放在右下角的，可以在“搜索框位置”里把“自动”改成“托盘旁”：任务栏图标居中时它也放在托盘图标左边（那一段比左端窄，放不下整个搜索框时会自动换成“图标和标签”或“仅图标”）。
- **样式**：和 Windows 搜索一样三选一：搜索框、图标和标签、仅图标（像任务栏上的一个按钮）。在“搜索框样式”里选。任务栏挤了会自动换成更窄的样式，连图标都放不下就先不显示。
- StartAllBack / ExplorerPatcher 启用经典任务栏时规则一样。
- **固定图标**：选它时 Windows 会问要不要固定，选“是”；没看到提示，再点一次“固定图标”。改回搜索框或关闭时，Win顺 没法替你取消固定：右键任务栏上的 Win顺 图标，选“从任务栏取消固定”。
- 搜索框可以单独使用，也可以与 Windows 搜索并存；是否隐藏 Windows 搜索、接管 `Win+S` 或开始菜单打字，都按需选择。

## 给 AI 助手用（MCP）

Win顺 可以当作 MCP 服务器，让 AI 助手（Claude Desktop、Claude Code、Cursor、VS Code 等）用它搜文件名、文件内容和最近修改的文件。

- 在设置里一键连接这些客户端。
- 默认只读，只看得到 AI 客户端本来就有权限看的文件。
- 可以设置不让 AI 看到的文件夹；每次调用都有记录。
- 打开“允许 AI 读取剪贴板历史”后，AI 也能拿到 Win顺 截过的图（识别出的文字和图片文件，截图开着时）。
- “允许 AI 修改设置”默认是“每次先问我”：AI 能帮你开关功能、调整参数，改之前弹出一个窗口，写明谁要改什么、为什么，你点“允许”才改；改完屏幕右下角会告诉你，几秒内点“撤销”能改回去。选“直接修改”就不再先问，仍会事后告诉你；开机自启、索引方式、网站搜索这几项涉及安全，不管怎么选都会先问你。对 AI 说“帮我设置 Win顺”，它会先问你几个问题再动手。
- “允许 AI 请求截屏”默认关着。打开后 AI 每次要截屏，屏幕上都会弹出一个确认窗口，写明是哪个 AI 客户端、截哪块屏幕；你点“允许”才截，点“拒绝”或 30 秒不理就不截。截下的图只交给它，不进剪贴板历史，确认窗口自己也不会被截进去。
- **装新版时**：AI 工具正连着 Win顺 的话，安装程序会先说是哪个（Claude Code、Cursor 等），问你现在装还是以后再装。现在装，它会和 Win顺 断开，装好后在它里面重新连接 Win顺（或者重启它）就行。还有别的程序占着 Win顺 的文件（比如以管理员身份运行的 AI 工具），安装程序会列出它们的名字，关掉后点“重试”。

## 命令行 ws

在终端里搜文件、搜文件里的字、读出文档里的文字，搜法和搜索框一样（拼音、`ext:`、`!` 都能用）。能运行命令的 AI 助手（Claude Code 这类）也能用，比 MCP 更省上下文。

- **打开**：设置 › AI 助手 › 权限，页面最下面的“命令行”一节（开关关着时它就在开关下面），点 **启用命令行**：它打开“允许 AI 助手和命令行连接”（ws 和 MCP 共用这个开关，默认关着），并把 `ws.exe` 所在的 `bin` 文件夹加进你的 PATH。那一节还会写明 `ws.exe` 找到没有、有没有加进 PATH、PATH 里有没有别的程序也叫 ws 排在前面（写出它在哪）。安装程序的“添加 ws 命令”（默认勾上）也会把这个文件夹加进 PATH：为所有用户安装加进系统的，“只为我”安装加进你自己的；卸载时只去掉这一项。
- **在新打开的终端里用**：已经开着的终端看不到新的 PATH，要重开；VS Code 里的终端要重开 VS Code。
- **PATH 动不得的时候**：你的 PATH 在注册表里如果不是文本类型的值，Win顺 读不了也不会去改它（宁可不加，也不把你的 PATH 弄坏），设置页会写明；这时可以用 `ws.exe` 的完整路径，或自己把 PATH 修好。从设置页“从 PATH 移除”只会拿掉 Win顺 自己写进去的那一项，你自己加的、写法不一样的同一个文件夹留着。
- **Win顺 刚启动时**：ws 会等它启动好（开机自启时管道出来得晚），等的时候写“正在启动，等它准备好…”；`ws status` 也等，但不会替你启动 Win顺。ws 在 Win顺 没有回应时最多等两分钟（`status` 十秒），然后以退出码 7 退出。
- **`--in` 要新版 Win顺**：`ws find 报告 --in D:\工作`（`grep`、`open` 也一样）靠 Win顺 自己只在那个文件夹里找；旧版 Win顺 不认，ws 会说“这个版本的 Win顺 不认 --in，请更新”，退出码 7，不会给你一个没筛过的结果。
- **几个例子**（含空格或 `*` 的查询要加引号：bash 会先把 `*.pdf` 换成当前文件夹里的文件名）：

  ```
  ws 报告                           按文件名找，每行一个完整路径，最多 100 个
  ws grep 合同金额 --in D:\工作      按文件里的字找（含 Word、Excel、PPT、PDF），只找这个文件夹
  ws text 合同.docx                 读出一个文档里的文字
  ws find "*.pdf" --in .            在当前文件夹里找 PDF
  ws open 周报                      打开最匹配的那个，和在搜索框里按 Enter 一样
  ```

- **给 Claude Code 装 Skill**：设置 › AI 助手 › 连接客户端里，Claude Code 那一行的 **装 Skill**，把一份说明写进 `%USERPROFILE%\.claude\skills\winshun\SKILL.md`（设了 `CLAUDE_CONFIG_DIR` 就写进那里），以后 Claude Code 要找文件时才加载它，让它用 `ws`。里面写着 `ws.exe` 的完整路径，所以没加进 PATH 也能用，不过建议先启用命令行。装好后那一行写着“已装 Skill”，按钮变成“重装 Skill”；装的时候按钮会灰一会儿，别连点。Skill 文件被删掉后，切回设置窗口或回到这一页，那一行会跟着变回“装 Skill”。
- **谁能看到什么**：和 MCP 一样只读，只看得到运行 ws 的程序本来就有权限看的文件；“不让 AI 看到的文件夹”对 ws 也有效。“允许 AI 打开文件和文件夹”只管通过 MCP 连接的 AI 客户端，`ws open` 按你自己的权限打开（能运行 ws 的程序本来也能打开文件）。设置 → AI 助手 里“命令行”一栏的最后一行“调用记录”会写“N 次调用，最近 14:32（search_files）”。

## 外观、设置和备份

在外观页可选择界面字体。四种界面风格及浅色、深色共用该字体设置，菜单密度跟随界面大小。

在 **设置 → 打开 Win顺 → 快捷键 → 双击修饰键呼出** 里可选择双击后的动作，包括搜索框、剪贴板或支持宿主通知的已启用插件动作。已保存但暂不可用的插件动作会显示原因。

- **界面风格**：**设置 › 外观 › 界面风格** 里四选一：精修原生（默认）、品牌色彩、轻拟物质感、液态玻璃。所有窗口一起换，每种都有浅色和深色。液态玻璃使用中性表面、简洁控件和玻璃背景；Windows 11 22H2 及以上、显卡加速并开启透明效果时，使用系统亚克力模糊背后的内容。关闭透明效果、软件渲染或不支持材质时保留实色质感。
- **玻璃参数**：液态玻璃开启透明效果后，可调“透明程度”和“卡片清晰度”。前者越高，背景颜色透出越明显；后者越高，卡片和工具栏底色越实、更容易阅读。拖动即时预览，松手保存，也支持方向键、Home 和 End；“恢复默认”一次重置两项。两项均以 50% 为主题默认基准，保留浅深色各自的材质配比。
- **外观**：浅色、深色跟随系统。**圆角**可以改成直角，窗口、菜单、按钮和输入框都不带圆角，和 Windows 10 一样。**界面大小**有紧凑、标准、宽松三档；剪贴板的文字和行高可以在 **设置 › 剪贴板 › 剪贴板大小** 单独选，默认“跟随界面大小”，想要和 Ditto 一样一条一行的小字，选“密集”。托盘和任务栏的图标可以换成单色。程序 Logo 统一位于搜索栏内；主搜索栏的 Logo 集中设置、钉住和位置菜单操作。窗口外侧不再显示装饰 Logo，也不再提供对应开关。
- **找设置**：设置窗口里按 `Ctrl+F` 搜索，`kjj` 就能找到“快捷键”。改了立即生效。
- **文件管理器**：打开文件夹、打开所在位置时用哪个，在 **设置 › 打开 Win顺 › 对话框** 里选：资源管理器、Total Commander、Directory Opus、XYplorer、Pulse、OneCommander（装了的才列出；便携版先运行一次），或者选“其他（自定义）”，填别的文件管理器打开文件夹和显示文件的命令（`{path}` 会换成路径）。用自定义的文件管理器时，`Ctrl+G` 和对话框的建议支持上面六个，也支持 Tessoa 0.22.0 及更新版的当前目录查询；Tessoa 暂不作为内置的默认打开方式。OneCommander 的 `Ctrl+G` 使用当前活动面板路径，对话框建议也能列出其他打开的标签；标签状态尚未同步时先使用活动目录。打开文件所在位置时，每个文件夹选中一个文件，多个文件夹分别开标签；文件夹的所在位置只打开上一级，不选中。
- **索引位置**：设置 › 高级 › 索引位置，可以把索引挪到其他硬盘。
- **备份**：设置 › 高级里选一个文件夹（放在网盘的同步文件夹里就等于云备份）。设置、收藏、对话框的固定项、自己加的网页图标和插件会自动备份，保留最近 10 份，随时恢复。
- **网络代理**：**设置 › 高级 › 网络代理**。“跟随系统”（默认）用 Windows 设置里的代理，包括自动检测和 PAC 脚本；用代理软件（Clash 之类）时，打开它的“系统代理”开关就行。想只给 Win顺 指定一个代理，选“手动”，填 HTTP 代理地址，比如 `127.0.0.1:7890`，开头可以写 `http://`；填错时输入框下面马上说哪里不对，改完立即生效，不用重启。“不使用代理”则不管 Windows 里设了什么，都直接连。插件库、检查更新、网站图标、搜索建议等联网都走这一个设置。暂不支持 SOCKS 代理和带用户名密码的代理（多数代理软件同一个端口也提供 HTTP）。插件库连不上 GitHub 时，错误提示下面有“设置网络代理…”按钮，一点就到这里。
- **换电脑**：旧电脑打开 **设置 › 高级 › 备份 › 导出设置**，点“导出备份…”保存 ZIP，不用先开启自动备份。把 ZIP 带到新电脑，安装 Win顺 后点“从备份恢复…”选择它，校验通过后程序会自动重启。快捷键、外观、网页搜索、收藏和插件设置等一起带过去；新电脑的自动备份位置、索引位置和磁盘选择沿用本机设置。收藏、搜索目录和自定义命令里的路径仍按原样保留，请检查新电脑上是否存在；插件密码和 API 密钥存在 Windows 凭据管理器里，需重新填写。索引、剪贴板和搜索历史不迁移。恢复前会在本机数据文件夹的 `backups` 中保存当前配置（设置 › 高级 › 数据文件夹可打开），写入失败时尝试退回原配置；具体错误在备份区域显示。
- **拾穗计划**：设置里的一页，列出作者的其他作品；页脚感谢收录推荐 Win顺 的网站（目前是果核剥壳）。程序不会为此联网。
- **更新**：有新版本时托盘会提醒。在提醒窗口里点“下载并安装”（便携版是“下载并更新”），Win顺 会自己下载新版本、核对 SHA-256 后装好并重新打开；也可以照旧手动运行新的安装程序。设置和索引都保留。AI 工具正连着 Win顺 时，安装程序会先问一声（见上文“给 AI 助手用”）。

## 0.17.0：旧反馈中的交互改进

以下改进包含在 0.17.0；仍需原环境确认的反馈见 [新回复复查](issue-replies-audit-20261101.md)。

- **剪贴板位置**：设置 › 剪贴板 › 记录 › 剪贴板打开位置，可选“鼠标指针旁”，每次打开都使用鼠标位置，包括从 Win顺 自己的输入框打开。空间不足仍限制在屏幕内。
- **全屏暂停热键**：剪贴板记录页和截图插件设置 › 快捷键分别有独立开关，默认关闭。其他程序全屏时暂停响应打开热键，菜单手动打开仍可用；剪贴板记录照常，已开始的截图仍可用快捷键取消。
- **文件夹菜单**：设置 › 打开 Win顺 › 对话框，总开关下的“触发方式”可以选双击鼠标左键、鼠标中键或两者都用。菜单可在当前目录打开命令提示符或 PowerShell，也列出收藏中的自定义命令与设置入口；命令的 `{query}` 接收当前目录，明确填写的工作目录优先。它不等于文件右键自定义命令功能。
- **按住快捷键选择**：剪贴板末条继续按会回到首条。在 Win顺 自己的窗口取得焦点、无法沿用外部按键钩子时，仍可继续按键浏览；这一分支松开不会自动粘贴，Enter 等手动操作继续可用。
- **Ditto 保护属性**：带“禁止自动删除”属性的条目进入“固定”，其余条目保留导入分组。普通的置顶顺序不会被误当成禁止删除；重复记录仍然跳过，不修改已有条目。
- **映射盘**：打开或定位网络结果时，优先使用当前仍连接的映射盘符。没有有效映射时保留 UNC，索引身份与历史记录保持一致。NAS 恢复连接的延迟仍需原环境复测。

## 常见问题

**双击 Ctrl 没反应？**
看托盘里有没有 Win顺 的图标。Listary、PowerToys 的“查找鼠标”默认也用双击 Ctrl，关掉其中一边，或者在 Win顺 里改成双击 Alt 或 Shift、只认左 Ctrl 或右 Ctrl，或换成组合键。全屏玩游戏、鼠标被隐藏时，Win顺 默认不响应双击 Ctrl。

以管理员身份运行的程序（以管理员身份打开的命令提示符、注册表编辑器、任务管理器，或被设成以管理员身份运行的微信）在最前面时，Windows 不让普通权限的程序收到发给它的按键，没装索引服务的 Win顺 就听不到双击。这时改按组合键（比如 `Alt+Space`，在 **设置 › 打开 Win顺** 的“快捷键”里设；带 Ctrl、Alt、Shift 或 Win 的组合键照样能用），或者装上索引服务（服务的助手听得到，双击就也能用了）：安装版重新运行安装程序、选“为所有用户安装”；便携版（含 Scoop 装的）在 **设置 › 搜索范围 › 磁盘 › 索引方式** 下面一行装，旧版服务不认双击 Alt、Shift 时，点同一行的“更新索引服务”就更新了。Win顺 以管理员身份运行（管理员直读）时没有这个问题。这种程序第一次在最前面停一会儿（约 1.5 秒）时，Win顺 会弹一次通知说明原因（设了组合键就提醒你改按它）；能装索引服务或还没设组合键时，点通知直接到对应的设置项；每个程序只说一次，最多说 3 个程序，一次运行只说一次。说过的程序记在设置文件 `[Launcher]` 的 `AdminTapHinted` 里，删掉这一项就会再说。

**刚装好，搜不到刚建的文件？**
新建、改名的文件马上就能搜到。如果一直搜不到，右键托盘图标选“重建索引”。

**内容搜索第一次很慢、磁盘一直在忙？**
内容索引默认关着，在 **内容** 范围搜索框下面那一行右端打开后，才会建；第一次建要把文件读一遍。安装版由索引服务直接从磁盘读文本文件，杀毒软件不用逐个检查，一般很快就好。便携版没装索引服务时一个个打开文件，杀毒软件（特别是 Windows Defender）会逐个检查，所以会慢一些、磁盘忙一阵；可以在 **设置 › 搜索范围 › 磁盘 › 索引方式** 里装上索引服务。建好之后只读改过的文件，就不忙了。

索引很慢或其他功能出问题时，到 **设置 › 高级 › 诊断日志** 点 **导出诊断日志**。界面上的字显示不对（比如变成别的字）时，先导出再重启：重启后就查不到原因了。程序会打开诊断文件夹，把其中的 `WinShun-diagnostics.zip` 发给开发者即可；设置里搜索“诊断”也能找到。安装版的目录是 `%LOCALAPPDATA%\WinShun\diagnostics`，便携版在程序旁的 `data\diagnostics`；用了自定义配置目录时跟随那个目录。

诊断包包含版本、系统和权限、磁盘类型、索引进度与耗时、直读及回退情况、慢读取和运行错误，以及界面显示和字体的状态（显卡、屏幕缩放、字体，和一次字是否画对的自检）、剪贴板按键转发统计、已装插件的名字／版本／是否开着，以及插件日志 `plugins.log` 的末尾 256 KB（插件自己写的启动、崩溃、报错，可能带路径）；不包含设置文件、剪贴板内容、搜索历史、AI/插件对话或文档正文。剪贴板搜索失效时，关闭面板后尽快导出即可；按键转发只记录安装/刷新错误码、转发与放行次数及原因，不记录具体按键、搜索词或窗口标题。运行错误可能带文件路径。诊断记录每份最多 1 MB、最多保留 3 份；7 天未更新的诊断文件在启动、写入或导出时自动清理。导出包固定为同一文件名，每次覆盖上一份，不会不断积累。程序和索引服务原有的错误日志各保留当前与上一份，诊断导出对每份最多读取最近 1 MB。

远程控制期间出现剪贴板乱码或重复记录时，复现后尽快导出诊断包。`summary.json` 的 `clipboard` 中只保留本次运行最近 16 次读取的元数据：读取前后序列号、最多 64 个可用格式 ID（包含 Windows 可自动合成的格式，只给已知格式标注名称）、实际读取的 Unicode 文本字节数和长度、打开失败错误码及占用程序名，以及来源是否回退为前台程序。不会额外读取正文或其他格式来做诊断，不记录正文、内容哈希、完整程序路径或未知格式名称；隐私标记阻止记录的内容不会采集文本长度。记录只存在内存中，重启后清空，仅在主动导出时写进诊断包。序列号变化也可能来自正常的延迟渲染，不能单凭它认定乱码原因。

**往管理员身份运行的程序里粘贴不进去？**
Windows 不让普通权限的程序往管理员程序里打字。这时 Win顺 会把内容复制好，提示你按 `Ctrl+V`。

**快捷键设成 F1 这类单个键，在管理员程序前面按了没反应？**
以管理员身份运行的程序在最前面时，Windows 只放行带 Ctrl、Alt、Shift 或 Win 的组合键，单独一个键（F1、PrintScreen 等）普通权限的程序收不到。装了索引服务时，服务的助手会替 Win顺 接住 F1–F24 和 PrintScreen，截图、打开 Win顺 等快捷键和插件的快捷键都照常能用，这一下按键也不会再传给那个管理员程序；需要新版的索引服务：安装版装新版时会一起更新；便携版换了新版本后会弹一次通知，点一下、Windows 确认一次就更新了。字母、Enter、Esc 这类单键不会替你接，用组合键即可。没装索引服务时，改用组合键，或以管理员身份运行 Win顺。Windows 的系统错误框（比如“找不到某某 DLL”“缺少运行库”）在前面时快捷键也能截图，截到的画面里有它，但它会一直盖在截图界面上面，挡住那一块；先把它移开或关掉再框选。

**占多少内存？**
用着的时候主要是文件索引，每 100 万个文件约 30 MB；三百万个文件的电脑上，搜索时整个程序约 150～230 MB。关掉搜索框约 20 秒后，Win顺 把用不着的内存还给系统，任务管理器里降到几 MB。

**AutoHotkey 改的键在 Win顺 里不起作用？**
选了“管理员直读”时，Win顺 以管理员身份运行，Windows 不让普通权限的程序拦截发给它的按键。换回别的索引方式，或用 AutoHotkey 的 UI Access 模式、以管理员身份运行脚本。

想知道内存花在哪：打开 **设置 › 运行状况**（左边列表最后一项）。最上面写着“Win顺 现在用了 N MB”，N 和任务管理器里 Win顺 那一行的“内存”是同一个数：Win顺 和它自己的子进程（插件、读文档的进程）加在一起；后台服务在任务管理器里单独一行，不算在里面。旁边是此刻的 CPU 和读取速度、上次归还的时间和数量。下面一条彩色长条和一行行明细把它分开：**文件索引**（搜文件名用的；刚归还过时会写“另有 M MB 已暂存到磁盘，用到时读回”）、**窗口和数据**（搜索框、设置窗口、剪贴板历史等程序里正在用的，设置窗口开着时它最大）、**缩略图**（列表和剪贴板里的小图）、**程序本身**（Win顺、Qt 和系统的代码，各个线程）、**插件**、**读文档**（读完 30 秒后退出），最后一行是后台服务。这些是逐页查出来的：文件索引和程序本身都是 Windows 说在内存里的页面，窗口和数据是剩下的。点 **现在就归还** 马上把 Win顺 和它的子进程闲置的内存还给系统；后台还在忙时也能点，但它接着干活会再用回一些。再往下是现在在做什么（进度条、大概还要多久）、各个进程各用了多少内存和 CPU。这一页开着时每秒读一次，离开或最小化后停止采样。

**会上传数据吗？**
不会上传你的文件和索引。只在这些时候联网：检查新版本（连接 lcstp.com，可以关）；点“下载并安装”时经第三方镜像或 GitHub 下载安装包，下载后用 SHA-256 校验；第一次显示某个网站时取它的图标；打了网站关键词后取搜索建议；打开设置里的“插件库”这一页、点“刷新”或安装插件时；开着“自动更新”时每天检查一次已装插件有没有新版（可以关）；你自己打开“按意思找”并选了云服务时；用“翻译”插件时，把要翻译的句子发给你填的翻译服务。

更多问题欢迎到 [Issues](https://github.com/LingCore/WinShun/issues) 或 [LINUX DO 的帖子](https://linux.do/t/topic/2996093) 里提。

翻译从 2.1.0 起会取消已经离开的查询，新词不再等待旧词的网络请求结束。成功结果缓存 5 分钟，请求最多等待 9 秒。诊断日志记录请求耗时和状态码。微软资源需要时填写资源区域，方舟需填写已开通的模型或推理接入点 ID。AI 词典使用模型生成释义，DeepL 和微软 Translator 提供翻译功能。
