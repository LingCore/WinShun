## 第一次用

1. 从 [Releases 页面](https://github.com/LingCore/WinShun/releases/latest) 下载安装程序，双击安装。Windows 提示“已保护你的电脑”时，点 **更多信息 → 仍要运行**。
2. 装好后，屏幕右下角的托盘里会出现 Win顺 的图标。索引几秒钟就建好。
3. **连按两下 Ctrl**，屏幕中间弹出搜索框，直接打字就行。再连按两下 Ctrl 或按 `Esc` 关闭。

> 双击 Ctrl 和别的软件冲突（比如 Listary、PowerToys 的“查找鼠标”）？在 **设置 › 打开 Win顺** 的“双击哪个键”里可以改成双击 Alt 或双击 Shift（输入法用 Shift 切换中英文的，双击会切换两次，最后回到原来的状态），“用哪一边”可以只认左边或右边，也可以换成别的组合键，比如 `Alt+Space`。双击 Alt 只认单独按下又放开的 Alt：`Alt+Tab` 这类组合、按住不放、配合鼠标用的都不算。

右键托盘图标可以打开设置、重建索引、暂停记录剪贴板、退出。

### 没有管理员权限：“只为我安装”

公司电脑、没有管理员权限的账户也能用。运行安装程序时，会问装给“所有用户”还是“只为我”：

- **为所有用户安装**（要管理员同意）：带索引服务，索引整个磁盘，最快。
- **只为我安装**（不要管理员权限）：不装索引服务，Win顺 只索引你选的文件夹，也不往系统里写别的东西。开机自启在不能建计划任务时会改用登录项。
- 同一台电脑上两种装法不能并存：已经为所有用户装了，再运行只为我的安装程序会提示直接用它；反过来也一样，要先卸载另一份。

只索引选中的文件夹时：

- **选哪些**：**设置 › 搜索范围 › 文件夹** 里的“索引哪些地方”有三个选项：自动、整个磁盘、只索引选中的文件夹。“自动”的意思是没有索引服务、又不是管理员时，只索引选中的文件夹。装了索引服务或以管理员直读时，总是索引整个磁盘，第三项会变灰并写明原因。
- **索引的文件夹**：一开始是桌面、文档、下载、图片、视频、音乐和 OneDrive 这些常用位置。点“添加文件夹…”挑一个，或直接从资源管理器把文件夹拖进来，或点下面“常用位置”里的一个。每个文件夹一张卡片，写着状态、有多少项、上次核对的时间；可以“立即核对”或移除。网络位置不能加在这里，要加到“网络共享”里。
- **实时更新**：选中的文件夹里新建、改名、删除的文件马上就能搜到。
- **定时核对**：每天把这些文件夹再整个走一遍，补上没跟上的改动，可改成每小时、每 4 小时或只在启动时。到点后等你离开电脑一会儿才核对，不会在你用电脑时打扰你。
- **搜到范围外的文件夹**：在搜索框里打一个不在索引里的文件夹，下面会提示“这个文件夹不在索引范围内”。点“这次也搜它”只搜这一次；点“加入索引”以后一直收录。搜出来的结果很少时，也会提示一次“只索引了你选的文件夹，可能有别的地方没搜到”，可以点“设置文件夹…”，或点“不再提示”。
- **内容搜索**：照样能用，没有索引服务时直接读文件，慢一些。

整盘索引也可以自己选磁盘：在 **设置 › 搜索范围 › 磁盘** 的“索引哪些磁盘”里选“自己选择”，勾上要收录的盘。不勾的盘会退出索引，再勾上会重新收录；一个都不勾就不索引本机磁盘，网络和 WSL 位置仍单独管理。移动硬盘还需打开“包括 U 盘和移动硬盘”。暂时没连接的盘会保留你的选择。

如果用 `mklink` 建了目录链接或目录联接，在 **文件夹** 页把链接所在的路径加进来，例如 `C:\工作\资料链接`。管理员运行或使用索引服务时也能加；程序会补充收录链接里的内容，按这个路径显示结果并跟踪变化。普通文件夹已包含在整盘索引中，不会重复扫描。磁盘选择和排除规则按添加的链接路径判断；移除索引只移除搜索记录，不会删除原文件。

### 索引服务装在哪里

索引服务是个很小的系统服务，只在为所有用户安装时才有。便携版在 **设置 › 搜索范围 › 磁盘 › 索引方式** 里也能装上它：为了安全，Win顺 会把服务程序复制一份放进 `%ProgramFiles%\WinShun Service`（只有管理员能改），不会让服务直接从你能随便改动的文件夹（下载、桌面）里运行。以前装过的便携版，设置里会提醒，点“修复”就换成安全的位置。便携版换了新版本后，在同一个地方再装一次，服务也会跟着更新。

## 搜文件

### 打字就出结果

- 打文件名的一部分就行，不用打全：打 `报告` 能找到“2024 年度报告.docx”。
- **拼音也行**：`ndbg`（首字母）、`niandubaogao`（全拼）都能找到“年度报告”，可以混着打。
- **打错同音字也能找到**：打成“年度报高”找不到时，Win顺 会自动按读音再找一遍。
- **多个词用空格隔开**，顺序不限：`报告 2024` 要求两个词都有，也可以有一个出现在所在文件夹的名字里。

### 选哪个结果

- `↑` `↓` 移动，`Enter` 打开。
- `Ctrl+Enter` 打开文件所在的文件夹，并选中这个文件。
- `Ctrl+Shift+Enter` 以管理员身份运行。
- **数字键直达**：按 `Ctrl+1`～`Ctrl+9` 直接打开第几行（设置里可以改成 `Alt`）。按住 `Ctrl` 时图标上显示序号；在 **设置 › 结果列表** 的“序号提示”里可以改成一直显示或不显示，启动器和剪贴板共用这个设置。
- `Ctrl+C` 复制文件（可以粘贴到资源管理器、微信），`Ctrl+Shift+C` 复制路径。
- 结果可以直接**拖出去**：拖进微信、邮件、资源管理器都行。
- **右键**一行有更多操作：打开位置、复制路径、加入收藏、在终端中打开等。按住 `Shift` 右键，或者点菜单里的“更多选项”，出现的是 Windows 自己的右键菜单（和资源管理器里一样），选中几行也行；复制、剪切、删除之后搜索框不关。
- **多选**：`Shift+↓`、`Ctrl+单击`、`Shift+单击` 都能选多行，再一起复制或拖出去。
- **缩略图**：图片、视频、PDF 等显示缩略图，代替类型图标；“打开”“另存为”对话框旁的搜索框里也一样。不想要的话，在 **设置 › 结果列表** 里关掉“显示图片缩略图”。

### 名字太长

名字放不下时，在中间缩短，扩展名和结尾留着（“…第二版.xlsx”）。

- 鼠标在这一行上停一下，显示完整的名字、位置、大小、修改时间和创建时间。搜索面板的名称列、对话框旁的搜索框里也一样。
- 想一眼看全：拖动搜索框的左边或右边把它调宽，宽度会记住。双击边缘恢复默认，或者在 **设置 › 外观 › 搜索框宽度** 里点“恢复默认宽度”。

### 范围：全部 / 文件 / 内容

搜索框右上角有三个范围，按 `Tab` 往后切，`Shift+Tab` 往前切：

| 范围 | 搜什么 |
|---|---|
| **全部** | 文件、文件夹、应用、系统设置、网页、收藏，混在一起按匹配度排 |
| **文件** | 只要文件和文件夹 |
| **内容** | 搜文件里的文字，见[搜文件里的文字](#搜文件里的文字) |

在 **文件** 里，搜索框下面有一排类型：文件夹、文档、图片、视频、压缩包、程序……按 `Ctrl+Tab` 依次切换，或者直接点。点 `+` 可以加自己的类型，比如把 `xlsx`、`xls`、`csv` 叫做“表格”。

也可以直接输入类型前缀：`:folder 报告` 只找文件夹，`:pictures 猫` 只找图片，单独输入 `:documents` 列出文档。前缀不区分大小写，在 **设置 › 结果列表 › 文件类型** 可修改或留空停用。前缀要放在最前面；不认识的前缀仍按原文搜索。删除前缀会回到之前的范围，直接点击类型则替换前缀、保留后面的搜索文字。

### 排序

按 `Ctrl+S`，或者点底栏左边的按钮，在三种排序之间切换：

- **最匹配**：名字最像的在前，你自己的文件排在系统目录、`node_modules` 前面。
- **最新**：最近修改的在前。
- **最早**：最早修改的在前。

底栏上的“更多”还有四种：**名称**、**所在文件夹**、**类型**（按扩展名）、**大小**（大的在前或小的在前）。选了以后，底栏上显示一个简短的名字（文件夹、大在前、小在前），`Ctrl+S` 仍在前三种之间轮换。文件和文件夹分成两组各自排，先放哪一组在 **设置 › 结果列表 › 文件和文件夹的顺序** 里选；文件夹没有大小，按大小排时跟着那一侧，彼此还是按匹配度排。输入了一个文件夹的路径（比如 `D:\My Files\`）时，列出来的里面的内容也照这里选的顺序排；按“最匹配”排则和以前一样，文件夹本身在最上面。

**单击还是双击**：结果怕点错的话，在 **设置 › 结果列表 › 点击结果** 选“双击打开”：单击只选中一行，双击或按 `Enter` 才打开。按住 `Ctrl` 或 `Shift` 点击、右键、拖出去都不受影响。

**收藏文件夹与 Tab**：默认按 `Tab` 切换搜索范围，选中收藏文件夹时也一样。习惯用 `Tab` 进入收藏文件夹的话，在 **设置 › 结果列表 › 显示与预览 › 选中收藏文件夹时按 Tab** 选“进入文件夹”：只在“全部”范围选中可用的收藏文件夹时进入，`Shift+Tab` 仍反向切换范围，插件和网页的补全规则不变。也可以在任意可用文件夹的结果上右键“进入此文件夹搜索”，在 Win顺 内列出其中内容，再继续输入搜索；`Enter` 仍然打开文件夹。

**程序优先**：按最匹配排时，名字差不多的结果里，程序和脚本排在前面：搜 `curl`，`curl.exe` 排在文件夹 `curl` 和 `curl.h` 前面。优先哪些类型，在 **设置 › 结果列表 › 优先显示的文件类型** 里改（默认 exe、bat、cmd、ps1、msi，用分号或逗号隔开），留空就不优先。

修改时间比现在晚一天以上的文件（相机、别的电脑上时钟错了的），按时间排序时排在最后。

**右边的信息**：在 **设置 › 结果列表 › 显示与预览** 打开“显示文件大小”，精简搜索窗口就会显示大小，无需展开面板；默认关闭，按大小排序时始终显示。大小和修改日期可分别开关，同时显示时上下排列。文件夹不统计大小，大小未知时留空，空文件显示为 0 B。打开“较早的日期也显示时间”，较早的文件也会带上时分。按 `Ctrl+E` 展开搜索面板时，会沿用当前的排序字段和方向。

### 什么都不打的时候

搜索框是空的时候，列出你**最近打开**的或**最近修改**的文件，可以在底栏或设置里换，也可以设成什么都不显示（只留收藏）。

如果不想让别人看到你上次搜了什么，在设置里打开“每次打开时清空搜索”。

### 常打开的排在前面

Win顺 记得你输入什么字、打开了哪一项。下次输入同样的字，你常打开的那一项排在最前；输入的字不同，互不影响。开头一样也算：打过 `bg`，再打 `b` 或 `bgs`，也会把它往前放。常打开的比刚打开一次的更靠前，很久没打开的会慢慢往后。`size:`、`dm:`、`ext:` 这类筛选和 `abc/` 这样的文件夹不算在字里。只记字和打开了哪一项，不记别的；在设置里关掉“记住打开过的项目”就不再记；“清除最近使用记录”会把这些一起清掉。

### 搜索语法

| 写法 | 意思 |
|---|---|
| `报告 2024` | 两个词都要有，顺序不限 |
| `ndbg`、`niandubaogao` | 拼音首字母、全拼，可以混用 |
| `"年度 报告"` | 引号里的当成一个整体 |
| `!草稿` | 排除名字里有“草稿”的 |
| `!node_modules\` | 排除这个文件夹里的 |
| `*.pdf`、`报告?.docx` | 通配符：`*` 任意多个字，`?` 一个字 |
| `ext:pdf,docx` | 只要这些扩展名 |
| `项目\readme` | 在名字里有“项目”的文件夹下面找 readme |
| `D:\My Files\`、`tools/out/` | 路径直达：按回车进去，列出里面的东西，接着打字在里面找 |
| `size:>10mb`、`size:1mb..5mb` | 按大小（见[搜索面板](#搜索面板筛选和排序)） |
| `dm:7d`、`dm:today`、`dm:2026-01` | 按修改时间 |

### 搜得到哪里

- **WSL 内部文件**：打开 **设置 › 搜索范围 › 网络与 WSL**，点检测到的发行版用户目录，或点“选择文件夹…”挑具体的项目；也可以粘贴资源管理器里的路径，例如 `\\wsl.localhost\Ubuntu\home\用户名\项目`（`\\wsl$\...`、带引号的“复制为路径”也认）。只收录添加的位置里的文件名和文件夹名，支持拼音搜索，Linux 中大小写不同的文件分别保留；不读取文件内容。WSL 停止时已收录的结果仍可搜索，卡片会显示“未运行”；需要时点“启动并索引”，后台不会为核对主动启动发行版。运行时自动核对 Linux 内部的新增、改名和删除，通常约半分钟，大目录按扫描耗时放宽间隔；也可以点“立即核对”。建议添加项目或用户目录，收录整个发行版时不深入 `/proc`、`/sys`、`/dev`、`/run`、`/mnt`，避免虚拟目录和重复收录 Windows 磁盘。

- 所有本地磁盘。U 盘、移动硬盘在设置里可以选择收录；没收录的 U 盘插着时，列表末尾会提示你顺手搜一下它。
- **NAS 和局域网共享文件夹**：在设置里加进来，就和本地文件一起搜；服务器关机时，收录过的文件照样搜得到。
- 新建、改名、删除的文件马上就能搜到，不用等。
- **没有管理员权限的电脑**：只索引你选的文件夹，见[第一次用](#没有管理员权限只为我安装)。
- **“用 Win顺 搜索此处”**：从资源管理器带着一个文件夹打开时，名字相近的文件夹（比如 F1 和 F11）不会混在一起：最近打开的东西里，也只有这个文件夹里的排在前面。
- **不想看到的文件类型**：设置 → 搜索范围 → “跳过的文件类型”里填扩展名（例如 `wbk`、`bak`，WPS 的备份文件），这些文件就不再出现在搜索结果和内容搜索里。文件还在索引里，加上或去掉马上生效；自己输入 `ext:bak`，或在“文件”里选了包含它的类型，还是找得到。

## 搜索面板：筛选和排序

结果太多、想慢慢挑的时候，用搜索面板。

- **打开**：按 `Ctrl+E`，或者点搜索框右上角的展开按钮（两个斜箭头）。同一个窗口会展开成大面板，已经打的字、选的范围都还在。
- **收回**：再按 `Ctrl+E`，或者点面板右上角的按钮。

### 左边：筛选

| 筛选 | 选项 |
|---|---|
| 范围 | 全部、文件、文件夹、内容 |
| 类型 | 文档、图片、视频、音频、压缩包、程序、电子书、代码，还有你自己加的类型 |
| 修改时间 | 今天、最近 7 天、最近 30 天、今年，或者自定义起止日期 |
| 大小 | 小于 1 MB、1～100 MB、100 MB～1 GB、大于 1 GB，或者自定义范围 |
| 位置 | 收藏的文件夹，或者点“选择文件夹…”挑一个 |

几个筛选可以叠在一起用。点“清除全部”一次全取消。

**不打字也能用**：只选筛选条件，就会列出整台电脑上符合条件的文件。比如只选“大于 1 GB”，就能看到硬盘上所有的大文件；再点“大小”列头排一下，最大的在最前。

### 右边：按列排序

默认显示 **名称 / 路径 / 大小 / 修改时间**。右键列头可开关列，还可显示类型、创建时间、所在文件夹和来源；名称列始终保留。拖动列头调整顺序，拖动列间分隔线调整宽度，配置会自动保存。点列头排序，再点一次倒过来；列太多时可横向滚动。右键菜单的“恢复默认列”可还原布局。

插件返回日期和大小时，也会显示在对应列，参与排序和筛选；未提供这些信息的旧插件仍可使用。

### 直接在搜索框里写条件

不想点筛选的话，也可以把条件直接写在搜索框里，普通搜索框和面板里都能用：

| 写法 | 意思 |
|---|---|
| `size:>100mb` | 大于 100 MB |
| `size:1mb..5mb` | 1 MB 到 5 MB 之间 |
| `size:large` | 用 Everything 的叫法表示大小档 |
| `dm:today` | 今天修改的 |
| `dm:7d` | 最近 7 天修改的 |
| `dm:2026-01` | 2026 年 1 月修改的 |
| `报告 size:>1mb dm:30d` | 名字有“报告”、大于 1 MB、最近 30 天改过的 |

面板的大小和位置会被记住。下次双击 Ctrl 打开的还是普通搜索框，需要时再按 `Ctrl+E` 展开。

## 钉住和移动搜索框

平时搜索框像菜单一样：点了别处、打开了文件，它就自己收起来。想一边看一边搜的时候，可以把它**钉住**：

- 按 `Ctrl+T`，或者点搜索框右上角的图钉。钉住后图钉变成实心的，底栏会提示。
- 钉住后，点别的窗口、打开文件，搜索框都留着，并且一直在最上层。
- 按 `Esc` 照样关闭；下次打开还是钉住的。再按 `Ctrl+T` 取消。重新启动 Win顺 后恢复成不钉住。
- 钉住时搜索框在别的窗口后面，双击 Ctrl 会把它拿到前面来，位置不变。

**移动窗口**：按住搜索框左边的放大镜拖动，就能把窗口挪到别处。**单击**放大镜打开设置。

## 预览文件

在结果上按 `Alt+P`（或者右键选“预览”），不用打开就能看一眼文件，搜索框也不会关。

- **能预览的**：图片；文本和代码（自动识别 UTF-8、GBK）；Word、Excel、PowerPoint、PDF（用和资源管理器预览窗格同样的预览程序，所以要装了对应的软件）；文件夹显示里面有几个文件夹、几个文件。别的文件显示大图标和类型、大小、时间。
- **换一个文件**：按 `↑` `↓` 换一行，预览跟着换。鼠标指着哪一行，就预览哪一行。
- **关闭预览**：再按 `Alt+P`，或者点预览窗口的叉。按 `Esc` 关的是整个搜索框；预览开着的话，下次打开搜索框时预览还在，显示第一个文件。剪贴板里的预览也一样。
- **QuickLook、Seer 用户**：如果后台开着 QuickLook 或 Seer，Win顺 会交给它们来预览。不想这样的话，在设置的“预览文件（Alt+P）”里改成“内置”。
- 从网上下载的文件，和资源管理器一样，为了安全只显示文件信息，不调用预览程序。

## 搜文件里的文字

想不起文件名、只记得里面写了什么时，用 **内容** 范围（按 `Tab` 切过去）。

- **能搜的文件**：
  - 纯文本：txt、md、log、csv、json、各种代码；
  - 文档：Word、Excel、PowerPoint、PDF、WPS。
- **结果**：显示命中的那一行。文档会告诉你在第几页、第几张幻灯片、哪个表的第几行。
- **怎么搜**：可以写多个词，用引号找整个短语，结果按相关度排。
- **只在某个文件夹里搜**：在词后面写文件夹名和斜杠。
  - `年度报告 财务/`：只在叫“财务”的文件夹里找；
  - `工作/财务/`：只要“工作”下面的那个“财务”；
  - 同名的文件夹有好几个时，搜索框下面会列出来，按 `Ctrl+Tab` 挑一个；
  - 也可以点下面的收藏文件夹，或者在结果的文件夹上右键“在此文件夹中搜内容”。
- **没搜到的文件**：太大的、系统目录里的、类型没列进来的，默认不搜；搜完会告诉你各有几个，点一下就临时把它们也搜了。要搜哪些类型、大小上限是多少，在设置里改；大小上限可以小到 KB，直接打 `50k`、`1.5m`、`2g` 也行。

没有索引服务（比如“只为我安装”）时，**内容** 搜索也能用，直接去读文件，只是慢一些。

内容索引默认是关着的（新装的）：这时 **内容** 直接去读文件，慢一些。想搜得快，在 **内容** 范围搜索框下面那一行，右端的“内容索引”开关点一下打开；关掉会清空索引。旧版升上来的，原来开着的还是开着。

打开后第一次建内容索引要把文件读一遍。安装版由索引服务直接从磁盘读文本文件，杀毒软件不用一个个检查，很快就好；Word、PDF 这些文档，和便携版没装索引服务时，还是一个个打开，开着杀毒软件会慢一些。之后只读改过的文件，就很快了。

## 系统开关

打“蓝牙”“深色”“音量”这类词，结果行的右端会直接显示现在是开还是关。按 `Enter` 就地切换，搜索框不关，马上看到结果；按 `Ctrl+Enter` 打开对应的 Windows 设置页。也可以点行尾的开关。

能开关的有七个：深色模式（应用和系统一起切）、显示隐藏的文件、显示文件扩展名、蓝牙、WLAN、音量和静音（默认输出设备）、保持唤醒。

| 打什么 | 会怎样 |
|---|---|
| `蓝牙`、`深色模式`、`音量` | 出一行，行尾是现在的状态；`Enter` 切换（音量行的 `Enter` 是静音 / 取消静音） |
| `开蓝牙`、`关蓝牙`、`bluetooth off` | 明确地打开 / 关闭；已经是那个状态就只在底栏说一声 |
| `关闭深色`、`浅色`、`深色` | 切到浅色 / 深色 |
| `静音`、`取消静音` | 静音 / 取消静音 |
| `音量 30` | 音量设为 30，同时取消静音 |
| `音量 +10`、`音量 -5` | 在现在的音量上加减 |
| `保持唤醒` | 电脑不睡眠、屏幕不关，直到你结束 |
| `保持唤醒 1小时`、`保持唤醒 到 18:00` | 到点自动结束 |
| `结束保持唤醒`、`关闭保持唤醒` | 结束 |
| `蓝牙设置` | 直接出“打开蓝牙设置”一行 |

- **音量**：行上按 `Alt+←` / `Alt+→` 每次减 / 加 5（加的时候顺带取消静音）。
- **保持唤醒**：开着的时候，空搜索框的列表最上面多一行“保持唤醒”，托盘图标的提示和右键菜单里也有；点菜单里打勾的那一项就结束。这一行不是默认选中的，打开搜索框直接按 `Enter` 仍是重开上次的东西。到点结束时不弹通知；退出 Win顺，它也随之结束。合上盖子、按电源键，电脑照样会睡眠。
- **别的情况**：开关行不会出现在空搜索框的列表里，免得打开窗口顺手按 `Enter` 就切了开关。没有这个设备（比如没有蓝牙）或权限不够时，这一行没有开关，写明原因，`Enter` 打开设置页；失败时第二行用红字说明。
- **深色模式**：切的是 Windows 的主题。Win顺 自己的外观如果在设置里固定成了浅色或深色，不会跟着变，要跟着变就改成“跟随系统”。
- **WLAN**：关掉会断网，当前正靠它上网时，底栏会写“会断网”；再按一次就开回来。

## 网页搜索

在关键词后面加个空格，就在那个网站上搜：

- `baidu 天气`、`zhihu 显卡`、`jingdong 键盘`、`bilibili 教程`
- 先打关键词，结果第一行是那个网站，按空格、`Enter` 或 `Tab` 进去，再打要搜的词。

自带百度、必应、B 站、知乎、微博、抖音、小红书、淘宝、京东、翻译。

### 搜索建议

打了网站关键词再打字，下面会列出那个网站的联想词：

- `Enter`：直接搜这一条；
- `Tab`：把它填进搜索框，接着改。

百度、必应、B 站、淘宝自带建议。只有你打了网站关键词，Win顺 才会把你打的字发给**那一个**网站取建议；平时搜文件一个字也不发。不想要的话，在设置的网页搜索里关掉“网页搜索建议”。

### 添加自己的网站

在设置的网页搜索里点“添加”：

- **网址**：把搜索结果页的网址里搜索词换成 `%s`，比如 `https://www.so.com/s?q=%s`；
- **关键词**：比如 `so`；
- **建议接口**（可选）：同样用 `%s`，填好就有搜索建议，改了马上生效，不用重启；
- **图标**：可以选图片或 SVG 文件，也可以在“粘贴 SVG 代码”框里直接贴 iconfont 上“复制 SVG 代码”复制来的内容；以后再编辑，框里还是这段代码，可以接着改。

网站列表和图标都可以导入、导出。

## 收藏夹

- 在结果上右键“加入收藏夹”。不打字时，收藏的排在最前。
- 给收藏起个**关键词**，以后一打关键词就能打开。
- 文件夹结果上右键“进入此文件夹搜索”，可在 Win顺 内接着搜。也可在 **设置 › 结果列表 › 显示与预览** 中选择按 `Tab` 进入收藏文件夹；默认按 `Tab` 仍切换搜索范围。

### 拖文件时按 ` 键：收藏圆盘

在文件或文件夹上按住左键（不用先拖动；从资源管理器、桌面、Total Commander 等别的程序都行），按一下 `Esc` 下面那个键（英文状态下是 `` ` ``，中文输入法下是 `·`，按哪个都一样，拖动时它不会打出字来），指针周围会弹出你的前 8 个收藏文件夹。

- **朝哪个文件夹的方向拖**就选中哪个，不用拖到它上面，松开文件就放进去。
- 和资源管理器一样：同一个盘里是移动，到别的盘是复制；拖的时候按住 `Ctrl` 是复制、按住 `Shift` 是移动。下面那行会写清楚松开会做什么。
- **中间**松开，或者按 `Esc`，什么也不做。再按一次那个键，或者拖远一点，它就收起，可以接着拖到别的地方。
- 在屏幕边上叫出来，圆盘会整个挪进屏幕，指针跟着跳到中间，照常往外选就行。

移动或复制由 Windows 自己来做，在资源管理器里按 `Ctrl+Z` 能撤销。灰色的文件夹放不进去（不存在了、文件本来就在那里、不能放进自己里面），下面那行会写原因。名字太长的收藏会从中间省略，可以在 **设置 → 收藏夹** 里点开它起个短名，表单里会显示圆盘上的样子。不想要这个功能，在 **设置 → 收藏夹** 关掉“拖文件时按 ` 键，弹出收藏圆盘”。Win顺 以管理员身份运行时用不了。

### 自定义命令

在 **设置 → 收藏夹 → 添加命令** 中填写名称、关键词和命令，可以点“选择程序…”选文件。含空格的程序路径要加双引号；工作文件夹可选，支持 `%环境变量%`。

图标默认从程序自动提取，搜索结果和收藏列表一起显示；填写命令时能看到预览。点“选择图标…”可使用 PNG、ICO、SVG，或从另一个程序、快捷方式提取；点“恢复自动”重新跟随当前命令。自定义图标随收藏保存，移动或删除原图片也不影响，导出收藏和设置备份都会带上。改完点“保存”才生效，取消会保留原图标。

例如关键词 `code`，命令 `"C:\Tools\Code.exe" {query}`：在“全部”搜索里输入 `code D:\我的项目`，回车就把 `D:\我的项目` 作为一个参数交给编辑器。`{query}` 自动处理空格和引号，不用再加引号。不含 `{query}` 的命令可直接通过关键词启动。命令与普通收藏一起编辑、排序、导入导出；导入或搜索不会自动运行命令。

程序和参数直接交给 Windows；需要命令提示符或 PowerShell 语法时，应在命令中明确填写相应程序。不要把不信任的文字交给解释器执行。

## “打开”“另存为”对话框

在别的软件里点“打开”“另存为”，或者在网页上传文件时：

- **对话框旁边的搜索框**：打文件夹或文件名（拼音也行），回车，对话框直接转过去，不用一层层点。WPS 的对话框也认。新装默认关，在 **设置 › 插件** 的“对话框搜索框”卡片上，或 **设置 › 打开 Win顺 › 对话框** 里打开。
- **`Ctrl+G`**：转到资源管理器（或 Total Commander、Directory Opus、XYplorer、Pulse、OneCommander）正在显示的那个文件夹。OneCommander 读取当前活动面板的路径，不需要额外配置；对话框的建议和自动跳转也支持。Pulse 刚换了文件夹时，可能要等它两三秒。
- **不打字时**：列出开着的文件夹、刚复制的路径、收藏和最近用过的文件夹。
- **自动转过去**：可以设成对话框一出现就转到资源管理器的文件夹；或者先停在上次的位置，等你从资源管理器切回来时再转。
- 拖动对话框或调整它的大小时，旁边的搜索框先藏起来，松手后出现在新的位置。
- **Inno Setup 安装器的“浏览文件夹”**：支持搜索文件夹并填入路径，仍由你点击安装器的“确定”。开始菜单快捷方式分组的选择框不接管。
- **管理员窗口**：普通权限的 Win顺 仍可显示搜索框；选中结果后复制路径，提示你在对话框的路径输入框中手动粘贴。此时不自动跳转、不接管 `Ctrl+G`。这保留了 Windows 的权限隔离。

## 在资源管理器里

### 双击空白处

在资源管理器或桌面的**空白处双击**，弹出一个文件夹菜单：收藏的、最近的、别的窗口里开着的文件夹。选一个，当前窗口就转过去（在桌面上会开新窗口）。菜单里还能在当前文件夹里搜、把它加进收藏。

- **新装默认关**：在 **设置 › 插件** 的“文件夹菜单”卡片上，或 **设置 › 打开 Win顺 › 对话框** 里的“双击空白处弹出文件夹菜单”打开。
- 方向键、回车、`Esc`、首字母都能用；点别处或再双击就关。
- **菜单里列哪几类**：在 **设置 › 打开 Win顺 › 对话框** 里，“菜单里列出收藏的文件夹 / 最近的文件夹 / 别的窗口里的文件夹”三项可以各自开关，至少留一项。
- **Directory Opus 里也能双击**：在 **设置 › 打开 Win顺 › 对话框** 里打开“在 Directory Opus 的空白处双击”，Win顺 替你在 Opus 的设置里加好命令（Opus 会重启一下）；关掉或卸载时换回原来的。
- 双击被别的软件占了，或者想在 Total Commander、XYplorer、Pulse 里用？在设置里给文件夹菜单设一个快捷键（“用快捷键弹出文件夹菜单”），在任何窗口里按一下就弹出，再按一次关闭。
- 在 Pulse 里选了文件夹，开在哪儿由 Pulse 决定：它默认“智能”，刚用过的窗口不打扰，会开一个新窗口；想在原来的窗口里开新标签，到 Pulse 的设置里把“从其他程序打开的文件夹”改成“标签页”。

### 右键“用 Win顺 搜索此处”

在文件夹、文件夹的空白处、磁盘上右键，选“用 Win顺 搜索此处”，搜索框带着这个文件夹打开，接着打字就只在里面找。Windows 11 上在“显示更多选项”里。设置里可以关掉。

### 直接打字搜索

在资源管理器的文件列表里**随便打字**，Win顺 就弹出来，带着你打的字，只搜这个窗口所在的文件夹（和 Listary 一样）。

- 中文输入法照样能用，拼音会在 Win顺 的搜索框里继续组字。
- 按 `Esc` 回到资源管理器。
- 选中的结果是文件夹时，在原来的标签页里打开，回到文件列表，接着打字就再往里一层，和 Listary 一样。
- 资源管理器里按 `Shift` 右键弹出的老式右键菜单，菜单里的字母键照常用，不会被 Win顺 抢去。
- 改名、地址栏、资源管理器自己的搜索框里打字不会触发；按着 `Ctrl`、`Alt`、`Win` 时也不会。
- **默认关**：它代替了资源管理器自己的“按首字母跳到文件”。在 **设置 › 打开 Win顺** 里打开“在资源管理器里直接打字搜索”。

**Directory Opus**：在 **设置 › 打开 Win顺 › 对话框** 打开“在 Directory Opus 里直接打字搜索”，或在 **设置 › 插件 › 已安装 › 内置功能** 打开对应卡片。这是独立开关，默认关闭。文件列表有焦点时，从字母或数字开始输入，就在当前标签的文件夹里搜；双栏分别按输入所在的标签确定路径。`Esc` 回到 Opus，打开文件夹或 `Ctrl+Enter` 定位文件时回到原文件列表。`*`、`/`、`>` 等符号起头仍交给 Opus 自己的查找模式，改名、地址栏、筛选框、目录树和菜单里的输入也保持原样；带 Ctrl、Alt、Win 的组合键不接管。取不到真实文件夹（例如虚拟位置或压缩包），就把输入还给原来的文件列表。

### 粘贴为文件

复制了一段文字或一张图片，想存成文件：在资源管理器的文件列表或桌面上按 `Ctrl+V`，或者在空白处右键选“粘贴为文件”（Windows 11 在“显示更多选项”里）。文件就放在这里，名字已经选中，直接打新名字、回车。不用先新建一个文本文档再粘贴进去。

- **存成什么**：看内容。普通文字存 `.txt`；从 Excel、WPS 复制的单元格存 `.csv`，Excel 直接能打开；还认 JSON、整页网页（`.html`）、SVG、XML、注册表（`.reg`，双击就能导入）、批处理（`.bat`）、Shell 和 Python 脚本。图片存 `.png`：截图、网页上复制的图都行，透明的地方保留。
- **叫什么**：普通文字用第一句有内容的话（标题前的 `#`、列表前的 `-` 去掉），网页用它的标题，太长就截短；表格、JSON、脚本、图片这些用类型加时间，比如“表格 2026-10-24 163015.csv”“图片 2026-10-24 163015.png”。已经有同名文件时在后面加 (2)、(3)。
- **从 Win顺 的剪贴板里选**：`Ctrl+V` 那种方式开着时，资源管理器或桌面在前面，在剪贴板面板里选一条文字或图片按回车，也是存成文件。
- **装了腾讯桌面整理**：在它盖着的桌面上点过之后，`Ctrl+V` 归它管，不会存成文件；按 `Win+D` 回到桌面后可以。
- **复制的是文件**：`Ctrl+V` 照旧是资源管理器自己的粘贴。改名、地址栏、搜索框里的 `Ctrl+V` 也不受影响。
- **受保护的文件夹**（比如 Program Files）：Windows 会请你确认管理员权限。压缩包里、“此电脑”这种不是文件夹的地方放不了，右键时会说一声。
- 资源管理器的 `Ctrl+Z` 撤销不了这一步；不想要了，直接删掉这个文件。
- **默认关**：在 **设置 › 插件** 的“粘贴为文件”卡片上打开。`Ctrl+V` 和右键菜单可以只留一个；`Ctrl+V` 要 Win顺 开着，右键菜单不用。

## 剪贴板历史

复制过的文字、图片、文件都记下来，随时找回来再贴。

图片支持 **GIF、PNG、JPEG（JPG）、BMP／Windows 位图**。来源提供 GIF 原始数据时，会完整保留动画；预览里可以播放、暂停，列表只显示静态缩略图。关闭预览或隐藏窗口会释放动图资源；系统关闭动画效果时默认暂停，仍可手动播放。照片按自身方向显示。若来源程序只把 GIF 的一帧放进剪贴板，只能记录这一帧，无法恢复原动画。

关闭“记录剪贴板历史”后，会停止监听、释放历史缓存和窗口；图片识别会在当前任务结束后释放模型。已有记录仍保留在本机，重新开启就能继续用。关闭期间仍可复制截图；导入历史会完成当前导入，再释放缓存。截图与剪贴板随程序安装，目前不能单独卸载。

- **打开**：在设置里打开“用 Win+V 打开，代替 Windows 自带的剪贴板”后按 `Win+V`；不想换掉 Win+V 的话，也可以自己设一个快捷键，比如 `Win+Alt+V`。它开在输入光标旁边，不抢焦点。
  - 光标靠近屏幕下边、下面地方不够时，它开在光标上方，并且上下翻过来：搜索框和最新的一条挨着光标，越往上越早，`↑` `↓` 照屏幕上的方向走。在 **设置 › 剪贴板** 的“搜索框位置”选“远离光标”，则条目挨着光标，搜索框在窗口另一头。不想翻转，关掉“开在光标上方时翻转”，开在光标上方时也和平时一样从上往下排。
- **粘贴**：双击或 `Enter` 粘贴；`Shift+Enter` 粘贴为纯文本；`Alt+1`～`Alt+9` 直接粘贴第几条。
- **调整宽度**：预览关闭时拖动面板右边缘，双击边缘恢复默认宽度；宽度自动保存。文字大小随“设置 › 外观 › 界面大小”调整。双击粘贴会取消待打开的预览，避免窗口先展开再粘贴。
- **不打开面板直接粘贴**：设置 › 剪贴板 › 快捷键，找到“不打开面板直接粘贴”，选择 `Ctrl+1–9` 或 `Alt+1–9`。在其他程序里直接粘贴“全部”列表的前九条，沿用“固定优先”顺序，不受上次搜索或分组影响；保留原格式。默认关闭，开启后会占用这些键在其他程序里的操作（例如浏览器切换标签页）。已被其他全局快捷键占用的数字会在设置里提示，其余数字仍可用。打开面板后使用上方单独设置的“面板内数字键粘贴”。
  - 想像 Windows 自带的剪贴板那样**点一下就粘贴**（比如用手机远程操作电脑时），在 **设置 › 剪贴板** 打开“单击粘贴”。打开后，鼠标移到一条上出现的按钮从“粘贴”变成“预览”；按住 Ctrl 或 Shift 点击仍是多选。
- **上传文件**：在 Windows 的“打开”文件选择框里，从剪贴板历史粘贴文件，会把完整路径填进“文件名”，多选文件也可以。确认后再点“打开”；不会把文件复制到对话框当前显示的文件夹。应用自己绘制的上传窗口仍按其自身支持的格式粘贴。
- **搜索**：打字就能搜，拼音也行；`@wx` 只看从微信里复制的。**图片里的字也能搜**（在本机识别，不联网）。
- **预览**：`Alt+P`，或者点一条旁边的眼睛按钮，开关预览，看全文、大图，颜色值显示 HEX / RGB / HSL。预览开着时，鼠标在某一行上停一下（约 0.1 秒），预览就临时换成那一行，选中的行不变，`Enter` 粘贴的还是选中的那条；鼠标移进预览栏时保持不变，可以滚动、选字；移到别处、按方向键或点一下就回到选中的行。鼠标只换内容，不会自己打开或关闭预览。预览栏默认宽一些；把列表和预览之间的竖线往左右拖可以调宽窄（最窄 280，往右最多拖到屏幕边缘；窗口左边不动，列表留在原处），双击竖线回到默认宽度，调好的宽度下次打开还在。觉得图片缩略图太小，在 **设置 › 剪贴板** 打开“大图片缩略图”，不打开预览也看得清。
- **拖出图片**：按住图片拖到文件夹里，按原格式保存（GIF 保留动画，JPEG 保留原文件；截图和位图保存为 PNG）；用 Ctrl 或 Shift 选多张后，从选中的图片起拖，就能一起保存。在资源管理器里打开剪贴板，粘贴图片也沿用相同格式。动图复制时同时提供原文件和静态兼容图片，由目标程序决定采用哪种；右键“编辑首帧”会以第一帧进入静态图片编辑器。
- **整理**：
  - 固定常用的，可以让固定的排在最前；顺序可以拖动，或者用 `Ctrl+↑` `Ctrl+↓` 调整；
  - 分组；
  - 多选后按选的顺序一起粘贴；
  - 清理：`Ctrl+A` 选中列表里的全部（固定的和分组里的不选，在某个分组的页签里则选中那一组）；搜索框里有字时，第一次 `Ctrl+A` 全选文字，再按一次才选条目。选好按 `Delete` 一起删。右键一条，菜单里的“删除全部 N 条”删掉列表里所有的（有搜索词就只删搜到的，固定和分组的保留）。删错了按 `Ctrl+Z` 一次全部恢复；
  - 钉住剪贴板窗口，一条接一条地往表格里填。
- **已经不在的文件**：复制过的文件后来被删掉或移走，那条记录会标“已不存在”。在 **设置 › 剪贴板** 的“已不存在的文件记录”里可以选“自动隐藏”（不显示，搜索还能找到，仍占条数上限）或“自动清理”（隔一阵再确认一次后删掉，不占条数）。固定的、分组里的不动；U 盘拔了、网络盘断了时不算不存在。
- **隐私**：密码管理器复制的密码不记录；历史只存在本机。托盘菜单里可以暂停记录。

## 截图

Win顺 自带一个截图功能，默认关着。在 **设置 › 插件** 的“截图”卡片上打开，再录一个快捷键（不录也行，从托盘菜单点“截图”）；想让 `PrtScn` 键也截图，打开“用 PrtScn 键截图”。

截图卡片默认只显示开关和当前状态，点“设置”展开。选项按 **快捷键、截图、鼠标、贴图、打码、工具条** 分类，一次显示一组；分类可用左右方向键切换。设置搜索也能直接找到并展开对应分类，例如“中键”“智能打码”“复制截图时同时贴图”。

- **选**：按快捷键后屏幕定住。鼠标移到窗口或按钮、输入框上，它就被框出来，框外立即变暗、框内保持原图，点一下选中；滚轮往上把框扩大到整个窗口、整个屏幕，往下缩回去。也可以按住拖出一块。
- **调**：拖八个小方块改大小，拖中间移动；方向键一次移 1 个像素，`Shift`+方向键改大小。旁边写着选区的实际像素大小。
- **放大镜**：跟着鼠标，显示放大的像素、坐标和颜色；按 `C` 复制颜色，单按一下 `Shift` 换写法（`#RRGGBB`、`rgb(r, g, b)`、`hsl(h, s%, l%)` 轮着来，Win顺 记着你用的是哪种；按着 `Shift` 去按别的键、点鼠标、滚滚轮都不算）。选好区域后，放大镜只在选区和它的蓝框上出现，移到选区外、工具条上就收起，拖边框时又出来。没有选区时方向键一次挪鼠标 1 个像素。
- **识别文字并复制**：`Shift+C` 识别选区里的文字，直接复制到剪贴板（还没有选区时识别鼠标下框出来的那块）。
- **上次的选区**：还没有选区时按 `Shift+R`，选区回到上一次截图的那一块（记得是哪块屏，所以热键按在另一块屏上也回到原来那块）。
- **控件识别**：鼠标移到窗口上，除了子窗口，还会向 Windows 的“界面自动化”问一声，把设置、计算器这类自己画界面的程序里的侧栏、按钮也框出来。Chrome、Edge、VS Code、微信这类 Chromium 程序不问：一被问到，它们就会打开整套无障碍支持（VS Code 会切到“已为屏幕阅读器优化”，要重启才恢复），所以它们只框子窗口或整个窗口，需要时手动框选。问是在后台做的，最多等 150 毫秒，超时（程序没反应）就只用普通子窗口，鼠标不会卡；提权运行的程序里问不到。设置里“识别 WinUI 等程序里的控件”可以关。
- **延时截图**：`D` 或工具条的“延时”：关掉这次截图，屏幕右上角出现倒计时，到点才冻结屏幕，用来截菜单、悬停提示。托盘菜单 **截图 › 延时截图 › 3 / 5 / 10 秒** 是直接开始倒计时。倒计时里再按一次截图快捷键，或点那个数字，就取消。倒计时的窗口在拍照前就撤掉，不在图里。秒数在设置里选，`D` 用的就是它。
- **二维码**：`Q` 或工具条的“二维码”：读出选区里的二维码，在小窗口里显示文字，可以复制；是网址（http、https）时多一个“打开链接”按钮，点了才打开，从不自己打开。选区里没有二维码时窗口会说没找到。
- **带鼠标指针**：设置里的“截图带上鼠标指针”（默认关）打开后，冻结的画面里画着按下快捷键那一刻的指针，复制、保存、贴图的图里都有它。
- **完成**：`Enter`、双击选区或工具条最右边的对勾（复制）：复制到剪贴板并关闭，截图也进剪贴板历史，图里的字可以搜。`Ctrl+S` 或保存按钮：存到“图片\屏幕截图”，名字是 `WinShun_日期_时间.png`。
- **退出**：`Esc` 或右键先取消选区，再按一次退出；截图时再按一次快捷键也退出。
- **工具条**：选好区域后，选区下面是一排只有图标的按钮，鼠标停一下会显示名字和快捷键。从左到右：九个标注工具｜撤销、重做｜长截图、延时、二维码、识别文字｜贴图、保存｜全部按键（?）｜取消（叉）、复制（主题色底、白色对勾，最右边，最常用）。编辑窗口里是同一排（没有长截图、延时、二维码）。
- **标注**：选好区域后，工具条第一行是九个工具：矩形（`R`）、椭圆（`E`）、箭头（`A`）、直线（`L`）、画笔（`P`）、荧光笔（`M`）、文字（`T`）、序号（`N`）、打码（`B`），也可以按 `1`–`9`。再按一次同一个键就关掉工具；输入法开着中文时这些键也直接起作用，不会变成拼音。
  - 画：在选区里拖。按住 `Shift`：矩形、椭圆画成正方形、正圆，直线和箭头吸附 15°，画笔和荧光笔画直线。序号和文字点一下就放。画到一半按 `Esc` 只取消这一笔。
  - 连续折线：在直线工具的样式面板选“折线”，单击加节点，鼠标移动预览下一段；双击、`Enter` 或右键结束，点起点闭合。`Backspace`、`Delete` 或 `Ctrl+Z` 退回上一个节点，`Esc` 取消这条折线；整条线只占一步撤销。按住 `Shift` 加点时吸附 15°，画完仍能拖动各个节点。
  - 曲线：直线和箭头都可选“曲线”。先拖出起终点，再拖动两个圆形控制点调弧度；移动端点时相邻控制点一起移动。保存后重新编辑仍能调整曲线。
  - 荧光笔：可选“涂画”“直线”“矩形”。直线拖一下划重点，矩形拖出一整块文字区域；覆盖后黑色正文仍然可读。三种方式共用颜色，矩形不显示笔宽。
  - 改：画完的东西自动选中，可以拖动、拖手柄改形状、方向键挪 1 像素（`Shift` 10 像素）、`Delete` 删除；没有工具时点一下图形就能选中它。第二行是样式面板：颜色、粗细、填充、字号、粗体、底框、打码的样式和格子大小。`[` `]` 或滚轮调粗细；`Ctrl+[` `Ctrl+]` 上移下移一层。每个工具各记一套样式，下次截图还在。
  - 文字：点一下写，微软拼音等输入法照常用，拼音看得见、候选窗跟着光标。`Esc` 先取消拼音，再按一次写完；`Ctrl+Enter` 也是写完。双击文字再改。
  - 序号：自动按顺序编，删掉中间一个后面自动补上。面板里能改起始值、“另起一组”从 1 重新数；双击一个序号可以单独改它的号。面板右边五个按钮选这一组的写法：`1 2 3`、`A B C`（Z 后面是 AA）、`a b c`、`I II III`（罗马数字，到 3999）、圈里的数字（空心圆圈，数字用颜色）；选中一个序号时改的是它那一组，没选就改正在用的一组，下次截图还用上次选的写法。
  - 序号旁边的字：放下一个序号后可以直接接着打字，字出现在序号右边，和文字一样微软拼音等输入法照常用；`Enter` 或 `Esc` 写完（Esc 先取消拼音），也可以直接点下一个位置继续放下一个序号。字跟着序号走，放序号加打字算一步撤销；不打字就没有字。序号工具开着时点一下序号，或没有工具时双击序号右边的字，可以再改；双击序号圆圈本身还是改号。
  - 打码：马赛克、模糊、纯色、抹平（用四周的底色盖住，像擦掉了一样），形状可以是“框”或“涂抹”（沿着鼠标走过的地方打码，笔宽 16 / 24 / 36），用的是区域外面的像素，里面的原样子不参与计算，所以还原不出来。打码总在最下面一层，不会盖住后画的箭头和文字。
  - 智能打码：选好区域停一会儿（约 0.3 秒），Win顺 在后台读图里的字，找到手机号、身份证号（校验位对的才算）、银行卡号（校验过的才算）、邮箱、密钥（sk-、ghp_、AKIA 开头的，password=、密码：后面的值）、本机用户名和电脑名，工具条边上就提示“发现 N 处 · 点此打码”。点一下，或在打码工具里点“智能打码”，或按 `Shift+B`，全部盖上，一次 `Ctrl+Z` 全撤。`$TOKEN`、`****`、`<your-key>` 这种占位的不算。已经盖住的不会再盖。识别只在本机进行，图和文字都不会发出去；自动找的可能有漏，发出去前再看一眼。设置 › 截图 里可以关掉自动识别（那样点“智能打码”时才识别）、加上 IP 和 MAC 地址、把所有文字都盖住、填自己的词。编辑窗口里同样有。
  - 打码之后，复制、保存、贴图的图和截图历史里认出来的字都是打码后的，在搜索框里搜不到被盖住的手机号。
  - 撤销 `Ctrl+Z`、重做 `Ctrl+Y`（工具条上也有）。`H` 隐藏或显示工具条；工具条挡到要画的地方时，拖动中它会自己让开。
  - 有标注时，`Esc` 先把选区和标注一起放下（边上写着“Ctrl+Z 恢复”），再按一次退出；再按一次截图快捷键也会直接关掉，不问你。关掉后这次的标注留 10 分钟，托盘菜单 **截图 › 找回刚放弃的标注** 把它贴回原处。
  - 复制、保存、贴图用的都是标注后的图。带标注的截图在剪贴板历史里还留着一份可以再编辑的文件（带着原图，包括被打码的部分，只在你这台电脑上；从 Win顺 出去的图都是打过码的）；用 `Ctrl+S` 保存或 `F3` 贴图的截图也记进截图历史。
- **再编辑**：截过的图可以再打开改。搜索框里 `jt` 找到那张图，按 `Shift+Enter`（或右键 › 编辑）；剪贴板窗口里的图片右键 › 编辑（任何图片都行，不是截图也行，那时这张图就是底图）；贴图上右键 › 编辑。会开一个普通窗口，工具条、样式面板和截图时一样，标过的东西都还能选中改，被裁掉和被打码盖住的原图也还在。
  - **看图**：`Ctrl`+滚轮、`Ctrl`+加号 / 减号缩放，`Z` 在“适合窗口”和 100% 之间切换（右下角的百分比点一下也一样）；滚轮上下滚动，`Shift`+滚轮左右；按住空格拖动或用中键拖动来平移。100% 时一个图像像素就是一个屏幕像素，和导出的图逐像素一样；改粗细用 `[` `]` 或 `Alt`+滚轮。长图只为看得见的部分画图，打开很快。
  - **裁剪**：没有选工具时，拖图片的边或角；选了工具时，从图外面拖它。可以撤销（`Ctrl+Z`），下次打开还能把裁掉的部分拖回来。
  - **多选**：`Shift`+点击加选或去掉，在空白处拖一个框框住要选的，`Ctrl+A` 全选。多选后可以一起拖动、改颜色、删除；`Ctrl+D` 复制一份（稍微挪开一点）。`I` 是吸管：点图上的一点取它的颜色（样式面板上也有按钮）；面板最右边的按钮恢复默认样式。
  - **完成**：`Enter`（或“复制”）把改好的图复制，作为一条新历史，原来那条不动，新的也能再编辑；一处没改就直接按 `Enter` 只是把原来那条再复制一次、移到最前，不多出一条。`Ctrl+S` 保存，`F3` 贴图，“取消”或关窗口不留任何改动。从贴图进来时 `Enter` 是“完成”，直接换掉那张贴图里的图，位置和大小不变，之后还能再点“编辑”接着改。
  - **Esc**：有改动时放弃全部改动（边上写着“Ctrl+Z 恢复”），再按一次关闭窗口。
- **贴图**：工具条上的“贴图”或 `F3`：截图留在屏幕原处，1:1 不缩放，一直在最上面。按住拖动；滚轮以鼠标处为中心缩放（10%–800%，100% 内外每一格 10%），双击回到 100%（设置 › 插件 › 截图 里的“双击贴图”可改成关闭、收起或不做什么）；`+` / `-` 键同样缩放；拖四个角之一自由缩放（比例不变）；方向键挪 1 个像素，`Shift`+方向键挪 10 个；`Ctrl`+滚轮调透明度。`Ctrl+C` 复制，`Ctrl+S` 存到“屏幕截图”，`Esc` 关掉。
  - **转和翻**：`R` 向右转 90°，`Shift+R` 向左转，`H` 左右翻转，`V` 上下翻转（也在右键 › 旋转与翻转里）；转的时候以图的中心为准，转四次回到原样、一个像素不差。转过、翻过的图不能再用原来的标注编辑，只当一张普通图。
  - **收起**：`空格` 或鼠标中键把贴图收成一块小缩略图（右键 › 收起 › 收成小块）；右键 › 收起 › 收到屏幕顶边是收成屏幕顶边（那块屏的工作区上沿）的一个小条，几张挨着排开。点一下就展开，位置、大小、像素都和收起前一样（拖过小块的话，展开在小块去的地方）。收起时只留图的 PNG 字节和缩略图，原来的大位图放掉，所以贴很多张又用不着时可以收起来省内存。
  - **选字复制**：`T`（或右键 › 选择文字）先把图里的字读出来（要有文字识别模型，贴图上方左下角有提示），然后在图上拖：碰到的整行字被框出来，松开鼠标就复制成文字（拖到一行的一部分，只取那一部分）；`Esc` 退出这个模式。
  - **一起管**：右键 › 关闭其他（只留这一张）、全部贴图 › 隐藏 / 显示全部贴图、全部置顶、关闭全部贴图。托盘菜单 **截图** 里也有隐藏 / 显示、全部置顶、关闭全部。新贴一张图时，隐藏着的会一起回来。设置里可以各录一个快捷键：“隐藏 / 显示全部贴图的快捷键”和“找回穿透贴图的快捷键”（默认都没有）。
  - **穿透**：右键还有另存为、识别文字、置顶、鼠标穿透（点击会穿过它落到后面的窗口）。穿透的贴图把光标放上去**按住 `Ctrl`** 就又能操作：拖动、右键菜单（里面可以取消穿透），松开 `Ctrl` 又穿透（边框会变深一点，表示现在能操作；`Ctrl`+滚轮仍是调透明度，要缩放先取消穿透）。也可以从托盘菜单 **截图 › 取消所有贴图的穿透** 或设好的“找回穿透贴图的快捷键”一次全部恢复；托盘的“截图”里还有“贴上最近一次截图”。
- **识别文字**：工具条上的“识别文字”或贴图右键菜单：图里的文字显示在旁边的小窗口里，可以选中、修改；“复制全部”放进剪贴板，“用它搜索”把选中的文字（没选就是全部）放进 Win顺 的搜索框，“网页搜索”用同样的文字在网页搜索列表里排第一的网站上搜（设置里的“网页搜索”，默认百度，调整顺序就换了）。需要 Win顺 文件夹里的 `ocr` 文件夹（文字识别模型），没有时按钮是灰的。
- **长截图**：比屏幕还长的网页、聊天记录、文档、文件列表，选好区域后按 `Ctrl+L` 或点工具条上的“长截图”，Win顺 一边滚动一边截，拼成一张长图。选区就是要滚动的那一块，比如浏览器里网页的部分；不拖选区时，按 `Ctrl+L` 用的是鼠标下框出来的那块。已经有标注时不能开始（先完成或放弃标注）。
  - 开始后遮罩消失，选区外面一圈细框，旁边一个小面板：拼好的缩略图、现在多高、“自动滚动”开关、“完成”“取消”和“复制诊断信息”。框和面板都不会被拍进去；焦点还在原来的程序上。
  - **自动滚动**（开关默认关）：需要时手动开启，Win顺 自己往下滚，每次滚大约半屏，等画面停稳再拍下一张；滚到底、或到上限（3 万像素高）就停，不用按键。它不挪你的鼠标；一种办法滚不动就换下一种，都不行时提示“自动滚动不起作用，请自己滚动”。
  - **自己滚**（默认）：用滚轮往下滚，滚完按 `Enter` 或点“完成”；`Esc` 或“取消”放弃。自动滚动开关在本次运行中沿用用户上次的选择，Win顺 重启后恢复关闭。截图的快捷键这时也等于“完成”。这两个键只在长截图进行中归 Win顺，结束就还给原来的程序。
  - 吸在顶上的标题栏只在最上面留一份，吸在底部的栏和“回到顶部”这类浮动按钮只在最下面留一份；往回滚的部分不会重复加进去。面板显示“跟丢了”时往回滚一点，接上刚才的地方；实在接不上的一小段会按滚动速度推测着接上，面板上的高度后面写着“有一段是推测着接上的”。
  - **以管理员身份运行的程序**：Win顺 替它滚不了，面板提示“这个程序以管理员身份运行，请手动滚动，滚完点‘完成’”。这时 `Enter` 和 `Esc` 会被那个程序收到（Windows 的规定），所以要点“完成”或“取消”。
  - 截完的长图直接在编辑窗口里打开：`Enter` 复制、`Ctrl+S` 保存、`F3` 贴图，也能标注、裁剪、打码。
  - 拼得不对时点面板上的“复制诊断信息”，把文字贴到 issue 里；设置 › 高级 里导出的诊断包也带着这些记录。里面只有滚动办法、位移、分数这些数字和程序的名字（比如 msedge.exe），没有画面、没有窗口标题。
  - 不太适合的：只能左右滚的内容、一直在动的画面（视频、动画）；一些老程序（没有为高分辨率屏幕适配、又是平滑滚动的列表），一行行长得一样时可能拼错，这时关掉自动滚动、自己慢慢滚好一些。
- **工具条上的按钮**：在 **设置 › 插件 › 截图** 卡片的“工具条上的按钮”里点一下显示或隐藏撤销、重做、长截图、延时、二维码、识别文字、贴图、保存、取消、复制（就是工具条上从左到右的顺序），默认全显示；标注工具一直显示。隐藏的按钮快捷键照样能用（撤销 `Ctrl+Z`、重做 `Ctrl+Y`、复制 `Enter`、保存 `Ctrl+S`、贴图 `F3`、长截图 `Ctrl+L`、二维码 `Q`、延时 `D`、取消 `Esc`），识别文字没有快捷键，隐藏后可以设给鼠标键。编辑窗口的工具条不受这个设置影响。
- 想选好就走，打开“选好就复制”：松开鼠标或点一下窗口就复制并关闭。
- **复制并贴图**：打开“复制截图时同时贴图”，按 Enter、点复制或用鼠标动作复制时，会同时把图贴在屏幕上；和“选好就复制”一起开，框选松手就能完成两件事。只想偶尔用，可以单独给鼠标键设置“复制并贴图”。标注仍保留，截图历史只记录一次。
- **框选之后的鼠标操作**：区域选好后，鼠标的几个键各做什么，在 **设置 › 插件 › 截图** 卡片的“框选后的鼠标操作”里分别选：**双击左键**（默认复制并关闭）、**右键**（默认后退，回到重新框选）、**中键**、**侧键（后退）**、**侧键（前进）**（这三个默认什么都不做）。可选的有：复制并关闭、复制并贴图、保存、贴图、识别文字、识别文字并复制（读出图里的字放进剪贴板，右下角提示一下）、识别文字并搜索（字送进 Win顺 的搜索框）、识别文字并网页搜索（字拿去网页搜索列表里排第一的网站搜）、取消截图、无；右键还多一个“后退（重新框选）”。正在标注（选了标注工具、正在画或写字）时，右键用来撤回当前这一笔，其他键不动作，不走这里的设置；`Esc` 随时可以后退。
- **移动截图工具条**：按住工具条最左侧的竖向三个圆点拖动，工具条和样式面板一起移动，保持在当前屏幕内。本次截图中调整选区、按 `H` 隐藏再显示都会保留位置；重新框选后恢复自动摆放。
- **截图历史**：在搜索框里打 `jt` 加空格，列出截过的图（最新的在上面），每行有缩略图、时间、大小和图里识别出的文字开头；接着打字就按图里的文字筛选，拼音也行（`jt hy` 找有“会议”的截图）。`Enter` 复制并粘贴回原来的窗口，`Ctrl+Enter` 贴到屏幕，`Alt+P` 预览，`Delete` 从历史删除（`Ctrl+Z` 撤销）。截图历史就是剪贴板历史里的截图，在剪贴板窗口里这些图片带个“截图”小标签。关键词可以在“截图”卡片上改；截图关着时 `jt` 不起作用。
- **最近截图快捷键**：在截图卡片的“贴图”分类里录制“贴上最近一次截图的快捷键”。把最近截过的图贴回原位置，保留标注。默认不设，仍可从托盘菜单操作。
- **保存文件夹**：截图卡片的“截图”分类可选择截图保存目录，截图、编辑窗口和贴图的快速保存共用。点“使用系统默认”恢复系统“屏幕截图”文件夹；“另存为”仍可临时选择其他位置。
- **区域录屏**：截图后框选区域，点工具条“录屏”或按 `Ctrl+R`。可选择系统声音、麦克风、是否录入鼠标指针；声音默认关闭。可开启“点击高亮”（默认关）：主键显示橙色圈，次键显示紫色圈，半秒内淡出；暂停、选区外和控制条上的点击不显示。画质分为“小体积”（15 帧/秒，保留原尺寸，适合文字和简单操作）、“标准画质”（默认，30 帧/秒）和“更清晰”（30 帧/秒，文件可能更大）。点“开始录制”，默认三秒倒计时；可关闭倒计时，或在倒计时中点“立即开始”。录制中控制条收小，可暂停、继续；点“停止并保存”或再次按截图快捷键结束，自动保存 MP4。控制条不录入视频。保存后可播放、复制文件、打开文件夹，或点“再录一段”沿用选区继续录，前一段文件会保留。录屏目录可在开始前更改，默认是系统“视频”里的 WinShun 文件夹。用于短时操作演示，暂不提供剪辑、摄像头或视频历史。
- **GIF 录制**：准备面板切换到“GIF 动图”。小体积、标准、更清晰分别为 10 / 15 / 20 帧每秒，最长边 960 / 1280 / 1920 像素，小选区不放大。GIF 不含音频，会自动循环；停止后后台生成并显示进度。转换失败会保留原始 MP4 并给出位置。
- **贴到屏幕**：启动器里图片文件（png、jpg、bmp、gif、webp）的右键菜单，和剪贴板历史里图片的右键菜单，都有“贴到屏幕”：图贴在鼠标旁边，和截图的贴图一样用。截图关着时也能用；关掉“截图”会把所有贴图一起关掉。
- 关掉“截图”后它不占内存，也不占快捷键。接管了 `PrtScn` 时如果 Win顺 没在运行，按 `PrtScn` 会像以前那样把整个屏幕复制到剪贴板；关掉这一项就恢复原来的设置。

## 任务栏搜索框

在 **设置 › 打开 Win顺 › 任务栏** 的“任务栏上的 Win顺”里三选一：**搜索框**（Win顺 自己的搜索框，Windows 11）、**固定图标**（固定在任务栏上的 Win顺 图标）、**关闭**。Windows 10 只能固定图标。点它，结果在任务栏上方淡入淡出。

- **位置**：搜索框的位置是固定的，不跟着图标挪。任务栏图标居中时在最左边（左边有小组件按钮就在它右边），图标靠左时在托盘图标左边。打开、关闭程序时它不动，只有托盘变宽这类少见的情况才换个位置。
- **样式**：和 Windows 搜索一样三选一：搜索框、图标和标签、仅图标（像任务栏上的一个按钮）。在“搜索框样式”里选。任务栏挤了会自动换成更窄的样式，连图标都放不下就先不显示。
- StartAllBack / ExplorerPatcher 启用经典任务栏时规则一样。
- **固定图标**：选它时 Windows 会问要不要固定，选“是”；没看到提示，再点一次“固定图标”。改回搜索框或关闭时，Win顺 没法替你取消固定：右键任务栏上的 Win顺 图标，选“从任务栏取消固定”。
- 搜索框可以单独使用，也可以与 Windows 搜索并存；是否隐藏 Windows 搜索、接管 `Win+S` 或开始菜单打字，都按需选择。

## 给 AI 助手用（MCP）

Win顺 可以当作 MCP 服务器，让 AI 助手（Claude Desktop、Claude Code、Cursor、VS Code 等）用它搜文件名、文件内容和最近修改的文件。

- 在设置里一键连接这些客户端。
- 默认只读，只看得到 AI 客户端本来就有权限看的文件。
- 可以设置不让 AI 看到的文件夹；每次调用都有记录。
- 打开“允许 AI 读取剪贴板历史”后，AI 也能拿到 Win顺 截过的图（识别出的文字和图片文件，截图开着时）。
- “允许 AI 修改设置”默认是“每次先问我”：AI 能帮你开关功能、调整参数，改之前弹出一个窗口，写明谁要改什么、为什么，你点“允许”才改；改完屏幕右下角会告诉你，几秒内点“撤销”能改回去。选“直接修改”就不再先问，仍会事后告诉你；开机自启、索引方式、网站搜索这几项涉及安全，不管怎么选都会先问你。对 AI 说“帮我设置 Win顺”，它会先问你几个问题再动手。
- “允许 AI 请求截屏”默认关着。打开后 AI 每次要截屏，屏幕上都会弹出一个确认窗口，写明是哪个 AI 客户端、截哪块屏幕；你点“允许”才截，点“拒绝”或 30 秒不理就不截。截下的图只交给它，不进剪贴板历史，确认窗口自己也不会被截进去。

## 外观、设置和备份

- **外观**：浅色、深色跟随系统。**圆角**可以改成直角，窗口、菜单、按钮和输入框都不带圆角，和 Windows 10 一样。**界面大小**有紧凑、标准、宽松三档。托盘和任务栏的图标可以换成单色。
- **找设置**：设置窗口里按 `Ctrl+F` 搜索，`kjj` 就能找到“快捷键”。改了立即生效。
- **文件管理器**：打开文件夹、打开所在位置时用哪个，在 **设置 › 打开 Win顺 › 对话框** 里选：资源管理器、Total Commander、Directory Opus、XYplorer、Pulse、OneCommander（装了的才列出；便携版先运行一次），或者选“其他（自定义）”，填别的文件管理器打开文件夹和显示文件的命令（`{path}` 会换成路径）。用自定义的文件管理器时，`Ctrl+G` 和对话框的建议只认上面六个。OneCommander 的公开接口只提供活动面板的路径，不列出后台标签；打开文件所在位置时，每个文件夹选中一个文件，多个文件夹分别开标签；文件夹的所在位置只打开上一级，不选中。
- **索引位置**：设置 › 高级 › 索引位置，可以把索引挪到其他硬盘。
- **备份**：设置 › 高级里选一个文件夹（放在网盘的同步文件夹里就等于云备份）。设置、收藏、对话框的固定项、自己加的网页图标和插件会自动备份，保留最近 10 份，随时恢复。
- **换电脑**：旧电脑打开 **设置 › 高级 › 备份 › 导出设置**，点“导出备份…”保存 ZIP，不用先开启自动备份。把 ZIP 带到新电脑，安装 Win顺 后点“从备份恢复…”选择它，校验通过后程序会自动重启。快捷键、外观、网页搜索、收藏和插件设置等一起带过去；新电脑的自动备份位置、索引位置和磁盘选择沿用本机设置。收藏、搜索目录和自定义命令里的路径仍按原样保留，请检查新电脑上是否存在；插件密码和 API 密钥存在 Windows 凭据管理器里，需重新填写。索引、剪贴板和搜索历史不迁移。恢复前会在本机数据文件夹的 `backups` 中保存当前配置（设置 › 高级 › 数据文件夹可打开），写入失败时尝试退回原配置；具体错误在备份区域显示。
- **拾穗计划**：设置里的一页，列出作者的其他作品；页脚感谢收录推荐 Win顺 的网站（目前是果核剥壳）。程序不会为此联网。
- **更新**：有新版本时托盘会提醒。在提醒窗口里点“下载并安装”（便携版是“下载并更新”），Win顺 会自己下载新版本、核对 SHA-256 后装好并重新打开；也可以照旧手动运行新的安装程序。设置和索引都保留。

## 常见问题

**双击 Ctrl 没反应？**
看托盘里有没有 Win顺 的图标。Listary、PowerToys 的“查找鼠标”默认也用双击 Ctrl，关掉其中一边，或者在 Win顺 里改成双击 Alt 或 Shift、只认左 Ctrl 或右 Ctrl，或换成组合键。全屏玩游戏、鼠标被隐藏时，Win顺 默认不响应双击 Ctrl。

**刚装好，搜不到刚建的文件？**
新建、改名的文件马上就能搜到。如果一直搜不到，右键托盘图标选“重建索引”。

**内容搜索第一次很慢、磁盘一直在忙？**
内容索引默认关着，在 **内容** 范围搜索框下面那一行右端打开后，才会建；第一次建要把文件读一遍。安装版由索引服务直接从磁盘读文本文件，杀毒软件不用逐个检查，一般很快就好。便携版没装索引服务时一个个打开文件，杀毒软件（特别是 Windows Defender）会逐个检查，所以会慢一些、磁盘忙一阵；可以在 **设置 › 搜索范围 › 磁盘 › 索引方式** 里装上索引服务。建好之后只读改过的文件，就不忙了。

索引很慢或其他功能出问题时，到 **设置 › 高级 › 诊断日志** 点 **导出诊断日志**。界面上的字显示不对（比如变成别的字）时，先导出再重启：重启后就查不到原因了。程序会打开诊断文件夹，把其中的 `WinShun-diagnostics.zip` 发给开发者即可；设置里搜索“诊断”也能找到。安装版的目录是 `%LOCALAPPDATA%\WinShun\diagnostics`，便携版在程序旁的 `data\diagnostics`；用了自定义配置目录时跟随那个目录。

诊断包包含版本、系统和权限、磁盘类型、索引进度与耗时、直读及回退情况、慢读取和运行错误，以及界面显示和字体的状态（显卡、屏幕缩放、字体，和一次字是否画对的自检）、剪贴板按键转发统计；不包含设置文件、剪贴板内容、搜索历史、AI/插件对话或文档正文。剪贴板搜索失效时，关闭面板后尽快导出即可；按键转发只记录安装/刷新错误码、转发与放行次数及原因，不记录具体按键、搜索词或窗口标题。运行错误可能带文件路径。诊断记录每份最多 1 MB、最多保留 3 份；7 天未更新的诊断文件在启动、写入或导出时自动清理。导出包固定为同一文件名，每次覆盖上一份，不会不断积累。程序和索引服务原有的错误日志各保留当前与上一份，诊断导出对每份最多读取最近 1 MB。

**往管理员身份运行的程序里粘贴不进去？**
Windows 不让普通权限的程序往管理员程序里打字。这时 Win顺 会把内容复制好，提示你按 `Ctrl+V`。

**占多少内存？**
每 100 万个文件约 30 MB，用着的时候一般 120～140 MB；一分钟不用后，任务管理器里降到十几 MB。

**会上传数据吗？**
不会上传你的文件和索引。只在这些时候联网：检查新版本（连接 lcstp.com，可以关）；点“下载并安装”时经第三方镜像或 GitHub 下载安装包，下载后用 SHA-256 校验；第一次显示某个网站时取它的图标；打了网站关键词后取搜索建议；你自己打开“按意思找”并选了云服务时。

更多问题欢迎到 [Issues](https://github.com/LingCore/WinShun/issues) 或 [LINUX DO 的帖子](https://linux.do/t/topic/2996093) 里提。
