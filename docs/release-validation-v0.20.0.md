# Win顺 0.20.0 发布验证

2026-11-04，在 Windows 11 x64、Qt 6.12.0、MSVC 2022 Release 环境验证。发布程序与插件包来自干净的提交副本（`git archive`）：`<待填：发布源码提交 SHA>`，路径 `<待填>`。之后的提交只有本记录。

## 内容

本版是修复和体验打磨，在集成分支 `r20-int` 上合并各修复分支后统一验证：
- 截图设了保存目录后，保存按钮、`Ctrl+S` 直接存入，通知点击选中文件（#194，插件“reveal”效果）。
- 文件夹快捷菜单设置整理为总开关、触发方式、触发位置，可挑选菜单里的操作，每组至少留一项（#196、#200）。
- 剪贴板直接粘贴：按住修饰键的第二段计时、不再漏键、Win顺 真在前台时才暂停数字键（#195、#199）。
- 搜索栏 Logo 下半部分可点；“文件”“文件夹”范围不出现插件关键词提示行（#162、#173、#193）。

## 实机验证

在 r20-int 构建、暂存目录加临时配置下实测，没有动正在运行的 Win顺：
- **#199**：按住 Win+Alt 点 V，约 1.5 秒后松开，粘贴第 1 条；0.3 秒就松开不粘贴；点三下 V 粘贴第 3 条；Esc 不粘贴。
- **#162**：Logo 上、中、下共 12 个点以及右下角的 `WM_NCHITTEST` 全是 `HTCAPTION`；切到“文件”再回“全部”后不变；下半部分悬停时底色出现。
- **#193**：“全部”里有关键词提示行，“文件”里没有。
- **#194**：设了保存目录后 `Ctrl+S` 不弹框，直接存入。
- **#196 / #200**：设置页触发方式、触发位置、菜单里的操作各行都是“至少保留一项”；总开关关闭时变灰。
- **#195**：新版 `Ctrl+4`…`Ctrl+9` 没有漏键；日志确认“Win顺有激活窗口但不在前台”时数字键保持注册。0.19.0 上也没能复现原来的现象，所以这一项只证明新版行为正确，不证明原问题已修好。
