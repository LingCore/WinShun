## 功能与实际归档

- 真实翻译插件通过 JSON-RPC、隔离本地 HTTP 服务验证连续查询、取消、缓存、词典、服务预设及微软请求和响应格式。下载并核验已发布的 2.0.0 包，与最终 2.1.0 包对照，在旧请求延迟 1.2 秒的固定场景中，新查询耗时分别为 **1203 毫秒和 31 毫秒**。该数值衡量旧请求阻塞解除，不代表第三方服务的翻译延迟。
- 最终休息提醒归档通过手动暂停、退出、重新启动、仍处于暂停状态及恢复的真实协议检查。原有定时暂停由回归测试覆盖。
- 最终宿主与网页搜索 2.0.0 实际归档通过 27 项生产路径检查，覆盖安装、迁移、自定义站点、设置、建议请求，以及停用和卸载后的行为。建议服务使用本地隔离端点。
- 快捷键面板和剪贴板尺寸预览通过 40 项生产 QML 检查。设置完整页面、分组与搜索导航预览通过。结果组合预览保留 13 条已知模型替换绘制警告，分别来自空模型 `selectedCount` 与 `undefined` 图片路径，其三份行为报告均通过。
- 图片文字搜索使用最终插件、真实增强 OCR 组件及独立配置，识别一张销售额图表。索引含 1 个文件、1 页，查询“西南”得到 1 条命中，预览返回对应文字框，错误为空。预览启动时先在隔离 `ocr-search.ini` 写入样例目录，避免异步打开索引期间 `--folder` 被忙碌状态忽略。
- 截图工具条、MP4 和 GIF 使用真实插件及自建演示窗口。四个文件全部通过 FFmpeg 解码。两段 MP4 为 H.264、1600×920、30 fps，分别 94 帧和 22 帧。两段 GIF 为 1280×736，分别 47 帧和 11 帧，约 15 fps。暂停、继续、再录一段与保留前段文件由现有生产预览检查。
