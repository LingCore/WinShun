# Win顺 0.22.0 发布验证

2026-11-07，在 Windows 11 x64、Qt 6.12.0、MSVC 2022 Release 环境完成构建和相关验证。干净源码副本为 `67ddbab54bbfc33ea8c4c797cdbdd582a784dca7`，构建目录为 `build/release022`，交付文件在 `dist/release022`。后续提交更新海报、文档、验证证据和 Scoop 清单。

## 构建与相关回归

- 全新配置、编译主程序及 9 个官方可选插件，之后以干净提交增量构建修复。标准、离线安装器及主程序版本资源均为 `0.22.0`。
- 按本次改动选择 38 项 CTest。最终一轮 37 项通过，前台粘贴测试与字体截图同时运行时失败，结束截图后单独执行并连续三次通过。前台相关验证采用串行执行。完整结果保存在 [CTest 记录](validation/release022/ctest.xml) 和 [粘贴串行复测](validation/release022/ctest-paster-serial.xml)。
- 覆盖搜索、历史、窗口、设置、剪贴板、粘贴、面板导航、前台内存、字体、插件审核、插件宿主、翻译、休息提醒、LocalSend、OCR、更新器和 Scoop。保留原有生产路径断言，测试与截图使用隔离数据。
- 发布流程的 6 个模拟远端用例通过，覆盖成功、摘要错误、大小错误、目标提交错误、缺失附件和上传失败。这些用例的 GitHub 操作均由模拟替代，真实发布另行核对草稿与公开结果。[模拟结果](validation/release022/publish-flow-check.json)

## 本轮修正

- 插件审核探针的中文索引路径改用 `_wputenv_s`，同步 Windows 的宽字符 CRT 环境表，并检查 Qt 读回值。真实插件库卡片加载、首次安装与同权限更新确认均通过。
- 窗口测试准备阶段显式显示自有窗口并取得初始前台，随后断开输入队列连接，再测试生产窗口切换和最小化恢复。窗口测试连续三次通过。
- 截图插件的独立预览有同类中文路径问题。1.1.6 发布后，实测发现其 Qt 导入失败，因此保留该历史版本并补发 1.1.7。插件库最终指向已在中文宿主路径通过工具条拖动验证、零警告的 1.1.7。
- 中文 MSVC 暂存路径在本机触发 D8050，使用项目内同一目录的现有 8.3 短路径后构建通过。相关根因与适用范围记入 [踩坑记录](pitfalls.md)。

原图按 150% 或 200% 真实渲染，采用 D3D11 和临时配置。16 张功能海报及封面沿用品牌模板，1440×1440、JPEG 质量 96、关闭色度抽样。README 使用包含“关注我”的封面，功能海报按功能分组放在截图文档，以 `width="49%"` 两列排列。海报的不可变图片提交为 `51d1a60cf02b30509206116878c3d2e375b33e6d`。原图与无损海报保存在忽略的 `tools/screenshots/work/release022/`，来源哈希与导出信息已归档。[截图规格](validation/release022/screenshot-check.json)、[二进制来源](validation/release022/capture.json)
